# Abzu

> 当前版本：0.0.75 ｜ GPL-3.0-only ｜ 私有自用开发

Abzu 是长篇网文写作工作台，目标是支撑几百万字级别的长篇小说。它把开书设计、逐章写作、审读修改、定稿沉淀与断点恢复放进一条可暂停、可继续的生产线；作品以本地文件和 Git 历史保存，进度从文件推导，不依赖会话记忆。

产品范围只覆盖写书技巧本身：不接入读者数据，不做平台运营和商业节奏。

## 设计：三层金字塔

| 层 | 内容 | 在仓库里的位置 |
| --- | --- | --- |
| 第一层：工业化代码流程 | 书仓、章节状态机、文件门禁、事务与锁、作者审批、Git 提交；测试、CI 与发版 | `packages/core`、`packages/bundle/src`、`scripts/` |
| 第二层：专业写作方法论 | 判据件、参考标尺、雷点清单、审读与评审底本 | `packages/bundle/skills/*/references`、`agents` |
| 第三层：人类作家的心智与流程 | 嵌在各技能里的心智条目，以及作者在环的裁决流程 | `packages/bundle/skills/*/SKILL.md` |

## 开始使用

1. 安装 Abzu 桌面端。
2. 按技术文档"构建与安装"构建 tgz（产物名 `abzu-<version>.tgz`；桌面端"添加插件"也可输入 `abzu@<version>`），在侧栏"插件 → 添加插件"安装并应用变更。`<version>` 取本次发布的包版本：以根 `package.json` 与 `packages/bundle/package.json` 的 `version` 为准，不写死在本节。
3. 在设置里配置聊天模型与凭据，选择一个工作区，在主会话里说出构想。

模型服务由你配置，调用会产生费用。不承诺无人值守写完整本书；重要作品使用前请备份。

本仓库为私有自用项目，不设公开报告渠道。不要上传真实 API key、启动 token、私人作品或未脱敏的会话；凭据一旦暴露，先在服务提供方撤销或轮换。工作台服务只绑定本机回环地址，不要把服务和启动链接暴露到公网。模型提示词、运行时技能和外部文字都是待处理数据，不能作为绕过作者确认或文件访问边界的授权。
