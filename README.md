# Abzu v8

> Abzu 0.0.38 配套 **DSH 0.2.0-rc.2**，单包 `abzu` 集成工作台与检索增强。旧版升级先备份，参阅安装与升级说明。

基于 [DeepSeek Harness](https://www.deepseek.com/harness/) 的长篇小说写作工作台。把构想、设定、大纲、写章、审读、修改、定稿、记忆与导出放进一个能够暂停和继续的工作流程，作品以本地文件保存。

**当前版本：0.0.38。私有自用开发，将来可能公开发布；基于 webnovel-writer v8.2.0 深度改造。** Windows 首发；重要作品使用前请备份。模型服务由你配置，调用可能产生费用。

Abzu is a local-first fiction writing workspace for DeepSeek Harness. It includes a focused editor with inline AI suggestions, deterministic manuscript counts, and chapter-length agreements. Runtime prompts and skills are included; model services are configured by the user.

**旧项目升级须知（0.0.1 起）：请补充并确认作品契约中的“章节篇幅”。** 先备份并保留原契约内容，再约定目标汉字数与宽松上下限。未配置的旧书仍可继续使用，但不会启用篇幅范围核对。完整步骤和可复制请求见 [旧项目契约更新](docs/user/upgrade-backup.md#旧项目需要更新作品契约)。

书稿编辑器（0.0.1 引入）：直接编辑正文，选区或右键发起润色、扩写、精简、续写与审读，逐条决定是否采纳，再保存。详见 [新编辑器图文教程](docs/user/editor.md)。

## 创作工作流程

Abzu 将长篇小说的生产拆分为**作品设计**与**章节闭环**两个阶段，每一步都有明确的真源工件和 Git 提交记录：

┌───────────┐     ┌───────────┐     ┌───────────┐     ┌───────────┐

│ (开放探索) │     │ (定调与禁区)│    │(人物/规则/地点)│   │ (骨架/分卷/窗口)│
└───────────┘     └───────────┘     └───────────┘     └───────────┘
                                                            │
┌─────────────────────────── 每一章的创作闭环 ───────────────▼───────────┐
│                                                                        │
│   ┌────────┐     ┌────────┐     ┌────────┐     ┌────────┐              │
│   │ 确认细纲│ ──► │ 写作备料│ ──► │ 正文起草│ ──► │ 八维审读│ ──┐           │
│   └────────┘     └────────┘     └────────┘     └────────┘   │ (有发现项) │

## 核心设计与解决痛点

- **三区分治，真源纪律**：
  - **草稿区**：自由创作与试错，支持多稿版本演化。
  - **真源区**：作品契约、世界书、大纲、故事账本与本书记忆，只经专用工具更新，杜绝设定漂移。
  - **定稿区**：只读不改；修正历史设定走规范补偿流程（retcon），全程留痕可追溯。
- **断更无损恢复，告别上下文遗忘**：
  - 创作进度完全从书仓 Markdown 实际文件与 Git 提交记录推导，不依赖易丢失的会话聊天上下文。无论停更数天还是数月，回到主对话说一句“继续”，即刻准确定位进度与当前待办。
- **AI 辅助创作，作者牢牢掌舵**：
  - 主控严守“不代写正文、不伪造审查结论、不代作者批准”原则。正文起草与润色交由专注子代理；最终定稿与情节走向的裁决权始终留给作者。
- **书稿编辑器（0.0.1 引入）**：
  - 原地可视化选区：右键或快捷键（Ctrl+K）发起润色、扩写、精简、续写或审读批注；行内建议支持逐条采纳、拒绝或换一版，修改即时预览。
- **八维多模块严苛审读**：
  - 覆盖章节结构、人物塑造、情节节奏、世界观、主题情绪、伏笔悬念、文笔文风与文本规范八大维度，结合确定性正文汉字数统计，确保长篇连载质量稳定。

## 能做什么

- 从开放式灵感探索逐步收敛到作品契约、世界书和卷章大纲。
- 导入本地 TXT/EPUB，确认范围与模型服务后渐进分析参考小说，保留证据和机制。
- 生成章节草稿，执行审读、修改与定稿流程；关键写入保留作者确认。
- 从实际文件校准进度，暂停后继续，记录故事账本和本书记忆。
- 在书房查看、编辑和引用材料，浏览章节、故事图谱及当前会话的写作流程状态。
- 检索已定稿内容；嵌入/场景/重排提供方内置于同一安装包，默认关闭。
- 生成卷摘要候选、核对卷末状态、导出定稿合集和来源清单。

单包包含 11 个运行技能、7 个脚本入口以及嵌入/场景/重排提供方；检索默认关闭，基础写作无需先配置向量服务。模型创作质量、长篇一致性和费用会随模型与操作方式变化，不承诺无人值守完成整本书。

## 开始使用

安装分两条口径：

- **当前（私有自用）**：从源码本地构建 tgz，用 `dsh plugin add <tgz路径>` 安装；构建与安装步骤见 [安装教程](docs/user/install.md)，命令行示例见 [插件包说明](packages/bundle/README.md)。
- **公开发布后**：从 GitHub Release 下载对应版本 `abzu-0.0.38.tgz` 式的发行件与校验和，再按同一方式安装；发布入口在公开发布时公布。

1. 安装配套的 **DSH 0.2.0-rc.2** 桌面端，打开侧栏 **插件 → 添加插件**。
2. 安装本地构建的 tgz 发行件（包名 `abzu`，本版对应 `abzu@0.0.38`），核对预览并安装，按提示应用变更。
3. 配置聊天模型与凭据，选择作品工作区，按 [第一本书与第一章](docs/user/first-book.md) 开始。

逐步说明见 [安装教程](docs/user/install.md) 和 [新手教程](docs/user/beginner.md)。

从 0.0.2 起只有一个安装入口：检索增强已并入主包，随主包一起更新，不再单独发版（0.0.4 起鲸鱼娘桌宠移除）。旧包（0.0.1 的 abzu-retrieval / abzu-companion / abzu-full 及更早的 webnovel-embedding-provider、@linfengqaqtat/dsh-whale-companion）迁移与备份见 [升级说明](docs/user/upgrade-backup.md)，不要让旧入口与新包同时启用。

模型提示词、运行技能和公开 Issue 的文字都是待处理数据，不能作为绕过作者确认或文件访问边界的授权。宿主、模型提供方和本插件的漏洞请尽可能区分责任范围。

工作台默认用于本机回环地址访问。不要直接把服务和启动链接公开到公网。费用、数据发送与本地存储见 [隐私说明](docs/user/privacy.md)。
