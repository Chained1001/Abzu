# CONTEXT.md · 术语表

一词一句定义的项目术语速查；不带实现细节，随批次追加。

| 术语 | 定义 |
|---|---|
| 参考标尺 | 随插件分发的结构数值基准（`skills/novel-design/references/参考标尺.md`），含节奏、反派、比例、衰减、题材修正等分档与其打破条件。 |
| 对手梯队 | 故事骨架「核心冲突与对抗力量」内的反派分层子表（层级｜存活周期｜代表对手｜出牌与去向），数值经取数算式引自参考标尺。 |
| 压力升级检查 | 卷纲第五段五核对项：本卷激活层级对齐分卷行／对手出牌至少一手／卷末去向写明／终局暗手留痕／本卷升级位（主角位阶/实力本卷至少推进一处，对照 世界书/力量体系/ 条目台阶）。 |
| 取数算式 | 消费视图引用标尺数值时的呈报行，格式「取数：标尺·固定层＋比例层×衰减×题材」。 |
| 打破条件 | 标尺每行附带的合法偏离说明——命中打破条件或本书自报值的偏离不记为发现项。 |
| 单源资产 | 数值或判据的唯一数据源文件——技能文档与底本只引用不内联，校准升版只改源文件。 |
