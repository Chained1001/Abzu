# 拆书扫描工任务书

## 读什么

只读三样：①原文行号段（批次单给绝对路径＋L起-L止，非连续章按多段行号）②handoff_cache（上一批缓存文件，只读其 `### 跨批状态` 节）③本任务书自带的行格式与打分锚点。禁读其他批次缓存、拆书产物、项目其他目录；改文件仅限被拒批次自己的缓存（Edit 定点改）。

## 写什么

写 `参考作品/{书名}/_teardown_cache/{batch_id}.md`（全路径——批次单已给），固定四节＋末行标记，节标题逐字如下：

- `### 跨批状态`：五项——已确认别名｜未闭合剧情点｜悬念｜关系变化｜待核事项
- `### 逐章事实`：按模式产出（下表）
- `### 跨章观察`：本批内模式性发现（节奏交替/关系动向/伏笔候选词＋章号），只写本批可见，不外推全书；批次单列出高潮候选章时，对候选章加一行 `- 信号|{N}|{前5章贬损:有/无}|{当众场景词:有/无}|{旁观反应段数}`
- `### 自查`：Grep count 对照计数判据，缺行就地 Edit 补齐再回执
- 末行必写：`<!-- teardown:cache-end:{batch_id} -->`

### 四模式行格式

| 模式 | 每章产出 | 行格式 |
|---|---|---|
| 轻扫 | 索引行×1＋要点行×≥min_要点数 | 索引行（无 `- ` 前缀）`第{N}章\|{章名}\|摘要\|{50-100字白描}\|人物\|{逗号分隔}\|位置\|{位置:原文L起-L止}`——N＝全局章序（批次单已给，勿写章题原文编号）；位置段值照批次单该章行号段写。可选尾段 `\|标签\|{七类}`（批次单附判据行时才产）；要点行 `- 要点\|{N}\|{k}\|{≤25字事实}`（N 同为全局章序；同章小事件合并，不逐句拆）。可选行（批次单注明才产，计数自查不计）：窄谱书每章 `- 计数\|{N}\|{句数}\|{八字内句数}\|{叹号数}\|{引号内字符数}\|{分隔行数}`；钩级采集每章 `- 钩级\|{N}\|{锐/钝/平}\|{末3句短引≤60字或形态自述}` |
| 深读 | 深卡×1：头行 `#### 第{N}章 深卡`＋11 字段行 | `- 六步\|{情绪事件/欲望目标/阻碍/解决/行动高潮/结局反馈}\|{≤20字}`×6；`- 钩子\|{章首/章末}\|{≤20字}`×2；`- 打分\|剧情{1-5}·情绪{类型}{1-5}·描写{1-3}`×1（各附≤15字理由）；`- 证据\|{章}·{短定位词}`×1；`- 深卡\|{200-400字白描}`×1 |
| 分卷 | 事实卡×1：头行 `#### 第{N}章 事实卡`＋14 字段行 | 每字段一行 `- {字段}\|{值}`，字段依次：章｜一句话(50-100字)｜场景与时间｜参与人物｜目标-阻碍-结果｜状态变化｜新增信息｜隐藏信息｜剧情强度1-5(≤15字理由)｜情绪(类型/1-5＋理由)｜描写密度1-3(＋理由)｜章首钩(≤20字)｜章末钩(≤20字)｜证据(章·短定位词) |
| 追踪 | 对象卡×1：头行 `#### {对象ID}·{弧线卡\|链条卡\|演变卡}` | `- 观察\|{章}\|{≤40字白描}`（每相关章≥1）；`- 结论\|{一句话}`、`- 证据\|{章}·{短定位词}`、`- 置信度\|A/B/C` 各×1；缓存按对象分文件（`追踪-{对象ID}-批{N}.md`） |

计数自查：轻扫＝索引行数==章数且要点行≥章数×min_要点数；深读＝字段行数==章数×11；分卷＝字段行数==章数×14；追踪＝观察行≥相关章数且结论/证据/置信度行各==对象数。可选尾段与可选行（计数/钩级/信号）一律不计入判据。

## 打分锚点

剧情强度：1 日常衔接移动／2 小障碍小线索／3 明确进展重要发现／4 重大损失身份暴露／5 核心真相不可逆抉择。情绪：先标类型（好奇/紧张/恐惧/兴奋/甜蜜/悲伤/愤怒/震惊/释然/厌恶/感动）再打 1-5，与剧情强度可分离（安静告别＝事件 2 情绪 5）。描写密度：1 概述跳时／2 常规场景／3 细节心理充分展开。三维分开标，每分附≤15字理由，分数不代替解释。

## 提取铁律

1. 客观白描：写发生的事实，不写解读（写"Y 告诉X…"，禁"通过对话，X 得知…"）
2. 新增信息（读者新知）与隐藏信息（读者知角色不知）分开标，不混
3. 摘要、深卡不超模式字数上限，必须自己转述——整段照抄原文＝没提炼，产物无用；证据记章号＋短定位词（引原文短句可选）
4. 只写本批可见；跨批疑点进"待核事项"，不写成结论
5. 缺失写"原文未明确"，不编造填空
6. 不评价好坏、不做全书推断、不停摆——敏感片段只跳过并在缓存标注，绝不拒整批

## 回什么

写完缓存文件，回执一行：`BATCH_WRITTEN {batch_id}`。不输出原文内容、不复述产物、不写任何解释（派发通道只取末行，解释性文字会被丢弃——自查叙述写进缓存自查节）。回执后立即结束，不等候、不追问。
