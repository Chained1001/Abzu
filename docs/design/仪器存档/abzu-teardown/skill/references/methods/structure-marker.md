# 结构标记识别

## 卷末三件套

判据：卷末章须同时命中——主线矛盾当面兑现＋至少一场告别/离场戏＋钝钩定格收束；宽谱书另验"章长≥卷中位 2 倍"。

操作：结构审计的 isVolEnd 只标"(本卷终)"标记章——网发版常缺，卷末定位主路径靠钝钩：轻扫批次单注明钩级采集时扫描工产钩级行（钝/平即候选，行格式见 agents/teardown-scanner.md）；合成时把钝钩候选章与前后章摘要连读，兑现主矛盾＋含告别戏者定为卷末，写进骨架三幕映射与分卷统计。

命中信号：识别顺序——先找钝钩章→回看是否兑现当卷主矛盾→两侧验证告别戏与章长倍率；双钝钩形态（定格句＋编年体）是卷级以上收束标志；宽谱书卷末倍率 2-3.5 倍区间、窄谱书约 1.2 倍量级（长度信号失效、三件套仍成立）。

不可靠：章长倍率只在宽谱书可靠，窄谱书完全依赖文本信号；钝钩也出现在单元高潮（诈尸式反转后定格），用"是否兑现卷级主矛盾"区分卷末与单元末；"下章预告式"结尾是衔接钩（方向朝前不朝上）不是卷末信号；只认"第一部完"标记会漏（网发版常缺、前几卷可无标记）。

## 换图四信号

判据：换图章＝新专名密度突增＋旧班底词频断崖＋身份/目标重置句＋一件从旧图带走的锚物，四中三即判。

操作：按人物总表跑首现章序列——任意 5 章窗口内≥3 个存活 50 章以上的新命名人物入场，标候选换图章；再取窗口前后各 20 章做旧班底人名词频对比，降幅>60% 确认；换图章写进骨架阵型结构（"全书换图 N 次，约每 X 章一换"）。

命中信号：跨地域型——首 300 字内新专名 3 个以上（新城市/新地理/新交通工具级）、旧班底仅一句告别桥、身份重置句（着装/姿态/自我定位显性变化）、锚物一件（承载性格/执念的随身旧物）；跨案件型——5 章内新命名主要人物 3 个入场＋旧案词词频进入衰减尾。

不可靠：支线换场也有新专名小峰，但旧班底不断崖、主角目标不重置——四中三的门槛就是滤它；锚物信号只在跨地域换图有效；历史书地名本密集，限定"叙事目的地"级专名（主城级，非每次行军）；不换城但换案件班底的书只盯地名会漏。

## 起飞点定位

判据：激励事件之后看三要素同章命中——计划句＋主动动作＋跨界优势首次使用，该章即故事正式起飞点。

操作：深读首 3 章时在批次缓存跨章观察节单列"起飞点"一行（章号＋计划句短引＋跨界优势首用动作——跨章观察节格式见 agents/teardown-scanner.md）；骨架三幕映射的"第一扇门"用该章号，不用激励事件章号。

命中信号：主角从"承受反应"翻转为"发起行动"，且行动的武器是外来优势（前世知识/推理/方术/史识）；四型——计划句＋主动索取关键资源（要卷宗/查档式）、主动重做一次前人的仪式做验证、群像死局中首次用观察推理主导发言、重生者首次用前世知识组班底。

不可靠：起飞点≠金手指获得章（装备/身份获得在后，起飞在首次主动验证）；激励事件常在第 1 章（穿越/夺舍/异变式开局）无区分度，当起飞点记会把第一幕边界推前 2-5 章；群像死局书主角台词可为零，"主动"看推理内容是否被众人采纳而非说话量；历史文的"优势"是史识不是系统，别找系统面板。

## 场景汇聚信号

判据：场景分隔密度（"……"分隔行）≥本书日常基线 3 倍＝事件汇聚章（卷级高潮前夜或高潮本体）。

操作：轻扫批次单注明时，扫描工在计数行报分隔行数（按抽样确定的本书分隔约定——计数行格式见 agents/teardown-scanner.md）；聚合时算全书基线均值，输出密度≥3 倍的章列表；对候选章读摘要验证"多源共指"，通过者标"事件汇聚章"，供深读选章加权与 Stage 3 卷内高潮定位。

命中信号：各场景（宫廷/官署/驿路/私宅等十余段）通过信使、纸条、流言传递同一条消息，最终全部指向同一中心事件——多源共指是本质，分隔密度只是外显；铺垫坡尾章分隔密度已开始爬升。

不可靠：蒙太奇≠汇聚——日常章也有 4-7 次分隔但无共同指向，须同验"≥3 个场景传同一条消息"；分隔符形态随书而变（……/空行/"同一时间"时间词起段），先抽样 10 章确定本书约定再计数；绝对阈值（"分隔>10 次"）跨书无效，必须相对化；汇聚常是前夜不是高潮本体，与章长倍率/句构指标联判。

## 平台噪音剥离

判据：(上)(下)/(2合1)/作者注/求票语先剥再测节奏，否则 2 合 1 章会伪装成高潮信号。

操作：audit.mjs **只标记不剥除**——isNoise 标 2合1/作者注/求票括注章、isSplit 标 (上)(下) 分章（正常章计可用）、authorNotes 定位章尾作者注行；高潮块与收口跳点计算已排除噪音章，(上)(下) 章保留参与节奏统计。字数口径＝原始正文（作者注行计入 charCount——跨源对比时以 authorNoteLines 标注说明）；标题括注保留在章名（去重用完整标题）。含设定信息的考据注由深读转述入拆书笔记，不删。

命中信号：合并章（标题含"（2合1）"）章长可达卷内中位近 2 倍，不剥会被误判事件章；作者注（"s：明天三更""PS："式更新预告/碎念）混入章末会把钝钩误判平钩；标题求票尾缀（《××（第三更求月票）》式）污染章名不污染正文。

不可靠：只有"（上）（下）（2合1）"等结构性括注可自动剥，括号里的剧情词（书名号术语）绝不能剥；拿原始标题串做章名去重会把同一章因尾缀不同判成两章；2合1 章长直接进倍率计算会得出"此书高潮密集"假结论；把作者注当正文钩子分析必错。
