## 〇、原则与裁定

1. **补强不推翻（2026-10-09 总裁定）**：他是承重墙，我们是装修队——已验证的（流程步骤/工件体系/工具 schema/状态机/底本协议）一律不动；我们注入的是每一步**里面**的"怎么想得好"：判据、追问、纪律、候选生成法。改造对比显示：两套设计六成概念同想，他强在执行态（机器耦合），我们强在想得深（生成法/判据）——分工恰好互补。
2. **冻结面（第一年不动）**：`packages/core/src/derive`、`ledger`、`settlement`、全部工具 schema。注入走技能文本层＋references 资产＋零依赖脚本。
3. **参考标尺＝单源数值资产**：反派量化体系内含于标尺；骨架对手梯队/分卷层级行/卷纲压力升级检查＝三个消费视图，只取数不自造；校准只改标尺单文件。
4. **知识库＝单源判据资产**：KB v2.0.2（12 文件 8930 行 105 节，`网文写作知识库\09_方法论成书\知识库\`）按域分发进各技能 references/，**净版纪律**（见第二节）；引用一律节级（§x.y）且可测试。
5. **两套方法论分层共存**（见第三节）：他的管操作规程（机器耦合，动不得），我们的管创作判断（接线住进来）。
6. **批次与开书**：E1 立即 → 瘦身 E5′（KB 接线＋对谈纪律＋种子三百字）护航开第一本书 → 其余补强件（三评委/采风/十查/连写等）由**写作痛点驱动启用顺序**（作者可随时调整）——反对"车间综合症"：真实写作是最好的评估器。

## 二、知识库分发（v1.1 新增）

- **域随技能走**：01_开书/02_人物/03_世界/04_大纲/05_卷纲＋0A_原语层＋0B_节级索引 → `novel-design/references/`；06_章纲 → `novel-outline/references/`；07_正文写作 → `novel-drafting/references/`；08_修订排障 → `novel-director/references/`（§8.0 排障索引接状态校准律）。KB 全书形态留在源库，不在库内拆文件。
- **净版纪律（2026-10-09 裁定）**：分发层**只含归纳态方法论**——去除来源类型行、原话引用（改写为判据句式或删）、可信度分级、编者推断标注；保留判据正文/条件检查/分歧默认/排障索引/原语层；唯一元信息＝KB 版本戳。源库全保真（自用工作台）。
- **提取管线**：程序剥标注行（格式统一）→ 按"内容：原话"标记定位含引用节 → 引用改写或删 → 人工过一遍（首批 01-05，随 E5′ 批做）。KB 升版重分发走同一管线。
- **引用一致性测试**：技能引用的每个 §x.y 必须存在于分发件（skills.spec 新断言——三层咬合"宣称消费点反向核验"的 CI 落地）。
- **上下文纪律**：按节引用（§x.y），禁止整文件读入步骤；同一步骤不同时全量加载两套方法论。

## 三、两套方法论分工（v1.1 新增）

| | 他的（操作规程层） | 我们的（创作判断层） |

- **冲突裁决顺序**：他的机器耦合判据 ＞ 他的底本判据 ＞ 参考标尺（带打破条件） ＞ KB 判据 ＞ KB 原语推导。真冲突逐个裁定记入 KB 分歧登记。

## 六、横切纪律（v1.1 增补）

1. 黑名单五词禁用；B 源文本搬运改写
2. 取数防护四层（读单点名/算式呈报/视图三验证闸/断言）＋**数值单源铁律**（SKILL 与底本永不内联标尺数值）
3. **判据可执行性优先**：接线时优先选能落成检查项形态的判据（可呈报/可对账）；纯感悟型少放；冒烟验收验"判据被真实执行"不是"文档存在"
4. **成本可见性**：每批冒烟记录 token 用量；回归简报带用量行
5. **体感回灌回路**：卷末复盘踩坑 → `novel_record_memory`（类:决策）或 KB 项目反馈文件 → KB/标尺升版走既有通道
6. **书房备份**：差异档案/灵感池/种子底子不在任何版本库——备份纪律引用 upgrade-backup 指引
7. E1 与 E5′ 同改 novel-design/SKILL.md，串行合入
