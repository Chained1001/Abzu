## 〇、原则与裁定

1. **补强不推翻（2026-10-09 总裁定）**：他是承重墙，我们是装修队——已验证的（流程步骤/工件体系/工具 schema/状态机/底本协议）一律不动；我们注入的是每一步**里面**的"怎么想得好"：判据、追问、纪律、候选生成法。改造对比显示：两套设计六成概念同想，他强在执行态（机器耦合），我们强在想得深（生成法/判据）——分工恰好互补。
2. **冻结面（第一年不动）**：`packages/core/src/derive`、`ledger`、`settlement`、全部工具 schema。注入走技能文本层＋references 资产＋零依赖脚本。
3. **参考标尺＝单源数值资产**：反派量化体系内含于标尺；骨架对手梯队/分卷层级行/卷纲压力升级检查＝三个消费视图，只取数不自造；校准只改标尺单文件。
4. **知识库＝单源判据资产**：KB v2.0.2（12 文件 8930 行 105 节，`网文写作知识库\09_方法论成书\知识库\`）按域分发进各技能 references/，**净版纪律**（见第二节）；引用一律节级（§x.y）且可测试。
5. **两套方法论分层共存**（见第三节）：他的管操作规程（机器耦合，动不得），我们的管创作判断（接线住进来）。
6. **批次与开书**：E1 立即 → 瘦身 E5′（KB 接线＋对谈纪律＋种子三百字）护航开第一本书 → 其余补强件（三评委/采风/十查/连写等）由**写作痛点驱动启用顺序**（作者可随时调整）——反对"车间综合症"：真实写作是最好的评估器。

## 六、横切纪律（v1.1 增补）

1. 黑名单五词禁用；B 源文本搬运改写

4. **成本可见性**：每批（含沙盘/采集/调研）的子代理用量记录在**批报告与会话用量统计**（执行侧已天然产生）；产品内回归简报**不加**用量行——宿主不向技能暴露会话 token 计数，加了即是伪数据（2026-10-11 澄清）
5. **体感回灌回路**：卷末复盘踩坑 → `novel_record_memory`（类:决策）或 KB 项目反馈文件 → KB/标尺升版走既有通道
6. **书房备份**：差异档案/灵感池/种子底子不在任何版本库——备份纪律引用 upgrade-backup 指引
7. E1 与 E5′ 同改 novel-design/SKILL.md，串行合入
