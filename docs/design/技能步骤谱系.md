## 依据链说明

五类类型定义与各自的证据纪律：

- **骨架**＝Scriptor v8.2.0 原生件（上游同名文件逐字或在位）。证据纪律：与上游基线 diff 核对在位即归此类；上游件的方法论出处不追（那是上游的谱系，不是本 fork 的）；改动仅行文层（目录英文化/术语归一/标点）不改变骨架归属。
- **判据件**＝判据资产（知识库净版/参考标尺/雷点清单/采集零件/词表）挂接到步骤。证据纪律：出处必须落到具体分发批（0.0.6/0.0.7/0.0.9/0.0.13/0.0.14/0.0.15）＋资产的单源位置；KB 件走净版纪律（剥来源/可信度标注，唯一元信息＝版本戳）＋引用一致性测试（§x.y 逐一反查分发件标题，悬空节号测试红）；数值判据让渡参考标尺单源，SKILL 与底本永不内联数值。
- **心智件**＝作家思维模式注入（怎么接收信息/怎么想）。证据纪律：本类最严——必须有人类作家认知调研证据（2026-10-10 调研，顶格证据猫腻访谈）或作者明示指示，且口吻短句直白可照做；未经调研校准的感悟型表述不进本类（0.0.10 批未记依据的六件因此暂归流程件而非心智件）。
- **流程件**＝我们设计的步骤调整（新门/新通道/新呈报格式/重组）。证据纪律：出处落到具体批次＋其裁定或设计依据（蓝图批次卡/作者裁定日期/B 仓概念源）；概念跨仓引进的记「概念源出 B 仓 X 文档，行式自拟」——B 仓侧锚点已核（如 docs/design/draft/章0-章循环.md 之于心动位/语态样本）。
- **实测件**＝沙盘/审查发现驱动（先有证据后有规则）。证据纪律：出处必须带证据编号与实测数据——沙盘 F 编号（F1-F42，报告在写作测试 1-1 工作区 `_测试发现.md`）、成品反推带具体书证（作者自陈/样本统计）、审查批带实锤描述（0.0.20 七 bug 各带复现场景）；「先例发生→规则补档」是本类独有形态，无实测数据支撑的不得归此类。
