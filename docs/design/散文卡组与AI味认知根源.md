# 散文卡组与 AI 味认知根源（0.0.27 文笔专项批·设计侧）

> 定位：设计侧理论说明——回答「散文卡组为什么长这样、AI 味从哪来」。运行时分发件（packages/bundle/skills/novel-drafting/agents/写作卡.md 散文卡组节）只含判据句与 T 编号出处，本文内容不进运行时。理论档案＝外部工作区 theory-cards（仓库外，72 张，T001-T072）；五书补采脚本与数据＝外部工作区 test2-6/散文补采（仓库外）。

## 一、AI 味的认知根源：转述知识而非转化知识

AI 行文的「机器感」在写作认知研究里有对应的假说框架：知识陈述-知识转换模型（knowledge-telling vs knowledge-transforming，theory-cards T009）与写作知识构成双过程模型（theory-cards T010）。

- **T009（Bereiter／Scardamalia）**：知识陈述＝把记忆中已有内容按检索顺序直接铺陈；知识转换＝在内容问题空间与修辞问题空间之间来回改造内容，使其服务于当前表达目标。AI 味的典型面貌——信息按清单顺序倾倒、每句自足规整、不为主题重组——正是知识陈述的成品形态。
- **T010（Galbraith）**：显式规划重组已有观念，隐式文本生成在生成时合成新内容，两过程偏好不同条件且会冲突。人类作者的「散文感」很大部分来自隐式生成把观念落成句子时留下的局部形态（省略、倒装、节奏起伏）；语言模型同样逐句生成，但缺人类写作认知里「为修辞目标重组」的约束，于是每个局部都规整、整段是转述。
- **证据边界照录**：T009／T010 均为 provisional 状态（T009 核心原文未取得，T010 核心章未读）；两者的边界——不能从成品判定写作者用了哪种过程、知识转换不保证文本质量——照单保留。本节把它们用作 AI 味的理论定位（假说层），不是已验证的生成机制。T003（写作认知过程理论，mature）作背景：写作是计划／语言化／检查递归嵌套的过程，不是线性转写——散文卡组补的正是「语言化」层的判据。

## 二、散文卡组的理论定位

散文卡组不治「没内容」（推进卡的事）、不治「结构差」（细纲与卷纲的事）、不治「人物不像」（塑造卡的事）——它治「内容有了、结构对了、人物活了，句子读着像机器」这一层，对应知识转换模型里「为表达目标重组语言形态」的散文层环节。八卡分工与理论出处（0.0.27 建组七卡；0.0.30 修辞上探卡入组成八卡）：

| 卡 | 出处 | 治什么 |
|---|---|---|
| 句法节奏卡 | T015／T017／T022 | 长短句跟情绪走；标点即意义边界；无空格字流的回看成本 |
| 零回指卡 | T019 | 主语省略的合法条件——AI 过度重复主语＝机器感的核心 |
| 对白工学卡 | T020／T028／T021／T027 | 人物言语相对模式；引语标记可选；语气词分层 |
| 话题-述位卡 | T026 | 已知前置新置尾；首提整体呈现；段首话题锚定 |
| 前景化卡 | T014 | 打破常规处＝意义重点处；醒目相对本书常规判 |
| 中心切换卡 | T012 | 段内注意中心平滑转移；无声滑换＝读者回溯 |
| 连接词卡 | T030／T024 | 隐式关系优先；连接词跨度经济；段间靠宏观结构不靠串联词 |
| 修辞上探卡 | KB §7.6（0.0.30 正文域批入组） | 上探只砸高显著位；五感×修辞组合拳；通感迁移；陌生化搭配；顶真回环 |

消费方式（与场景八卡的差异）：散文判据跨场景通用，不走「场景功能」挑选，随任务包整组内联；与场景卡冲突时场景卡优先。

## 三、五书人类参照带（2026-10-12 轻量补采）

各书均匀抽 10 章（跳过头 3 章）机械层统计，作判据校准的参照带（提示级，不是阈值）：

| 指标 | 五书带 | 判据用途 |
|---|---|---|
| 句长标准差 | 16-46 字 | 句长均质化判据：人类方差大（约七成以上达均值级），AI 均质 |
| 相邻双代词起句（叙述句） | 0-0.7% | 主语重复判据：两连即为异常候选 |
| 显式连接词 | 2.9-6.3 处/千字 | 密度本身不作数；成串／成对全套才是候选 |
| ≤8 字短句占比 | 5.7-39.6% | 快节奏书的短句带（十日 39.6 最高） |
| 对白行占比 | 23-49.5% | 对白工学参照（十日 49.5 最高） |
| 感叹号 | 0.3-4.2 处/千字 | 书间差异大（诡秘 0.29-绍宋 4.18），只作单书对照 |

口径注：句界＝。！？；…；引号行不内切（诡秘诗句行并入一句，其句均值 56 略高估）；连接词表 16 词整章计（含对白）；叙述句＝非引号起句句；样本 10 章/书。

**对白占比章型子带**（1-4 卷01 全卷实测——单章 3.3-36.7% 章型波动谱，书级带对单章判定失配）：对白戏章 30-50%｜叙事章 10-25%｜独行章 3-10%——对白行占比的书级带 23-49.5% 只作书级参照，单章统计先分章型再对子带（独角戏/结算章贴书级带下缘属章型常态，按书级带直判必错报）。

**长句配额（句长谱长句端补位）**：示例口径单源＝「每章 ≥3 处 ≥40 字」（1-4 卷01 试运行参数——M27：批3 起作工作纪律，SD 批1 带下（3/5）、批2-3 入带（5/5、6/6），三批均值 15.3→17.1→18.3 单调上行）；novel-drafting SKILL 文风建档门句法层「长句配额行」引用同值——只压短句的单侧画像靠配额补长句端（参照带上表「句长标准差」行的长句端），仲裁句「画像优先、卡组兜底」下作长句端下限口径。
