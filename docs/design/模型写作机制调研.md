## 1. 指令遵从动力学

### 1.1 存量盘点

方向二已立 R4 覆盖倾向根因：SFT 示范满足全部列出要求、RLHF 奖励"无遗漏"，模型把任务包每要件平均用力（Padmakumar ICLR 2024 instruct vs base 因果对照——存量，强）——"多约束下注意力怎么分配"的根因已有。方向二另裁"不要写得像 AI"式指令无操作语义、不建议（存量）。方向一 §四 留了两道待验题：判据内联 vs 状态指令的效力差、给数字目标 vs 给判据目标对生成分布的影响——本文 §1、§3 增量部分回答。

### 1.2 增量调研

**多约束退化有量化基准。** FollowBench（ACL 2024）把约束分五类（Content／Situation／Style／Format／Example），从 L1 到 L5 逐级增一条，13 个开源闭源模型的全满足率（Hard Satisfaction Rate——全部约束同时满足）随约束数累积显著下滑，Format／Example 类最难。IFEval（25 类可机验单指令）作单约束基线。合看：单条指令遵从率本就不到 100%，多条同时在场时全满足率加速下滑。解读（需实测）：长生成＝模型在更长轨迹上持续维持遵从，退化斜率可能比英文短任务更陡。〔通用，英文短任务测得〕

**位置效应：首尾强、中部弱。** Lost in the Middle（TACL 2024）：相关信息置于上下文中部时，检索与利用显著劣于首尾（U 型曲线）；作者归因之一是指令调优数据习惯把关键信息放 prompt 首尾。Anthropic 官方长上下文指南（20k+ token 输入）：长文档放顶部、指令与判据放文档之后、引用/参照材料放 prompt 尾部效果更好。〔Claude 系实测为主；DeepSeek/GLM 的 U 型幅度需实测〕

**程序性指令 vs 特征描述指令：未找到直接对照实验。**【未找到实证，仅有间接证据与实践共识】间接三条：(a) Self-Refine 的增益依赖反馈可操作性——具体可改的动作优于泛泛评价（见 §4.2）；(b) 中文社区共识"命令 AI 写"而非"求 AI 写"，把抽象风格拆成场景/情感/细节三层可执行指令（见 §5.2）；(c) 仓内裁定同向：现行任务包状态句（"你是他"）已在《作家心智总分架构》删除句清单判死、操作核保留。

### 1.3 对心智设计的消费建议

1. **任务包总约束账**：心智条目 ≤8/阶段只计心智一件；FollowBench 管理的是"同时在场的全部约束"（硬约束＋选卡判据＋心智＋自查行）——组装侧应记总账，阈值经项目实测定（如 3/6/9 条对照批），不只盯心智单件预算。
2. **首尾双锚排位**：任务包件序＝必须持续在场的件（硬约束＋心智运行时形态）放首（首位强，现行"心智排第 0 件"一致，无需改）→一次性消费的语料（细纲/材料包）放中部→紧邻生成点的锚（语态样本＋落点自查行）放尾（近因强）；中部件的关键要求由尾部自查行回指一遍，对冲中部衰减。
3. **思维序列全部动词化**：每步＝可执行动作（读 X→对照 Y→判 Z→落 W）；特征描述词（"要像 X"）不进序列——需要特征时改为"查判据卡 X 单源"。

来源：arXiv:2310.20410；arXiv:2311.07911；arXiv:2307.03172；Anthropic Prompting best practices（URL 见来源清单）。

## 2. 风格锚定机制

### 2.1 存量盘点

方向二 R3 已立高频搭配先验根因＋提示词层"负例清单"干预（存量）；方向三已盘 r/WritingWithAI 预防型手法（感官锚点/声腔样本注入）与 NovelAI·ST 社区预设实践（存量）；文风画像＋近三章章摘要"语态样本："行机制已实装（《作家心智总分架构》R1，存量）。

### 2.2 增量调研

**示例牵引强于指令描述，但只锚显性层。** 工程共识：模型文风靠指令很难改变、靠示例能有效引导（Evan Armstrong《Few-Shot Examples Done Properly》）。学术侧三证：ChatGPT 对名作者风格可做到体裁级忠实、高于随机但有限（Ishihara 2026）；高保真风格模仿不等于高质量产出（How Well Do LLMs Imitate Human Writing Style?）；日常作者的隐性风格在 4 万+生成实验中仍模仿失败（Catch Me If You Can (Not Yet)）。分层结论：**显性统计特征**（句长分布/词频/口头禅/连接词习惯）可被上下文示例锚定；**隐性分布风格**（修辂数量的分布、着力分配、时机感）模仿不可靠——恰是仓内 T1/T2/T5 痕迹所在层。〔通用〕

**样本量级：未找到严格实证。**【实践共识】精选段落（数百至千字级）即可锚语态，全章注入无已证增益且挤占约束预算；样本宜选与本章场景功能同型的段落（打斗章锚打斗样本，防语态锚错型）。此项需项目实测定量。

**负面指令反弹：提及即激活。** 否定处理是模型弱项（Language Models are not Naysayers——否定词常被忽略、默认按肯定解读）；工程界"pink elephant"共识：写出禁词本身抬高该词先验概率（priming）。对存量 R3"负例清单可"精细化为两级：**词汇级负例＋替代词＋可 grep 检测＝有效**（消费端有机械检查闭环）；**抽象风格负例（"不要写得像 AI"）＝无操作语义＋反向 priming，双重有害**。〔通用〕

**位置与新鲜度**：参照材料放 prompt 尾部（Anthropic 指南）；工业实践同构——ST Author's Note 在对话历史尾部注入短风格块（§5.2），与位置效应互证。

### 2.3 对心智设计的消费建议

1. **R1 写前重读强化**：语态样本行挪到任务包最尾（生成点前最后一读）；样本选取加同型约束（本章场景功能 ↔ 样本段落类型）。
2. **负例正例化守则**：任何禁用判据必须带替代动作——AI 痕迹六条"超了怎么改"已是此形态，新增判据一律"禁 X→改 Y"双要素；纯禁条不入任务包。
3. **文风基准分工表**：显性层（句法/词频/口头禅）→画像＋样本锚定；分布层（比喻/破折号/三连/格言密度）→不指望模仿，交修辞预算计数门禁（存量 S5）兜底。分工写进设计侧，防将来把分布问题误当模仿问题修。

## 3. 生成时行为

### 3.1 存量盘点

方向二已立 R2（无饱和/无厌烦→意象均匀，Fu et al. 2021 理论支撑）与 R1 中位化根因＋S1 采样建议（存量）；方向一 §四.2 留题：线管单过是否 AI 味的结构性来源。

### 3.2 增量调研

**自回归单向生成：生成中"回头修改"机制上不存在。**【机制事实，非实证命题】逐 token 采样、已生成前缀作为后续条件（KV 缓存固定）——输出里看到的"改口"（"不对，应该……"）也是顺流生成的表演，不是真修订。真修订只有两条通道：重新生成（整体/部分），或外部循环（生成完→反馈→重写，Self-Refine 即此）。推论：R8"一气呵成"防的不是"回头改"（机制上本不可能，指令空转），防的是**中断**——中途停下查证/润词会把分析语料插进上下文，改变后续采样的语态分布（上下文污染）。

**单次输出有长度墙，字数指令跟随不精确。** LongWriter（THUNLP，GLM-4-9B 训练）：主流模型单次输出长度受 SFT 数据分布限制（多数 SFT 样本短于 2000 英文词），显式要求"写一万字"也早早收尾；长度跟随是独立可训练能力（LongWriter-6K 训练后 2000→10000+ 词）；AgentWrite 免训练管线＝先规划再分段逐段生成，任何模型可产万字长文。〔GLM，中英双语〕对网文的换算（解读，需实测）：2000 英文词约合三千余中文字，网文单章 2000-4000 字恰压墙线——仓内单元制把单次生成压回墙内，外部研究反证其机制必要性。字数指令的系统性偏差方向（长目标欠产/短目标注水）未定——方向一 §四.1"配额诱导均匀化"担忧是否成立需项目实测；验收的机械数数＋欠产处置四档已是正确对冲。

**长生成漂移随长度退化有实证，章内位置规律无实证。** 逐章长篇生成需维护压缩的叙事状态，否则一致性随长度退化（Learning to Reason for Long-Form Story Generation；NstAgent）；递归生成中语义漂移比事实漂移更重的线索（r/MachineLearning 讨论引用研究，一手论文未核对）。**语态/视角随章内位置的漂移规律：未找到实证**【仅有实践共识】——POV 漂移在仓内已是热回看机械自查项，现有对冲与证据状态匹配。每单元生成前重锚（重读衔接段＋语态样本）在机制上等价于 AgentWrite 的逐段规划——是防漂移必需，不是仪式。

**高温不是免费午餐。** When Temperature Doesn't Work（2025）：提高温度增多样性的惯用法有失效场景；Selective Sampling（2025）：高温＋质量筛选的组合优于纯高温（质量-多样性权衡更优）。对存量 S1 的修正：高温单挂不可靠，需与双生成取拼（存量 S6）＋机械门禁选优捆绑。〔英文任务为主，中文场景需实测〕

### 3.3 对心智设计的消费建议

1. **R8 条目重写要点**：表述从"不回头改、不自我审查"（前半句机制上永真、无指令价值）改为"不中断、不查证、不换语态"——拦截对象是上下文污染；"待定标注"的机制定位＝给润色轮的修订坐标（补偿"生成中自改"的不存在）。
2. **润色切分粒度＝段级**：段级定向重写丢弃的前缀最少、语态污染面最小（存量 S2 方向正确，机制依据在此补全）。
3. **采样三件套捆绑**：高温（min-p 护航）＋双生成取拼＋机械门禁（散文统计/修辞预算）选优——对 DSH fork 的功能请求合并为一条，不单独请求温度开放。

## 4. 过程监控

### 4.1 存量盘点

热回看三项自查（POV/禁入/事实，机械）＋自评行（最得意/没劲段，自愿）已有；方向一 G5 提案自评行升格判据式自问；方向二已裁外部 AI 检测 API 不入管线（存量）。

### 4.2 增量调研

**自我校正按"判据可验性"分裂——本文最重要的增量认知之一。** Large Language Models Cannot Self-Correct Reasoning Yet（ICLR 2024）：无外部反馈的内在自纠错在推理任务上不改善甚至变差（把对的改成错的），早期文献的收益来自 prompt 泄漏（提示里暗含正确答案）；When Can LLMs Actually Correct Their Own Mistakes?（TACL 2024）综述：内在自纠错只在简单任务或有外部/金标准反馈时成立。对照 Self-Refine（NeurIPS 2023）：7 任务平均约 +20%——但其任务是表面标准可自验的（情感极性改写/格式/对话风格）。精确划界：**自我反馈对"判据可机械或可对照的表面层"（格式/风格/POV/禁词）有效；对"需要外部真值的深层"（事实/一致性/走向）不可靠。**〔通用，跨族多证〕

**自评假阳性的定量证据：自偏好。** Self-Preference Bias in LLM-as-a-Judge（2024）：模型给自己生成的输出打分系统性更高，且自偏好幅度与"自我识别能力"相关、与实际质量无关；Extreme Self-Preference（2025）：输出被故意注入缺陷后模型仍偏好自己的版本。推论：模型自评"没问题/合格"不可作为质量证据；自评的可靠用途是**定位**（哪里最得意/哪里没劲），不是**判定**。〔通用〕

**推理渗入正文：思考模型的特有风险。** 机制推演【非直接实证】：思考链与正文同上下文时，思考的分析性语言分布（列表式/hedging/"让我们"腔）渗入正文采样。侧证（2026 新文献，幅度待验）：CREATE 发现推理 trace 对联想创造的贡献分任务有正有负；When More Thinking Hurts（ACL 2026 Findings）：更长思考在部分任务上降低输出质量（overthinking）。**"思考模型 vs 非思考模型写小说正文"的干净对照：未找到实证**【实践共识：中文社区对 R1 系写文的"分析腔"抱怨普遍】。仓内互证：AI 痕迹六条中破折号解释装置/段末格言化正是"解释性思维正文化"。〔思考模型：DeepSeek-R1 系/GLM 思考模式/o 系——对作者主力模型适用面最高〕

**"想一下再写" vs "直接写"：未找到对照实验。**【未找到实证，仅有倾向性证据】Self-Refine 的增益全部发生在"写完再改"（后置），不在"想后再写"（前置）；渗入风险也在"想与写同上下文"时最大。设计取向：把"想"后置化与外置化。

### 4.3 对心智设计的消费建议

1. **落点件的机制依据**：schema 第 5 件"落点"（无落点且不声明＝不可证伪）的支撑即上述——模型内省不可信，可观测外部痕迹（申报行/自查行/计数）是唯一可靠校准通道；纯内化判断条目（如 R1 语感状态）必须显式声明，与架构现行设计一致。
2. **热/冷回看边界修订**：热回看保留表面层自查（POV/禁入/禁词——自改有效域）；事实核对与质量判读移冷回看（隔上下文重评/脚本/人工），事实自查必须对照账本与材料包（外部锚），不凭记忆自评；自评行永不作合格判定，只作定位信号。
3. **思考预算分任务**：正文生成直写（关闭思考或最小思考预算）；判读/审读/拆书用推理模式——DSH 层按任务类型配置思考预算（对 fork 的功能请求）。

## 5. 开源写作系统横向

### 5.1 存量盘点

方向三已盘主要项目（humanizer 26 模式／说人话三档边界／ai-flavor-remover 三段输出／de-slop 43 规则计分／humanize-text 训练管线不吸收／NovelAI·ST 社区预设调风／Vela·InkOS）与治理手法归类——不重抄；Author's Note 在存量中已被点名为调风手段，下文增量是结构机制细读。

### 5.2 增量调研

**ST 预设结构细读：顺序即权重＋模块按需在场。** ST 的 chat completion preset 由可拖拽排序的 prompt order 构成（系统块/世界书/Author's Note/风格模块），采样参数全暴露——社区把"什么信息放离生成点多近"当一等公民调参，工程共识"顺序即权重"。Author's Note＝对话历史尾部注入的短风格块（距生成点最近），是工业界对"尾部注入"的自发收敛，与 §1 位置效应互证。Chatstream 预设（r/SillyTavernAI）：模块化风格条目**默认关闭、按需开启**——与心智条目"停机条件"（条目不总在场）同型设计。

**生成管线侧：事件级预决定管线的普遍化。** LongWriter/AgentWrite（规划→分段生成）、Learning to Reason for Long-Form Story Generation（逐章计划器）、NstAgent（叙事状态维护）——开源长文生成系统清一色走向更深的写前预决定。与方向一 §3.3 人类作家对照（锚点级预决定、事件序列写时生长）反向：**工程管线越深越可控，人类流程越浅越人味**。Abzu 现行位置＝细纲事件级（深，可控）＋心智停机条件（造不均匀，人感）——在两极间自觉取衡，这个定位是差异化不是缺陷。

**中文实践社区增量（交叉验证为主）。** 方向三未覆盖的中文侧共识：去结构化（移除"首先/其次/最后"机械结构词）、三层叠加法（场景层＋情感层＋细节层组合指令）、"命令式而非求式"、人定大纲 AI 填充（知乎/博客园/人人都是产品经理/新浪财经 2026-02）。与仓内结论一致度高（去结构化≈连接词卡与清单式全景判据；三层叠加≈程序性指令拆解；人定大纲≈细纲制）——增量价值低，作交叉验证证据收录。

**打分器模式：绝对分 vs 相对基线。** de-slop（43 规则 0-100 分）/humanizer-skill（55 模式计分）代表开源界主流＝**规则绝对分**；Abzu 用五书参照带做**相对基线**（AI 稿 vs 人味语料带）——对网文文体更稳（绝对分隐含英文散文规范，误判快节奏网文）。存量 S5 修辞预算制方向正确，增量认知是定位性的：坚持相对分，不学绝对分。

### 5.3 对心智设计的消费建议

1. **任务包工程参照**：件序规范（§1.3-2 首尾双锚）＋Author's Note 等价物——材料包"近期正文衔接段"已有，增量是位置最尾化（每单元生成点前最后注入"上单元末句＋当前段语态锚"）。
2. **条目在场/离场机制**：Chatstream 型"模块默认关闭"映射为组装侧实现停机条件——按单元场景功能带条目子集（§1.3-1 总约束账的执行机构）。
3. **打分器定位声明**：机械门禁（修辞预算/散文统计）＋参照带相对分做闸，不引入绝对 AI 分（与方向三"检测器只作相对门禁"裁定一致）。

## 6. 版本适用面与失效条件

| 结论 | 适用面 | 失效条件 |
|---|---|---|
| 多约束退化（FollowBench） | 通用（13 模型，英文短任务） | 指令调优范式转向多约束强化后曲线抬升；中文长生成退化斜率未测 |
| 位置 U 型 | Claude 系实测为主 | 长上下文训练进步弱化位置偏差；DeepSeek/GLM 幅度需实测 |
| 示例锚显性层/隐性层模仿不可靠 | 通用 | 写作专用模型（更强风格训练）可能收窄隐性层差距 |
| 负例提及即激活 | 通用 | 无近期失效迹象 |
| 自回归不可回头 | 机制事实（全部自回归 LLM） | 架构换代（非自回归/编辑式生成）才失效 |
| 长度墙 | 2024 代模型量级（GLM-4/Llama3.1） | 新代模型长输出能力提升中；中文万字单次生成验证前按墙设计 |
| 高温需配选优 | 英文任务为主 | 中文网文场景的温度-质量曲线需实测 |
| 内在自纠按可验性分裂 | 跨族多证 | 推理模型可能略扩有效域（CREATE 线索），不可依赖 |
| 自偏好偏差 | 跨族多证 | 同上 |
| 推理渗入正文 | 仅思考模型 | 非思考模型无此问题；思考/正文分离的 API 形态出现则失效 |
| RLHF 中位化等四根因 | 存量结论（2023-24 代训练） | 多样性奖励/新对齐范式可能减弱 |

**统一失效条款**：本文外部证据多出自英文任务与非 DeepSeek 模型族；凡进设计规范前，先在项目主力模型（DeepSeek 系）跑对照批——最终校准权在项目实测。
