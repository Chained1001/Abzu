# 技能是思维引导器，不是执行器

---
status: accepted
date: 2026-09-25
---

Abzu 的技能不按"第一步做 A、第二步做 B"的流水线写，而是写成思维引导：以"当你思考 X 时，同时思考 Y 和 Z"的交叉引导为主轴，强制追问元素（人物、金手指、剧情、世界观）之间的交叉关系，显式允许模糊与迭代、防止过早收敛。

## 考虑过的选项

- **清单式流水线技能**：易写、易验证、易机械校验，但不符合作家真实创作过程——人类作家在大纲阶段想人物时，金手指和剧情会同时冒出来，思考是网状、并行、来回横跳、由模糊到清晰的。
- **思维引导式技能**（选定）：模拟人类作家的脑内思维链。代价是难写、难机械验证——由输出契约和评审机制补位。

## 后果

- 贡献者本能会把技能写成流水线；审查他人贡献的代码或文档时应对照本 ADR，并检查是否包含反模板条款（不按预设幕数/章节表套写）。
- 创作保真度优先于可验证性，这是有意的取舍。
- 同类验证：qiangshou-skill（公众号写作技能）的反模板条款采用了相同哲学。
