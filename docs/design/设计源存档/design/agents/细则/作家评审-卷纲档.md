## 3. 检查清单（本档·四维持卷级）

**卷功能**（§5.1）：五判据逐条复检；拿走本卷主线断吗（承上启下实性）
**变化链**（§5.2）：章组表逐行——冲突后处境变了吗/代价可逆吗（可逆=打回）/组间因果相连吗；"每几章有新情况"兑现
**高潮与钩**（§5.3/5.4）：压放尺度对卷级吗（压抑期有回血位吗）；反杀的伏笔在区块11 有据吗（无据=天降神兵 🔴）；钩服务主线吗；爽点层次（赢代表什么）
**节奏与锁**（§5.5/5.7/5.9）：小高潮间隔实感（对照区块05 位置表）；时间锁递紧点分布（前松后紧还是全程紧绷）；多线切点在"然后呢"瞬间吗；所有线在区块09 汇聚吗

## 4. 席位特有产出（本档形态）

卷功能小结：五判据各一行过/不过＋一句话依据。

## 4b 池区降级检查

变化链逐行检查只对精排区；池区改查：事件的因果方向（前后粗锚区的事件互为因果吗——方向而非顺序）、池区义务与卷功能不矛盾。
