## 3. 检查清单（本档）

四维依次过。每条 = 检查动作 + 目标区块 + 判据节号。

### D1 结构（§8.2 结构检查型为纲）

1. 拿走驱动内核，故事还立得住吗（§4.15"拿走内核故事散"反推；区块 04）
2. 激励事件"回不去+绑定过往"两性占全了吗，还是只挪了个地方（§4.12；区块 02）
3. 从结局倒推：每一灾都必要吗——删掉这一灾，赌注还成立吗（§4.14；区块 01/03）
4. 结局三件事齐吗：兑现赌注、主角变了、新平衡照映旧失衡（开头的问题在结局有了答案）（§4.14；区块 03）
5. 镜像：结局画面照映开局画面吗（§8.2；区块 01↔03）
6. 每次换图三件套齐吗：揭开点什么、新谜团、班底继承（§4.6；区块 07 附表）
7. 第二卷世界变大了吗（§4.5；区块 07）

### D2 逻辑（§8.2 自我辩证型为纲）

1. 十二步每步是对抗性动词还是流水账动词（"决定/前往"≈没戏；§4.2；区块 05）
2. 因果链全吗：每个果有因、每个因有果（§8.2；区块 05 内部 + 05↔07 交叉）
3. 反转"回头看都对上"了吗：明线误导在揭晓前可自然解读、暗线真线提前铺了吗（§4.10；区块 11）
4. 反派为什么打不过主角——理由成立吗，还是靠降智留活口（§4.10 反推 §2.11 判据"反派有智商"；区块 13）
5. 伏笔的埋与收成对吗：埋设处读者无感、揭晓处回头恍然（§4.8；区块 10）

### D3 设定（§8.2 人物检查型为纲）

1. 主角弧是"人的成长"还是"只有力变强"——开局认知→结局认知有质变吗（§2.5/§2.17；区块 01↔03↔05）
2. 金手指是助力还是全包——拿走金手指，主角本人的能力还剩什么（§2.18；区块 04/09）
3. 反派有自己的正当性吗，还是纯工具人（§2.10；区块 13）
4. 红线核验与规则模糊带：红线逐条对区块 14（红线遵守声明）；世界规则模糊地带（留痕/记忆/抹除等边界）对 §3.6 逐项查大纲事件有无蹭模糊带（区块 05/07/09）

### D4 节奏（§8.2"中间不拖"为纲）

1. 一级循环"模式同、内容不同"做到了吗——逐卷看循环六步的内容变量（§4.4；区块 09 对照区块 07 各卷）
2. 三灾间隔的铺垫量级合理吗——每灾前的章数区间有没有超长干蹚（§4.5；区块 05/07）
3. 支线离场-回归的间隔与主线咬合吗：回归点落在主线需要换气处吗（§4.3；区块 08）
4. 收线四件事（伏笔回收/人物归宿/情绪升华/三线同爆）在同一点爆发还是错峰（§4.8；区块 12）
5. 情节模式配比纪律执行位：主模式 ≥60% 类型守恒、辅阵型升浓不夺"解谜破局"收尾（区块 06 自带配比纪律；§4.4 错误项"核心卖点太单一"反推）
