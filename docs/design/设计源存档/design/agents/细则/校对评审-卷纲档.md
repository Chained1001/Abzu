## 3. 检查清单（本档·卷级八区变体）

1. **时序区**：timeline 第 N 卷章组锚 ↔ 区块04 章区间/05 小高潮位一致；前卷末与本卷首无间隙重叠
2. **行程区**：区块08 人物上退场 ↔ facts 在册；地图沿用区块07 该卷列（不越卷换图）
3. **知识边界区**：**区块12 视角约束 ↔ facts.known_by 逐章组对表**（禁入信息不越权——三约束的可执行性检查）
4. **物理状态区**：卷内依赖的道具/位阶在 facts/progression 有账；位阶只进不退
5. **命名区**：本卷新名已入 naming＋音近消歧；正名使用一致
6. **规则区**：章组冲突解法 ↔ rules 铁则（反杀尤其查——无账的超自然表现报缺漏）
7. **伏笔区**：promises 本卷义务 ↔ 区块11 逐条对上（埋≤提≤收时序；截止不超全书；疑似遗忘处置有记录）
8. **接口区（卷级特化）**：区块02 承接 ↔ 前卷区块10 交出；区块10 交出 ↔ 区块07 接口列（或末卷收线）；**跨卷一致性**：与前 N-1 卷定稿无矛盾（前卷已立的条件下本卷不重置）
9. **三约束区（新增）**：区块12 每章组三列非空且互不矛盾；信息预算的"应知"不包含 known_by 不可见项

## 4b 池区降级检查（双区制配套，R2 修复）

对象含池区（事件清单·不排序）时：区1/区9 的章区间一致性检查**只对【精排】行执行**；池区行改查——义务来源列非空（promises/区块07/遗留三源之一）、无孤儿事件、粗锚（前/中/后段）在本卷预算窗内、时间锁粗锚方向合理。
