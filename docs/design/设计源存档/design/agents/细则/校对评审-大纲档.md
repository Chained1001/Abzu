# 校对评审·大纲档细则

> 版本 v1.0 ｜ 2026-09-28 ｜ 隶属 proofreader.md（设计源：[校对评审.md](../校对评审.md)）｜ 入口：任务书 §0 路由
> 审读对象：故事剧情/大纲/大纲_定稿候选.md（15 区块 + 镜像附表）

## 1. 方法论加载（本档）

**无知识库加载**——校对评审的判据 = 登记册六本 + 本清单（角色常量，见任务书 §1）。这是它可跑标准档模型的原因。

## 2. 输入增量（本档）

无（基础输入：登记册六本 + 基本规格，见任务书 §2）。

## 3. 检查清单（本档）

八区按序过。每区先扫区块、再对登记册、后判冲突型。**总则：先对照区块 11（反转清单）排除故意手法（有意的误导设计不是矛盾），再立冲突条目。**

### 区 1 时间线

- 区块 05（十二步表）、区块 07（分卷表）中事件的先后顺序 ↔ timeline 登记册：有无 A 后于 B 却依赖 B 的因果倒置
- 主角年龄、季节、时代锚点在各区块间一致
- 换图节点（区块 07 附表）标注的卷位 ↔ timeline 对应事件条目卷位一致

### 区 2 地点与行程

- 回访口径对表（地图卡·回访口径行——不可回的地方又回去了=🔴；2026-10-02 接消费）

- 区块 07 附表每次换图：迁移手段（谁带路/什么法子）在 facts 中有账吗
- 跨地点会师的情节（十二步或分卷冲突列）：两地距离与剧情可用时间量级相符吗（只判数量级，不精算）

### 区 3 角色知识边界

- 大纲中任何角色基于信息 X 做出的行动：facts.known_by 里 X 是否已对该角色可见（含可见卷位早于行动卷位）
- 区块 11（反转清单）的暗线真线：不知情角色有无"未卜先知"——在揭晓位之前依不可知信息行动
- POV 越界：叙述视角角色说出其 known_by 之外的信息（大纲档查计划层面的 POV 标注；正文级逐段查属章纲档）

### 区 4 物理状态

- 伤势、持有物（I 前缀道具）、修为境界（progression 只进不退）：情节依赖的状态在 facts 有取得/达成记录吗
- 区块内使用的道具 G/I：登记册有该实体吗；没有 → 报缺漏
- 金手指能力越界：大纲中金手指表现 ↔ **G 节使用规则组**（冷却/禁用情形/代劳边界——替主角干完了该干的=越界）＋升级节点当前档＋rules 对应限制（列名对齐 2026-10-02 G 节扩容）

### 区 5 命名一致性

- 对象文件全文实体名 ↔ naming 登记册（含别名列与消歧记录——正名核对以此册为唯一基准）：有无未登记别名、正名替换漏网
- 近似名冲突：两名角色/两地名字高度近似且登记册无消歧说明

### 区 6 世界规则

- 区块 05/07/09/13 中的事件、能力表现 ↔ rules 登记册（含 C 前缀铁则、V 前缀境界约束、力量天花板条目）：有无违反
- 世界观矛盾型冲突（前文设定无 X、后文出现 X）——大纲档查区块之间与登记册之间

### 区 7 伏笔对账

- 区块 10（伏笔摘要）逐条 ↔ promises 详表：内容、埋设卷位、揭晓位一致吗
- 每条 promise：埋设卷位 ≤ 揭晓位 ≤ 截止章节；截止章节 ≤ 全书章数预算（区块 07 字数合计 ÷ 单章字数档换算，如 200 万÷3500 字≈571 章（单章口径随段4B 锁定值——2026-10-02 从 2500 校准为 3500））
- **埋收距离窗**（§4.8 判据）：小/中型伏笔的埋设→回收距离 ≤10-15 万字（超出且无中途提醒=读者已忘，回收失效）；贯穿型（深伏笔）例外但提醒节奏必须齐；挂设定上的伏笔（无人物挂靠）距窗减半
- 有埋无收：promises 中存在条目，但区块 12（收线设计）与区块 10 均未覆盖 → 逐条列出
- 10 万字还账暗示：截止章节距埋设位超过 10 万字的 promise，中段有无暗示安排（区块 05/07 查）

### 区 8 结构因果

- 区块 05 十二步每步的"因"在前序步或前置卷中有交代吗（果无因）
- 区块 05 阶段 ↔ 区块 07 卷：有无十二步阶段无卷承载；有无卷不服务任何阶段（挂空卷）
- 区块 02（激励事件）↔ 区块 01 背景句：激励事件确实打断了该日常吗
- 区块 03（结局）↔ 区块 12（收线设计）：结局兑现的赌注在区块 01/05 中下过吗

## 4. 席位特有产出（本档形态）

- 冲突计数行：A型 {x}｜B型 {x}｜C型 {x}（型定义见任务书 §4）
- 修复方向提示区：每条只指认冲突两侧待作者二选一，不出剧情方案

## 5. 本档禁止增量

无。
