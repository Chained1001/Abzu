## 3. 检查清单（本档）

### E1 标尺全项对标（主尺，机械性强）

逐行对照《参考标尺.md》，产出 §4 标尺对照表。对标纪律三条（来自标尺文件自身约定）：

1. 【待校准】数值项 → 仅供参考、不计入问题计数（标尺头部规定），只在对照表标 ⚠️待校准
2. 未覆盖题材 → 标尺兜底规则：修正系数全取 1.0 + 对象文件已标注"该题材标尺未校准"；**绝不编造修正值**——发现对象文件或他人编造修正值即报 🟡
3. 题材修正系数用对了吗：按基本规格题材取标尺修正表对应行

### E2 卖点与定位（§1.6 + §1.7 + §1.2）

1. 撑百万字的引擎明确吗：一句话能指出"这书靠什么撑"（区块 09 一级循环 × 金手指）——说不清即 §1.6 不过（🔴）
2. 题材组合新意：差异集"写什么"表 + 区块 01——组合有新意还是纯换皮（§1.7）；新意点能撑到读者眼前吗（书名/简介体现差异了吗，与 E3 交叉）
3. 同质化风险：差异集"改什么"表 + 区块 04 阵型——与参考作品的差异是否只停在皮层（换皮无保核说明）；差异集申报"不写什么"的内容在大纲中真的没写吗
4. 读者画像清晰吗：基本规格读者画像 §1.2 判据过一遍（有没有、细不细、能不能指导定位）

### E3 门面（§1.12 + §1.13）

1. 书名（基本规格终定版）：题材信号、差异化、长度——§1.12 判据逐条过；同题材货架撞名风险（凭常识判断，不联网，标注局限）
2. 简介：钩子前置吗、信息剂量合适吗、剧透关键反转吗（区块 11 的反转有没有被简介漏底）——§1.13 判据逐条过

### E4 节点与预算（标尺·签约/上架区）

1. 上架节奏：按基本规格字数档与标尺签约/上架节点对照——开局爽点兑现位在上架前吗（标尺节点参考值）
2. 预算自洽：区块 07 字数列合计 = 基本规格全书预算吗（量级核对；精确核算归落地审查脚本，此处只报量级异常）
