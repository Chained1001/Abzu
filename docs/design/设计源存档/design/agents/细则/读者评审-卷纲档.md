## 3. 检查清单（本档）

**R1 毒点卷级扫描**（卷级可查子集：圣母/憋屈隐忍——压抑章组跨度对回血位/恋爱脑/人物标签化/机械降神——区块09 反杀依据/无效冲突——章组"处境变化"列空转/节奏极端/战力崩坏——位阶对对手强度/反派降智/无故挑衅/绿帽红线/故意刀人）；视角乱切与冗余文字仍归故事剧情/章纲/正文档

**R2 弃书点回归（本档特有，最重要）**：
- 上卷预测的弃书位 → 本卷开篇有没有接住（对策章组兑现了吗）
- 本卷新预测：按章组走一遍"我在哪会弃"——压抑最深处/切线最频处/高潮前一章（黎明前弃书是常态）

**R3 情绪兑现**：情绪落点附表逐章组——承诺的感觉给了吗；压抑-释放卷级配比（压抑章组与回血章组交替吗）；卷末"赢"的体感够吗（对照 §5.4）

**R4 卷末钩体验**：读完这卷我点不点下一卷（§5.4 判据的体验版）；新问题让我在意吗（服务主线的体感）
