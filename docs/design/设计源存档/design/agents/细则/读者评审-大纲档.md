## 3. 检查清单（本档）

### R1 毒点扫描（§8.5 十九条，挨个过）

毒点本质 = 情绪亏损：读者投入情绪、作者没兑现承诺。每条先问"这毒点在本档可查吗"，可查的落到区块取证。

**人设类（5 条，全可查）**

| 毒点 | 大纲档查法 |
|---|---|
| 圣母 | 区块 05/07：主角面对冲突的应对——该杀该断时收手且无代价 |
| 憋屈隐忍 | 压抑-释放间隔：被打压的章数跨度超过分卷表该卷长的一半且卷末无释放 |
| 主角恋爱脑 | 感情线任务（区块 07 情绪任务列）干扰主线目标达成的卷数占比 |
| 人物只有标签 | 区块 01↔03↔05：主角在开局/中段/结局的行为方式有无差异；配角按区块 08 五类归属查是否只有功能 |
| 混淆实力与人的成长 | 区块 03 主角"变了"的内容——只有境界/实力变、认知不变即中招 |

**剧情类（6 条，5 可查）**

| 毒点 | 大纲档查法 |
|---|---|
| 机械降神 | 区块 05 十二步的冲突解法：靠外部巧合（捡功/贵人/天降）解困的步 |
| 大量无效冲突 | 区块 07 冲突类型列：冲突过后人物状态/关系无任何变化的卷 |
| 通篇流水账 | 区块 05 动词质量：连续"决定/前往/获得"式无对抗步 |
| 节奏极端 | 区块 05 章数区间分布：三灾之间铺垫量级悬殊或全程无喘息卷 |
| 世界观矛盾 | 承诺的规则被剧情打脸：区块 01/04 建立的规则在后续区块被无解释突破 |
| 视角乱切 | → 故事剧情/章纲/正文档查（本档不查） |

### R2 追读力（§2.19 + §1.16 + §5.4）

1. 代入感三问（§2.19 判据）：读者"看到"主角看到的吗｜勾起什么已有情感｜对人物有感情了吗——从区块 01（背景）/02（激励事件）检验开局，从区块 07 各卷情绪任务检验延续
2. 主情绪漂移（§1.16/§1.4）：全书主情绪 vs 各卷情绪任务——有无整卷滑向另一种情绪且未归位
3. 卷末钩逐卷过（§5.4）：按卷顺序读区块 07，每卷末自问"我会点下一卷吗"——答"不会"的卷逐个记录，这就是弃书风险位
4. 卷间接口：上一卷的问题在下一卷开头有承接吗（区块 07 卷间接口列）

### R3 情绪兑现（§8.5 判据 + §6.4）

1. 承诺-兑现配对：大纲每卷立起的期待（冲突类型/情绪任务）在卷内有兑现吗——压抑后必须有释放（§6.4 压抑-释放）
2. 爽点类型与主爽点一致吗：开局承诺的爽法（区块 01/04）与中后期爽点（区块 07）同型吗——读者为 A 爽点而来，后期全换成 B 爽点即中招

### R4 一句话测试（§1.9 + §8.2 主题检查型）

1. 合上大纲能用一句话说清"这书讲什么"吗（区块 01）——说不清即主题散
2. 书名+简介（基本规格终定版）：作为读者，这个书名简介让我想点开吗——题材信号清楚吗、有钩吗
