## 拆书三阶段触发关系（依赖分层）

```
 S1 快速通读（硬前置——大纲进场前必须完成）
   │ ★骨架五件套 = 技能一大纲的全部输入
   │
   ├─ S2 深度全书分析（延迟触发——卷纲首次运行时）
   │    触发条件: 卷0 步5 检测 深度分析.md 不存在
   │    缺失处置: 挂起提示作者运行 /abzu:abzu-teardown
   │    前置不可行: 延期支（旧格式代用声明＋登记册兜底）
   │    依赖: S1（章节索引+伏笔/人物总表）
   │
   └─ S3 分卷细拆（窗口拆解制——每卷规划时触发）
        触发条件: 卷0 步5 检测 分卷拆解/第N卷.md 不存在
        默认: 只拆精排区对应章位 ±10 章（省 60-80% token）
        缺失处置: 同 S2 挂起 / 延期支
        依赖: S1（章节索引定位起止章）

 关键: 卷0 的硬依赖只有 S1——S2/S3 缺失时走代用降级继续，
      不阻塞卷纲运行（登记册是第一道保险，拆书参照是第二道）
```

## 三档模式（对外呈现——README / SKILL 入口用）

| 档 | 触发条件 | 包含 | 跳过什么 |
|---|---|---|---|
| **轻量** | 试水/短篇（<50 万字）/新手 | 拆书 S1 切片档→大纲段 0-5 基本流程→段 6 只跑脚本检查（跳四席）→直接写正文 | 四席评审、打磨轮、登记册六册（只建 promises）、台账 |
| **标准**（默认） | 长篇连载（50-300 万字） | 全流程：S1→大纲七段→卷纲完整轮回→章循环→单元批/卷级批 | — |
| **重型** | 超长篇（300 万+）/存稿期 | 标准＋连跑模式（卷纲 ≤3 卷串行）＋全量打磨轮＋Stage 2/3 全量拆 | — |

> 档位不是独立流程——是**同一流程的密度开关**。裁决权属（哲学常量）不变；裁决密度（体验变量）按档调。作者随时可升档/降档（记创作进度）。

## 三条主回路（本图灵魂）

```
 ① 滚动细化回路（防过早收敛的执行形态）
    卷纲精排区 ──三约束──▶ 章纲卡──▶ 正文 ──余量<3章──▶ 卷2细化支
    （池区事件不排序，写到哪细化到哪——猫腻"2万字细纲管10万字情节"）

 ② 反馈回路（乌贼式卷末复盘）
    正文/数据 ──▶ 卷末复盘(困难+偏差+注意项) ──▶ 下一卷卷0对表包 ──▶ 设计输入

 ③ 一致性回路（作家的自我一致性）
    任何阶段发现矛盾 ──▶ 评审四席引证举报 ──▶ 台账(根因标注) ──▶ 裁决
    ──▶ 变更提案(影响面) ──▶ 一次回改 ──▶ 复评回归 ──▶ 销项
```
