## 一、章循环总览（第 N 章，一次调用产一章）

```
 /abzu:abzu-draft 第N章 […第M章(连写≤3-5章/轮)]
   │
   ├─ 读创作进度断点（正文·第N章·段X → 续跑）
   ├─ 手改保护：正文与章末写入登记不符(作者手改过)？
   │    └ 是 → 停问：沿用/重写/只看状态（不覆盖手改）
   ▼
 步1 进场对表
   ├ 读上章正文尾【★章末写入】(下章计划+状态摘要)
   ├ 读本章组★三约束（三约束_第N卷.md 直读——章纲无需回读全卷纲）
   ├ 缓冲区余量<3章？ → 记提示（单元批时引导重入卷纲滚动细化）
   └ 欠账过滤：挂账清单(世界参照档案到期项)＋待验证清单(应验=本章)
      ＋台账遗留(触发=本章/本单元)
   ▼
 步2 ★章纲卡（细纲缓冲区的一格——大神形态）
   ├ 核心：一句话事件＋编号情节点1-3条(动作+目标+冲突结果+决定)
   ├ 冲突分层≤3 ｜爽点位(打脸=烽火三层/解谜=§6.4路径)
   ├ 场景表：地点细节｜人物+动机一句话(gate:薄弱即停)｜
   │  ★动作节点(动用哪些设定条目ID)｜情节点数≠场景数
   ├ 信息预算执行(新知/仍不知/应忘锚/禁入清单) ｜POV+读者比谁多少知道
   ├ 章末双钩(信息钩+情绪钩) ｜跨章资产(promises逐条+反派不轻易写死)
   ├ 前后接口(承上章末写入｜交下章) ｜头:字数档+时间行(倒计时章必填)
   ├ 可选件(不占密度)：「放」括注｜复沓锚句｜核心情绪前→后
   └ 过门：作者过目(连写可授权跳过)  ◀── 密度纪律:1:5~1:6只计创作区
   ▼                                                    不写对白和叙述
 步3 四段式正文 ══════════════════════════════ 详见下图二
   ▼
 步4 章末写入＋入账
   ├ 正文尾固定节：下章计划+当前状态摘要(AI特有件——对话记忆不跨章)
   ├ ★先对账后写册：申报表↔提取互对(漏报补/幻觉剔) → 通过才追加
   └ 登记册章级：known_by增量｜promises落章｜timeline标记
      ｜naming新称呼回写｜新实体(消歧先行)
   ▼
 段末四态 → 断点=下一章步1（或单元边界→批1）
```

## 二、四段式明细（灵魂段）

```
 段一 校对（写前对表——把"作家记忆"显式化）
   ├ 相关旧章反查(四维:伏笔/人物历史出场/状态变化/关系
   │  ——facts出处列+章级增量节检索,只读命中段) ──缺设定──▶ 记【待采风】
   ├ 设定注入：★动作节点优先(章纲卡预标注→按节点注全文)
   │  +关键词扫描兜底(中文包含式) +核心常驻
   └ 产出校对清单：POV边界｜禁入｜状态连续｜本章目标(对节奏锚点)
      ＋接钩义务(上章双钩本章哪场回应·可部分兑现)
      ＋时间三查(跨夜过渡/倒计时不跳跃/不回跳)
   ▼
 段二 ★入戏（写前仪式——大神隐式能力的显式化，全设计独有）
   ├ 画面预演：场景表逐场景画面化重述到"能看见"
   │  (剑主沉浮:"像放电影一样过一遍,写时一帧帧放出来")
   ├ 情绪圆融两问(香蕉)：①情绪链每步都把握清楚了？(开局状态→章末钩闭合)
   │  ②每个画面都为情绪链服务？(不为→砍或并)
   ├ 末读语态：动笔前最后读入=正文语态文字(上章末两段+本章开头草起笔)
   └ 出场S/A人物声线节(对话习惯/口头禅/禁语)
   ▼
 段三 写作（一气呵成——检查台不在这）
   ├ 黄金三百字起笔(§6.2:主角+处境+钩,禁设定大科普)
   ├ 按场景表顺序写｜场景内动作-反应交替(§6.5)
   ├ 方法论即时加载:§7.2对话/§7.3动作/§7.4环境/§7.12幽默死亡——按需0-2节
   ├ 新增物三级申报：微连接直接写｜★具名新物=写了要报(入申报表)
   │  ｜改剧情已定结果=先问作者("本章没写成的")
   │  └ 严禁为填表加设定/不拿新增物补字数
   └ 发现错误→记【待改】不打断(B+C纪律)
   ▼
 段四 回看（检查台不是改稿台——"一修改就完蛋"的机制化）
   十二项自检：
   ①黄金三百字 ②章末双钩在吗 ③POV没漂(禁入没泄) ④字数档[出带三岔协议:
     欠字不硬凑(作者三选:收下·推荐/改卡重写/弃章,<一半不推荐收下)
     ｜超字一次净删(零新语义:保情节点/事实/因果/情绪/钩,删重复解释/
     装饰排比/无功能微动作)] ⑤情节点全兑现 ⑥断档红线(脚本:主5/情10/世15)
   ⑦信息预算对表(多给/漏给) ⑧回头砍(删没效率的句子)
   ⑨契约四问🟡:主角靠选择挣到结果?收益被无交换拿走?提前用底牌?
     旧期待付息留新期待?(不过→记台账走修订,不自动改稿)
   ⑩四级文风扫描（tier1-4，含豁免）(脚本:tier1 章纲/情节点/登记册等→必改;tier2 第X章/本章→提示,
     故事内系统文豁免)
   └ 处置：🔴仅三项即时回改(禁入泄露/事实错/POV漂) → 章末写入
```

## 三、批量层与回路

```
 ┌─ 单元批（每1-2章组或满10章，先到为准） ─────────────────┐
 │ 1 缓冲补写检查：精排区余量<3章                            │
 │     └─▶ 提示运行 /abzu-volume 第N卷（引导式）            │
 │         ══▶ 卷2细化支：骨架校准→池区升格→三约束合法append ◀═ 滚动细化回路
 │ 2 章组批评审(轻量档): 校对(区3/4/7章级化+POV抽查)         │
 │        +读者(毒点抽扫1/3+黄金三百字抽查+三章连读体感)      │
 │     → 台账(对象=chapter-单元N) → 🟡走修订通道             │
 │ 3 断档统计+★伏笔到期视图(超期红/临近橙/活跃蓝——纯文件甘特) │
 │ 4 摘要冻结(单元摘要≤10行,写定即冻结) ＋【待采风】集中盘点  │
 └──────────────┬────────────────────────────────────┘
                │ 卷末
                ▼
 卷级批(四席全量·卷纲档细则) ＋ 卷末复盘(喂下一卷卷0)
   → 台账 → 打磨轮 → 开卷判定(继续/完本)
                │
                ▼ 完本
 收线对表＋【可选】完本砍修(崩卷预案第四型:猫腻"砍到二百万")

 ┌─ 修订通道（变更提案在技能内一次完成） ─────────────────┐
 │ 触发:章组批🟡🔴｜作者明示｜回看累积【待改】              │
 │   写作中发现→不打断记【待改】→章/单元边界集中处理         │
 │ → 病灶×时态分岔: 本卷正文就地改｜已发章=提案｜            │
 │    卷纲=提案｜设定=提案｜大纲=提案                        │
 │ → 变更提案CP{N}(影响面:涉及章+登记册+下游章末写入链)      │
 │ → 作者裁决 → 一次完成回改(同步点清单+更正记录+受影响章复评)│
 │ → 已发正文修改必走本通道;受影响章的章末写入链同步更新      │
 └─────────────────────────────────────────────┘

 写崩了？(继承卷纲SKILL 21): 偏离≠崩(先骨架校准) →
   硬写冲过去+回头缩减(主流)｜早期推翻(限前20万字)｜
   边写边修(谨慎)｜完本后砍修
```

## 四、AI 特有件（如实标注——无大神先例，合法性=补 AI 短板）

| 件 | 补什么短板 |
|---|---|
| 信息预算执行（应知/应疑/应忘/禁入） | 防 AI 注水与泄底（对冲"一直写不回头"） |
| 章末写入 | 对话记忆不跨章（人类不需要，AI 需要） |
| 相关旧章反查 | AI 无阅读史（人类作家记得自己写过的） |
| 动作节点预标注 | 设定注入的确定性（AI 不会"自然想起"设定） |
