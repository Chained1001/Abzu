## 一、全流程总览

```
 /abzu:abzu-outline
   │
   ├─ 读 创作进度.md
   │     ├─ 不存在 → 进段0
   │     └─ 存在   → 定位断点(记到"步") → 跳到对应段·步续跑 ◀──┐
   │                                                            │
   │  ┌─────────────────────────────────────────────────────────┘
   │  │ 每次会话推进一段/子段；段末: 清账+报告四态+更新断点
   │  ▼
 │ [段0] 进场建档（骨架预检前置——拆书在前；原文由 abzu-teardown 进场入库）
 │        预检: 参考作品/{书名}/三件套 ─缺→ 先运行 abzu-teardown(段0挂起:需要你处理)
 │                                    └齐→ 六字段问卷(参考作品/题材/篇幅/红线/灵感库双库/可选念头)
 │        → 复述纠错 → ★基本规格/创作进度(十节版)/灵感库
 │        → 骨架报告(核心阅读承诺/节奏总体形态) → 断点=段1
   │  ▼
   │ [段1] 确定差异（这本书和参考作品哪里不一样）
   │        静默组装差异来源 → 分组菜单裁决 → 推导核心画面/一句话故事
   │        → ★差异集.md(五栏,含暂存) → 断点=段2
   │  ▼
 │ [段2] 开书定向（产物均为"方向器"初定版，段6复核终定）
 │        定读者→定主情绪→定主题(§1.11)→定长线→定一句话→定书名→定简介→备资料(步1-8)
 │        → ★基本规格.md(定稿态) + 待验证清单 → 断点=段3
   │  ▼
   │ [段3] 主角构建
   │        步0选切入点(四条路径) → 九件事(主攻项插队先做)
   │        → ★主角卡 + 世界文档(铁则/体系/天花板) → 断点=段4A
   │  ▼
   │ [段4] 结构生长（三子段）
   │   4A 立四梁: 阵型→结局倒推→激励事件→一段式概括→主线(松紧可选)
   │   4B 铺卷线: 情节模式(九选主配)→★分卷表→换图→支线(配角冒出)
   │   4C 收伏线: 一级循环→★伏笔表→反转→收线→牌局(反派成形)
   │        → ★大纲_草稿.md(01-13区块) + 嫁接日志 → 断点=段5
   │  ▼
   │ [段5] 设定归档
   │        SABC分级→关系/感情线→认知表→世界收拢→原创性终检
   │        → ★登记册六册入齐(facts/promises/progression/rules/timeline/naming)
   │        → 断点=段6
   │  ▼
 │ [段6] 审校定稿
 │        组装15区块+复核书名简介→落地审查→校对评审(评审台账初始化+落盘建条目)
 │        →三评审(落盘建台账条目)→打磨轮(裁决/修复记台账)
 │        → ★大纲_定稿.md + 归档三件(建归档//差异集移入/旧版本移入)
 │        → 报告四态:已完成（第一期打样走通标志）
```

## 二、段 1 确定差异（分支明细）

```
 静默组装(零提问):
   题材迁移差异(自动) + 反面清单修复项(自动) + 换变量扫描(5-8个,自动)
   + 灵感库命中零件 + 建档念头(若有,高优先)
        │
        ▼
 问1(仅当建档无念头,可跳过): 有没有特别想写进去的东西?
        │
        ▼
 问2 分组菜单裁决
   ├─ A 题材迁移: 自动生效 │ 唯一开放点: 想保留移植的现代元素?
   ├─ B 反面清单: 逐条 ✅ 或异议
   ├─ C 换变量候选: 哪个让你兴奋?(多选/改/毙/暂存)
   └─ D 灵感库零件: 配不配?
        │
        ▼
 问3 核心画面×2-3(骨架开局空位×已选差异) ─都不满意─▶ 说明哪里不对,重推 ─┐
        │ 选定                                                        │
        │◀───────────────────────────────────────────────────────────┘
        ▼
 问4 一句话故事(骨架动机链×差异集) → "和你想写的是同一本书吗?"
        │ 否 → 回问3
        ▼
 ★差异集.md 落盘(五栏: 写什么/不写什么/改什么/避什么/暂存什么)

 暂存栏: 拿不准、舍不得毙的候选留观 → 段3/段4 遇对应场景 AI 提示捞回
         → 段6 审校定稿前必须清空(转正或删除)

 兜底: 全程"都行" → 最小差异方案(仅A+B, C/D留空, 标注可后补) —— 流程永不卡死
```

## 三、段 3 主角构建：九件事与交叉追问

```
 步0 选切入点(静默判断+作者确认)
   差异集换的是身份/人格 ──▶ A 人格内核先行 ┐
   一句话故事处境最突出 ──▶ B 处境欲望先行  ├─▶ 主攻项(先做、做深)
   差异集换的是金手指  ──▶ C 金手指先行     │    其余八件事按默认顺序补
   段1画面候选强       ──▶ D 画面先行       ┘
        │
        ▼
 九件事: 身份→欲望→缺陷→铁则→力量体系→天花板→[金手指★边最密]→衔接→成长弧
   每件事: AI出2-3候选(带追问卡) → 作者 选/改/毙
   金手指追问卡: 兑现主情绪?│长新困境?│体系哪层+受铁则什么限制?
                猫腻三连: 给什么安全感→杀死什么矛盾→怎么再造可控不安全感
   卡点三板斧: 换路径 → 角色代入假设("如果主角是X") → 仍卡→向上记账
        │
        ▼
 段末四轨道自检: 一句话故事 ↔ 主角卡 ↔ 力量体系 三方对齐
                错位 →【待改清单】→ 段末统一清账
```

## 四、段 6 审校定稿（含打磨轮）

```
 组装《大纲_定稿候选.md》(15区块) + 复核书名/简介与大纲终稿对齐(初定→终定)
        ▼
 落地审查(脚本: 格式/完整性/红线/镜像检验)  报告三级: 阻断/警告/提示
        │ 阻断 ─▶ 修复 ─▶ 重跑 ─┐
        │过                       │
        ▼                        │
 校对评审(八区审计,依登记册,引证必验真;落盘即建评审台账条目)
        ▼                        │
 三评审·大纲档(作家→读者→编辑,标根因;落盘即建台账条目)
        ▼                        │
 ┌─ 打磨轮 ──────────────────────┤
 │  首轮全评 → 修订 → 存 大纲_v1  │
 │  复评只跑上轮发现问题的评审     │
 │       → 再修 → 存 v2 …         │
 │  超3轮熔断 → 作者逐条裁决落档   │
 └──────┬────────────────────────┘
        ▼ 作者满意
 ★定稿: 大纲_定稿.md + 登记册转正式 + 80/20留白确认
        + 归档三件(建归档//差异集标已完成使命移入/旧版本文件移入;
                  旧轮评审快照默认留评审/作审计证据)
        + 终稿保护(此后只建议不改稿,修改走变更提案)
        + 待验证清单移交卷纲/正文阶段
 (作者可明示跳过评审直接定稿,跳过原因记创作进度)
```

## 五、全程横切机制（不占流程位置，随时在场）

```
 ① 四轨道在场:  人物 ──── 剧情 ──── 金手指/设定 ──── 爽点/情绪
                    (交叉追问边画在轨道之间,追问卡随候选展示)

 ② 回改链路:    下钻受挫 ─▶ 记入【待改清单】(不打断思考) ─▶ 段末清账
                草稿态自由改 │ 定稿后改 → 正式变更提案

 ③ 采风双轨:    主动: 段2步8备资料(题材资料期,引导式batch派researcher)
                被动: 思考流中【待采风】标记 → 段末盘点(段1-5各段末grep汇总)
                两轨结果 → 抽象化 → 作者裁决沉淀(灵感库/世界参照档案)

 ④ 嫁接日志:    每个候选标注 填槽/保核/换皮/反着来/校验 → 随草稿落盘
                (供原创性终检与评审追溯: 哪些来自参考/哪些是原创)

 ⑤ 一段一会话:  段末固定动作 = 清账 → 报告四态 → 断点更新
```
