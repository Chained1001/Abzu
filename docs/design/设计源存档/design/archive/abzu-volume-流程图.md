> 以《abzu-volume-卷纲设计.md》v1.2 为准（大神校准后快照）。图例：`★`=关键产物；`▶`流向；`├─`分支；【】标记；`◀──`回环。
> v1.2 三关键：**双区制**（只锁近端+事件池）、**卷是作家意图的延长线**（对表=回忆自己写过的）、**钩是双向的**（热开场+卷末钩）。

## 一、全流程总览（第 N 卷轮回）

```
 /abzu:abzu-volume [第N卷 | 第N-M卷(连跑≤3,串行)]
   │
   ├─ 读创作进度断点 → 直入该卷段 ◀─────────────────────┐
   ├─ 显式跳卷 → 前卷未完成警告(乱序:跨卷检查降级=正典+登记册) │
   │                                                    │
   │ [卷0] 进场对表（机械+接口枢纽）                       │
   │   ①大纲正典(区块07第N卷行/05/08/10/12/15去向项)       │
   │   ②登记册+欠账(promises义务/挂账清单过滤本卷/          │
   │     待验证清单/世界参照档案待采清单)                   │
   │   ③台账遗留: 触发=本卷→消费(欠账必清,禁静默丢失)       │
   │   ④拆书: Stage2(首次)/Stage3(每卷)缺失→              │
   │     引导式挂起"请运行 /abzu:abzu-teardown"(技能不自动  │
   │     串联) | 前置不可行→延期支(旧格式代用声明)          │
   │   ⑤数据与商业对表(均订/追读/上架节点;采纳派vs隔离派     │
   │     由作者选;问"近期在读什么"→参照输入)  [首卷跳过]     │
   │   ⑥预算行(爽点间隔/高潮位/断档上限)                    │
   │   2b.骨架校准(N≥2): 原方向仍是最佳后续? ─偏差大→提案   │
   │        ("已发生的是现实,骨架是可修订的计划")            │
   │   → ★对表包+★上卷复盘(固定输入) → 断点=卷1            │
   │  ▼
   │ [卷1] 卷功能定位  §5.1→§5.6→§5.5
   │   步0 本卷心动位("早就想写的场面/对决/爽点?"→高优先     │
   │       锚点,冲劲优先于结构匀称;没有→纯结构驱动也合法)
   │   五判据(目标/冲突/主角变化/承上启下/三件)→情节类型骨架
   │   →字数倒推对表(>15%偏差→调内容or提案)
   │   两查: 兴奋阈值(高潮被上卷末透支?)│换图代价(莲花地图法)
   │   → ★区块01-03 → 断点=卷2
   │  ▼
   │ [卷2] 卷内结构·双区制 ★(v1.2核心:只锁近端)  §5.2→§5.9→§5.7
   │   精排区(前1-2章组,10-20万字"剧纲"窗口): 全字段细排
   │     (冲突+不可逆变化+线别+切线点;大案=案组可跨组连号)
   │   事件池区(其余): 待发生事件清单·不排序·只标义务来源
   │   小高潮序列→多线(主绳/汇聚点=卷3高潮位;压力线轮转:
   │     每组只主推1-2线,静默线一句比价维持)→时间锁(可选强度)
   │   →人物调度(含安全阀:可控退场留回归活口)
   │   →情绪落点+弃书对策(含刻度台阶:尺子先于度量)
   │   段末: 四轨道交叉自检(谁的弧断了?金手指有戏吗?)
   │   → ★区块04-08+附表 → 断点=卷3
   │  ▼
   │ [卷3] 高潮与钩  §5.3→§5.4→§4.8
   │   步0 卷首热开场(钩是双向的:开卷前3章重新抓住读者)
   │   大高潮(压放/汇聚/反杀须有promises依据🔴/爽点层次)
   │   →卷末钩(四型/服务主线/接下卷)→伏笔卷级操作(义务逐条
   │     落位;疑似遗忘优先)→情绪债表(可选:跨卷情绪欠条,
   │     "可不推进情节但必须还")
   │   → ★区块09-11 → 断点=卷4
   │  ▼
   │ [卷4] 归档与生长修正
   │   设定演化三通道: 增(入册)│改(派生/提案)│删(deprecated+
   │     引用扫描:零引用就地退役/有引用走提案)
   │   修正分岔(病灶×时态): 本卷就地改│前卷已定稿→提案│
   │     前卷已规划未产出→欠账路由│大纲→提案
   │   登记册卷级追加(六册契约)+遗留销项
   │   → 断点=卷5
   │  ▼
   │ [卷5] 审校定稿
   │   暂存栏清零确认→组装(首件=★一页卷约:主题/功能/高潮
   │     扣子/断卷点/伏笔债/精排窗口)→逐区块diff防缩水
   │   落地审查7项→四席(卷纲档,六参数,真派)→台账建条目
   │   打磨轮≤3(裁决即生成同步点清单/修复分级/复评回归)
   │   → ★卷纲_第N卷_定稿 + ★★三约束_第N卷(分档:精排区
   │     全保真/池区粗约束——滚动细化时追加)
   │   → 登记册formal+台账遗留快照+归档
   │   ★卷末复盘(乌贼式:困难+解法+偏差+下卷注意→下卷对表包)
   │  ▼
   ├─ 开卷判定(主线终局?长线收束?promises归零?人物有交代?
   │   双向陷阱:防稳态收笔/防凑字数续卷)
   ├─ 非末卷 → 第N+1卷卷0 ───(回环)
   └─ 末卷 → 收线全量对表+三线同爆+留白终清 → 正文阶段(三期)
   
 写崩了?(SKILL 21 决策树): 偏离大纲≠崩(先骨架校准,酒徒"丢
   大纲顺着写")→真崩四型: 硬写冲过去+回头缩减(主流,"一修改
   就完蛋")│早期推翻(限前20万字)│边写边修(谨慎)│完本后砍修
```

## 二、双区制与滚动细化（v1.2 核心）

```
 卷N 时间轴: ├────精排区────┤├────────事件池区────────┤
              前1-2章组全字段     待发生事件·不排序·只标义务来源
              (≈10-20万字窗口)   (高潮位/汇聚/钩有粗锚,顺序留活)
                                    │
 正文写到精排区耗尽 ──────────────→ │
   → 重入卷2: 骨架校准→池区下一段升格精排区→细化
   → 三约束追加(该段升全保真) → 继续写正文
   (对应猫腻"写两万字细纲管十万字情节"的滚动节奏;
    亦即 ADR-0001 防过早收敛在卷纲的落地)
```

## 三、作者使用动线（运行期编排）

```
 连载期的一天/一周:
   写正文(abzu-draft,三期) ──精排区耗尽──→ /abzu-volume 第N卷
                                            (滚动细化模式,轻量:
                                             校准→细化→三约束追加)
   一卷写完 → /abzu-volume 第N+1卷 (完整轮回,含复盘输入)
   连跑选项: /abzu-volume 第2-4卷 (一次授权,串行,提案即暂停)

 会话组织建议: 一卷段=一会话(卷0-1 合一段,卷2 一段,卷3-4 一段,
   卷5 一段);断点随时可续(创作进度断点=卷纲·第N卷·卷X)
 数据回路: 卷0 步5b 问数据(采纳/隔离作者选) → 卷末复盘记快照
   → 下卷对表包 → 设计输入 (三卷一循环的反馈环)
```

## 四、卷4 修正分岔（病灶 × 时态）

```
 病在本卷(未定稿)→就地改 │ 病在前卷: 已定稿→变更提案[前卷根源]
   已规划未产出→欠账路由回该卷 │ 未规划→设计输入
 病在大纲→变更提案[主线/规格/设定根源]
 登记册双通道: 补位值(不改语义)=更正记录 │ 改行值本体=提案
 设定演化: 增=入册 │ 改=派生/提案 │ 删=deprecated+引用扫描
```
