# 命名规则

> 预置资产，随插件分发。管所有可命名物：人物(P)/势力(F)/地点(L)/功法·金手指(G)/道具·法宝(I)。称号·道号·绰号**不拿 ID**——走登记册 naming 册的别名列登记（消歧用）。ID 前缀唯一权威=模板统一规范 §二（C=铁则，勿撞）。
> 与知识库附.6《起名清单怎么用》分工：附.6 管怎么起（方法论），本文件管什么不能起+风格偏向（约束）。
> 消费点：段 5 步 1 批量命名（含主角正式姓名——段 1 只定工作代号）、段 5 步 6 登记册 naming 册入册、abzu-draft 章纲生成（新配角命名）。

## 使用方式

题材字段 → 查下表对应题材节 → 硬禁自动过滤 + 软偏好作为候选风格 + 提示信息附注。

**杂交题材路由**：题材涉及多个节时（如"现代都市×超自然悬疑"），**多节合并适用**——各节的硬禁取并集（任一节禁则即禁）、软偏好取交集优先（两节共同偏好优先于单节偏好）、提示取并集。

## 严格程度三级

| 级别 | 含义 | 执行方式 |
|---|---|---|
| 🔴 **硬禁** | 不可违反，违者命名不成立 | 脚本可查（正则匹配禁用词表→自动标红→重新生成） |
| 🟡 **软偏好** | AI 默认执行，作者明示可覆盖 | 候选生成时作为风格参数，标注"可后改" |
| 🔵 **提示** | 信息性建议 | 附注在候选旁，不阻塞 |

## 一、按物类的通用规则（全题材生效）

### P 人物名
- 🔴 禁生僻字（读者念不出=记不住=不订阅）
- 🔴 禁与已有人物别名池撞名（查登记册 naming 册消歧）
- 🔴 禁与参考作品主要人物同名（原创性红线）
- 🟡 二三字为主（网文主流，四字需作者确认）
- 🟡 一人多别名可行（字/号/道号/绰号/化名），但 ID 唯一且 naming 册全量登记
- 🔵 主角名建议避开高频大众名（降低撞名搜索干扰）
- 🔵 **跨物类音近/形近提示**：新名与已有池内所有名（含其他物类）比对——v1 由 AI 逐对自查（拼音首字母＋字形目测；程序化拼音比对与零依赖冲突，待内置映射表后升级）；命中则标"与已有 XX 音近/形近，注意读者混淆风险"（不硬禁——有时故意音近做伏笔，但作者需知情）

### 运行时别名（正文阶段新冒出的称呼）
- 正文中 AI 临场编的新称呼（如敌方蔑称"老不死的"、亲近昵称"老顾"）——**不经过段 3/段 5 命名步骤**，需在 draft 技能回看阶段补管
- **回看·新称呼扫描**：写完一章后扫描本章所有人名/称呼/代称，比对 naming 册别名池：
  - 已在池内 → 跳过
  - 新称呼 → 自动追加（带使用上下文标注：敌方蔑称/亲近昵称/身份代称/故交字号），并检查是否与已有别名撞名
  - 这是动作节点 [登记] 的具体化

### F 势力/门派名
- 🔴 禁与已登记势力撞名
- 🟡 名字暗示势力性质（"宗"=正道修仙、"教"=偏邪、"阁"=情报/暗杀、"殿"=高位、"谷"=隐世）
- 🔵 势力名层级感：小门派不带"天/圣/神"等越级字

### L 地点/地图名
- 🔴 禁与已登记地点撞名
- 🟡 地名暗示地理特征（山/水/城/漠/渊/窟）
- 🔵 新地图名与旧地图名有区分度（防读者混淆）

### G 功法/金手指名
- 🔴 禁与已登记功法撞名
- 🟡 名字暗示能力属性（火系→炎/焰/灼；暗系→影/幽/冥）
- 🟡 功法名与境界体系命名风格一致（同一世界观内不混搭）

### I 道具/法宝名
- 🔴 禁与已登记道具撞名
- 🟡 品级暗示（凡品简洁/灵品带灵字/仙品带仙或古字）
- 🔵 消耗品与法宝的命名长度区分（消耗品短、法宝长）

### C 称号/道号/绰号
- 🔴 禁同句式碰撞（如"守钟人×守阁人"——已有碰撞需作者裁决+禁则兜底：naming 册登记后同句式不再新增）
- 🟡 称号暗示人物特质或来历（"翻谱人"=家传恩债、"守钟人"=立制者）
- 🔵 绰号比道号更口语化

## 二、按题材的偏向规则

### 古代架空 / 东方修仙
**人名**：
- 🔴 禁现代词汇：手机、电脑、公司、微信、QQ、OK、有点东西、yyds、绝绝子、emo
- 🔴 禁现代姓名结构：三字名中带"婷/轩/浩/子涵/梓萱"等现代高频名（2000 后取名热词）
- 🟡 偏古雅：可用单名+字/号（如"拾，字守拙"）
- 🟡 可带姓氏文化（复姓稀有但可用：慕容/上官/司马）
- 🔵 示例风格：顾拾、纪炎、墨守、守拙、玄诚

**门派/功法/地名**：
- 🔴 禁现代地名（北京/上海/纽约——除非穿越设定）
- 🟡 功法名偏四字（"长生不灭""熬天诀"）
- 🟡 地名可用古雅字：澜/渊/墟/墟/岳/巅

**称号**：
- 🟡 道号偏"×人/×子/×叟/×翁"（但禁同句式重复）
- 🟡 绰号偏形象化（"老扫帚""翻谱人"）

### 都市/现代
**人名**：
- 🔴 禁过度文言（之乎者也类）
- 🟡 常见现代名，与年龄段匹配（90后父母取名风格）
- 🔵 可用网名/花名/英文名（但 ID 唯一）

**门派/组织**：
- 🟡 公司用"×公司/×集团/×工作室"，地下组织用"×会/×帮"

### 科幻/未来
**人名**：
- 🔵 允许字母数字代号（如"K-7""Alpha"）
- 🟡 可混编（中文名+英文名/编号）

**科技/地点**：
- 🟡 允许缩写和代号（"NT-域""星环-7"）

### 西方奇幻
**人名**：
- 🟡 音译风格（"艾瑞克/塞西莉亚"）或纯中文风格但避免东方味
- 🔵 可用姓氏+封地（"艾瑞克·风语者"）

**组织/地点**：
- 🟡 用"公会/教会/议会/王国/领地"

### 悬疑/推理
**人名**：
- 🟡 正常现代人名，避免过于花哨
- 🔵 可用有暗示性的名字（本格推理传统）

### 女频（古言/现言）
**人名**：
- 🟡 女性名偏柔美（可用叠字/花字/月字），男性名偏清冷/温润
- 🟡 古言中可用"×姑娘/×公子"称呼体系
- 🔵 现言可用小名/昵称/英文名

## 三、命名生成时的执行流

```
1. 读题材字段 → 确定本节适用的题材规则集
2. 读登记册 naming 册 → 已有别名池（消歧用）
3. 生成候选（附.6 起名清单的方法论 → 候选 2-3 个）
4. 硬禁过滤（🔴 规则逐条检查 → 违者重生成）
5. 软偏好排序（🟡 规则作为风格参数 → 优先符合者）
6. 提示附注（🔵 规则标注在候选旁）
7. 作者裁决 → 正名+别名全量入 naming 册
```

## 四、文件模板规范（供命名规则自身维护用）

- 题材节结构：`### {题材名}` → 人名/门派功法地名/称号三小节 → 每条规则标 🔴🟡🔵
- 新增题材：复制现有节结构，填写该题材的禁用词表+风格偏好+示例
- 新增物类：在第一节加对应小节，与登记册前缀对齐
- 示例维护：示例风格行应与该题材的知名作品命名风格一致
