## 进场

1. 检查当前目录是否存在 `项目基准/创作进度.md`
2. **存在** → 读该文件"当前断点"节 → 按路由表跳到对应段
3. **不存在** → **先做骨架预检**（见下），再从步骤 1 开始执行

**骨架预检（前置，2026-09-29 裁定：拆书在前）**：

| 检查 | 结果 | 处理 |
|---|---|---|
| `参考作品/{书名}/` 三件套（骨架/拆书笔记/反面清单） | 齐全 | 直接进入问卷 |
| 缺失（或目录不存在） | — | 先引导运行 abzu-teardown 完成快速通读（**原文由拆书进场入库：复制或外置登记，段 0 不再过问原文**）→ 拆完回来做问卷 |

预检只问作者书名（"参考作品是哪本书？书名+作者"）——书名定了才能查目录；原文路径、合法持有声明都归拆书进场。

## 步骤 1 问卷（六字段——L4 混合分组呈报，2026-10-01 交互标准改造：六连问→一表呈报+开放追问）

**呈报形态（标准形）**：可枚举字段（题材推荐／篇幅档／灵感库三选／参考作品在位状态）**预填推荐值后一表呈报**（L4——每行：字段｜推荐｜改法提示，作者逐行 ✅/改）；**开放字段（书名+定性／念头／红线细节）表后单独追问**（L2——创作输入禁进选项表）。

**开场一句（兜底规则 6 的明示化）**："想快就回'**都用默认**'——我按推荐值一次填完（每项标'可后改'），你只纠错。"

### 字段 1：参考作品

**问法**："参考作品是哪本书？（请提供书名+作者）"（预检时已问过则跳过）

**追问一句定性**（类型锚，2026-09-29 大奉误判教训）："这本书你会怎么一句话定性它？（比如'玄幻升级爽文'/'都市脑洞文'——说个大概就行）"——**作者定性＝类型锚点**，存基本规格；骨架消费时与拆书结论对照，**不一致即警报呈作者裁决**（AI 先验常被出圈开头带偏——作者通常知道参考作品的真实类型）。

**输入解析**：
| 作者说 | 处理 |
|---|---|
| 明确的书名+作者 | 直接采用 |
| 只有书名无作者 | 采用书名，作者栏标"待补" |
| 多本书 | 取第一本为主要参考，其余记"次要参考" |
| "还没想好" | 回复"想好了再来运行本技能" → 报告四态：需要你处理，本段终止 |

原文入库已在预检/拆书完成——本字段只记书名与拆书产物在位状态。

### 字段 2：题材

**问法**："这本书是什么题材？"

**输入解析**：
| 作者说 | 处理 |
|---|---|
| 明确题材 | 直接采用 |
| 复合题材 | 采用原文，标"杂交题材·段 4 标尺按杂交合成规则处理" |
| 与参考相同 | 采用，标"同题材——段 1 差异走换变量路线不走迁移路线" |
| "都行/你推荐/不知道" | 执行下方**方法论驱动的推荐** |

**方法论驱动的推荐**（仅"都行"时触发）：

1. **加载方法论**：读知识库 `01_开书.md` §1.7（题材元素怎么组合出新意）核心卡 + "常见思考路径"表
2. **收集输入**：读骨架嫁接空位表"题材外壳"行的"可替换方向"列（骨架已由预检保证在位；若该行空缺→降级：只用 §1.7 路径推荐，不引骨架原文，注明"骨架无题材空位"）
3. **读念头**：检查基本规格（此时只有字段 1）——字段 6 的念头是否暗示方向
4. **匹配路径**（按 §1.7 的路径表匹配，不自己发明）：
   - 念头暗示了明确方向 → 沿该方向从"可替换方向"列找对应题材
   - 无念头 → 取"可替换方向"列中与参考差异最大的
5. **呈现格式**：
   ```
   推荐题材：{X}。
   依据 §1.7 路径"{路径名}"：{一句话理由}。
   骨架可替换方向：{从骨架复制的原文}。
   你觉得行吗？（后面想改随时改）
   ```
6. 标"可后改"

### 字段 3：篇幅

**问法**："目标篇幅？（100 万 / 200 万 / 300 万+）"

**输入解析**：
| 作者说 | 处理 |
|---|---|
| 明确数字 | 采用 |
| "越长越好/不确定" | 默认 200 万，标"可后改" |
| "跟参考差不多" | 读骨架·基础信息·总字数 → 取最近档位 |

**收到后机械操作**：
1. 读 `references/参考标尺.md` 第四节"衰减系数"表
2. 匹配系数，按以下格式输出：

```
篇幅 {N} 万字，衰减系数 ×{K}。
换算：单章 3500 字（五书中位，2026-10-02 校准）× 日更 4000 字 ≈ {N×10000÷3500} 章 ≈ {N×10000÷4000÷30} 个月。
```

单章字数口径此时为初定（标"可后改"）；**段 4B 步 7 分卷预算前锁定，锁定后变动走变更提案并重算全表**。

### 字段 5：灵感库（双库，2026-09-29 裁定）

**问法**："灵感库怎么弄？A. 新建本书专属空库 B. 指向你已有的全局灵感库（我只记路径，不复制） C. 两个都要——全局库做底，本书再建专属库"

| 作者说 | 处理 |
|---|---|
| A / 新建 | 创建书内 `灵感库/`（索引+六类子目录，模板见下） |
| B / 有全局库 | 索引.md 记**全局库指针**（绝对路径），不复制任何文件；跨书通用零件直接读全局库 |
| C / 都要 | 全局指针＋书内专属库并存：检索顺序=书内→全局；沉淀时"跨书通用→全局库、书专属→书内"由作者裁决 |
