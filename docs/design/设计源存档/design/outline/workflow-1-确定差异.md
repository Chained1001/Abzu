## 静默准备（四个来源，前三个有方法论驱动，第四个纯机械）

### 来源 A0：类型定性对照（机械，最先做）

读骨架·类型占比表＋引擎/载体/表象三层 → 对照基本规格·作者类型锚：
- **一致** → 照常进行
- **不一致**（如拆书结论"悬疑主导"vs 作者锚"玄幻升级爽文"）→ **警报呈作者**："拆书把《X》定性为{A}，你的定性是{B}，引擎判定/占比数据是{表}——以谁为准？"（通常是拆书被开局钩子带偏——修正骨架定性后再继续）
- **反面清单消费门禁**（2026-09-29 沙盘实测补）："类型漂移/类型演变"类条目**无读者流失数据时不得进 B 组修复项**（大奉教训：原"守住 60% 探案"建议正是误判的制度化——教新作者把载体焊死成引擎、避开参考作品主体）；此类条目只作备忘呈作者
- 取材层级标注：后续差异候选凡取自参考作品，标**取自引擎/载体/表象**——**取载体放大为核心时，强制引擎自造检查**：新书的引擎强度是否对标参考引擎强度？（不对标=放大了一个 10% 的表象却丢了 90% 的动力——嫁接日志记此操作）

### 来源 A：题材迁移差异

**加载方法论**：读知识库 `01_开书.md` §1.15（拆完怎么变成自己的）核心卡

**机械比对**（先做，不涉及创意）：
1. 比较基本规格·题材值 vs 骨架·基础信息·题材标签值
2. **相同** → A 组菜单只显示"同题材，无迁移项。差异走换变量路线。" → A 组完成
3. **不同** → 继续下方步骤

**方法论驱动操作**（§1.15 的"借魂不借形"框架）：
1. 从拆书笔记·意图层提取"可迁移的魂"——§1.15 路径"拆底层逻辑"：{意图层的核心爽感}
2. 从骨架嫁接空位表"题材外壳"行提取"必须换的皮"——§1.15 路径"换视角/加变量"
3. 生成四层迁移清单（机械格式化，不需要创意）：

```
魂（保核，§1.15"借魂"）：
  {意图层核心爽感}

皮（必换，§1.15"不借形"）：
  {骨架题材外壳元素} → {新题材对应物}

知识杠杆（必答题）：
  参考作品杠杆 = {从意图层或机制层提取}
  迁到{新题材}后 → {保留 / 需 redesign → 方案}
  §1.15 检验："换个背景，核心爽点还在吗？"
```

### 来源 B：反面清单修复项（纯机械）

1. 读反面清单的骂点清单表每一行
2. 逐条生成修复建议格式：`"{具体动作}，防止{骂点}重演"`
3. 汇总成 B 组表（# / 骂点 / 建议 / 严重度）

### 来源 C：换变量扫描

**加载方法论**：读知识库 `01_开书.md` §1.7（题材元素怎么组合出新意）核心卡 + "常见思考路径"表

**匹配到当前上下文**：
1. 读骨架嫁接空位表每一行
2. 按 §1.7 的五条路径（换金手指/换视角/换人物关系/类型杂交/换表现方式），对每个空位逐条匹配：
   - 嫁接空位"金手指"行 → 匹配 §1.7 路径"换金手指"
   - 嫁接空位"视角"行 → 匹配 §1.7 路径"换视角"
   - 嫁接空位"人物关系"行 → 匹配 §1.7 路径"换人物关系"
   - 嫁接空位"题材外壳"行 → 匹配 §1.7 路径"类型杂交"
   - 嫁接空位"表现方式"行 → 匹配 §1.7 路径"换表现方式"
3. 每个匹配生成候选，按 §1.7 的判断标准初筛："读者看了开头能否立刻 get 到与经典版的区别？"
4. 念头命中的候选置顶标★

**§1.7 过门**（C 组汇总后检验）：
- 检验方法："读者看了开头，能不能立刻说出这和{参考作品名}有什么不一样？"
- 不过 → 换变量太弱，回到步骤 2 换更强的路径

## 问 3 核心画面推导

**加载方法论**：读知识库 `01_开书.md` §1.1（种子从哪来）核心卡 + "常见思考路径"表

**匹配到当前上下文**：
1. 从 §1.1 的八条路径中，按以下规则匹配（不自己发明路径）：

| 条件 | 匹配路径 |
|---|---|
| 差异集有多个不同元素要组合 | 元素缝合法 |
| 差异集换了题材外壳但保留结构 | 旧瓶装新酒 |
| 差异集颠覆了参考作品的经典设定 | 经典反转 |
| 念头里有明确的高光片段 | 情节片段式 |
| 差异集有极强的单一核心卖点 | 核心看点式 |

2. 用匹配到的路径方法生成 2-3 个画面

**§1.1 检验**（生成后逐个检验）：
- "把种子讲给别人听，对方会不会问'然后呢？'"
- 会 → 种子有画面感，通过
- 不会（"哦，知道了"）→ 还是设定空壳 → 换路径重新生成

**呈现格式**：
```
用 §1.1 路径"{路径名}"，我推出了这几个开局画面：

画面 1：{3-5 句}
画面 2：{3-5 句}
画面 3：{3-5 句}

——哪个是你想写给读者的第一幕？
```

| 作者说 | 处理 |
|---|---|
| 选某一个 | 记录 |
| 都不满意+说了原因 | 换路径重新生成 |
| 都不满意+没说原因 | "哪里不对？"（本段唯一开放追问）→ 得到答案后重推 |
| "都行" | 取画面 1，标"可后改" |

**选定后机械操作**：
1. 从画面提取 2-3 字代号（取核心意象物/核心动作）
2. 提议："这个主角总得有个称呼——提议「{代号}」"
3. 检查暂存栏相关项 → 有则提示捞回

## 问 4 一句话故事

**加载方法论**：读知识库 `01_开书.md` §1.9（一句话故事怎么写）核心卡 + "常见思考路径"表

**匹配到当前上下文**：
1. 从 §1.9 的四条路径中匹配：

| 条件 | 匹配路径 |
|---|---|
| 差异集有清晰的欲望-阻碍-代价结构 | 四要素法 |
| 差异集有颠覆性的假设 | 如果问句法 |
| 差异集反了参考作品的经典套路 | 反预期法 |
| 差异集有清晰的因果推进链 | 链条法 |

2. 用所选路径的方法构造一句话故事
3. 用 §1.9 的判断标准检验（不自己发明标准）：

| 检验 | 方法 |
|---|---|
| 四要素齐 | 主角/欲望/阻碍/代价各是什么？ |
| 复述测试 | 讲给别人听，对方能否复述出主角+欲望+阻碍？ |
| 长度 | 两句话以内，压到 25 字更好（但四要素优先于字数） |

**呈现格式**：
```
按 §1.9 路径"{路径名}"，这本书的一句话故事是：

「{故事}」

四要素：主角={X} ｜ 欲望={X} ｜ 阻碍={X} ｜ 代价={X}

——和你想写的是同一本书吗？
```

| 作者说 | 处理 |
|---|---|
| "是" | 确认，进入问 5 种子验证 |
| "不是"+说了哪里 | 修正该处 → 重新呈现 |
| "不是"+没说 | 回到问 3 重推画面 |
| "都行" | 确认，标"可后改" |

## 问 5 种子验证

**加载方法论**：读知识库 `01_开书.md` §1.8（种子怎么验证）核心卡

**匹配路径**（§1.8 四条测试路径）：

| 测试 | 方法 | 本段执行？ |
|---|---|---|
| 一句话测试 | 能一句话说清这个故事吗？ | ✅ 已由问 4 覆盖 |
| **三百字测试** | 写 300 字开头 | **✅ 本段核心测试** |
| 自问测试 | AI 模拟读者——想看下一章吗？ | ✅ AI 代执行 |
| 三章测试 | 写前三章细纲+第一卷大纲 | ❌ 标【延后】→ 正文阶段 |

**执行**：
1. 问作者："要不要写 300 字试试这个开头？**测试通过后这段就是你第一章的底子，不白写。**（这是测试点子，不用写好，写爽就行）"
2. 无论谁写（作者自写 / 作者"都行你写"→AI 代写），完成后 AI 都执行两道检验：
   - **作者侧**："写的时候激动吗？想继续吗？"（作者自写版直接问；AI 代写版观察作者读了几遍）
   - **模拟读者侧**：AI 用通用男频画像跑自问："想看下一章吗？"并指出扣分项（模拟读者用通用画像，段 2 画像定稿后自问口径随之升级）
3. 测试不过 → 告知"点子不过不等于字白写——金句、意象、基调进灵感库，画面重推时可带走" → 返回问 3 重推画面或问 2 调差异

**§1.8 过门**："本段应过三项（一句话已覆盖/三百字/自问）全过即过门；三章测试已标延后正文阶段补。三百字或自问不过→回问 3/问 2，不进段 2。"（通过的 300 字底子**落盘至 基本规格.md 段1 追加节"种子底子"字段**——原文保存，跨会话可取；draft 步 0 首章建档门自动呈上作锚点候选，2026-10-01 接线）

**这是段 1→段 2 过渡前唯一的创作动作——从分析切到动笔，防纯分析疲劳。感情投射在这里结晶。**
