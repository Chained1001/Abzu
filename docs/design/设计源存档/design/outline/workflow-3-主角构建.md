## 步 1-9 九件事（L4 三组分组裁决——2026-10-01 交互标准改造：九连裁→三组呈报）

每件事统一执行模式：

```
加载 §X.X 核心卡 → 匹配路径 → 用路径方法出 2-3 候选 → 呈现 → 作者裁决 → 过门
```

**呈报分组**（三组各一次分组菜单，组内逐项 ✅/换/深挖；🔴 分歧项与主攻项仍逐项 L3）：

| 组 | 含 | 呈报要点 |
|---|---|---|
| 一·主角内核 | 步 1 身份／2 欲望／3 缺陷 | 三件事互为因果（§2.1-2.3）——同表呈报，改一项看联动 |
| 二·世界底盘 | 步 4 世界四件／5 力量体系／6 天花板 | 一次呈报＋穿帮检查表随附 |
| 三·金手指与弧光 | 步 7 金手指★（主攻项）／8 衔接／9 成长弧 | 金手指插队逐项（L3 带推荐）；衔接+成长弧同表 |

> 网状思考保留：三组不是串行流水——作者在任一组提另一组的事（"缺陷定了金手指也想好了"）→ 即时联动改表，不"等下一组"。

### 步 3 缺陷

**加载**：§2.3（主角缺陷怎么写）
**输入**：从欲望反推（§2.3 主路径）
**§2.3 过门**：缺陷能造成不可逆损失

### 步 4 世界铁则+暗面+地图+势力

**加载**：§3.1（世界铁则怎么定）+ §3.8（世界观暗面怎么用）+ §3.4（世界地图怎么预置）+ §3.5（势力怎么分布）+ §3.6（世界规则怎么不穿帮）
**输入**：题材标配 × 骨架规则层 × 差异集迁移项

**铁则设计**（§3.1 框架）：
- 3-5 条，每条必填作用域（约束谁）
- 数值挂【待回填：步 5 定后回写】

**暗面设计**（§3.8 框架）：
- 对每条铁则追问："**谁在这条规则下受害/被压迫/付出代价？**"
- 暗面不是随意的黑暗设定，是**铁则的必然代价**
- 暗面是主线对手的滋生环境（§3.8："暗面要具体、绑定成长弧"）

**地图预置**（§3.4 框架）：四要素（地图资源/场景氛围/权利规则/势力划分）搭世界空间框架——后续分卷在此基础上细化
**势力分布**（§3.5 框架）：按五类功能（正派/反派/中立/弱派/工具势力）配置
**穿帮检查**（§3.6 三步）：铁则之间不矛盾｜暗面与铁则因果成立｜势力与铁则一致

**§3.1+§3.8+§3.4/3.5/3.6 过门**：规则统一不穿帮；作用域必填；暗面与铁则因果关系成立

### 步 7 金手指 ★主攻项

**加载**：§2.4（主角金手指怎么设计）核心卡 + 六路径表

**匹配**：

| 条件 | 路径 |
|---|---|
| 差异集要跳过重复过程 | 跳过枯燥型 |
| 差异集强调代价与限制 | 有限制型 |
| 差异集要求社交互动 | 逼互动型 |
| 金手指本身会制造新问题 | 长新问题型 |
| 金手指是欲望的具象化 | 欲望替身型 |
| 金手指设定最不合理、需再包一层内在合理性（把"凭什么"弱化掉） | 包合理性型 |

**交叉追问卡**（四轨道）：
- 情绪轨：兑现主情绪吗？
- 剧情轨：怎么长出新困境？
- 设定轨：在体系哪一层、受铁则什么限制？
- **猫腻三连**：它给主角什么安全感 → 杀死什么矛盾 → 怎么再造可控不安全感

**§2.4 过门**：四判据（替读者跳过想跳的/长新困境/逼互动/人生轨迹变了吗）

## 通用机制

**主攻项插队回填**：追问卡指向后面步骤的产物 → 标【待回填：步 N 定后补】→ 对应步骤收尾时当场回填

**卡点三板斧**：①换路径（§X.X 路径表换一条）②角色代入假设 ③向上记账

**解卡反哺**：解开后副产品直接改写目标文件并注明"此条由步 N 解卡反哺"

**暂存捞回**：进场时读了暂存栏 → 九件事中遇到相关场景 → "暂存项「{名}」在此适用，捞回吗？"
