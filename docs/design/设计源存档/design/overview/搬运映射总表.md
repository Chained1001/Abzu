# 搬运映射总表（设计期 → 运行期）

> 版本 v1.0 ｜ 2026-09-29 ｜ 五路整体审查就绪度路产物——"设计与实现之间的搬运层"的唯一权威 ｜ 分发脚本的输入规格
> 用法：里程碑 A 分发脚本按本表执行；改设计文件后重跑分发即同步

## 一、总则

- **单一源**：docs/design/ 为唯一编辑源；sources/ 为聚合中转（知识库+agents 的运行态名）；skills/*/references/ 为分发终点。分发单向，禁止手改终点
- **设计期→运行期转换三规则**（剥离）：①头注剥离——`> 版本 v…`起的引用块整块删（运行期版本在 frontmatter）；②链接改写——`docs/design/…`/`../research/…` 相对链接改 `references/…` 或删除（末行技术备注可整行删）；③标题去"（设计稿）"字样。正文其余逐字保留 ④变更记录节整节删——设计期历史（含设计仓路径引用）运行期零消费（2026-10-02 审查修复 P1-5 增补）
- **frontmatter 添加规则**（三份缺 frontmatter 的 SKILL 补写；agents 见 §四）：
```yaml
---
name: abzu-teardown   # 或 abzu-volume / abzu-draft
description: {一句话中文职责，≤1024 字符}
disable-model-invocation: true
---
```
（abzu-outline 的现有 frontmatter 补 `disable-model-invocation: true`）

## 四、agents frontmatter 规范（sources/agents/ 与技能内嵌 agents/）

```yaml
---
name: proofreader          # 英文小写连字符（§二映射表）
description: {任务书 §6 表的 description 值，中文}
model: {sonnet|opus 分层值——按任务书 §6}
tools: Read, Grep, Glob    # researcher 加联网；scanner/writer 加受限写路径声明
disable-model-invocation: true
---
```
正文=任务书全文（剥离规则 §一 适用）。tiers/ 细则文件无 frontmatter（references 性质）。

## 六、CI 检查项与分发白名单
