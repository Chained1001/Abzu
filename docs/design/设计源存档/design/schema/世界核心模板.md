4. **底线式考据**：常识层不出错、大方向不能错——不按史学层设阈值
5. **正文期增长**：新组织/新地图（各按分立模板建卡）/新境界（境界表追加 V 行）/新铁则（铁则表追加 C 行）随卷出现（卷4 设定演化增通道）→ 建卡或追加行＋登记册入账＋消歧先行；**组织分级同人物 SABC**：S/A 级建卡，B/C 级不建卡（一句话入 facts 势力行）
