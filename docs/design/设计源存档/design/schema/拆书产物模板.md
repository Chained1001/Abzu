  "emptyChapters": [], "noiseChapters": [], "splitChapters": [],
  "authorNotes": [ { "chNum": 0, "index": 0, "noteLines": 0 } ],
  "volumeSummary": { "卷号": { "start": 0, "end": 0, "count": 0, "chars": 0 } },

## 二、章节索引.csv（Stage 1a 建列→1b 回填；参考作品/{书名}/章节索引.csv）

产出 `章节索引.csv`。**规范表头串（单一权威常量，与 index.mjs HEADER 恒等——2026-10-02 对齐批，以脚本为准）**：

```
全局章序,卷号,卷内章号,章名,字数,参与人物,位置标记,一句话摘要,sha256,剧情强度,情绪类型,备注
```

- 1a generate 建全 12 列（参与人物/位置标记/一句话摘要/剧情强度/情绪类型/备注留空）→1b 轻扫回填前三者；Stage 3 可选回填剧情强度/情绪类型；备注列固定前缀两个——`类型:{值}`（七类单源：探案/战斗/升级修炼/权谋/装逼打脸/日常/感情；混合打星号；感情＝恋爱感情线、亲情归日常；设定灌输章归升级修炼——2026-09-29 大奉定性误判教训的机械修复）、`状态:空章`/`状态:污染`（1a 标，派工跳过）
- 摘要或人物含逗号/引号时整格双引号包裹，内部引号翻倍；位置标记以 `位置:` 前缀记入位置标记列

## 章节速览.md（可选投影——作者读的速览）

Stage 1d 骨架确认后可产：三列（章号/章名/一句话摘要），由 章节索引.csv 直接投影导出，不含 hash 等工程列；只读投影，不另维护——索引更新后重导一次。

示例（1b 回填后）：
```
1,1,1,"第一章 骡铃",3200,"韩立,七玄门",位置:L1-L86,"二愣子被叔父带上山参加考核",{章sha256},,,
2,1,2,"第二章 骡铃",2800,"韩立,墨大夫",位置:L87-L195,"韩立被墨大夫收为弟子",{章sha256},,,
```

> 表头串门禁（generate/verify/断点解析三处逐字恒等——verify 查表头/行数/列数/sha/摘要长度；摘要建议 50-100 字）。
