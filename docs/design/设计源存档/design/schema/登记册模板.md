# 登记册字段 schema

> 版本 v1.0 ｜ 2026-09-28 ｜ 来源：test2-7 实例回写（三轮沙盘演化收敛的格式，非从零设计）＋ 模板统一规范
> 运行形态：**.md 为主**（人读＋AI 读，脚本按 Markdown 表格解析）；.jsonl 为**运行时缓存**（脚本从 .md 解析生成，不手编、可随时重建、不进分发）。裁定依据：架构对齐审计 #2

## 通用纪律（六册同守）

1. **只追加不修改**：既有行永不改写；修正走文末 `## 更正记录` 节（追加行：日期｜台账ID｜条目ID｜更正内容）——评审驱动的修正通道（test2-7 评审沙盘实证）。**双通道边界（卷6 沙盘成文）**：补位值（补截止/补复响位/口径注记等**不改语义**的补充）＝更正记录通道；改行值本体/改语义/删行＝变更提案通道（终稿保护联动）——拿不准时按"语义是否变化"判
2. **消歧前置**：新条目入账前先与已有条目＋别名池匹配，匹配不上才新建；ID 一次性分配永不复用，作废条目保留行标 `已废弃`
3. **frontmatter**：`id`（facts/promises/...）/`type: ledger`/`status: draft → formal`（段6 步6 转正，此后与终稿保护联动）/`version` 整数递增
4. **known_by 三态**：`知道：…｜怀疑：…｜隐瞒：…（对谁）`——三态分写，"对谁"必填（校对评审区3 查 POV 泄漏的依据）；无内容写 `无`
5. 章位可写区间（`541-620`）或约数（`≈50`/`471+`）；双值写法 `400（临终证词）/540（遗案立档）`（事件双落点先例）
6. **设定主键互引**：同一设定物在多册各现一面时（如扮演法=rules 铁则+promises 伏笔+G 机制三行），各行互引同一 SID：行内记 [SID:{设定名}]——修订时按 SID 全册检索联动。依据：诡秘扮演法五面目四册分立（F6·2026-10-02 反测）

## _总目.md（册首索引）

- ID 前缀映射表（前缀｜对象｜所在册）：P 人物（仅 S/A 级建卡；**B/C 级一句话直接入 facts 人物行**——一行即档，不建卡；2026-10-02 明示落点）｜F 势力｜L 地点（大图级）｜G 金手指｜I 道具｜E 关键事件｜FS 伏笔｜V 阶位｜C 铁则｜卷/章用自然键不拿 ID
- 消歧规则（编号条目：别名匹配→称谓映射→B/C 级不拿 ID→永不复用）
- 六册清单（册｜内容｜初始化来源）

## promises.md 伏笔册（单表）

> **债类型标记**（2026-10-02 oh-story 吸收）：行加 `债型：FS｜SD`——FS=情节种子（埋了要收），SD=情绪欠条/打脸债（“可不推进情节但必须还”，原话断言·谁说的·预定兑现）；批1 A.3 到期视图同屏过滤（SD 到期=该还嘴债）；卷级批读者席对账。

列：**ID｜内容（一句话）｜埋设位｜揭晓位｜截止章｜挂靠（实体 ID＋挂靠面，值域见下挂靠列纪律）｜提醒节奏｜状态**（F4·2026-10-02 反测）

- 纪律（册首引言固化）：条条有截止章节（"登死账"）；埋设后每 10 万字（≈40 章）至少一次还账暗示；截止 ≤ 全书章数预算（字数÷单章档换算）。**提醒轻重递进语法**（提醒节奏列的写法，§4.8 火候判据量化）：每条提醒标轻重——`一句带过`（早期/刚埋）→ `半场景`（中段）→ `正面回忆`（临近截止——可正面帮读者回忆）；**离截止越近提醒越重越频**；挂设定上的伏笔（无人物载体）提醒加密一档
- **链式注记**（提醒节奏列写法扩充）：A 条的揭晓位=B 条的埋设位时，A 行提醒节奏记 `↘{B 的 ID}`（一喂多线记多个 ↘——诡秘 237 一页日记喂三线实证）；**截止章补充口径**：设定型长线（神明层伏笔等无逐条截止的设定锚）允许"区间＋卷锚"写法（如 `400-600·卷4 锚`）——作者卷大纲"拉旧线/设新伏"无逐条表（F13·2026-10-02 反测）
- **明/伪装标注**（提醒节奏列——每条提醒可标）：明=按字面轻重执行；伪装态=以玩笑口吻藏真伏笔，**按字面轻重执行会毁信息差**（龙族老唐实证）（F26·2026-10-02 反测）
- 揭晓位/截止章支持双值（事件双落点）；**状态受控值**（2026-09-30 三处口径归一，沙盘复合态入域）：`已埋／已提醒·卷{N}／已回收／部分回收·待{章}／疑似遗忘／已废弃`——volume 主设计 §5 状态流转与批1 伏笔到期视图均引此值域
- **挂靠列纪律**：挂靠对象=登记册任意实体 ID（P/I/F/L/C/V/G/E）——伏笔的天然锚可能在任何设定物上：法则型挂 C（诡秘扮演法式）、地点型挂 L（卡尔德隆城式）、道具型挂 I；挂靠列记 {ID}＋挂靠面（该设定的哪个侧面被用作伏笔）；人名/势力名混入=错——人名先经 naming 册正名对照换 ID 再入列——依据注：诡秘三层伏笔天然锚大量落在法则与地点（反测报告_诡秘 缺口2）（F4·2026-10-02 反测）
- 册尾两个固定节：`反转挂账索引`（R←FS 映射——**写入步**：段5 步6 从大纲区块11 编↔挂伏笔列逐行转译初始化；章0 步4 新反转落章时同步追加；**消费**=批1 A.3 反转位距行，2026-10-02 闭环）＋ `更正记录`
