# 行文规格（本书的行文默认——文风基准未申报的维度按本规格走）

## 一、分段（排版五判据（2026-10-02 正名——原标四实五））

1. **一事一段，镜头自然断**（手机竖屏 3-4 行为常态参照——非硬限）
2. **一人一段**：换人说话必换段；引号跨段按国标（每段前引号、仅末段后引号）
3. **转场三档**：同场景微转换=换段｜时间小流逝=**空行**｜大切换（地点/视角）=居中分隔符（`*` 或 `---`）+新场景前三句给新时空（关门句）+**门后重提示**（前三拍内重提跨门活约束——EST）
4. **长短段随情绪 beat 交替**——忌连续 5 段等长（AI 通病之首，脚本可测）；紧张拆句多换行、舒缓长句大段落
5. **单句成段=重拍工具**——留给金句/章末钩/情绪锤；不作默认（段评时代：金句独立成段才可截图可传播）

## 二、句级（中文自然化四判据——思维操作而非规则）

1. **让动作直接出现**：删"进行了/做出了"类名词化壳——先问"这里发生了什么、谁做的"，按事件顺序组句。保留项：含完成态/状态义的名词化不删（"完成校对"≠"校对"）
2. **抽象标签展开成做法**：说不出具体所指=概念空转——展开成动作/画面（"内心紧张"→"手里的稿子攥皱了"）。**护栏：展开的细节必须出自画面预演/场景表/设定，不凭情绪标签编现场**
3. **做事的人接上动作**：主语与谓语相邻；无主句漂移/主语频繁更换=镜头晃（POV 的句级落点）。保留项：被动句本身没错（"钱包被偷了"关心遭遇）
4. **按意思停顿**：一句含几件事先看清楚；停顿处=事情发生变化的地方；换了事才断句——**气口=思维单元边界**（非句长目标）

## 三、指称维持

1. 主语链：话题人物可承前省略（汉语零形回指），竞争人物在场时显式姓名——判据来自 §7.13（九张汉语卡背书）
2. 新实体首现给全名+身份锚（naming 册登记名），此后可用别名（naming 别名列）
3. 代词/姓名/描述的选择是中心连续信号——错配=读者推断负担（中心化理论）

## 四、事实层口径（文风不可覆盖区）

- **字数档**：单章 {N} 字（段 4B 锁定；变动走变更提案）——事实层，文风基准不可覆盖
- **工程词隔离**：tier1 全禁（章纲·情节点·登记册等）——事实层
- **禁入信息**：known_by 不可见项——事实层
- **章末写入节序**：正文区→作话（可选）→章末写入→附件——三处提取范围=正文区

## 五、与文风基准的关系

- 本规格=**默认层**；文风基准=**个性层**（叙述者画像/锚点/保留技法）
- 文风基准"保留技法"申报的偏离（碎段风/长段风/三连锤等）覆盖本规格对应条目——tier 扫描豁免以申报为准
- 冲突裁决：事实层（§四）> 文风基准 > 本规格默认 > 通用手法
