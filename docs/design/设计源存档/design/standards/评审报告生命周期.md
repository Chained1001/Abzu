# 评审报告生命周期

> 版本 v0.1（沙盘反推稿）｜ 2026-09-28 ｜ 管辖范围：评审报告从产生到销项到跨阶段消费的全生命周期
> 依据：test2-7 沙盘观测报告（四席真跑+两轮打磨+卷纲消费实测——沙盘已清空，结论已内化本文）＋[代理设计规范](./代理设计规范.md) §4 交互契约
> 上游：workflow-6 审校定稿（流程侧）；本文补其未定义的"报告后半生"

## 1. 总则：双层结构（沙盘结论 A/B 之争的答案）

评审产物分两层，职责不同、缺一不可：

| 层 | 载体 | 性质 | 内容 |
|---|---|---|---|
| **快照层** | 两目录方案（唯一口径）：校对席→`评审/校对评审/{对象类型}_第{N}轮.md`；三评审席→`评审/三评审报告/{对象类型}_第{N}轮_{席位}.md`（对象类型受控值=outline｜volume-{N}｜chapter-单元{N}——**volume 快照名=volume-{N}_第{轮}轮_{席位}.md**，2026-10-01 钉死，各写入点不得自造变体） | 写定即冻结，永不修改（摘要冻结铁律延伸） | 报告全文：问题清单、席位特有产出（弃书点/标尺对照/冲突四型）、修复方向两侧方案、未检查项诚实降级注 |
| **台账层** | `评审/评审台账.md` | append-only，唯一真相源 | 条目 ID、裁决+理由、状态机流转、遗留总账（去向+触发时点）、席位特有产出仅存指针 |

实测依据：卷纲消费方**先台账拿状态图、再按指针回快照取全文**——"只有台账能答"（跨轮状态/裁决/路由）与"只有快照能答"（产出全文/两侧方案/降级注）同时成立。

## 2. 条目 ID

- 格式：`R{轮次}-{席}{快照内序号}`，如 R1-校05、R2-作01；**轮次为全书连续编号**（跨对象累计，如大纲用 R1-R2 后卷6 首轮=R3），另设**对象列**（outline／volume-{N}／chapter-单元{N}——draft 章组批的对象键）区分审读对象——并行评审以对象列消歧（卷6 沙盘实证）
- **推导制**：由轮次+席位+快照内序号拼接，宿主不回写快照（快照保持冻结）
- 席字：校/作/读/编——全项目跨文件引用以 ID 为锚（DOI 思路，同登记册实体 ID）

## 3. 条目状态机

```
新发 → 已裁决（接受·侧一/侧二/建议 ｜ 驳回·维持 ｜ 延后·去向 ｜ 顺手补）
     → 已修 ｜ 已记录 ｜ 已延后
     → 复评确认：✅已销项 ｜ 部分修复→派生新条目（lineage 记 parent ID）｜ 未修复·符合裁决
```

- 🔴 必修才销项｜🟡 按裁决执行即销项｜🔵 记录项长存，触发消费时点后重开
- **裁决理由必存档**（驳回/延后项尤其）——实测价值：卷6 消费方称其"省掉一次注定被打回的迭代"

## 4. 产生管线（补齐代理设计规范 §4.3）

```
派出（六参数：对象类型/对象文件/轮次/上轮报告/判据资产路径/细则文件路径）
（上轮报告=只传本席自己的；**例外条**：读者席卷纲档的跨卷弃书点回归可附入本席上卷快照的弃书点节——席位历史产出附入，非他席、非宿主叙述）
→ 评审产出报告文本（快照格式）
→ 引证验真（列感知：「」按列提取；引证列↔对象+登记册+规格，判据列↔KB+标尺；
  建议/修复方向列的拟议文本不入验真——拟议文本禁用「」）
→ 快照落盘（每轮必落，零例外——沙盘中第2轮漏落盘即被消费方抓）
→ 宿主建台账条目（ID 推导、状态=新发）
```

## 5. 消费矩阵（谁在哪个时点读什么）

| 消费方 | 时点 | 读台账 | 读快照 | 备注 |
|---|---|---|---|---|
| 作者裁决 | 每轮汇总 | 全量（按 ID 逐条裁决） | 按需（看两侧方案全文） | 汇总视图=台账按严重度排序 |
| 修复执行 | 裁决后 | 本轮已裁决条目（裁决+落点） | 修复方向提示全文（含指路与【待采风】标记） | **方法论=§8.1 改稿怎么改**（从整体到局部，禁上来改句子）；**修复分级**（点修直改/面修先影响面清单）；**同步点清单**逐位核销；无解时走修复支持三角（§6.5） |
| 复评评审 | 轮次>1 | **本席裁决切片**（哪些修了/哪些记录不动——禁止宿主口述） | 本席上轮快照 | 回归表逐条判状态；部分修复派生新条目 |
| 定稿遗留清点 | 步6 | 状态∈{已记录,已延后,驳回}+区块15 留白 | — | 遗留总账快照随定稿冻结 |
| 下阶段进场（故事剧情/卷纲/正文） | 各自进场步 | 遗留总账按"触发时点"过滤本阶段条目 | 按指针取全文 | 见 §7 |
| 登记册更正 | 修复含登记册时 | — | — | 更正记录节（append-only）+单源原则 |

## 6. 修复执行纪律（沙盘暴露的三处缺口，全部立规）

1. **同步点清单（机械化，三轮沙盘实证：跨文件落点靠记忆必漏）**：裁决落点跨文件时（对象区块/登记册/附表/详版四类落点），**裁决时刻机械生成同步点清单随裁决下发**（逐位列名：文件·条目·改成什么），修复者按清单逐位打钩；复评为兜底（有效但多耗一轮）
2. **登记册单源原则**：同一数值多处出现时，非主行写"以{主行}为准"引用式，改值只改主行——防"改行值不改汇总"型联动残留
3. **版本身份同步**：产物改名/晋级（候选→v1→定稿）时，头注版本链、frontmatter title/status/version、自称句三处机械同步——列为组装/修订步的固定子步
4. **修复分级**（改情节/改人物必须整体看影响）：
   - **点修复**：单值、措辞、计数类（同步点核销即可）——直接改
   - **面修复**：语义变化类（人物动机/情节因果/设定规则/结构移动）——判据：修复涉及 ≥2 个实体 ID，或根因=设定根源且改动超出单条目。执行序：先出**影响面清单**（依登记册 ID 关联反查：该人物/事件/伏笔挂靠的全部条目＋大纲区块引用反查，列出受影响实体与区块）→ 作者过目确认 → 逐项改 → 影响区写入复评范围
   - 面修复=段内迷你变更提案：影响面分析纪律与 PRD §5 变更提案同源，但仍在段 6 未定稿期内，不走完整变更提案流程；定稿后的同类修改走变更提案
5. **修复支持三角**（人类作家改不好时会翻书架、翻参考书、上网搜——机制同构）：
   - ① 方法论（KB §节——评审指导意见的"指路"）→ ② 本地参考（灵感库＋拆书零件索引＋参考作品骨架，**永不含原文**）→ ③ 采风兜底（researcher 代理：网络检索技巧/桥段/灵感，结果抽象化沉淀后再用）
   - 触发：指导意见带【待采风：查询词】，或修复执行中①②均无解——汇总去重后**一轮集中派采风一次**（沿用待采风标记机制，不逐条打断打磨轮）
   - 纪律：采风结果抽象化再用（版权红线＋原创性红线）；🔴 结构级必修项不依赖采风（方法论能修的不检索）

## 7. 跨阶段消费（遗留路由）

- 遗留总账每条：`遗留项｜来源 ID｜去向｜触发时点`
- **路由按"消费现场"而非"发现地"**：约束指向其第一次被实际消费的位置（如 R5 相关约束路由到布点卷，不是反转揭晓卷）
- 下阶段进场固定动作：读台账遗留总账 → 过滤"触发时点=本阶段"的条目 → 作为设计输入（沙盘实测：卷6 进场拿到 9 组约束，含 1 条头号欠账+1 条情绪接口+1 条路由错位自纠）
- 延后项销项现场：延后条目在去向阶段交付时**必须回填**（回填义务在裁决理由存档中钉死，如 R1-作05=回填 FS006/FS007+世界核心）

## 8. 报告统一骨架（四席快照共用，定义在各任务书 §4）

```markdown
# {席位}评审报告 · {对象类型} · 第{N}轮

- 对象文件：{路径}
- 输入：{实际读入的文件清单；复评含上轮报告+裁决切片}
- 判据：{知识库核心卡清单/参考标尺/登记册——版本以判据资产文件实况为准}
- 计数：🔴{x} 🟡{x} 🔵{x}（席位特殊计数：校对加 A/B/C/D 型分计；编辑加 ⚠️待校准不计入）

## 总评（≤100 字，席位各自的总结形态）
## 席位特有产出区（校对=冲突四型统计+修复方向提示｜读者=弃书点预测表｜编辑=标尺对照表｜作家=四维小结）
## 问题清单（固定列，脚本按列解析验真）
  校对：# ｜型｜严重度｜位置｜引证｜依据｜冲突描述
  作家：# ｜维｜严重度｜位置｜引证｜问题｜判据｜根因｜建议
  读者：# ｜类｜严重度｜位置｜引证｜问题（读者语言）｜判据｜根因｜建议
  编辑：# ｜区｜严重度｜位置｜引证｜问题｜判据｜根因｜建议
## 未检查项与原因（诚实降级；输入状态未变的项复评沿用申报）
```

引证一律「」包裹（验真锚点）；修复方向/建议中的**拟议文本禁用「」**（不入验真语料）。

## 9. 熔断与例外

- 打磨轮 ≤3（workflow-6 步5 不变）；熔断后逐条人工裁决落台账，状态=已裁决·人工
- 作者跳过评审：台账记"跳过·原因"，无条目——但快照零产出时台账须记空转（防止后续阶段误以为审过）
