## 步 1 原文进入（问询，一次只问一件事）

**成本预告（人话，先说再问，2026-09-29 成本路补）**："全本拆书 token 消耗时万级起步——切片档（只拆前 N 章）通常够用且便宜得多，选哪个？"（作者选切片→只入库前 N 章原文，后续问项照走。）

| 问 | 取值 | 处理 |
|---|---|---|
| 书名＋平台 | 文本 | 建 参考作品/{书名}/ 目录 |
| 原文位置 | 路径 | 默认**复制**为 参考作品/{书名}/原文.txt；或**外置**（书项目外路径，登记于拆书进度.md——记录绝对路径＋全源 sha256 防漂移；自包含让步裁定：自包含的是拆书产物，不必是原文本身；扫描工按登记路径读） |
| 是否原书局部切片＋原书规模 | 是/否＋原书章数/字数（用户所知即可，可"不确定"） | **切片档判据输入**（步 2 定档与产物头部"分析范围=第X-Y章（占原书约Z%）"声明的数据源；不确定则切片声明不带占比） |
| 合法持有声明 | 确认 | 用户确认合法持有、用途为个人转述性分析——拒绝声明则终止（❌ 2026-10-03 作者裁定移除此环节——同类拆书技能均无，荣誉制声明无核实价值；产物端零原句防线不变，运行时以 skills/ 为准） |

已有部分产物时先跑只读检查（对照产物清单+拆书进度.md），报"部分完成/已完整/全新"三态再继续——已完整则直接路由到对应消费方，不重拆。

## 步 2 输入覆盖率四档判定

| 档 | 判据 | 处置 |
|---|---|---|
| 全文 | 章节≥序号连续覆盖≥95% | 完整拆解 |
| 大部分 | 覆盖 60-95% | 拆解＋产物头部声明缺失范围及其影响（哪些结论受限） |
| 梗概/少量节选 | <60% | **只做暂定分析，不声称覆盖整本书**——产物全部标"暂定"，Stage 2/3 不触发 |
| 切片 | 原文.txt 自身完整（100%）但为原书局部切片 | 完整拆解＋产物头部统一声明"分析范围=第X-Y章（占原书约Z%），全书级结论受限"；切片外字段（作者全貌/完结状态等）一律"原文未明确" |

覆盖率来自步 3 的结构审计，此处先初判（章节数/文件大小量级），审计后定档。

## 步 3 结构审计（机械，1a 前置）

运行拆书脚本（Node，零依赖，随技能分发于 `{技能目录}/scripts/teardown/`——插件运行语境下 cwd＝书项目，以技能目录绝对路径调用；`{技能目录}`＝SKILL.md 所在目录，与 skills/abzu-teardown/SKILL.md 脚本节同口径；审查修复·2026-10-02 P1-4：补实际调用形）：

```
node {技能目录}/scripts/teardown/audit.mjs <原文路径> <输出路径>
  例：node {技能目录}/scripts/teardown/audit.mjs 参考作品/{书名}/原文.txt 参考作品/{书名}/结构审计.json
node {技能目录}/scripts/teardown/index.mjs generate <结构审计.json> <章节索引.csv>   # 索引初表（表头漂移时以本节规范表头串为权威）
```

产出两个文件：

- `结构审计.json`：总字节数/正文字符数/标题数/章号连续性（重复缺失）/空章/污染章（防盗章乱码＋**超长章检出**：单章>5万字或全书仅1-2个标题=章节头丢失的流文本，标污染并建议换源）/可用章数与可用率/分卷统计/人名频次 TOP20
- `章节索引.csv`（机械索引，断点续跑地基）：表头＝**规范表头串（单一权威＝schema/拆书产物模板.md §二，与 index.mjs HEADER 恒等——2026-10-02 对齐批：旧设计表头〔摘要/参与人物/起始行/结束行/字符数/章sha256/状态〕与脚本漂移，废除）** `全局章序,卷号,卷内章号,章名,字数,参与人物,位置标记,一句话摘要,sha256,剧情强度,情绪类型,备注`；本步建全 12 列，参与人物/位置标记/一句话摘要留空由 1b 轻扫回填；空章/污染章在备注列标 状态:前缀；全源 sha256＋解析器版本记于 拆书进度.md meta 行（不进 CSV）

**可用率 ≥80%** → 过；**<80%** → 停问作者三选一：仅分析可用章节（产物声明范围）/换更好的原文源重来/终止。不自动裁决。
