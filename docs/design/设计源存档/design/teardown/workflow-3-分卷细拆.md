# 拆书 workflow-3：Stage 3 分卷细拆

> 版本 v1.1 ｜ 2026-09-29（审查修复：章节事实卡注明 14 字段、置信度聚合期补） ｜ 触发：卷纲技能第 N 卷规划（二期）或用户显式 `/abzu:abzu-teardown {书名} 第N卷` ｜ 产物格式：分卷拆解/第N卷.md（见 [schema/拆书产物模板.md](../schema/拆书产物模板.md)）；流程与协议见 [拆书设计稿](主设计.md)
> 硬依赖：Stage 1（缺则先补 Stage 1）。软依赖：Stage 2 深度分析——无则伏笔切片降级"仅本卷内可识别"，产物标注"深度分析未生成，伏笔视角受限"

## 步 1 定位与派工

- 从章节索引取该卷起止章（分卷统计）——只拆该卷段落，他卷不读。**窗口拆解制**（2026-09-29 成本路裁定；审查修复·2026-10-02 P0-2：workflow 侧同步主设计 Stage 3 口径——全卷事实卡消费率低，窗口化省 60-80%）：默认只拆**对应窗口**＝参考书中与本书精排区章位对应的参考章位 ±10 章（位置映射按两书总章数等比折算：本书精排区章位 ÷ 本书总章数 × 参考书总章数）；窗口外章节**不拆**，产物该卷概要标"未拆章位：第X-Y章"；draft 章纲卡对照时命中未拆章位 → 触发**增量补拆**（单章/小批量，同一触发不做整卷）；作者明示"全卷拆"才全拆（先呈成本预告）
- 扫描工·分卷模式逐批（批次协议同 workflow-1 的 1b：隔离七条＋handoff_cache＋定稿 门禁）；**窗口内每章必产（全卷拆时＝该卷每章）**章节事实卡（14 字段，置信度聚合期由主会话补——扫描工不产；逐行格式见扫描工任务书 §3b）**：章｜一句话｜场景与时间｜参与人物｜目标-阻碍-结果｜状态变化｜新增信息（读者新知）｜隐藏信息（读者知角色不知）｜剧情强度1-5｜情绪（类型+强度1-5）｜描写密度1-3｜章首钩｜章末钩｜证据（章+短定位词）
- 打分锚点（扫描工任务书携带）：剧情 1=日常衔接…5=核心真相不可逆抉择；情绪先标类型再打分（安静告别事件 2 分情绪可 5 分）；密度 1 概述/2 常规/3 场景化——**三维分开标，分数不代替解释**

**方法论加载**（审查修复·2026-10-02 P1-2）：实证方法论/拆书方法论/结构标记识别（卷末三件套——本卷末章是否"主线兑现＋告别戏＋钝钩定格"核验，喂卷间接口与卷边界确认）＋节奏量化（三维节奏曲线剧情强度列预填先验——高潮块内章给 4-5 分候选；卷间接口从收口跳点＜0.6 处取材）——分发为 references/methods/structure-marker.md、pacing-metrics.md

## 步 2 卷内聚合（主会话）

| 件 | 来源 |
|---|---|
| 三维节奏曲线 | 章节卡三列直出＋异常点备注 |
| 六步实例化（逐单元） | 章节卡序列归并为叙事单元（情绪事件/欲望/阻碍/解决/高潮/反馈） |
| 伏笔操作明细 | 有 Stage 2：链条图切片本卷行；无：仅本卷可识别伏笔＋降级标注 |
| 双时间线切片 | 本卷内调度操作（真实序/披露序/标签） |
| 卷间接口 | 承接上卷（什么结果成为本卷起因）／交出下卷（什么悬念驱动下卷）／班底变动 |

## 步 3 可选：文风定点取样

按索引定点读 4-6 段原文锚点（对白密集/战斗/过渡各取样），产出文风备注（句长节奏/对白密度/描写习惯；**每条标题材词汇｜语感标记**——语感标记=换书仍适用的写法，题材词汇=该书专属不入文风（2026-10-02 补——按需层过滤器的产端配套，否则过滤空转）→ 若新书项目已有故事文风/文风基准.md 则回填观察区——**不重扫全书**；置信度三档（A/B/C）。消费方已接线（2026-10-01 批③方案 b）：观察区对标归纳→draft 组装包按需层 1-2 条（语感标记类·置信 A/B）——不再是零消费区。用户未要求则跳过。

## 收尾门

- 覆盖率：**窗口口径**（审查修复·2026-10-02 P0-2）——窗口内 100% 章节有卡（缺章标"待补"）；窗口外章位标"未拆"（非缺失，不触发补拆；增量补拆完成后更新未拆标注）；全卷拆时窗口＝该卷
- 终检：三节奏分开｜隐藏信息≠新增信息（不混标）｜接口有证据章｜与骨架/深度分析不矛盾
- 报告四态（作者口径）：本卷拆完（窗口第X-Y章 {N} 章卡/单元 {M} 个/接口已对上——窗口拆时注明窗口章位与未拆范围，全卷拆时 {N}＝该卷章数）；下一步=卷纲第 N 卷规划消费
- 进度：批次表追加本卷批次；阶段表 stage3-vol{N}=completed
