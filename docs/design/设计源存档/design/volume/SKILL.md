## 定位

两种运行形态：**完整轮回**（一卷六段，开新卷用）与**滚动细化**（正文期精排区余量<3 章时轻量重入，只走卷2 细化支——大神校准后的双区制配套；阈值与 draft 批1 统一）。在大纲正典约束下逐卷设计：对表进场 → 卷功能 → 卷内结构 → 高潮与钩 → 生长修正 → 审校定稿＋**章纲三约束**（三期输入）。**一卷一轮回**。

## 全局规则

0. **交互形式按《交互统一标准》五级选型**（见 references/interaction-protocol.md；2026-10-01）：对表步 L1 静默、心动位 L2 原话、字数偏差等裁决 L3 附推荐

继承大纲 SKILL 全部十+二条（断点第一读/方法论一步一节/四轨道/复述纠错/追问限额/兜底/四态/段末三件事/设计外直答/待定标记/暂存达限/嫁接改造触发），另加：

13. **正典约束优先**：大纲定稿与登记册是硬约束——本卷设计与之冲突时，要么改本卷设计，要么走变更提案；禁止就地改正典
14. **欠账必清**：台账遗留路由过滤到本卷的条目，卷0 必须消费（设计输入或明确延期并记台账），不允许静默丢失
15. **三约束是最终出口**：所有卷内设计的终点是章纲三约束总表——写不到三约束里的设计等于没做完
16. **末卷特殊**：末卷运行时区块12 收线设计全量对表＋三线同爆落位＋留白终清
16b. **开卷判定**（每卷定稿后，ainovel 完结判定吸收）：下一卷开卷前过判定——主线终局达成？长线收束？promises 归零？人物命运有交代？判据不齐→继续开卷；**双向陷阱**：防"看到稳态就收笔"（判定是下限非充分条件）、防"凑规模注水"（为字数续卷）——判定结果记创作进度
17. **段末【待采风】盘点**（全卷段统一）：每卷段末扫描本段产物与会话记录的【待采风】→ 汇总去重 → 报告并问"现在派采风还是留到下一段？"（集中一次）；无则跳过
18. **范围调用（连跑模式）**：默认一次一卷；用户可指定范围（如 第1-3卷）连跑——**串行非并行**（跨卷一致性依赖前卷定稿）；每卷间轻确认或一次授权跑完（报告合并）；**触发变更提案立即暂停**（影响面可能波及后续卷，裁决后继续）；连跑上限 3 卷（token 与修正风险控制）
19. **灵感库零件入口**：卷2 章组冲突设计时可检索灵感库（剧情结构类优先）——命中零件不需改造直接采用（记嫁接日志）；需改造适配→派嫁接改造（fusion，规则12）
20. **卷纲暂存容器**=卷纲草稿的"暂存栏"节（拿不准的章组设计/钩型/人物安排留观；达限规则照继承的第 11 条）；卷5 组装前必须清零
21. **崩卷预案**（大神实际四型，写崩时的决策树）：硬写冲过去＋回头缩减平淡段（唐三/猫腻主流——"一修改就完蛋"）｜**早期推翻**（限前 20 万字，老鹰型——过线禁用）｜边连载边修（猫腻将夜/择天记型，谨慎：锐气损耗大）｜完本后系统砍修（猫腻"砍到二百万"型——记完本待办不急做）。**偏离大纲≠崩**（酒徒："写到三分之一就会偏离大纲，丢大纲顺着写"）——先走骨架校准，校准过不了才谈崩卷
21b. **作者口径契约**（同大纲 SKILL 规则 15／拆书 SKILL §七）：面向作者说书不说系统——机制编号必须带人话名（「退婚当众打脸」（EM-003）式）、工程细节最多末行一注、裁决选项用人话呈报
