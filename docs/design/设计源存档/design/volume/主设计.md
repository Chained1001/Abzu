> 版本 v1.2 ｜ 2026-09-29 ｜ 全面归一版：四轮演进（接口沙盘/五问修复/竞品吸收/大神校准+作家思维）全部回灌本文件——本文件为 schema 与接口契约的单一源；与 volume/ 流程件冲突时，操作细节以流程件为准、schema 与契约以本文件为准

## 1. 定位：卷纲不是大纲的缩小版

| # | 差异点 | 设计含义 |
|---|---|---|
| 1 | **驱动方向相反**：大纲=从零创造（差异集/嫁接），卷纲=**在自己意图的延长线上继续写**（大纲与登记册=作家自己定过的意图记忆） | **对表的哲学定位：不是对着外部规范施工，是回忆自己写过和定过的**——对 AI 是记忆假肢（补阅读史/写作史的短板），对作家是"我之前写到哪、定过什么"；正典约束的实质=作家的自我一致性（作家最恨的是自己吃自己的书）。创造空间=卷内全部具体化；改约束走变更提案=改自己的意图要有仪式感，不是被表格拦住 |
| 2 | **中途修正维度**：写到第 N 卷时前 N-1 卷已定 | 设定生长修正通道（卷4 时态分岔）；前卷/大纲问题走变更提案（终稿保护延伸） |
| 3 | **产物是约束不是内容**：最终出口=**章纲三约束**（节奏锚点/信息预算/视角约束）——三期章纲的输入 | 产物 schema 以"可执行的约束表"为核心；**分档**：精排区全保真、池区粗约束（§4） |
| 4 | **逐卷重复运行**＋**只锁近端**（大神校准：猫腻"2 万字细纲管 10 万字情节"/酒徒"丢大纲顺着写"/ADR-0001 防过早收敛） | **双区制**：精排区+事件池区；滚动细化；一卷一轮回，逐卷差异显式分岔（§7） |

两种运行形态：**完整轮回**（开新卷六段走全）与**滚动细化**（正文期精排区余量<3 章时轻量重入，只走卷2 细化支）。思维引导器定位不变（ADR-0001）：卷内设计仍是创作思考，只是思考的边界由大纲定。

## 3. 六段流程总览（与 volume/ 流程件一致，此处为总览与契约）

### 卷0 进场对表（机械+接口枢纽，无创作）

1. 定位（含乱序运行降级基准=正典+登记册）
2. 大纲对表（区块07 第N卷行全列/05/08/10/12/15 去向项）
2b. **骨架校准**（N≥2）："已发生的是现实，骨架是可修订的计划"——偏差大→变更提案
3. 登记册与欠账对表（六册＋挂账清单过滤本卷（含待采分账）＋待验证清单＋**上卷复盘**——固定输入）
4. 遗留路由消费（台账过滤"触发时点=本卷"，欠账必清禁静默丢失）
5. 拆书**引导式**触发（Stage2 首次/Stage3 每卷；缺失→挂起提示用户运行——技能不自动串联；前置不可行→延期支含旧格式代用边界；作者暂缓→欠账标"作者暂缓"）
5b. 数据与商业对表（均订/追读/上架节点；采纳派 vs 隔离派作者选；问"近期在读什么"）
6. 预算行生成

### 卷1 卷功能定位（创造·有约束）§5.1→§5.6→§5.5

步0 **本卷心动位**（"早就想写的场面/对决/爽点"→高优先锚点，冲劲优先于结构匀称）→ 五判据 → 情节类型骨架 → 字数倒推对表（>15% 偏差→调内容 or 提案）→ **两查**（兴奋阈值：本卷高潮被上卷末透支？/换图代价：莲花地图法）

### 卷2 卷内结构（创造·主干）§5.2→§5.9→§5.7(+§2.13)

- **双区制排布**：精排区（**前 3-5 个章组，约 10-20 万字**——v1.2 口径修正，原"前 1-2 章组"与窗口量级矛盾；字数窗按篇幅档折算：3-5 章组不变、字数为参考值，轻量档（<50 万字全书）精排区可占全卷 50-80%、少量池区合法（大奉卷三 139 章无池区实证）——打样P2·2026-10-02 修复，细则见 volume/卷2 步1）全字段细排；**事件池区**（待发生事件清单·不排序·只标义务来源；高潮位/汇聚/钩留粗锚）
- 精排区章组表：冲突+不可逆变化+线别+切线点（大案=案组可跨组连号）；小高潮序列（对预算行——**精排区细位，池区粗锚**）
- 多线组织（主绳/汇聚点=卷3 高潮位）＋**压力线轮转**（每组主推 1-2 线，静默线一句比价维持）；时间锁（可选强度——轻量书可降为检查项）
- 人物调度表（含**安全阀**：可控退场留随时回归活口）
- 情绪落点+弃书对策（含**刻度台阶**：读者的尺子先于度量出场 1+ 章组）
- 段末：**四轨道交叉自检（对精排区）**＋暂存栏节落盘
- **五步法对照**（oh-story 吸收，实装期操作化）：选段→标关键点→换素材→修正硬伤→排章

### 卷3 高潮与钩（创造·关键件）§5.3→§5.4→§4.8

步0 **卷首热开场**（钩是双向的——开卷前 3 章重新抓住读者）→ 大高潮（压放/汇聚/反杀须有 promises 依据🔴无据=天降神兵/爽点层次）→ 卷末钩（四型/服务主线/接下卷接口）→ 伏笔卷级操作（义务逐条落位；疑似遗忘优先）→ **情绪债表**（可选：跨卷情绪欠条，"可不推进情节但必须还"）

### 卷4 归档与生长修正（机械+修正通道）

- **设定演化三通道**：增（入册）/改（派生追加 or 提案——登记册双通道边界）/删（deprecated+引用扫描：零引用就地退役，有引用走提案）
- **修正分岔（病灶×时态）**：本卷就地改｜前卷已定稿→提案｜前卷已规划未产出→欠账路由｜未规划→设计输入｜大纲→提案
- 登记册卷级追加（§5 契约）＋遗留销项

### 卷5 审校定稿（类推段6 换档）

暂存栏清零门 → 组装（**首件=一页卷约**：卷主题/功能/高潮点与扣子清单/断卷点/上卷数据与伏笔债/精排区窗口；逐区块 diff 防缩水）→ 落地审查 7 项（**#2 分档**：精排区=区间合计+间隔严检🔴；池区=义务来源齐+粗锚在预算窗内🟡）→ 四席评审（卷纲档细则，均含池区降级检查；快照命名 `volume-{N}_第{轮}轮_{席位}.md`——生命周期 §1 权威公式，校对席无 `_{席位}` 尾落 校对评审/、三评审席含尾落 三评审报告/（打样P5·2026-10-02 修复归一））→ 台账建条目（R{轮} 全书连续+对象列 volume-{N}）→ 打磨轮 ≤3（裁决即生成同步点清单/修复分级/§8.1/复评回归）→ 定稿：

- **三约束产出（分档+档位标记）**：精排区章组=三列全保真，行首标【精排】；池区=粗约束，标【池区】——draft"缓冲区余量"的数据源；独立落盘 `故事剧情/卷纲/三约束_第N卷.md`
- 台账遗留快照＋**待验证清单验/销**
- 归档（候选/v 轮/裁决切片）
- **断点双出口**：默认=**第 N 卷正文（draft 章0 第 1 章）**；作者可选=第 N+1 卷卷0（提前设计下卷，存稿期适用）
- **卷末复盘**（乌贼式，≤30 行：本卷困难+解决思路/实际节奏 vs 预算偏差/数据快照/下一卷注意项）——下一卷卷0 固定输入
- **开卷判定**（定稿即判，记创作进度）：主线终局/长线收束/promises 归零/人物交代——不齐→继续开卷；双向陷阱（防稳态收笔/防凑字数续卷）；计划末卷判定失败→提案增卷；非计划卷提前达成→按末卷义务补对表

### 章纲三约束（卷5 产出，三期章纲的全部出口）

按章组三列：**节奏锚点**（小高潮/铺垫/回血/切线/压放位）｜**信息预算**（应知/应疑/应忘+伏笔操作+情绪落点）｜**视角约束**（POV/known_by 对表/禁入）。分档如上。

## 4. 产物 Schema：卷纲_第N卷.md

| 件 | 内容 | 严检 |
|---|---|---|
| **一页卷约**（头部首件） | 卷主题一句话/功能定位/高潮点与扣子清单/断卷点/上卷数据与伏笔债/精排区窗口 | 大神形态（一页级） |
| 区块01-03 | 功能定位（五判据+两查结论）/承上启下/字数与预算行 | 五判据全过；偏差≤15% |
| 区块04 | **章组排布·双区**：精排区表（章组/章区间/冲突/不可逆变化/线别/切线点）＋事件池表（事件/粗锚前中后段/义务来源） | 精排区每组有变化因果相连；池区义务来源齐、无孤儿事件 |
| 区块05-08 | 小高潮序列/时间锁/多线组织/人物调度（含安全阀） | 对预算行；progression 一致 |
| 区块09-11 | 大高潮/卷末钩/伏笔卷级操作 | 反杀有伏笔；义务全覆盖 |
| 区块12 | **三约束总表·分档**（【精排】/【池区】行首标记） | 精排区三列齐；池区粗锚在预算窗内 |
| 附表 | 情绪落点与弃书对策（含刻度台阶注记）＋情绪债表（可选） | 台账弃书条目有对策 |
| 附节 | **暂存栏**（草稿态；卷5 前清零） | 清零门 |

frontmatter：id: volume-{N} / type: volume / status: draft→candidate→active；版本链同大纲。

## 6. 评审卷纲档细则（四份，细则/ ×4——均含**池区降级检查**节）

| 席 | 加载 | 检查核心 | 池区降级 |
|---|---|---|---|
| 校对 | 登记册 | 卷级九区（时序/行程/知识边界/物理/命名/规则/伏笔/接口/三约束）＋跨卷一致性 | 池区查义务来源与粗锚，不查章区间一致性 |
| 作家 | §5.1-5.9＋§4.8 | 卷功能达成度/变化链/高潮压放/卷末钩/多线 | 变化链只查精排区；池区查事件因果方向 |
| 读者 | §8.5/§2.19/§5.4/§1.16 | **弃书点回归**/毒点卷级扫描/卷末钩体验/压抑释放配比 | 精排区按章组通读；池区按事件清单+粗锚做体验预判 |
| 编辑 | 标尺＋§5.5（输入含前卷定稿区块09/10） | 预算执行/字数逻辑/断档/连卷趋势 | 区间合计只对精排区；池区对预算窗 |

复评/台账共用大纲体系；根因含**前卷根源**。

## 7. 逐卷运行差异

| 卷 | 差异 |
|---|---|
| 第 1 卷 | 无承接上卷；Stage 2 触发点；首高潮位重点对表 |
| 第 N 卷 | 标准轮回；遗留路由过滤；前卷接口咬合加重；骨架校准 |
| 末卷 | 大纲·区块12 收线全量对表＋三线同爆落位＋留白终清（设计期义务，卷0-卷5 内执行） |

## 8. 与四邻的接口契约

| 邻 | 契约 |
|---|---|
| 大纲（上游） | 消费：定稿区块+登记册+台账遗留+**上卷复盘**；回流：变更提案 |
| 拆书（侧供） | 引导式触发 Stage 2/3（技能不自动串联）；旧格式升级通道（拆书 SKILL 路由"补跑 1a+1b"）；用法=对照非复制 |
| **章纲（下游）** | 出口=三约束总表（分档+档位标记）；**滚动细化追加契约**：既有行不可改写（改=变更提案），追加新精排段行=合法 append（行首【精排】＋追加节＋修订记录）；draft 触发阈值=精排区余量<3 章 |
| 评审/台账 | 同体系换档；快照命名 `volume-{N}_第{轮}轮_{席位}.md`（生命周期 §1 权威公式——校对席无 `_{席位}` 尾；打样P5·2026-10-02 修复归一）；读者席跨卷弃书回归输入=本席上卷快照弃书点节（席位历史产出附入——代理设计规范 §4.1 例外条） |
