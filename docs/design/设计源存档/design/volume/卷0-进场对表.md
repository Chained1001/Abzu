# 卷纲 卷0：进场对表（第 N 卷）

> 版本 v1.0 ｜ 2026-09-29 ｜ 机械+接口消费，无创作；产物=对表包（会话内呈现）＋断点

## 步 1 定位

读创作进度当前断点 → 确认卷号 N；显式调用则核前卷完成状态（未完成→警告确认；**确认继续=乱序运行：跨卷一致性检查降级基准=大纲定稿正典+登记册**，校对席同此降级并如实申报——卷6 沙盘实证可行）。

**回归简报**（步 1 固定输出——断更回归时作者最先要的是"心智恢复"不是数据表；数据步 2-4 本来就读，格式化成作者视角的"欢迎回来"，随对表包一并呈现）：

> 欢迎回来。上次停在：{断点一句}｜上章收在：{最近已写章的章末写入·当前状态摘要一句——断点经过正文期时}｜本卷：{区块07 第 N 卷行主题一句}｜欠账 {N} 条（步 4 遗留过滤；零则省略）｜伏笔超期 {N} 条（步 3 promises 对表超期项；零则省略）。

人话呈报，不说系统字段（作者口径契约）。

## 步 2 大纲对表（读）

- 大纲定稿·区块07 第 N 卷行**全列**逐项摘出（章数/字数/十二步对齐/冲突类型/地图/势力/三线预算/卷间接口/情绪任务/关键事件）
- 区块05 该卷所属步的 G/C/F 线；区块08 该卷支线与回归点；区块10 该卷伏笔摘要；区块12 该卷收线义务（末卷全量）
- 区块15 留白区中"去向=本卷"的项（消费清单）

## 步 2b 骨架校准（第 N≥2 卷时；ainovel"展开前校准"吸收）

已写各卷的**现实**是最高优先级输入——铺本卷前先问：区块07 该卷行的原方向**仍是最佳后续吗**？对照：前卷定稿的实际走向/登记册累积/读者反馈（若有）。偏差小→本卷设计内消化（记偏差说明）；偏差大→**变更提案调区块07**（"骨架是可修订的计划，已发生的是现实"——禁止为服从旧计划扭曲已写内容）。

## 步 3 登记册与欠账对表（读）

- 登记册：timeline 第 N 卷行＋promises 该卷条目（义务三型：埋/提醒/回收，各列章位或"卷内待落"）＋progression 该卷位阶段＋rules 全册速览＋naming 本卷新名预留
- **创作进度·挂账清单**：过滤"消费段=本卷"的待采分账项 → 待采项即本卷采风输入（**打通"分账→卷级消费→触发采风"闭环**；世界参照档案溶解后挂账清单为唯一待采账本——2026-10-01）
- **创作进度·待验证清单**：过滤"应验时点≤本卷末"的项（如上架数据回验挂到本卷末的）→ 卷5 定稿时验或销
- （现实依据栏的待查项不设独立过滤——按世界核心模板·设定族纪律 2 全部登记在挂账清单，上行过滤已覆盖；现实依据栏只收已转化的结果）
- **上卷复盘**（N≥2）：读 `故事剧情/卷纲/复盘_第{N-1}卷.md` 全文入对表包；**前卷附表B·情绪债未清条目**（欠什么/欠于哪卷/应还位置——本卷设计输入，2026-10-02 修跨卷断头）；**前卷附表B·情绪债未清条目**（欠什么/欠于哪卷/应还位置——本卷设计输入，2026-10-02 修跨卷断头）——上卷的困难/偏差/注意项是本卷的起点（乌贼式回路的入口）

## 步 4 遗留路由消费 ★（台账接口）

读 评审/评审台账.md 遗留总账 → **脚本过滤**（台账对象列＋触发时点受控值过滤→输出命中条目清单，AI 只读清单——触发时点受控值见 schema/评审台账模板.md）→ 逐条：
- 输出：条目 ID＋一句话＋裁决理由（反查存档）＋对本卷的设计要求
- 处置：**作为卷1/卷2 的设计输入**（记入对表包）；本卷确无法处理的 → 显式延期（台账状态改去向并记理由），禁止静默丢失
- 本卷卷4 清偿后回台账销项（状态流转）

## 步 5 拆书触发（接口）

| 条件 | 动作（**引导式，非自动串联**——技能只能用户显式调用，设计哲学 5） |
|---|---|
| 首次运行任意卷 且 深度分析.md 缺失 | **引导拆书**：呈成本（Stage 2 高成本全书分析）与缺位影响 → 作者同意 → 提示运行 `/abzu:abzu-teardown {书名}` → **本技能挂起**（断点=卷0 步5，报告四态：需要你处理）→ 用户拆完回来从断点续 |
| 分卷拆解/第N卷.md 缺失 | **引导拆书**（同上）：提示运行 `/abzu:abzu-teardown {书名} 第N卷`（直达 Stage 3）→ 挂起等回 |
| **前置产物缺失且即时补齐不可行**（如旧格式拆书产物无章节索引——Stage 2 追踪式无地图） | **延期支**：向作者呈成本与影响→确认延期→欠账入台账（去向=拆书升级补索引）；旧格式代用边界声明：骨架/笔记/总表可作**卷级参照**（节奏曲线/高潮位/爽点铺放比），**追踪层（人物弧线/伏笔链全书视角）不可代用**——登记册完备度是第一道保险；产物与报告全程标注"Stage 2/3 未生成，卷级参照受限" |
| 作者当场不拆也不延期 | 明确说"暂不"→按延期支处理但欠账标"作者暂缓"（区别于技术性延期） |
| 均在位 | 跳过；读 分卷拆解/第N卷.md 的"卷间接口/三维节奏"节做参照底 |
