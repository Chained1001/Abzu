# 反测执行方案（成品书正装反测——外部效度验证）

> v1.0 ｜ 2026-10-02 ｜ 三轮 grill 定案 ｜ 定位：验证体系第三条腿——内部一致性（三层咬合审计 ✓）／前向可跑通（打样剧本 ⏳）／**后向可装下（本方案）**。我们的仪器（模板/字段/判据）能否装下已被证明成功的东西，装不下即设计缺口的铁证
> 语料：`桌面根 原文/`（仓库外——"原文永不入仓"铁律天然满足）；8 本全完结 ｜ 试点先行：大奉（全仪器快测）＋诡秘（G 节/promises 深测），方法验证后铺开

## 二、方法：正装反测（主）＋逆向重构（缺口追认）

**正装**：拿我们的表格去"装"这本书（假设这位作者当年用我们的 G 节/章纲卡写作），测三件事：
1. **覆盖度**：装得下吗（表格格子能被书的实际内容填满吗）
2. **缺口**：装的时候有没有"作者显然考虑过、我们没这格"的东西
3. **冗余**：有没有这本书永远填不上的格（标注"题材特化"或"真没用"）

**逆向重构（仅缺口追认）**：发现缺口时，反推"作者自己的仪器上那一格大概叫什么"帮助命名新字段——不独立成方法（作者的笔记不存在，重构=想象）。

## 三、三重纪律（防放水——本方法的最大敌人是 AI 自圆其说）

1. **先证据后填表**：每个格子的填入内容必须附章节证据（第 N 章＋原文事实一句话**抽象转述**）；无证据的格留空并标"样本未覆盖"，禁止脑补
2. **缺口双栏制**：报缺口必须双栏——原文证据栏（章位＋事实转述）＋反推理由栏（为什么认为作者考虑过这个）；缺一栏不算缺口
3. **填表与复核分离**：正装 agent 与复核 agent 分独立上下文；复核席只拿"填好的表＋原文选章"，专找三件事——无证据的填入／硬塞（内容与格子语义不符）／漏报的缺口（原文明显有考虑但表上没报）
4. **证据回核五查**（**加试已验证达标：证据级放水 0/10=0%，2026-10-02 复核确认可铺开**）：①计数回数②说话人回认③推测实写回辨④对象归属回认（金手指/体系/技能三侧分栏——借挂即错）⑤无处装对缺口表核销。加试附加纪律：⑥**补读章许可栏**（样本外补读须在报告声明）⑦**语义映射两态标注**（自然装下 vs 类比填入——复核席先例：账本槽）⑧**升级节点措辞须有首现证据**（不得拔高为成型点——复核席先例：138 章）
5. **章号口径报备**（诡秘复核发现章号体系差一——只数正式章/卷末总结并入前章）：定位 JSON 必须注明本书章号计数口径，铺开各书前先跑口径声明

## 四、版权纪律

语料在仓库外；**反测报告入仓的证据=章位＋抽象转述，零原句**（同拆书 commit 门禁口径，>30 字连续匹配即违例）。

## 六、反测报告 schema

`docs/design/反测报告_{书}_{仪器族}.md`：

```
## 一、正装结果（每格一行）
| 模板.字段 | 填入摘要（≤20 字） | 证据（章位＋转述） | 判定：装下/硬塞/无处装 |
## 二、三列表
| 缺口（原文证据＋反推理由双栏） | 冗余（题材特化 or 真没用） | 效度确认（装得又满又顺） |
## 三、修正提案（P0-P2，进 PRD §14 待批）
## 四、方法自评（本报告哪里可能放水——复核席结论附此）
```

## 七、执行顺序

试点（大奉快测＋诡秘深测，双正装 agent＋双复核 agent）→ 方法验证（放水率<10% 铺开，否则改纪律重试）→ 铺开（绍宋/道诡/十日/龙族）→ 修正提案汇总进 PRD §14 → 修缺口 → **打样剧本**（反测先行已定）。
