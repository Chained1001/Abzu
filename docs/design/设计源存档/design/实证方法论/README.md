## 调度机制

写手 agent 按需加载（不批量常驻）：
- 路由表在写手任务书（agents/写手.md）——"写作场景→条目组"映射
- 每条目注入版 ≤120 字；总量 ≤600 字；同条目连续 3 场景自动降权
- 零消费条目淘汰（复盘时对照申报表）
