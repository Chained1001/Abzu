# 拆书方法论提取→真拆文→大纲卷纲方法论反推 执行计划

> 2026-10-02 ｜ 三步闭环：拆书方法论（怎么拆）→ 真拆一本（产出结构化产物）→ 从产物反推大纲/卷纲方法论（填空目录）

## 逻辑

```
拆书方法论（实证——"大神的结构长什么样"的分析方法）
    ↓ 用来真的拆
拆书产物（骨架/节奏/结构/伏笔/人物弧——结构化数据）
    ↓ 从数据反推
大纲方法论（"怎么搭大纲"——从成功书的结构反推设计决策）
卷纲方法论（"怎么排卷"——从成功书的分卷节奏反推）
    ↓ 验证
对照我们现有的大纲模板/卷纲模板——看设计能不能装下成功书的实际形态
```

## 选书：大奉打更人

理由：
1. 网文结构最标准（仙侠探案=主流题材，结构不偏门）
2. 我们已有卖报调研（世界观/文风审计的基础）
3. 914 章/415 万字/完结——量够全卷分析
4. 三阶段拆书产物可以直接服务后续四技能全链验证

## 三步执行

### 第一步：拆书方法论提取（从"怎么分析"维度）

不从"怎么拆"的流程角度（那是 teardown skill 已有的），从**"分析什么才能反推出大纲/卷纲"**的维度：
- 结构标记识别：怎么从正文识别"这是一个卷的结尾"/"这是换图节点"
- 节奏测量：怎么量化压放节奏（不是感觉，是数据）
- 伏笔定位：怎么从全文定位伏笔链（埋/提/收的分布）
- 人物弧线提取：怎么从出场序列反推弧线设计

### 第二步：真拆大奉（三阶段全跑）

用第一步的方法论，按 teardown skill 设计跑 Stage 1→2→3：
- S1 快速通读：结构审计+轻扫+关键章深读+骨架合成
- S2 深度分析：追踪七步（人物弧/伏笔链/关系/双时间线/爽点循环）
- S3 分卷细拆：逐卷节奏/结构/场景
- 产出：真实可用的拆书产物（.sandbox/拆书/ 下）

### 第三步：从产物反推大纲/卷纲方法论

拿拆书产物做"实证对照"：
- 大纲层：大奉的十二步/阵型/伏笔布线/换图节奏 → 提取大纲方法论条目
- 卷纲层：大奉的双区粒度/高潮位/钩型/三约束实际形态 → 提取卷纲方法论条目
- 同时验证：我们的大纲模板 15 区块/卷纲模板 12 区块能不能装下大奉的实际结构
