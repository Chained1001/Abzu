# 实证方法论提取与调度方案（从五书语料到写手手里）

> v1.0 ｜ 2026-10-02 ｜ 依据：打样正文 AI 味诊断＋狗头军师调研（docs/research/ 落档）＋六书反测基础设施 ｜ 目标：**让写手写出的正文有网文味而非文学腔**——不是等 KB 入仓，是从语料直接抽取实证写法、确立统一格式与调度机制

## 一、提取什么（范围）

五书语料（大奉/诡秘/道诡/十日/龙族——桌面 `原文/`），提取**正文层写法**（§7.x 级），按场景分族：

| 族 | 提取内容 | 教科书章 |
|---|---|---|
| **开书章** | 黄金三百字实际形态、信息密度（几件事/章）、紧迫感建立手法、性格展示技巧 | 各书第 1-3 章 |
| **内心独白与吐槽** | 独白占比、语言形态（自嘲/网感/分析型）、与叙述的交替节奏 | 大奉（吐槽流）/诡秘（独白流）/十日（分析流）各 3 章 |
| **对话写法** | 对话出场时机、多角色区分、潜台词/信息差写法、动作穿插 | 道诡（粗粝直给）/大奉（吐槽对话）/十日（群像对话）各 3 章 |
| **动作与高潮** | 压放节奏的实际章法、高潮章长度倍率、爆发句式形态 | 各书最长章 |
| **日常与过渡** | 低压章"往下看的理由"实际怎么给、生活质感细节 | 各书中段日常章 |
| **吐槽/梗/网感** | 现代梗的用法形态、自嘲句式、网络语言的节奏 | 大奉/道诡/十日 |

## 二、统一格式：实证实证方法论条目（五字段）

综合狗头军师"原概念—机制—风险—转译"四元组＋我们的量化要求＋"错误用法"强制节：

```markdown
### {卡名}——{一句话可执行判据}
**出处锚**：{书名}第{N}章（{卷位}段位）——抽取日期 {YYYY-MM-DD}
**可观察机制**：{量化到可执行——"内心独白占全章 60-70%"/"对话在 200 字内出场"/"信息密度 4-6 件事/章"级}
**失效边界**：{何时不用/用多了什么代价——狗头军师"效果/代价"对}
**AI 落地转译**：{写手可直接执行的指令形态——"写内心吐槽时用主角的口吻直接说，不用'他心想'引导"}
**错误用法**：{AI 最容易怎么把这条用成文学腔——"把吐槽写成抒情独白/把'网感'写成网络热词堆砌"}
**最小例句**：{引用级一句（≤25 字），不存段落——版权纪律}
```

## 三、调度机制：两跳路由＋场景触发

### 3.1 结构（借鉴狗头军师双层＋我们写作场景重造键空间）

```
写手任务书（常量）
  └─ 路由表（~20 行，常驻写手上下文）
       │  "写开书章/首章" → 卡组·开书（3-5 张）
       │  "写内心独白/吐槽段" → 卡·吐槽流（大奉型）/卡·分析流（诡秘型）
       │  "写对话/多角色场景" → 卡·对话三型
       │  "写高潮/爆发" → 卡·压放
       │  "写日常/过渡" → 卡·低压章
       └─ 按需加载对应卡组（1-3 张），不批量加载
```

### 3.2 调度键（与狗头军师的关键差异）

狗头军师的路由键是"用户当前问题"（问答粒度）。**我们的键必须是"当前正文局部场景"**：
- **章纲卡场景表已有关键字段**：场景功能（推进/塑造/展开）→ 对应卡组
- **核心情绪基调六值** → 决定语气卡选择
- **写手写作段分场景执行**：每进入新场景时，主会话在组装包按需层**附当前场景对应卡**（1 张/场景）
- 这比狗头军师多一层"**连续注入**"——万字的连续生成中方法论不能衰减，靠章纲卡场景表逐场触发

### 3.3 防"方法论疲劳"（连续生成的独有课题——狗头军师没回答的）

- 每张卡限 ≤120 字——写手上下文里卡总量 ≤600 字（5 张×120），不超过画像区
- **同一卡连续使用 3 个场景后自动降权**（标记"已内化，不再注入"）——防方法论变成模板
- 复盘时回查"哪些卡实际影响了正文"（对照申报表）——零消费卡淘汰

## 四、CI 三件套（打包自检，从狗头军师直接吸收）

1. **路由完整性检查**：路由表引用的每张卡必须存在（删卡=CI 红）
2. **行为回归标记**：写手任务书关键行为句（四段式/接钩/黄金三百字）做字符串存在性检查
3. **CJK 感知 token 预算**：写手系统提示 ≤N token（CJK×1＋拉丁×1.3），超限报错

## 五、防膨胀（狗头军师治理句直接引用）

> **"不设置最低篇数，不以数量激励膨胀"**
> **"删除内容时检查路由和所有相对链接"**

- 首批卡量上限：**30 张**（六族×各 5 张）——超限须先删后加
- 每张卡必须在写手路由表有消费路径——无路由=零消费=删
- 版权纪律：出处锚+最小例句（≤25 字），不存段落

## 六、执行计划

| 步 | 做什么 | 谁 | 产出 |
|---|---|---|---|
| 1 | 定教科书章清单（六族×五书，约 40 章定位） | 脚本（零 LLM） | 选章 JSON |

| 3 | 建路由表＋挂写手任务书 | 主会话 | 路由表进写手.md 按需层 |

## 七、与 KB 的关系（不冲突声明）

本方案产出的**实证实证方法论条目**与 KB §7.x（理论方法论）**互补不替代**：
