# haohao-writing 调研

> 2026-09-29 ｜ fredalxin/haohao-writing（"好好写作"）｜ 6★/无 license/2026-09-06 一次性推送 ｜ **无 license——只借鉴设计思想，严禁复制代码**（同 webnovel-writer 纪律）
> 定位：**文章尺度**（理念文/周报/复盘，非网文）的单技能中文写作 Skill（SKILL.md+8 方法页+2 零依赖 Python 脚本）；宿主 Codex CLI 为主、兼容 Anthropic 格式

## 核心机制

1. **确定性文风扫描器**（check_article.py，只读输出带行号 JSON）：六类字面模式（中文半角标点/编号标题/**翻案句式 11 正则变体**："不是…而是/你以为…其实/看似…实则/真正…的是"/元话语"值得深思不禁让人"/破折号/长气口≥28 字无停顿）＋四类节奏启发式（句长单调/连续软尾"的了性化问题工作"/调子单一/句尾分布）
2. **反 Goodhart 三原则**（贯穿三处文档）：命中表示"这里需要看"不表示写错｜不凭命中打质量分｜不为清零反复改稿——"不能据此识别文章是否由 AI 写成"
3. **八类事实保真清单**（editing.md）：数字专名/代码/动作方向/效果/关系/程度范围/机制条件/引用证据——每类附"保持什么+容易误改的地方"，按场景加查（技术文档/事故复盘/进度汇报各加查什么）
4. **改稿学习四步**：沿用户亲改学表达（看开头换了什么/看展开压缩/看句子连接/应用到未改部分），护栏"一次改动≠全局偏好"
5. **工程**：打包即验证（链接校验→解压→自测→集成扫描→**原子替换** zip"失败不破坏已有"）；脚本内嵌 30+ 断言自测、仅标准库、`python -I -B` 隔离；代码内 `ponytail:` 签名标记"已知限制/刻意范围决策"；单方法页 100-220 行封顶表格化
6. **交互**：默认自治+例外上报（"缺失信息会改变事实或主张时再询问"）；编辑前确认范围（授权多少改多少）；事实缺口与编辑取舍写 editorial.md 与正文分离
