# 产品定义

> 定位：Abzu 产品层的总纲——做什么、给谁用、怎么算成功；域设计、契约、术语与验收文档均以此为上位。
> 依据：迁移自根 `AGENTS.md` 项目一句与 `README.md` 门面陈述，剥离开发底座后扩写；目标用户与成功判据**待设计**。

## 一、产品一句

Abzu 是跑在 Claude Code 上的 AI 写作 skill 套件——面向长篇网文的阶段化创作流程：从立项、设定、全书总纲，到单卷规划与章节撰写，按阶段推进、按门控停靠。

## 二、产品范围（三域）

| 域 | 命令 | 覆盖阶段 |
| --- | --- | --- |
| 大纲域 | `/abzu-outline` | 立项、设定、全书总纲 |
| 卷纲域 | `/abzu-volume` | 单卷规划与收卷判断 |
| 正文域 | `/abzu-write` | 章纲与章节撰写 |

域清单与建设状态的唯一真源在[架构设计](架构设计.md) §一；本表只作产品范围概览——详表（含建设状态）见该节。

## 三、与开发底座的分界

产品运行在用户机器上（安装与使用见 `README.md`）；本仓库根目录与 `docs/standards/`、`docs/specs/`、`scripts/` 属开发底座——不随产品分发，读者是开发者与开发用的 AI 工具。产品层设计（域设计、契约、术语与验收场景）落 `docs/product/`。
