## 写法纪律（全文档步骤单元的统一规矩）

1. **步骤单元七字段**（序固定）：①作用〔一句大白话+一句心流锚〕②收集〔程序要干的事：读什么→取什么〕③怎么想④产物与完备校验⑤过关标准⑥交互〔逐字话术+{变量}占位〕⑦异常与降级。
2. **「怎么想」=思考指令**（问句链/因果指令），禁知识描述。生成型步骤走**四拍流水**：拍一·方法论问句 → 拍二·参考对照 → 拍三·量级参照 → 拍四·灵感注入；收集型步骤拍数递减。**四拍有权重（S33④）**：每个生成型模块标**主拍**（本模块思考密度最高的一拍，问句从密），非主拍问句从简——四拍顺序不变，密度分配看模块性质。
3. **完备律（零待定推进）**：每步产物过关=必填字段全为具体值；「没想好」不停——现场给 2-3 个具体选项让作者选，或触发采风。比较想写的（灵感槽）除外。
4. **序号体系**：章中文序与步骤十位对齐；步骤 `N.M 步骤名`（名字为一级标识）；四拍定名；**门控命名制**（规格门/资料门/定稿门——阶段级硬停）区别于**停靠**（模块级条件停）。
5. **评委铁律**：三维度（编辑/作者/读者）苏格拉底问句，只呈报不拦截——处置权在作者，跳过须登记理由。
6. **数值纪律**：标尺类数值一律范围值+依据强度三级（锚定实测｜多源统计 N 源｜推演⚠️）；情绪用描述性文字，禁百分比。
7. **规格字段准入律**（沙盘 S7 立例）：只有「作者开书时真知道＋影响市场定位」的字段才进基本规格必答清单；创作决策类字段住创作步骤（有语境时再定），规格里最多留**可选倾向**——与「不收金手指/主角设定」同一原则的成文化。
8. **字段值必须可执行**（沙盘 S9 立例）：LLM 消费的字段，值要能直接转成写作/决策指令——基调等风格字段用**受控词表词组**（词表见附录 A-2，词序即主次（跨轴选词时为整体主次，同轴内为局部主次）），比例/百分比类伪精确数值不入字段（与第 6 条「情绪描述性」同源收紧）。
9. **统一情绪词表**（沙盘 S10 立例）：基调字段、参考标尺②情绪基调组、灵感库情绪爽点标签槽、评委问句的情绪判断、分卷五件套情绪弧线，五处共用附录 A-2 词表——一处增词五处生效，查询对比才对齐。
10. **用户语言规范**（沙盘 S16 立例，承旧 SKILL「话术零黑话」）：运行时对作者说的话一律大白话，内部术语只活在设计文档与文件层。对照表（不完整即增）——

    | --- | --- |
    | 档案／档完 | 参考资料包／采完了 |
    | 内核定标 | 这本书的本质类型 |
    | 锚定实测 | 实测（从原书数据数的） |
    | 多源统计 | 多方印证 |
    | 推演⚠️ | 推算值（仅供参考） |
    | 级联 | 连带检查 |
    | 完备律／零待定 | 信息齐了才往下走 |

    | 采风员 | 采风助手 |
    | 标尺 | 标尺（作者原词，保留） |

11. **亲和簇原则**（走查 S26 立例）：耦合的思考放同一模块或相邻模块（**亲和簇内聚**），簇间通过**显式接口**把结论传递给下游（**接口传递**），避免注意力折返——跨模块来回跳会稀释思考密度、诱发返工。首例＝第三章模块序重排：金手指-主角-故事核同簇入 3.1，下游按「金手指三型／体系+底盘」两接口消费（见第三章模块序段）。

12. **作家思维四问**（2026-09-11 作者裁定恢复落地，正式名「作家思维」）：生成型步骤开工前先跑四问（问句链，写在 ③怎么想 的**最前**）——①**理论选择**：这一步该用哪套写作理论/方法论？为什么是它而不是别的？②**知识缺口**：这件事上我有哪些是记不准、可能过时、样本偏的？③**权衡评估**：这里有几条路可走？各自的代价与最坏情况是什么？④**读者模拟**：读者读到这儿会怎么反应——哪里爽、哪里会弃读、哪里看不懂？

    **三级配档**（级别写在 `③怎么想` 行首的方头括号标记里，形如 `〔作家思维：全量〕`）：**全量**＝四问全跑，用于产出创作决策的核心生成步骤（3.1／3.2／3.3／3.4——人设／冲突设计／大纲）；**降级**＝只跑③权衡评估＋④读者模拟，用于采集、统计、评审、处方类（1.1／2.1／2.2／2.3／4.1／4.2）；**免**＝确定性/机械步骤不跑（1.0／3.5／4.3）。**问与拍的关系**：四问是**开工前的前置自检**（回答「我该怎么想」），四拍是 ③怎么想 内部的问句流水（回答「这一步按什么顺序想」）；①的选定注入拍一，②的缺口影响拍二/三的对照口径。

    **落点（文件账本律）**：四问不是空转自省，结论必须有文件落点——①理论选择写进本步 ③怎么想 的首句；②知识缺口逐条落成动作（触发采风／联网核实／问作者），**不得带缺口硬写**；③权衡与④读者模拟的结论写进本步产物的对应字段（3.1 故事核小节／3.2 体系条款／3.3 分卷五件套与节点表／3.4 人物卡），产物无对应字段时写进该模块产物末尾的「已评估」备注。**④不替代评委**：读者模拟是**生成上下文内的自演**，与 4.1 读者评委的隔离素读（刻意不装标尺/规格/底盘）不是同一机制，不得用来省掉评委。

    **正例**＝3.1 故事核：全量四问——①定「本书用哪套故事核模型」、②暴露「这个题材我没数」当场触发采风、③在「爽点前置 vs 悬念前置」间取舍、④定「第一章给不给金手指」；四条结论分别落进故事核小节与该模块的「已评估」备注。**反例**＝3.5 草稿验收跑全量四问：四查是机械校验，四问在此**没有产物落点**（书还没给读者看，「读者模拟」只能空转；四查结论已有验收单模板承载），正是 §5 反模式 #9 要防的空转思考。

13. **参考标尺用法**（作者 2026-09-11 定性：**参考而非硬指标——故事性大于硬指标**）：标尺治的病是**内容密度失衡**（百万字只有两三个反派、主要人物三四个——上千章的作品不该如此匮乏），不是配额考核。

    **十组二分**：**可数组（5 组＋2 派生项）**＝真源已给区间、可由产物机械数出的组——①节奏目标（爆发密度/高潮周期 → 派生**节点数**）、③结构要点（暗线数/换图规划/条目数 → 派生**卷数**）、⑤人物梯队、⑥反派层级、⑦伏笔量；**不可数组（5 组）**＝②情绪基调、④主角压力、⑧读者情绪曲线、⑨爽点类型分布、⑩信息揭示节奏——只作**参照视角**（写的时候对一对量级感觉），不做偏离判定。

    **三层分工**：脚本数事实（从产物机械数出可数组实测值）→ LLM 提处置（对照区间给建议）→ 作者裁决（**改标尺**与**红灯处置**须作者确认）。**本期无脚本**——可数组实测值由 LLM 代跑，须在产物中显式声明「本值系代跑」（标尺脚本属 skill 建设批次）。

    **三级判定**（实测值 n、标尺的区间记作 [a,b]；偏离幅度＝**所在侧边界值**（缺口侧取下限 a、超出侧取上限 b）÷3，向下取整、最小 1）：**过**＝n∈[a,b]；**说明**＝偏离＜幅度（在产物里写一句为什么即可，不阻塞）；**须处置**＝偏离≥幅度。**记录用词**：判定为「须处置」后，产物状态表按四选之一记录为「**已处置**（补／删合／改标尺／接受并说明）」——「须处置」是判定态、「已处置」是落盘态，两者不混用。**判定对象须在本步已成形**——本步尚未产出该组字段时（如 3.1 的 ③ 结构要点）只做对照、不出三态，判定随其成形步补（条目量＝3.2／卷数＝3.3）。

    **处置四选**（须处置时逐项选一，并落行产物状态表）：**补**——按本书自身工艺补足，**禁止为凑区间注水**（新增反派须带层级定位与镜像点、新增节点须带因果与功能、新增伏笔须有埋有收）｜**删/合**——超出时收缩密度（合并功能位、拆卷出场、砍冗余节点）｜**改标尺**——本书体裁/体量与标尺本就不同（非修炼类、短卷结构、平台节奏差异），修正数值并注明依据强度，**须作者确认**（标尺是跨阶段资产，卷纲/正文继续对表）｜**接受并说明**——评估后认为偏离合理（如本书就是「少反派·深反派」结构），写明理由标「已评估·接受」。

    **反机械红线**：差异大时先答「本书是否真需要这个量级」，再决定补／改标尺／接受——**不得为对齐区间新增无功能内容**。**正例**：规格需 10 个反派、区间 15-20 → 缺口 5＝下限 15 的 1/3 → 须处置；评估后若本书确实只需 10 个，出口是「改标尺为 10-15」或「接受并说明」，**不必然补 5 个**。**反例**：看到缺 5 个就派 5 个只出场一次的杂鱼反派——密度指标过了，内容密度更差了。

⑤过关：联动校验全绿+完备律过——硬检查即过关（本步无评委）。
⑥交互（三段式）：

- 段一·你先说（对话）：「先把你想写的这本书聊聊——什么类型、发哪、像哪本书、有没有已经想写的画面？想到哪说到哪，缺的我来问。」

- 收拢式重问：段三未答全时，把剩余必答项合并成一次问清单重问（「还剩三个小项，答完规格就齐了：…」），不逐项追问。
