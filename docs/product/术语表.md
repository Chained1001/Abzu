# 术语表

> 定位：产品语言的**词条表**与叫法权威——工作流类／写作项目文件类／网文创作类共 39 词条（中文名 ＋ 定义 ＋ 英文对应）；用法与维护纪律见 `docs/standards/文字与命名标准.md` §9。
> 依据：迁移自原《术语标准》§2–§4（38 词条，原文逐字）＋ 本批新增 1 条（灵感库）与旧版 §二 业务正反例；维护纪律与治理／资产类词条（`subagent`／`skill 资产`／仓库治理文档等）见 `docs/standards/文字与命名标准.md` §9。

## 一、工作流类

| 术语 | 定义 | 英文对应 |
| --- | --- | --- |
| 立项 | 确定卖点、题材、金手指、目标读者与参考作品的起始阶段，产出 `基本规格.md` | concept |
| 世界观 | 构建世界设定、力量体系与势力的阶段 | worldbuilding |
| 分层大纲 | 总纲→卷纲→细纲逐层细化的大纲体系，每层只细化到当前卷 | layered outline |
| 总纲 | 全书结构，规划分卷结构与主线大事件 | master outline |
| 卷纲 | 单卷的剧情规划，含本卷目标与关键转折 | volume outline |
| 细纲 | 当前卷逐章的拍点清单，是起草单章的直接输入 | chapter outline |
| 起草 | 按细纲写章节正文的阶段 | drafting |
| 修订 | 对已有正文做结构性修改 | revision |
| 润色 | 对已有正文做语言层面的打磨，不动结构 | polish |
| 阶段确认点 | 每个工作流阶段产出后暂停，经作者确认才进入下一阶段的控制方式 | stage gate |
| 会话恢复 | 新会话开始时按既定顺序读取进度与追踪文件、重建上下文的行为 | session resume |
| 作家思维四问 | 生成步骤开工前的四问自检协议（理论选择／知识缺口／权衡评估／读者模拟），按步骤性质三级配档（全量／降级／免）——让 AI 像人类作家一样思考，压住空跑与知识幻觉 | author-mind check |
| 一致性检查 | 核对人物言行、设定、伏笔是否前后矛盾的审查动作 | consistency check |
| 采风 | 问题驱动的定点资料调研——创作卡点处按当前需要检索参照（史料／范式／氛围／节奏／技巧）。**本词只作动作与角色义**——大纲阶段的阶段名／阶段确认点名称／状态值／书目录一律用「资料收集」系（资料收集步／资料门／大纲-资料收集中／`资料/`），标尺类跨阶段资产见「参考标尺」。范围提醒：该动作在大纲阶段实际指对参考清单内各作品做全字段等量深采，不止于本条的卡点定点检索——两者同属 field research，只是层级不同 | field research |
| 采风票据 | 采风产出的统一写入文件格式：来源／用途／关键摘录／关联步骤标签，消费时按标签匹配载入 | field note |
| 采风助手 | 逻辑角色：问题驱动定点调研的执行者（单点叫法），v1 为各域 workflow 内步骤分支，T1 候选物化为实体 agent | field researcher |
| 三评委 | 逻辑角色：读者／编辑／同行三视角独立审同一份大纲的评审组，只看产物不看创作过程，产出处方化报告 | three-judge panel |
| 逻辑角色 | 按职责与输入输出定义的角色（触发／输入／输出／产物／人设），物理形态可为 v1 subagent／步骤或 T1 实体 agent | logical role |
| 内容比对校验 | 采风产出与原素材的相似性／照搬校验，防采风采成照搬 | content comparison check |
| 上下文包 | 起草单章前按该章需要、从各定稿件动态装配的派生视图（细纲拍点＋前情＋快照＋设定＋伏笔），不写入文件 | context pack |
| 写后自检 | 单章起草后的一体化检查：一致性核对＋伏笔登记＋AI 痕迹扫描三合一 | post-write check |
| 参考作品（对标） | 立项必填的质量基准作品（主参考 1 ＋辅助 ≤3，AI 辅助寻找、至少确认 1 本）；是采风定向采集的基准 | reference work |
| 回读补问 | 立项流程中把已采集信息回读给作者、再按六类问题组（题材细化／主角种子／结局倾向／体量预期／更新节奏／雷区规避）补问的采集动作 | read-back follow-up |
| 灵感库 | 跨书用户级外置资产——作者写作积累成的独立库（独立 git、不随本仓分发、跨项目共用）；本仓只消费不生产；当前为初期状态（手动库），其契约在库侧且待消费验证（本仓只认接口形态，不认版本细节） | inspiration library |

## 二、写作项目文件类

| 术语 | 定义 | 英文对应 |
| --- | --- | --- |
| 写作项目 | 用户某本书的目录，由 skill 创建并遵循标准结构 | writing project |
| 手稿 | 章节正文文件，按卷分目录存放 | manuscript |
| 人物卡 | 单个角色的档案（身份、动机、能力、关系、口癖），一角色一文件 | character card |
| 前情提要 | 滚动更新的已写剧情梗概，供续写时快速重建上下文 | synopsis |
| 伏笔账本 | 登记伏笔埋设章节、计划回收点与回收状态的追踪文件 | foreshadowing ledger |
| 人物状态快照 | 各角色当前所在位置、已知信息与关系变化的追踪文件 | character states |
| 参考标尺 | 从参考作品实测出的十二组量级画像（范围值＋依据强度三级），供大纲／卷纲／正文跨阶段对表；**参考而非硬指标**——越界须按三级判定处置 | reference scale |
| 进度 | 记录当前所处阶段与最近进展的文件，会话恢复的入口 | progress |

## 三、网文创作类

| 术语 | 定义 | 英文对应 |
| --- | --- | --- |
| 黄金三章 | 开局前三章的专门设计：悬念前置、金手指早现、钩子密度高于常规 | golden three chapters |
| 金手指 | 主角获得的超越常规的初始优势或成长体系 | golden finger |
| 爽点 | 读者获得情绪满足的剧情兑现点 | payoff |
| 期待感 | 读者对即将发生的兑现的预期，由铺垫制造 | anticipation |
| 章末钩子 | 每章结尾留下的悬念或牵引，硬性质量标准 | chapter hook |
| 节奏 | 剧情推进与情绪张力的快慢配比 | pacing |
| 卷 | 网文的结构单位，一卷包含一个完整的大剧情弧 | volume |

## 四、正例与反例

- ✅ 大纲阶段的阶段名／阶段确认点名称／状态值一律用「资料收集」系（资料收集步／资料门／大纲-资料收集中）；「采风」只作动作与角色义。
- ✅ 「参考标尺」是参考而非硬指标（越界按依据强度三级判定处置）。
- ✅ 三域 skill 的入口一律写 `/abzu-outline`、`/abzu-volume`、`/abzu-write`。
- ✗ 把「采风」当阶段名用（如「大纲-采风中」——叫法收尾为本表 §一 采风条）。
- ✗ 同一角色两种叫法并存（如「采风助手」与「调研助手」并用）。
- ✗ 用「对标作品」指代「参考作品」（设计文档中「对标」叫法以本词条为准）。
