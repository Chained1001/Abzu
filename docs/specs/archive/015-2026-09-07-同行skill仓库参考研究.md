# 规格：015 · 同行 skill 仓库参考研究（mattpocock/skills 机制借鉴与采纳裁定）

> 本规格自包含。研究对象的机制事实经 2026-09-07 现场抓取核实（README、仓库文件树、11 份机制文件原文：invocation / SKILL-MECHANICS / CLAUDE.md / CONTEXT.md / CONTEXT-FORMAT / ADR-0001 / grilling / code-review / writing-for-agents 等）；采纳项落位点全部经现场 read 确认（宪法 §3.8 锚点纪律）。

## 背景与目标

作者要求研究 mattpocock/skills（Matt Pocock——Total TypeScript 作者的 skill 工程仓库，自述「Skills for Real Engineers. Straight from my .agents directory」），提炼可借鉴的机制、规范、标准与经验。按外审驱动惯例：发现逐条裁定（采纳/已覆盖/拒绝），采纳项落位为文件级改动清单，作者确认后施工。

**研究对象概览（现场事实）**：

- 26 个 skill 按 5 个生命周期桶分组：`skills/{engineering, productivity, misc, in-progress, deprecated}/`
- 每 skill：SKILL.md + `agents/openai.yaml`（跨宿主元数据）+ 同目录深化文档（SKILL-MECHANICS / CONTEXT-FORMAT / ADR-FORMAT / PHASE-BOUNDARIES / DESIGN-IT-TWICE / tests / mocking / OUT-OF-SCOPE 等）
- 仓库机制件：`.agents/invocation.md`（调用双层立法）、`.agents/adr/0001-0002`、CLAUDE.md（AGENTS.md 为其符号链接）、CONTEXT.md（自家共享语言）、`.changeset/` + `scripts/sync-plugin-version.mjs` + `.github/workflows/release.yml`（版本自动化）、`.claude-plugin/{marketplace.json, plugin.json}`、`.out-of-scope/`（3 份否决留痕）、`docs/`（10 份人读深文）
- **无 tests/ 无 evals/ 目录**（质量保障靠 dogfooding，README 未提测试）
