> 本规格自包含。外审来源：scripts/check.sh 双轨评审（内容 P1×4 / P2×3、性能 8 项）。按宪法 §3.1 转规格逐条裁定，**共 12 项**（采纳 3 / 拒绝 8 / 已覆盖 1；外审「python -m 探测」子建议经实测否决，附于 F1 与 F4 不另计数）。关键实测（2026-09-07，锚点纪律）：`python -m agentskills` / `python -m skills_ref` **均不可行**——本机 `importlib` 探测 `skills_ref` 包存在但无 `__main__`（"is a package and cannot be directly executed"），`agentskills` 模块名不存在；现状锚点为 check.sh 全文逐行（51 行，L6/L14-21/L35/L40 为改动落点，行号系原版坐标，施工顺序致漂移时以原文锚文本为准）。

### 2. check.sh 探测链补 Unix 用户安装路径 [A]（审查分身 P1-1 更正：位于第一个探测块之后）

  AS=$(ls "$HOME/.local/bin/agentskills" 2>/dev/null | head -1)

## 三、验收标准

- [ ] `bash -n scripts/check.sh` 语法通过
- [ ] `grep -c "pipefail" scripts/check.sh` = 1；`grep -c ".local/bin/agentskills" scripts/check.sh` = 1；`grep -c "若因未安装，先执行一次" scripts/check.sh` = 2
- [ ] `bash scripts/check.sh` 全绿退出 0（本机 agentskills 在 PATH，探测链新分支不触发）
- [ ] 探测链新分支沙盘验证（审查分身 P0-1 补齐步骤，防假绿）：.tmp 下模拟——①提取改动后脚本的探测段为独立脚本；②置 `PATH` 排除 agentskills **且** `LOCALAPPDATA=` 置空 **且** `$HOME/.local/bin/` 放置假 agentskills 可执行文件；③断言 AS 解析到假路径（新分支命中）。只排 PATH 不够——Windows 分支（不依赖 PATH）会先命中致假绿。验完删 .tmp
- [ ] `git status` 变更为四项：check.sh、CHANGELOG.md、collab-log.md（行 9 登记）、本规格归档（审查分身 P1-5 修正）
