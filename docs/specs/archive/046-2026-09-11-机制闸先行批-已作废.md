- **② 模块级白名单区**（锚行首 ALLOWED = re.compile(，加在它**之前**）新增常量，并在形态闸中引用：

  ```python

  EXEC_BLOCKED = re.compile(
      r'^(bash|sh|node|npx)\b'
      r'|^(python3?|py)\b.*\s-c'
      r'|^(python3?|py)\b.*\s-(\s|$)'
      r'|^(python3?|py)\s*$'
  )
  ```

  （**四条备选各有明确对象**：① shell 解释器与包执行器整族；② 解释器带 -c 的任意代码入口（**不要求 -c 后跟空白**，故 `-c"x"` 形态一并拦下）；③ 从 stdin 读代码的裸连字符形态（`python - <<EOF`、`python - x`）；④ 裸解释器（`python`／`python3` 无参数）。第 ③④ 条是一审报告指出 `python3` 与裸 stdin 两个漏网后的补入。**反面教训（复审独立实测订正）**：三稿曾用 `\s-(\s|$)` 试图覆盖 stdin 形态，实测该式**会误伤**正常命令——凡以解释器名开头、行内任意位置出现「 - 加空白」者皆命中（如脚本路径中含连字符、或带 `-` 参数的长命令），且**并不能**覆盖 `python - <<EOF` 形态；故改为「`\s-c` 不限后随字符」＋「`\s-(\s|$)` 双备选」＋「裸解释器」三条分工。第 ③ 条仍会拦下极罕见的合法用法（如 `py - x`），判定为**可接受的误伤**。

          print(line)
      except UnicodeEncodeError:  # 编码侧崩溃：非 GBK 字符（如报告分隔符）
          print(line.encode('ascii', 'replace').decode('ascii'))

          _safe(f'[{i}] {src} exit={r.returncode}: {c}\n    {head[:200]}')

## 三、验收标准

**断言口径声明**：命令一律用 git grep 的固定串计数形态（-F -c，数命中行）；-F 不可省（默认 BRE 下含 `*` 或 `+` 的模式会 exit 128）；**零命中时退出码 1 且无输出＝通过**。命令不含 shell 变量、不含循环、路径全字面量；围栏块内**不写注释行**（预验器跳过 `#` 行）。本规格**不改** docs/specs/** 与 CHANGELOG.md（仅追加其自身条目为过程产物）。

git grep -F -c -- "|python|py|npx)(\s|$)" scripts/check_spec_assertions.py
git grep -F -c -- "EXEC_BLOCKED" scripts/check_spec_assertions.py
git grep -F -c -- "if EXEC_BLOCKED.match(c):" scripts/check_spec_assertions.py
git grep -F -c -- "crashes" scripts/check_spec_assertions.py
git grep -F -c -- "r.stdout is None" scripts/check_spec_assertions.py
git grep -F -c -- "_safe" scripts/check_spec_assertions.py
