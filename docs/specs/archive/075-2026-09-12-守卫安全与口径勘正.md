## 六、被否决的替代方案

- **动态阶段改 `shell=False` ＋ `shlex.split()`** → 否决：① Windows 下白名单里的 `npx`（`npx.cmd`）等 `.cmd` 载体无 shell 无法直接 CreateProcess（虽然 `unauditable()` 已把 `npx` 整族拦下，但白名单形态随批次会变，留此隐患不划算）；② `shlex.split` 的 posix 语义会吃掉本仓断言 token 里的反斜杠转义（如反引号转义形态），`posix=False` 又保留引号 → 两难；③ **真正要关的两个向量**（引号内展开符、参数级写）由 F1 的「引号内外一律拦 `$`／反引号 ＋ 参数级禁令」直接关闭，且**保住** `\|` 型合法 token 的覆盖面。故本批取 F1 方案，并在 §八 记「若将来要求宿主无关的确定性语义，再评估 `shell=False` ＋ 逐命令参数表」。
