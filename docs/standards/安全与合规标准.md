# 安全与合规标准

> 定位：凭据不入库、外部参考的引用边界与版权、脚本对外部站点的行为边界（限速与礼貌抓取）。
> 依据：旧仓《项目宪法》红线「外部参考只读」与「密钥与凭据不入库」两条、旧仓《文件规范》脚本编写规范的限速行、`main` 存档 `docs/product/总纲.md` §六 外部对标与规范依据（外部参考纪律）与旧仓域设计文档的资料收集合规约束（来源件与相关域已随 rebuild 作废，条文逐条迁移，逐条出处见各条括注）。

## 一、条文

### 1. 凭据与敏感信息

1. **密钥与凭据不入库**：token、key、密码、`.env` 类文件不进 git；凭据一律用环境变量；已提交的凭据视同泄露，立即轮换。〔出处：旧仓《项目宪法》红线第 6 条〕本条与 `AGENTS.md`「红线」节同源——红线给禁令，本条给实施细则（不复制红线全文）。
2. 外部资源位置类配置同样走环境变量，不把机器相关的绝对路径硬编码入库（如外部素材库位置由环境变量指认）。〔出处：旧仓域设计文档的外部素材库接口：真源指向环境变量所指目录，未声明路径即降级〕

### 2. 外部参考的边界

1. **外部参考只读**：引用的外部项目与参考目录绝对只读——不在其中安装依赖、跑构建、跑联网命令。〔出处：旧仓《项目宪法》红线第 3 条〕
2. 引用分级如实标注：设计与规范条文只可引用外部权威源，并按其级别如实标注（官方规范与文档／官方实物与社区标杆／目录评测三类），不虚标分级。〔出处：`main` 存档 `docs/product/总纲.md` §六（分级 T0／T1／T2 与权威源清单）〕
3. 前作不作设计依据：旧作与参考仓库只作沿革记录与教训出处（失败数据、事故），**不得以「某项目这么做」为任何设计立据**；例外是架构参照研读——可作架构优缺点、踩坑记录与好机制的参照系研读，设计主体按本仓已商定理念独立推进，研读所获须标注来源，学了不照搬、不复制实现。〔出处：`main` 存档 `docs/product/总纲.md` §六（外部参考纪律与架构参照研读例外）〕
4. 研究程序：点名研读的仓库／规范，其成果须先转正式规格再施工，逐条标注采纳（落位到文件节与自由度）／已覆盖／拒绝（带理由）——禁止拿到外研结论直接改文件。〔出处：旧仓协作日志参考研究裁定表与转化纪律〕

### 3. 版权与第三方内容

1. **不复制原文入库**：对外公开发布的样本内容（无需越权即可访问者）是「不爬原文」的唯一合法例外，且只做统计锚定（数节奏、密度），不复制原文入库，使用处标注「锚定（公开样本）」并留痕来源 URL。〔出处：旧仓域设计文档资料收集步的试读锚点约束〕
2. 参考档案记录事实性数据与评论综合（作品名、字数、结构层级、公开共识等），不搬运正文原文。〔出处：同上，硬数据／判断类／背景类分权条款〕
3. 引入第三方内容（代码、文案、素材）时补 `THIRD_PARTY_NOTICES.md`，并核对其许可与本仓 `LICENSE`（MIT）的兼容性。〔出处：旧仓《版本与发布规范》发布前置「引入第三方内容时补 THIRD_PARTY_NOTICES.md」〕

### 4. 脚本对外部站点的行为边界

1. 限速：对外部网站的请求间隔 ≥ 2 秒；失败退避重试 ≤ 3 次（2s／4s／8s）；部分成功时在 stderr 明示缺失规模。〔出处：旧仓《文件规范》脚本编写规范「限速」行；旧仓域采集脚本契约〕
2. 站点范围：只检国内可达站点；**境外站默认不访问**——如确需境外信息，走合规评估后再定。站点白名单与检索预算属域设计真源范围，本标准只定行为边界。〔出处：旧仓域设计文档资料收集步的站点白名单／黑名单条款〕
3. 受限内容不抓：只取公开页面信息；不抓视频字幕、音频转写一类受限内容（视频页只取简介与评论）。〔出处：同上，白名单括注〕
4. 超时与降级：每个外部调用有超时上限，超时后降级或报错；依赖不可用时逐级降级，不静默失败。〔出处：旧仓《Skill 写作规范》运行时规范「超时上限」「降级行为」两行；契约细则见[运行环境标准](运行环境标准.md) §5〕
5. 采集类脚本的入口与用法须自声明（依赖、站点范围、限速），使审查者能据脚本头注判定其外部行为。〔出处：旧仓《文件规范》脚本文档头四要素「依赖与前置」〕

### 5. 用户数据与书稿

用户书稿文件的写入边界（默认禁止自动改写用户书稿、迁移默认只出说明）与有副作用操作的停靠确认，分别归[版本与分发标准](版本与分发标准.md) §4 与[skill形态标准](skill形态标准.md) §11——本条只作指认，不复制细则。

## 二、正例与反例

- ✅ 凭据走环境变量；外部资源位置（如外部素材库目录）由环境变量指认，未声明即降级。
- ✅ 已提交的凭据视同泄露，立即轮换。
- ✅ 在外部参考目录内只读者视角研读；要跑构建或安装依赖时换到独立工作副本（外部参考只读）。
- ✅ 引用外部权威源时如实标注级别（官方规范／社区标杆／目录评测）。
- ✅ 公开样本只做统计锚定，标注「锚定（公开样本）」并留源 URL，不把原文抄进档案。
- ✅ 采集脚本请求间隔 ≥ 2 秒、失败退避 ≤ 3 次；采集缺项在 stderr 明示。
- ✅ 引入第三方素材时补 `THIRD_PARTY_NOTICES.md`。
- ✗ 在外部参考仓库内 `npm install` 或跑构建（红线级违规）。
- ✗ 以「某项目这么做」为设计立据（须给权威源或本仓理念依据）。
- ✗ 把公开样本原文复制进参考档案。
- ✗ `.env`／token／密钥文件提交入库（已提交者立即轮换）。
- ✗ 抓取视频字幕或音频转写。
- ✗ 请求失败后无退避地连续重试，或把限速做成 0 间隔的批量抓取。
- ✗ 采集脚本不声明依赖与站点范围，审查者无从判定其外部行为。
