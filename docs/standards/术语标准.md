# 术语标准

> 定位：术语用法与维护纪律——产品语言词条表落 [`docs/product/术语表.md`](../product/术语表.md)（词条与叫法以该表为准），本件管用法、维护规则与治理／资产类词条。
> 依据：存档 `docs/product/总纲.md` §七 术语（叫法权威）逐条迁移（来源件已随 rebuild 作废）；删除仅与已退役域（扫榜调研／拆书分析／文风）相关的词条，其余词条定义原文保留、仅改指消歧；业务词条整块迁出产品层，本件只留治理与资产类词条与维护纪律。

## 一、条文

### 1. 用法

- 首次出现的术语必须有定义，或指向[术语表](../product/术语表.md) 与本标准 §3（治理与资产类词条）；发现第二种叫法当次收口。
- 词条与叫法以[术语表](../product/术语表.md) 为准；本标准管用法与维护纪律。
- 术语优先取既有的通用词——预训练里已有的说法能免费招募先验（读者与模型都少费解）；生造词须在同一处给出定义，且定义本身要花 token（自造词的自带成本），落笔前先问一句「通用词能否替代」。同一概念的叫法不得替换（收口动作见首条）。
- 每条 = 中文名 + 一句话定义 + 英文对应（英文用于 skill 内文件与代码命名）；**例外**：平台标准词可径作词条名（如 `subagent`——宿主生态的既定叫法，中文名反而生造），此时英文对应列与词条名同形。

### 2. 词条分类（已迁出产品层）

工作流类／写作项目文件类／网文创作类词条整块迁入 [`docs/product/术语表.md`](../product/术语表.md)（原文搬家）；词条与叫法以该表为准，本件不复制（单一真源）。

### 3. 治理与资产类

| 术语 | 定义 | 英文对应 |
| --- | --- | --- |
| subagent | 宿主中由主会话派生的 AI 执行体（**独立上下文**＝全新会话、不复用施工期记忆）；**工序角色轨的单称**——由规划方在**会话内 spawn**、**无物化文件、不进用户书项目**（英文对应另有 `process-role subagent`）。**两种用途**：工序角色（施工／独立审查／产物审查，现行默认工序）与实体 agent（运行时物化，待 T1 触发，触发档位定义见 `docs/product/架构设计.md` §四）；区别于浏览器自动化 CLI 这类工具。**曾用名与英文对应对照见 `CHANGELOG` 081 条目** | subagent |
| skill 资产 | 随安装分发到用户机器的 skill 运行时文件（**references／assets／scripts**），引用规则受部署自包含约束 | skill asset |
| 仓库治理文档 | 仓库根目录与 `docs/` 下的规范、记录类文件——不随 skill 安装分发，引用可用 Markdown 链接 | governance doc |
| 调用双层 | skill 触发方式的分层裁定：skill 入口唯一——`/{skill 名}` 显式调用（自然语言不触发）；skill 间禁互调（跨域只经文件衔接）；预留命令薄壳属 user-invoked 编排层——与直呼同属用户显式发起，双层指「直呼 skill／薄壳编排」两级入口（域名清单见[架构设计](../product/架构设计.md)；细则见[触发与交互标准](触发与交互标准.md)） | model-invoked / user-invoked |
| 作者 | 纯裁决位——规格确认、提交确认两处常规出手，另有治理微调的会话内逐项确认与重大分歧裁决（`施工机制` §一） | author |
| 候选类发现（简称候选） | 机器检出但非阻断的发现——只呈报、不影响退出码（与「失败即置红」的守卫相对） | candidate finding |
| 红基线 | 当前已知失败集合；建设期内「未建设」不计入（判据见 `测试与验收标准` §1.2） | red baseline |
| 负向流程守卫 | 「不许发生某事」的检查（与「拦截式宿主 hook」相对） | negative-path guard |
| 维护出处 | skill 资产内指向**仓库治理文档**的标注形态（「维护出处：{件名} §N；运行时不必加载」）——标明该出处仅供维护追溯、部署副本内不存在、运行时不必加载；可执行事实须自包含（写法与正例行见 `命名标准` §5） | maintenance pointer |

### 4. 维护

- 新术语：先查本标准；没有 → 定义后回写本标准（中文 + 定义 + 英文对应；平台标准词可径作词条名，见 §1 例外），再在其他文档使用。
- 改叫法：全仓 grep 涟漪面，当次同步全部引用（grep 词须含概念近义词，不止原句）。
- 退役术语：从本标准删除行，退役记录进 `CHANGELOG.md`。

## 二、正例与反例

- ✅ 术语用平台标准词并随行中文解释（如：`subagent`（独立上下文）、`skill 资产`（skill asset））
- ✗ 把 skill 资产与仓库治理文档同等对待（前者禁跨目录链接，后者允许）。
