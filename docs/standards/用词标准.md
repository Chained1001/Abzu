# 用词标准

> 定位：约束本仓治理文档与运行资产的用词——一词一义、禁比喻借词、禁单字缩写；**禁用清单**（§一.2）是唯一出处，守卫逐行读该段。

## 一、条文

### 1. 用词规则

1. **一词一义**：同一概念全仓只用一个词；发现第二种叫法当次改齐（改一处，或把旧叫法登进 §一.2）。
2. **禁比喻借词**：不得借用实物、建筑、机械类比喻表达机制（如把检查点叫成建筑部件）；机制叫什么，就写它做什么。
3. **禁中文单字缩写**：不得把单字当名词用（如「态」「面」单独成词）；须写全词。
4. **禁自造代号**：不得用自造简称指代检查项、流程或文件（判定步骤一律写它做什么）；编号是标签，引用处须复述它查什么。
5. **禁英文残留**：正文不得混用英文词（产品与生态固有名词、文件与命令名除外）；确无中文对应者，先入 §一.2 再统一替换。
6. **一句一事**：一句只写一件事；并列条件拆成短句，避免嵌套从句。

### 3. 迁移做法

- **生效面＝迁移目标面**：`AGENTS.md`／`docs/standards/**`／`docs/specs/施工机制.md` 与其附录／`docs/product/**`／`skills/**`／`README.md`。条文对**新写入的文本**即时生效；**存量按三批迁移，迁移期不追溯**（故上述件现存的旧词不构成违例）。
- **模板固定节名除外**：标准件模板第三节的节名为各标准件共有，随标准件迁移批统一改（本件暂随模板）。
- **不适用面**：`docs/specs/archive/**`、在制批次规格、`CHANGELOG.md`——过程记录与历史证据，改写即篡改。
- **读旧件时按本清单翻译**：归档件与在制规格里的旧词照读，理解时对照 §一.2 换成新词，不改原处。
- **覆盖边界**：本清单只网已列出的词；单字缩写家族由 §一.1 第 3 条与人工审查兜。
- **迁移分三批**：第一批每批必读件（`AGENTS.md`／`施工机制`／附录），第二批标准件，第三批产品层与 `skills/`。
- **双读窗口**：迁移期守卫恒为新旧双读（规格与守卫的定位写法同时认旧词与新词），直到存量清零。
- **不预先立法**：新增禁用词须先在正文发现实例，再写入 §一.2。

### 4. 可用项目词

下列项目词**不必替换**（已在全仓有定义、单义、用法一致）：规格／批／施工／审查／核验／候选／断言／守卫／红线／不做清单／缺口表；产品领域词：量级／爽点／心流／人物卡。

判定标准：该词在唯一出处件里有定义、全仓只有一个意思、各处用法一致——三条都满足即保留；缺任一条，登进 §一.2。

## 二、正例与反例

- ✅ §一.2 的禁用清单带两行界标，守卫逐行读该段；清单只列实测有实例的词。
- ✅ 机制叫什么就写它做什么：如写「提交前自动检查」而不写建筑部件的比喻。
- ✅ 候选行写法：逐词给出旧词、次数与新词三件（字面见 `scripts/check_content.py` 的 `_check_words()`）；末行报清单词数与命中件数、处数。
- ✅ 新词在唯一出处件里有定义且全仓只有一个意思（如「位置」「判定标准」）。
- ✗ 借用建筑或机械部件的比喻表达机制（如把检查点叫成建筑部件）。
- ✗ 用自造简称指代检查项或流程，引用处不复述它查什么。
- ✗ 把单字当名词用（如「态」「面」单独成词）。
- ✗ 清单段缺界标或缺新词一半：守卫读不到整段即报「用词检查未生效」。
