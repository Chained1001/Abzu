# Abzu 是什么

产品定位、书仓与工件结构。回答「这个产品是什么、它管着什么」。方法论资产另见[判据体系](../标准/判据体系.md)。

相关：[怎么走](怎么走.md)、[术语](术语.md)、[已知问题](../技术/已知问题.md)、[技术现状](../技术/现状.md)。

## 1. 定位

**目标**：支撑几百万字级别的长篇网文——多卷、数百到上千章，长期连续写作，中途可以停很久再接着写。

**范围**：只做写书技巧本身，即构思、设计、写作、修改和长篇一致性维护。不做读者数据（章评、追订、追读率）、平台运营（上架、签约、推荐、更新频率）和商业节奏。

**角色分工**：

| 角色 | 是谁 | 做什么 | 不做什么 |
| --- | --- | --- | --- |
| 作者 | 使用者本人 | 定方向、拍板、批准定稿；可以自己写任何一章 | — |
| 主控 | DSH 主会话里的 agent | 按技能调度节点、组装任务包、调工具、向作者呈报 | 不代写正文，不伪造审读结论，不替作者拍板，子代理失败时不代劳，切书必须作者指定 |
| 子代理 | 隔离运行的 agent | 起草、润色、审读、改稿、沉淀对账、设计评审、采风 | 看不到主会话，只读任务包里给的材料 |
| 确定性代码 | 工具与脚本 | 写入真源、Git 提交、状态推导、字数统计、门禁、审批弹窗 | 不做语义判断 |

**两条基本纪律**：进度只从书仓文件和 Git 历史推导，不靠会话记忆；真源只经专用工具写入，草稿区才允许自由试错。

## 3. 书仓与工件

### 3.1 分区

| 区 | 位置 | 性质 | 怎么写 |
| --- | --- | --- | --- |
| 工作区 | 会话选中的目录 | 可放多本书 | — |
| 书仓 | `<工作区>/<书名>/` | 一本书；本身是 Git 仓 | — |
| 真源区 | 书仓内 `作品契约/`、`故事剧情/`、`世界书/`、`账本/`、`本书记忆/` | 已确认的设计与沉淀事实 | 只经专用工具〔码〕 |
| 构想 | `构想/构想快照.md` | 建书时冻结 | 只读〔码〕 |
| 定稿区 | `定稿/卷NN/NNNN-章名.md` | 作者批准的章节 | 只能经定稿入档追加〔码〕 |
| 草稿区 | 书仓内 `草稿区/` | 候选细纲、材料包、草稿、审核记录、待定稿包、提案 | 可写；不进书仓 Git，另有独立快照仓 |
| 书房 | `<工作区>/书房/` | 跨书资产：灵感池、灵感库、参考库、评审报告、信息释放台账、种子底子、史实基线 | 可写；有独立快照仓 |

### 3.2 主要工件

| 工件 | 路径 | 结构要点 | 由谁写 |
| --- | --- | --- | --- |
| 作品契约 | `作品契约/契约.md` | 六部：题材与读者定位、核心看点与差异化、阅读体验与情绪承诺（可含"章节篇幅"子节）、主角原则与关系边界、叙事方式与文风基调、创作禁区与不可妥协项；每部带〔已确认/暂定/留白〕 | `novel_update_contract`，按部更新 |
| 世界书 | `世界书/模块声明.md`、`世界书/<模块>/<条目>.md` | 按七类模板起稿（含可选「世界常量」速查表模块，写入时自动登记），留白合法 | `novel_confirm_worldbook_entry` |
| 全书大纲 | `故事剧情/全书大纲.md` | 九部：主角目标与成长轨迹、核心冲突与对抗力量（含对手梯队子表）、故事阶段与关键转折、人物弧线与关系发展、主线与支线、线索悬念伏笔、信息披露、读者承诺与兑现、结局方向与远期锚点 | `novel_update_full_outline` |
| 分卷布局 | `故事剧情/分卷布局.md` | 八部：故事阶段分配（每卷一行卷行）、卷目标与卷末状态（主战层级行）、主线与支线分布、人物弧线分布、承诺与兑现分布、信息披露分布、卷节奏与体量、卷间衔接 | `novel_update_volume_layout` |
| 卷纲 | `故事剧情/卷规划/卷NN/卷纲.md` | 叙事结构、弧线、线索推进、卷末兑现四段，加第五段压力升级检查；逐部设计时末尾有"方向选择" | `novel_confirm_volume_outline` |
| 计划时间线 | `故事剧情/卷规划/卷NN/计划时间线.md` | 窗口覆盖、窗口外锚点两节 | 同上 |
| 近期窗口 | `故事剧情/卷规划/卷NN/近期窗口.md` | 近期要写的章节清单，条目名＝章名 | `novel_roll_window` |
| 幕纲 | `故事剧情/卷规划/卷NN/幕纲/幕NN-幕名.md` | 六个必备段：本幕故事、线与伏笔、出场人物、查证清单、章组排布、幕末结算（＋可选段备料自查）；幕末结算段在幕写完时填 | `novel_confirm_volume_outline`（目标：幕纲） |
| 章细纲 | 候选 `草稿区/章细纲/卷NN-NNNN-章名.md`（键带章号，未定位占位 0000；旧格式 `卷NN-章名.md` 兼容读）；确认后 `故事剧情/卷规划/卷NN/章细纲/NNNN-章名.md` | 定位段九节＋四个固定小节（本章形状、已排除走向、冲突与爽点、章末双钩）＋叙事单元 | `novel_new_outline_draft`、`novel_confirm_outline` |
| 材料包 | `草稿区/材料包/卷NN-NNNN-章名/`（键带章号；旧格式兼容读） | 十段＋`材料清单.json` | `novel_assemble_materials` |
| 草稿 | `草稿区/草稿/卷NN-NNNN-章名/稿N.md`（键带章号；旧格式兼容读） | frontmatter 八项；同一时间只能有一份"待审稿" | 起草、润色、改稿子代理；`novel_import_draft` |
| 审核记录 | `草稿区/审核/卷NN-NNNN-章名.json`（键带章号；旧格式兼容读） | 各模块发现项、处置、审读指纹 | `novel_record_review_findings` |
| 待定稿包 | `草稿区/定稿准备/卷NN-NNNN-章名/`（键带章号；旧格式兼容读） | 正文、事实变更、时间线变更、账本变更、章摘要、卷对账、本书层记忆候选、`清单.json` | `novel_prepare_pack` |
| 定稿章与章摘要 | `定稿/卷NN/NNNN-章名.md`；`故事剧情/卷规划/卷NN/章摘要/NNNN-章名.md` | 章摘要 ≤200 字，含"语态样本"行与末行"章末状态" | `novel_settle_chapter` |
| 账本 | `账本/{故事线,人物弧线,承诺,线索,时间线}.md` | 线索状态：已埋/已示/已收/已弃；承诺状态：进行中/已兑现/已结束/已放弃 | 定稿入档时写入 |
| 本书记忆 | `本书记忆/{文风,决策}.md`、`本书记忆/<条目名>.md`、`索引.md` | 两类：文风（锚点段）与决策（偏离处置等）；旧书的对话/灵感文件只读兼容 | 定稿入档时写入 |
| 卷摘要 | `故事剧情/卷规划/卷NN/卷摘要.md` | 卷末汇编 | `novel_confirm_volume_outline` |
| 信息释放台账 | `<工作区>/书房/信息释放/<书名>.md` | 揭示域清单＋逐章揭示登记行 | 主控用通用写工具 |
| 体量对账 | `<工作区>/书房/开书/<书名>/设计草案/体量对账.md` | 路径 B 全书大纲与分卷聊完后、写入前出的对账表（列与规则单源在参考标尺「体量对账」小节） | 主控用通用写工具 |
| 默认文风 | `novel-drafting/references/默认文风.md`（随包分发） | 五层立场（叙述者／表达逻辑／节奏／语言／情绪与趣味）＋数值参照指针 | 单源资产，不改动 |
