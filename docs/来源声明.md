**基于 [lingfengQAQ/webnovel-writer](https://github.com/lingfengQAQ/webnovel-writer)（Scriptor v8.2.0，DSH 插件形态）深度改造**，本地基线对应上游提交 `a0bdd2d`（v8.2.2 合并点，可随时重新克隆对照）。改造主线（0.0.1→0.0.34，详见 CHANGELOG）：

- **数据保护三件套**（草稿区/书房独立 git 版本化、一键备份、事务与锁强化）与产品体验件（路径 A 新手流程等）。
- 上游 v8.2.2 的四族改进（事务/锁/已转提案/记忆守卫）已语义跟入。
