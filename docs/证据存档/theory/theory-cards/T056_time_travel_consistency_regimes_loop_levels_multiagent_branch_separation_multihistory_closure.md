## B. 原始研究问题与对象

Helvensteijn与Arbab 2016直接问：怎样把时间旅行故事或游戏编码成离散时空、因果规则和观察记录，并分别在Novikov自洽原则（NSP）与多世界解释（MWI）下做模型检查。其核心对象不是文本风格，而是状态集合、注入式时间步关系、LTL含过去算子、CTL*含路径量词、因果链和观察者。固定历史下，若规则集没有任何线性模型，则出现逻辑矛盾；分支历史下，冲突可由新分支承载，但空间/时间碰撞等非时间性约束仍需设计者另写规则。[QF118-P1, pp.261-276, §§1-2]

同文把非互动故事与互动行动者分开：作者可控制人物行动并预先构造一致历史，真人玩家却可以故意违反已经观察到的记录。单人NSP游戏可以把悖论作为失败条件，MWI游戏则产生需由AI控制的“量子克隆”。多人情况下，两位玩家各自的记录可以单独满足NSP，合并后却不可满足；NSP给出双方失败，MWI把玩家送入不同分支，互动遂退化为彼此隔离的单人游戏，除非限制旅行自由或空间隔离。[QF118-P1, §§3-4]

Effingham 2023（2021年在线）处理固定过去与可改变过去的哲学二分为何不足以覆盖同一系列中有时可改、有时不可改的叙事。其“混合模型”把普通时间、超时间及回到同一/较早超时间的旅行分开，允许不同次旅行服从不同可变性。固定点不是无条件的神秘禁令；作者把它解释为处于旅行者个人因果史中的事件，若其改变会破坏跨时间/超时间因果环，则低概率阻碍事件会维持相关结果。该说明经常需要为作品补入未明示的跨层因果环，因而是可行性解释，不是文本自动事实。[QF118-C1, pp.1309-1329, §§1-6]

Lahdenperä 2018问循环究竟发生在故事层、游戏机制层还是两者。她以焦点化和行动者位置区分三种情况：只有故事内角色知道并操纵循环；只有故事外玩家通过重试形成循环而角色无知；玩家与角色都知道循环。循环与分叉路径的差别不只在图形，而在是否有同一行动者跨轮保留经验并学习；同一分叉游戏被玩家重玩时可在机制层呈现为循环，而角色只能知道单次playthrough内部的循环。[QF118-C2, pp.143-165, §§1-5]

Hauser与Shoshany 2020则在1+1维扭曲Deutsch–Politzer时空、无质量粒子、离散颜色与特定碰撞律的物理玩具模型中问：多历史能否消除一致性悖论与bootstrap悖论；旅行者能否回到已经访问的历史；有限还是无限历史足够。无限分支/覆盖历史通过不再形成闭合因果曲线而消除两类悖论；有限循环历史仍有闭合曲线，却在该模型中仅当颜色数`C`整除历史数`H`时对全部初始条件不存在一致性悖论。bootstrap悖论还取决于顶点被解释为弹性碰撞还是可穿透交叉。该定理是对特定状态转移律的严格结果，不是叙事作品的普遍循环公式。[QF118-F1, 064062-1–18, §§I-VII, Theorem 5.9]

## C. 核心命题

1. 时间旅行诊断必须先声明一致性体制；固定单历史、不可返回旧历史的分支多历史、可循环返回的有限多历史和混合可变性不是同一模型的同义名称。
2. Helvensteijn–Arbab的离散时空模型`m=(S,→)`要求时间步关系注入，即每个状态最多一个前驱；因此其基本分支树允许分歧而不允许会合。会合历史应继续交由T055处理。
3. NSP把模型限制为非分支线性历史；规则集有至少一个满足模型才算自洽，无满足模型才是形式矛盾。
4. MWI把路径量词加入因果规则，使原状态或新分支可以承载效果；所有NSP模型是该MWI模型域的子集，但这不等于一切分支规则都自动一致。
5. 空间占位、资源互斥或旅行者与旧自身落在同一格的“时间碰撞”可能在MWI下仍无模型；分支不能替代显式碰撞规则。
6. 状态必须容纳与因果有关的人物、物品、位置、记忆和观察；只画时间节点会漏掉决定一致性的内容。
7. 因果规则与观察者记录有关；未被观察的状态可保持欠定，观察过的空位、物体或行动会形成约束。
8. 同一规则集可能有多个满足模型；“不存在矛盾”不等于历史唯一，也不等于作者已经给出唯一真解。
9. 非互动作者能控制人物行动而预先构造满足模型；互动玩家兼具观察者与行动者身份，可以故意制造对记录历史的违背。
10. NSP单人互动可把悖论编码为失败条件；这是一种游戏设计方案，不是一般叙事美学优越性。
11. MWI单人互动在分支后同时留下旅行者和本地旧版本；若旧版本行为不可由真人玩家重新控制，就必须另写克隆策略，原型只以随机器/简化AI处理。
12. 两个观察者的规则集可各自可满足而联合不可满足；多行动者一致性必须检查规则集合的合取，而不是逐人通过就算全局通过。
13. 在Helvensteijn–Arbab的多人游戏模型内，联合冲突在NSP下导致双方失败，在MWI下导致玩家被迫分到不同分支；空间隔离或严格限制旅行是其给出的有限规避方式。
14. 上一命题是特定互动模型的不利结果，不证明所有小说中的多旅行者必然分离，也不提供多化身的完整身份语义。
15. 循环必须区分故事内`diegetic_loop`、机制/话语层`extradiegetic_retry`和两层同时存在的`aligned_loop`。
16. 只有角色跨轮记得并利用经验时，分叉路径才从该角色焦点成为时间循环；若每个角色版本只经历一条路径，重复可能只是话语呈现或玩家重玩。
17. 学习和基于前轮经验改变行动是Lahdenperä用来区分循环与普通分叉的一项定义性特征；重复次数本身不足以判定循环。
18. 玩家重玩线性或分支游戏可形成玩家层循环，角色却可能没有任何循环记忆；玩家知识与角色知识必须分栏。
19. 带故事内循环的游戏被整局重玩时，会形成高一层玩家循环；角色只知道单次playthrough内部的循环，不自动知道另一局的历史。
20. Lahdenperä以可能世界逐次实际化与角色意识合并解释循环；这是概念化方案，不是对真实玩家认知、人物本体或作品唯一语义的实验验证。
21. 某些局部循环只覆盖一段事件，不覆盖全作；一部作品可同时含局部循环、分叉和其他时间操作。
22. Ludovician体制不允许过去改变，但允许因果环；非Ludovician超时间体制用第二时间维把同一普通时刻在不同超时间的状态分开，避免直接矛盾。
23. Effingham的混合模型允许某些旅行向超未来移动而改变历史，另一些旅行停留或回到较早超时间并受Ludovician自洽约束，从而表示同作中“有时能改、有时不能改”。
24. 固定点在该模型中是个人因果史的一部分：改变它会威胁使旅行发生的因果环，故低概率事件可能阻止改变；固定的是因果所需内容，不一定是每个实现细节。
25. 固定点解释常需为作品补入未来/超未来行动者或未明示因果链；若文本没有证据，只能标`metaphysical_embellishment`，不能登记为作品事实。
26. 该固定点账户依赖关于个人因果史、理性概率与内在因果的哲学论证；没有读者实验、语料可靠性或自动检测验证。
27. 无限多历史的分支与覆盖模型让每次穿越进入新历史且不能返回旧历史，因而不形成闭合因果曲线；两类悖论是在删除闭合曲线的意义上被避免。
28. “新历史与旧历史在旅行者出现前相同”是该模型的构造假设；旅行者出现本身立即造成新历史，不需等其主动改变重大事件。
29. 有限循环历史把最后历史重新连接第一历史，闭合因果曲线横跨整个历史束；局部历史可被改变而全历史束仍满足扩展Novikov自洽。
30. 在Hauser–Shoshany特定模型内，有限历史对所有初始条件无一致性悖论当且仅当`C | H`；任何项目转译都必须保存颜色状态、碰撞律和历史数这些前提。
31. 有限循环是否含bootstrap对象依顶点解释而变；把弹性碰撞改为粒子穿透并交换/递增颜色可消除该模型中的无来源粒子，显示闭包依状态转移身份，而非只依图的环形。
32. 相同初始条件可有多个一致演化；闭包测试应返回“无解/一解/多解/未定”，不能把有解自动写成唯一历史。
33. 物理模型没有给出创造新历史的机制、一般时空中的跨历史切换位置、2+1/3+1维推广、现实物理定律、多个时间机器或开关控制；这些均列为未来工作。
34. P1作者明确承认两人都没有理论物理背景；其NSP/MWI是选择的逻辑规则集。F1则是物理玩具模型而不是叙事理论。两者的互补是项目综合，不能写成彼此的经验验证。
35. 四份来源均没有自然章节/卷的完整fabula双端、跨卷多线同步、中文网络小说语料、普通读者实验、平台追读/留存/付费或自动写作评估。

## D. 机制与关系图

`作品/系统边界 -> 一致性体制声明(single_fixed / branching_unlimited / cyclic_finite / mixed_mutability) -> 状态词汇与观察记录 -> 因果规则/时间旅行边 -> 单观察者可满足性 -> 多观察者联合可满足性 -> [冲突类型]时间悖论 / 空间资源碰撞 / 分支隔离 -> 循环层级(diegetic / extradiegetic / aligned)与记忆持有者 -> 固定点是否属于个人因果史 -> 历史连接规则与状态转移律 -> 无解/一解/多解/未定闭包 -> 有界诊断`

必须保持六条分离线：固定单历史不等于单一解释；分支不等于会合历史；故事内循环不等于玩家重试；逐行动者自洽不等于联合自洽；固定点不等于任何细节不可改变；有限循环有解不等于普遍时间旅行闭包。T055继续负责完整分支域、会合历史、重载撤回和化身身份；T056只增加一致性体制、循环层级、联合规则失配和有条件闭包。

## G. 边界与不适用条件

1. 不在未声明体制时混用“过去不可改”“进入平行世界”“覆盖旧时间线”和“同一时间线被重写”。
2. 不把P1的注入式分支树写成允许分支会合；会合历史由T055另行登记。
3. 不因规则有一个满足模型就宣称历史唯一、作品无歧义或读者必能理解。
4. 不把时间碰撞当作时间悖论；空间、资源和身份占位冲突要单独写转移规则。
5. 不把两位玩家各自自洽当作联合系统自洽；必须检查规则合取。
6. 不把特定多人游戏的分支隔离结论外推为所有多旅行者小说的必然结构。
7. 不把玩家重试、读者回看、作者修稿和人物故事内循环混成一类重复。
8. 不把可能世界意识合并当作人物本体事实；它是Lahdenperä的概念化方案。
9. 不把固定点账户用于文本未支持的事件；需要补饰时显式标记`metaphysical_embellishment`。
10. 不把低概率阻碍解释写成实验概率、真实物理机制或通用剧情公式。
11. 不把`C | H`从颜色—碰撞玩具模型外推为“循环次数必须整除角色数”之类写作规则。
12. 不把消除闭合因果曲线的无限历史方案称为已经解决所有身份、因果来源和叙事动机问题。
13. 不把bootstrap重解释为纯拓扑结果；它依粒子顶点的身份/转移解释。
14. 不把物理同行评审论文当作叙事经验验证，也不把叙事形式论文当作理论物理证明。
15. 不生成、重排、补写、修复或评分任何生产文本；未经用户批准不分析具体小说。

## H. 批评、竞争与修正

P1内部已经提供正面—失败链：NSP的固定线与MWI的分支树分别有模型检查语义，但右行观察者在NSP下矛盾；MWI虽能分支，却仍无法解决同格时间碰撞；单人交互可通过失败条件或克隆策略继续，多人联合记录则导致失败或分支隔离。其限制不是后加的谨慎措辞，而是模型自己产生的不利结果。与此同时，作者把两种物理解释直接用于离散游戏规则且自述无理论物理背景，故本项目只承认“选定规则集的形式化”，不承认宇宙真实时间旅行理论。

Effingham直接竞争固定/可变二分：同一系列常同时出现因果环和历史改写，混合模型用超时间层区分。其固定点解释的代价也被作者明说：需要“embellish”作品，补入未来行动者和跨层因果环；逐层再加超时间维虽然能解释更多叙事，却可能变成按案例增加维度的可行性工程。故该来源支持“此类叙事可有一致模型”，不支持“文本实际采用此模型”或“固定点应这样写”。

Lahdenperä修正只看事件图的做法：同一分叉结构从玩家角度可成为循环，从角色角度仍只是分叉；反过来，游戏内角色知道循环，整局重玩时却不知道玩家的高层循环。其证据主要是概念分析和作品案例，65%/35%的游戏统计不能说明首次成功比例，博客评论也被作者明确限制不可广泛外推。故层级区分可成熟，玩家真实性和情感结果不成熟化。

F1严格修正“无限历史才安全”的常见说法：在特定模型中有限循环历史也可自洽，并允许回到旧历史；但`C | H`定理严格绑定1+1维TDP、无质量粒子、颜色更新、同一初始条件和特定碰撞结构。弹性碰撞仍有bootstrap悖论，改为穿透解释后才去除；相同初始条件还可有多个演化。作者明确没有新历史生成机制、一般切换点或现实维度/物理律推广。故它是强形式边界，不是通用闭包完成证书。

## I. 与本项目的有限转译

- **theory_directly_supports：** 建立“作品/规则版本—一致性体制—状态词汇—观察记录—因果规则—单人/联合可满足性—冲突类型—循环层级—记忆持有者—固定点证据—历史连接—状态转移—解数”审计表。
- **formal_complement_supports：** 在明确有限状态与连接规则时，将闭包结果分成`no_consistent_model`、`one_consistent_model`、`multiple_consistent_models`、`underdetermined`；无限历史与有限循环历史分开测试。
- **project_translation：** 对传统小说只在文本明确存在时间旅行/循环规则时使用；循环段落、场景、章节或卷只是容器标签，不从容器边界推出循环语义。
- **project_hypothesis：** 中文长篇时间循环/多世界网文可能需要把T055的分支/化身身份、T056的体制/层级/联合闭包和T051的fabula双端放在同一可追溯表中；该组合尚未做真实文本可靠性试验。
- **not_supported：** 自动决定“正确时间线”；从循环次数判断质量；自动修复悖论；证明固定点增强悬念；预测追读、留存、付费或商业成功。

## J. 实际诊断价值

T056适合诊断“故事说过去不可改，下一次却直接覆盖旧史；两名旅行者各自逻辑通顺，合在一起却互相改写已知事实；玩家反复重试但角色莫名拥有前周目记忆；固定点每次换死法却没有任何维持时间旅行因果环的证据；画了一个环就宣称已经闭包；有限多条时间线有解却被误写为唯一解”等问题。

诊断先要求作品明确体制和循环层级，再把观察者记录与人物记忆写入状态；单独检查每人规则和联合合取；区分时间悖论、空间/资源碰撞与分支隔离；固定点只登记文本证据或显式项目假说；最后在给定转移律上报告闭包解数。其净增量相对T055是“全局体制—联合行动者—循环层级—固定点候选—历史束闭包”；T055仍负责“完整分支—会合历史—重载撤回—化身身份”。两者合用仍不提供自然章卷时间真值或跨卷同步。

## K. 与其他理论的关系

- **与T008：** T008规划角色意图和因果行动；T056检验已给规则在时间旅行体制下是否联合可满足。规划分支不自动选择NSP/MWI。
- **与T036：** T036处理成品叙事中同时多线的编织；T056的多人分支隔离是互动观察规则失配。多线并存不等于多历史。
- **与T042/T043：** 局部时间关系可在每个历史内部标注；T056先决定事件属于哪种历史连接体制，不能把跨历史边无条件塞入单轴图。
- **与T044：** 倒叙是话语重排，人物不因读者再次看到过去就自动处于时间循环。
- **与T046：** 叙事频率的多次讲述不等于角色跨轮学习；循环次数必须带层级和记忆持有者。
- **与T051：** T051报告单fabula轴在时间环/平行世界失效；T056提供何时换成固定线、分支线、混合超时间或历史束的有界规则，但不补自然章卷双端。
- **与T052：** 章际`parallel`粗标签不能区分同时线、替代历史或角色/玩家循环层；T056提供语义拆分，不提供章级完整区间。
- **与T053：** 文本世界可及性登记愿望/信念/实际化世界；T056只对明确时间旅行规则建立历史连接和自洽测试，不能把所有modal-world当时间分支。

- **与T006/T024：** 事件边界和宏命题可作为状态单位候选，却不决定时间旅行连接规则或固定点。
- **与QF-115：** 章节有效状态检索候选可以存记录，却没有验证循环体制、联合可满足性或多历史闭包。
