### 1.3 矩阵读出的三条结构性结论

1. **频率型痕迹（T1-T4）全层可治，管线门禁最确定**——可脚本计数、零歧义、不占生成注意力；提示词层次之；流程侧治本但改造周期长。
2. **结构型痕迹（T5/T6/欠产）外部工具覆盖薄**——开源社区停在词汇/句式层；这三项只能靠细纲规格（着力分级/声腔栏/配给改制）自研。
3. **矫枉过正是治理自身的产品**——连接词清零证明单向阈值会被 R4 过度满足；一切新阈值必须带状＋按本书参照带校准。

## 三、落地批次（裁决后执行；排序原则＝病灶三＋病灶二：低成本高确定性先行，干预位置由门禁→生成→流程→验证递进）

### 第一批：判据与预算（门禁层——零生成注意力成本）

1. **S5 修辞预算制**：散文统计脚本扩四指标＋修一指标——比喻密度（像/仿佛/犹如/宛如 per 千字，参照带 0-2.1）≤2/千字；"不是A是B"≤2/章；三连列举（窄式可测）≤2/章；破折号≤4/千字（文体裁定点见 §六-1）；连接词下限 ≥2.9/千字（修矫枉过正）。先在 test2-6 用 1-4 已知 AI 章×十日三章校准阈值，再按开发流程设计侧先行→搬 A 仓脚本。
2. **humanizer/说人话判据吸收进润色**：26 模式叙事适用子集改写为中文小说语境判据（表演句/金句收尾/三连排比/拔高词/聊天残留——不抄原文，注来源）；说人话三档改动边界（自由/保结构/原位）＋"事实/数字/设定/承诺不动"护栏→润色管线改动护栏。
3. **写作卡吸收预防型手法**（方向三可吸收④）：感官锚点只配高显著位、潜台词、声腔样本注入。
4. **AI 痕迹类型学六条进行文自查卡**：段末格言化/比喻超密/破折号解释/三连列举/清单式全景/对白零冗余——每条给判据问句（例："这段收在动作或悬问上，还是收在重新表述上？""这个比喻处在高显著时刻吗？""这个新场景是首次清点还是在重复清点？"），合并吸收既有重叠条目（一进一出，见 §5.1）。
5. **判据纪律固化**（方向二"不建议"项）：禁"不要写得像 AI"类无操作语义判据；一切判据可数或可问。

### 第二批：流程归还决策权（生成侧——给判据不给答案；均为可选行，不动确认协议）

从方向一 P1-P9 筛选取 4＋1：

1. **P2 写时发现登记位**（最高优先）：候选事实段增第六类前缀 `- 发现：{情节可能/人物意外/主题涌现/自我修正}｜{内容}`；沉淀分拣——情节可能→近期窗口候选，人物意外→人物档案"实测反应"栏。
2. **P1 单元意图行＋P3 双目标对账**（合并为细纲可选增补行一次扩展批）：`- 单元意图：这场要让读者{认识到/感到/期待}什么`＋`- 角色此刻想要：…`（与"目标"字段分立——作者目标与角色目标解耦，张力可声明）。
3. **P4 问号栈**（信息边界/双钩节扩展批）："仍不知道"行升级有序栈——栈顶（本章在答）/压栈（记得但不答）/新入栈记账；零揭示但栈顶推进≠栈顶静默，两种病分开判。
4. **G1 字数配给降级**（§四归位判断的落点）：配给降为参考带宽；验收从机械对表改判据式两问。

缓行：P5 情感结构行／P6 边界判据进热回看／P7 反馈回流（P7 依赖审读产物稳定供给后再评估）。不采纳：P8（五书共识已覆盖，对账确认）／P9（拆书侧资产，不动）。
落点：novel-outline templates/章细纲固定小节规格.md 可选增补行节＋novel-drafting 任务包与候选事实段规格。

### 第三批：生成机制（机制层——S2 依赖第一批脚本）

1. **S3 首句强制变化**：段落首句句型轮转（陈述/对白/动作/时间戳禁连用同型）——治 T7 时间戳节律与首句锚定锁段。
2. **S4 减法写作**：130% 超规格生成→"只删不改"压回规格（删稿指令防"删时顺手改写"）——治 T5 兼治欠产（§四）。
3. **S2 局部重写循环**：复用第一批指标做段级复合打分（段内比喻数/破折号数/"不是…是"计数/连接词零出现），只重写超阈段，不伤已合格段。
4. **S1 min-p 高温采样**：temperature 1.2-1.5＋min-p 0.05-0.1——**对 DSH fork 的宿主侧功能请求**（开放采样参数配置），非提示词可替代，请求可提前发（宿主排期不由本计划控制）。

### 第四批：验证体系（不进生成链）

1. **朱雀/GPTZero 手动抽样门禁**：终稿前人工过一次；不入自动化管线（外部 API＋题库偏差——只做相对门禁，手动步骤不构成运行时依赖）。
2. **本地 burstiness 代理脚本**：句长方差／n 元困惑度代理（对拆书人味语料算交叉熵）／连接词密度／禁模式 grep——输出**相对分**（AI 稿 vs 本书参照带），不做绝对 AI 分；需先拿已知 AI 稿＋人味语料校准。
3. **盲测实验设计**：1-4 章节混五书章节、判官盲评——样本配比/盲评表/判据问句细化后另出实验方案；同时承载方向一遗留三个开放观测项（写时发现供给稳定性／判据内联 vs 心智效力／写前路由 vs 写时判别）。

批次依赖：三依赖一（S2 复用 S5 指标）；四依赖一二（盲测对象是治理后产物）；二独立可先行。

## 四、字数不够问题的归位判断

**判断：归第二批治本（G1），第三批 S4 兼治标；不进第一批。**

1. 根因是 R4×配给的复合——方向二根因表明确 R4 采样层无效、流程/规格层最有效，而流程/规格改动正是第二批领地（G1：配给降参考带宽＋验收判据化——"读者最想看的那一秒写足了吗／配给差 X% 的单元是信息量不足还是偷懒"）。
2. 第一批是频率型判据门禁（修辞密度），管不着注意力分配；把字数塞进去会让"判据预算"超支到非判据问题，加剧 §5.1 的判据轰炸。
3. S4（超规格生成再删）从机制侧直接补欠产：先富余生成、再用删除定节奏，一步同治 T5 与欠产——多一轮生成成本，故列第三批，与 G1 构成"治标＋治本"双保险。
4. 验证：G1 改版后连续 5 章欠产率与"配给差 X% 单元的信息量判读"进第四批盲测观测项。

## 五、风险与豁免

### 5.1 判据轰炸（"处处用力"以判据形态复发）

判据分两类，轰炸只对生成类成立：**门禁类**（脚本事后跑，不进 prompt，零生成注意力成本）与**生成类**（进卡/任务包，占注意力）。三原则：**能落脚本不落卡；能合并不新增；一条进必一条出。**

| 批次 | 进 prompt 的新增判据上限 | 说明 |
|---|---|---|
| 第一批 | ≤6 条（T1-T6 自查卡一张） | 五项预算指标全在脚本侧；自查卡六条须合并吸收既有重叠条目 |
| 第二批 | 0 条（只加通道/登记位） | 可选行 ≤4 条/文件；缺省不拦、写了不校 |
| 第三批 | ≈1 条（首句轮转） | 其余为机制类（配置/流程/管线） |
| 第四批 | 0 条（不进生成链） | 验证侧独立 |

复核机制：每批落地后用散文统计跑 1-4 新章，对照矫枉过正带检查（连接词是否仍在带内、短句率、单行段落率）——治理是否制造了新的稀有物。

### 5.2 题材豁免（预算制 vs 文风冲突）

1. **阈值不通用，按本书参照带校准**：五书极值带已示差异（句长均值 22.9-56.1，SD 16-45.7）——预算阈值取"本书参照带内分位"，不是普适常数。
2. **绍宋式长句文风**：句长类上限/短句率类判据豁免，改用该书参照带分位；破折号在长句文风中可能是文风器官而非解释装置——是否豁免并入 §六-1 裁决。
3. **类型装置半权**：T7 时间戳属守则恐怖类型自带装置——判"类型放大项"，门禁减半或声明豁免。
4. **豁免声明位**：文风画像层增"判据豁免声明"行（豁免项＋理由＋替代校准带）——豁免必须配替代校准，不允许无带裸豁免。
