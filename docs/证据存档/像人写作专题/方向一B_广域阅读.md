## 一、核心命题与结构性发现

**命题**：人类作家写第 N 章时，参照的不只是"第 N 章细纲"——脑子里自动携带**前面全部的语感积累＋后面模糊但确定的方向**。Abzu 的起草子代理是隔离设计（看不到主会话、不预装技能、只见任务包），**广域必须显式喂**。

**结构性不对称（本补研最重要的一条）**：人类的广域是**低成本高带宽**——已写文本作为写作约束"免费"驻留在工作记忆里（T003 C03：已写文本成为后续写作的新约束），远期画面/主题作为长期记忆自然在场；我们的广域是**高成本低带宽**——每多喂一件都占任务包体量与子代理注意力。因此补广域的判据不是"复刻人脑携带的一切"，而是**单位字数的边际收益**：喂"一句级"的远端锚（方向句/承诺句/原句引句），不喂"一段级"的远端正文。

**一个反向校准（防过度设计）**：人脑的广域也不可靠——乌贼 ch895 奥黛丽"嘟嘴"人设争议时，作者靠**全文检索自证**用法频次才反驳读者记忆偏差（batch876 摘录）。人脑广域＝模糊在场＋按需检索；Abzu 的账本（索引）已等价"按需检索"半边，**缺的是"模糊在场"半边——低分辨率常驻锚**。这给四件的设计规格定了性：**索引之外补语料级的一句，不补段落**。

## 三、块 2·四缺口分析

人类"广域"的内容分类与 Abzu 逐项对表：

### 缺口①：语感连续性（最近 2-3 章而非 1 章）

- **人类**：语感来自近期已写文本的持续暴露（写前重读/滚动记忆）；语态漂移在 3 章尺度显形（作者命题；A 仓语态样本机制自述"跨章语态基准，防语态漂移"同口径）。
- **Abzu 现状**：3 章摘要＋3 行语态样本**已在衔接段内**；但写作心智指令只说"重读上章末尾原文与衔接段"——语态样本行淹没在 3 份 200 字情节摘要中间，子代理无"这是语感基准"的信号。正文原文只有 800 字×1 章（人作家重读至少整章）。
- **判**：**半缺（指令缺口非材料缺口）**。修法＝指令点亮（把语态样本行从"顺带看到"变"点名读"）；可选加码＝上一章末尾字数 800→1200-1500（预算常量单点改）。成本近零，收益直接作用于 T 系之外的人味底层（语态连续）。

### 缺口②：远期回响（写第 50 章时记得第 3 章的伏笔细节/人物口癖）

- **人类**：E4 千章预埋——写 1100+ 章时第一部种子"有意识埋线勾勒"仍在场；人物口癖（奥黛丽嘟嘴）数百章持续到读者能争论频次（E8 反证其持续在场）。
- **Abzu 现状**：账本是**索引不是语料**——线索条目有埋设点章号、无埋设原句；一行制 roster 给子代理的是"有这条线"的事实，不是"那句话当时怎么说的"的语料。远期回响要兑现出"呼应感"（同词/同物/同口癖复现），必须见过原句。写前十查③到期过滤在**组装侧**（主 Agent）起作用，到期条目全文进包——但"未到期但本章可轻触"的远期伏笔只有一行。
- **判**：**真缺**。修法＝账本线索条目增 `埋设原句：`一行（沉淀时登记）＋组装侧过滤（活跃＋跨度>20 章≤3 条带原句）。存量条目无此字段则缺省跳过（渐进迁移，不回填）。

### 缺口③：后向压力（知道卷末要去哪——写本章时留斜度）

- **人类**：E2/E3/E9——写下一段时手里握着下一段的结尾画面，开书时握着全书结尾；这使当前章自然长出"朝那个方向的斜度"（伏笔/人物位置/情绪蓄势）。
- **Abzu 现状**：**子代理看不到卷纲**。走向定在卷纲层、细纲承接（novel-outline Off-limits），但承接产物是章级事件序列；卷末兑现段只在"窗口名命中"时偶然进包（assemble.ts 暂定与警告段逻辑）。章末双钩的兑现章号管 ≤5 章近视野，卷末中视野无人携带。
- **判**：**真缺（四件中最重）**。修法＝卷末兑现段首 1-2 句常驻进包（脚本抽取，无条件不再依赖窗口名命中）。注意形态：给**方向句不给路线图**——与方向一 G 族"给判据不给答案"同构，不构成新的预决定。

### 缺口④：主题在场感（全书要说什么）

- **人类**：E5/E6——主题以氛围在场（"为了最后十几章不再去提"），取舍围绕中心思想防侧重点偏移。
- **Abzu 现状**：契约六部有「阅读体验与情绪承诺」分部（novel-design SKILL 确认），但起草任务包的文风基准只取「叙事方式与文风基调」分部——**情绪承诺对子代理不可见**。主题在流程里只在设计侧（定调/评审）起作用，生成侧失明。
- **判**：**真缺**。修法＝该分部首 1-2 句常驻进包（脚本抽取）。

### 成本收益总判

四件的共同规格：**一句到三句级、脚本可抽取、不新增取数步骤**（全部从已在组装链路上的文件取：章摘要/卷纲/契约/账本）。对照"包已很大"的约束（效率调研口径：固定件占 40-50%），四件合计 <300 字，增量 <4%，且其中两件（卷末句/承诺句）是卷级/书级常量——天然属固定件缓存域，比每章变量件更便宜。

任务包新增节 **「广域视野」**（四行式，脚本产出自材料包组装链路，随包派发）：

| 件 | 内容 | 来源与机制 | 每章变量? |
|---|---|---|---|
| 1. 近三章语态样本 | 最近 3 份章摘要的 `语态样本：` 行原样并置（3 行） | 材料已在衔接段——**新增的只是消费指令**：写作心智·写前重读改为"重读上章末尾原文，并读最近三章「语态样本」行找回语感基准" | 是 |
| 2. 卷末方向一句 | 本卷卷纲「卷末兑现」段首 1-2 句（约 30-60 字） | assemble.ts 暂定与警告段增无条件抽取（现仅窗口名命中） | 否（卷级常量） |
| 3. 全书情绪承诺一句 | 契约「阅读体验与情绪承诺」分部首 1-2 句（约 30-60 字） | assemble.ts 同上无条件抽取 | 否（书级常量） |
| 4. 本章远期伏笔引句 | 账本活跃线索中跨度 >20 章（预期兑现区间上限−埋设点）者取前 ≤3 条，各带 `埋设原句` 一行 | 沉淀对账.md 线索新埋条目模板增 `- 埋设原句：<一句原文>`；assemble.ts 故事线承诺线索段增过滤；存量无字段跳过 | 是 |

**落点**（按件拆）：

1. 件 1＝`novel-drafting/SKILL.md` 写作心智·写前重读一句改写（纯文本）；
2. 件 2/3＝`packages/core/src/assembly/assemble.ts` 暂定与警告段抽取逻辑＋`novel-outline/SKILL.md` 备料段描述同步（十段结构不变——两件并入既有段，不动 `材料清单.json` schema）；
3. 件 4＝`novel-settle/agents/沉淀对账.md` 线索模板一行＋`novel-settle/SKILL.md` 对应行＋assemble.ts 过滤；
4. 广域视野作为**消费指令的节名**活在任务包（主 Agent 组包时以四行小节置顶或并入写作心智后），材料本体不必新开段——两种并法（并入既有段 vs 新开段十一）以"并入既有段"为建议（免 schema 动）。

**成本估算**：3 行语态样本（约 90-150 字）＋两句常量（60-120 字）＋≤3 条引句（60-90 字）≈ **210-360 字**，对照包体 8-15k → **增量 1.5-4.5%**。开发成本：core 一处抽取逻辑＋两个 SKILL 文本修订＋一个沉淀模板行。

**与效率专题的兼容**：件 2/3 是卷级/书级常量，恰是固定件缓存的最佳形态（只在卷/书边界失效）；件 1/4 搭既有衔接段与账本段的组装链路，不新增取数步骤。固定件缓存化不受影响。

**风险与护栏**：

1. **防"主题轰炸"**（§5.1 判据轰炸的广域版）：情绪承诺句只给一句，不给分部全文——主题在场感靠低分辨率常驻，不靠反复申明（E5 的教训正是"前面反复强调，为了后面不再提"——申明过度的主题会死）；
2. **防新的预决定**：卷末方向句是方向不是路线图，不得附兑现步骤（那是细纲的事）；
3. **防引句膨胀**：件 4 硬上限 3 条，宁缺毋滥（与候选事实段同纪律）；
4. **存量兼容**：老书账本无 `埋设原句` 字段——缺省跳过不报错，不要求回填。
