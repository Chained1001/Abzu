## 二、排序逻辑归纳

**总结论：时间线顺排为骨、信息释放顺序决定插位、末单元由"开什么问号"反选——三层嵌套，不是单因子。**

1. **时间线是默认骨但不是裁决者**：全部 11 章主时间线均顺排，无一处倒叙场景单元（大奉 ch9 山海背景是嵌在对话流内的闪回叙述，非场景单元）。时间线被违反的只有一种形态——**冻结瞬间插入反应蒙太奇**（ch373 单元 2：战斗骤停，插入四方 POV 扫描后恢复；反推报告弧 B 同款"最暗→最亮镜像对切"）。插不插、插多长，由信息释放需求决定：口供波（单元 3）之后必须垫信念尚存（单元 4/5），物证波（单元 7）才打得动。
2. **信息释放顺序与情绪曲线同构**：公审章排序＝惧（立威）→疑（众生）→怒（控罪）→抗（辩解）→崩（验剑）→燃（混战）→压（结盟），每一单元转换读者情绪一档；验剑（物证）压在口供与辩解之后＝释放顺序决策，不是时间顺序决策。对应五书共识#5（信息释放是全书级工程）的章内投影。
3. **钩位决定法（末单元反选）**：末单元的唯一选法是"它开什么问号"，与其内容重量无关——末单元字数全部最小（47/84/98 字级，占 2-5%），且**不收信息只开信息**（ch500 紫裙少女两句话；ch1 末拍讨卷宗）。收信息单元放中段。
4. **卷末章 POV 换轴排序**：余韵两单元（旧线：八卦台＋喜剧复读）→新图三单元（潜龙城/任务/钩），顺序＝清算在前开户在后（五书共识#10 卷末清算＋下卷引信的章内落位）。
5. **颁布章的规则分批释放**：十日 ch2 规则先给一半、抽牌时补刀"说谎者必须说谎"——执行意外被设计进单元序列层面，不是写时随机。

## 三、字数分配规律

1. **不平均是常态且极差巨大**：语料单元配给极差（章内最大/最小单元比）＝大奉 ch1 2.2×、ch9 3.3×、ch373 4.3×、ch500 17.9×；十日 ch2 13.5×、ch96 7.4×、ch116 4.8×。人类作家的单元字数分布近似幂律：极少数重场单元吃掉大块，大量小单元速过。
2. **字数跟着读者注意力走，不跟事件走**：ch373 全章最长的不是战斗（917/912）而是验剑崩塌（1169）与立威/众生扫描（1134/1142）——反推报告弧 A 模板提炼原话："听众的即时反应就是情绪放大器"。反应单元、崩塌单元、揭示单元吃字；对抗波最短（269）。
3. **压缩带：交接/背景/垫层**：交接 147、背景闪回 312、余波 186、辩解 269——功能为铺垫的单元一律 0.3-0.5 倍章均值速过。
4. **章级总量由章型定，单元级由戏定**：大奉全书均值 4106 字/章，ch373 高潮 7963（1.9×）、ch16 过渡 1810（0.44×）——与标尺每章字数三档行/终卷通胀律一致；章型档是结构约束，档内分配是注意力分配。
5. **钩单元一两句话**：47-98 字，不超过全章 5%。

## 四、拆并信号

**合并写（相邻单元合一）**：
- 同场＋同时空＋功能同 → 合一（ch186 整章一单元；ch9 餐桌推理＋群像＋猪队友信息三事合一单元）。
- 长时间跨度压缩为蒙太奇连排（ch16 日记：一月压成 15 条，单条 20-200 字）。
- 喜剧外壳＋功能内核合并（ch116 借烟喜剧＝组织密谈的功能单元）。

**拆开写（切开成独立单元）**：
- POV/空间变 → 必拆（ch500 三地；ch373 众生扫描内逐 POV 小块）。
- 信息释放分波 → 同一时空连续也拆（ch373 口供波/物证波分置，中间垫反应）。
- 情绪大转向 → 同场也切（控罪→辩解→崩塌；对应 KB §6.5"这个场景的情绪有转向吗"的单元级放大）。
- 钩独立成末单元 → 全部样本章无例外。

**冻结插入信号**：大事件中途暂停→多 POV 反应蒙太奇→恢复主线（ch373 单元 2；反推报告弧 B ch471-478 镜像对切同构）。

## 六、条目裁定（5 条：3 核心＋2 可弃；暂编 U 序，落位编号待作者定）

**U1 拆并判据**（三维切分＋情绪转向）——核心
- 触发点：细纲段叙事单元列表落笔时
- 时序位：写前
- 思维序列：①本章事件按时间/空间/POV/目标四维粗切成候选块 → ②相邻块四维全同且功能同→合并；任一维变且读者需重建情境→拆开 → ③同场强情绪转向（读者情绪换档）处即使四维不变也切 → ④长时间跨度压缩为蒙太奇单元（连排小条），不逐场展开
- 方法绑定：KB §6.5（换场维度判据：时间/空间/角色/目标/因果，变维越多边界越清楚）；情绪转向判据＝§6.5 判断标准第三条
- 红线：无情境模型更新且无情绪转向的切分＝伪单元（凑数拆分）；同场强转向硬合＝节拍丢失
- 落点：细纲段单元列表
- 停机条件：过渡章简章（单元≤3）时降为一次粗切＋蒙太奇二选一
- 冲突裁决：与定位段冲突与爽点冲突时本条先让（结构服务于节奏）
- 运行时形态：拆单元时数维度：时空-POV-目标变了几个，全同且功能同就合并；情绪大转向同场也切；长跨度压成连排小条。
- 出处：KB §6.5＋语料（大奉 ch373/ch500 多维拆分、ch9/ch16 合并压缩、十日 ch186 整章合一）

**U2 排序＝信息释放顺序**（时间骨＋冻结插入＋末单元反选）——核心
- 触发点：单元序列成形时
- 思维序列：①默认时间线顺排 → ②找本章最大信息单元，问它前后各需什么铺垫与反应（铺垫在前、群像反应垫后）→ ③大事件中途可插反应蒙太奇（冻结瞬间，多 POV 各带一条独立反应，不重复主信息）→ ④末单元反选：它开什么问号——末单元只开门不收信息，收信息单元放中段
- 方法绑定：KB §6.7（信息怎么分配）；参考标尺信息释放分级行；O4 双钩还债预检（末单元开门与钩承诺对表）
- 红线：末单元承载信息收束＝钩位失守；反应蒙太奇无新信息＝复读
- 落点：细纲段单元顺序
- 停机条件：纯过渡章（无揭示计划）只跑①④
- 冲突裁决：与 O2 信息边界冲突时 O2 赢（本条管顺序不管总量）
- 运行时形态：排单元先顺时间线；最大信息单元前后配铺垫和反应；大战中途可插一拍众生反应；末单元只开一个问号。
- 出处：语料（大奉 ch373 口供/物证两波释放、ch500 末单元 98 字只开门、十日 ch2 规则分批）＋反推报告弧 A 公审模板＋五书共识#5

**U3 配字＝读者注意力分配**（戏在哪字在哪）——核心
- 触发点：逐单元预期字数行落笔时
- 思维序列：①逐单元问"读者此刻最想知道/最怕什么" → ②重场单元给足（章均值 1.5-2×；反应/崩塌/揭示单元优先） → ③交接/背景/垫层压缩（0.3-0.5×） → ④钩单元一两句话（≤5% 章字数） → ⑤合计对账——低于目标带下限＝加单元加事，不硬堆字
- 方法绑定：KB §6.6（节奏密度）＋§7.7"笔墨花在读者最关心的地方，不平均用力"（R4 的细纲生成端，同一单源两头用）；章细纲固定小节规格预期字数行（合计对照目标带——现行规格原文保留）
- 红线：全章单元配给比接近 1:1＝均匀化 AI 签名；反应/崩塌单元配给低于对抗单元＝放大器缺位
- 落点：预期字数行（配给合计核对句既有位，本条是其生成端）
- 停机条件：过渡章简章（蒙太奇单元逐条极小，合计对账即可）
- 冲突裁决：与章型字数档冲突时章型档赢（档内再分配）
- 运行时形态：配字先问读者最想看哪一秒：那一秒给足，交接带过，钩一两句；合计不足加事不加字。
- 出处：语料实测（极差 2.2-17.9× vs AI 1.7×）＋KB §7.7＋标尺每章字数三档行＋反推报告§2.4 长短章与事件强相关

**U4 重场深挖权**（单元可吃掉整章）——可弃
- 触发点：本章定位为大揭示/情感重场/公审类时
- 思维序列：①问本章信息释放单元是不是本体 → ②是——允许单元数坍缩到 1-2，全章当一个深挖单元排（对谈/文档/公审皆可为一单元） → ③深挖单元内部用动作-反应交替与阶段升级保节奏（§6.5 六问排场），不注水（§6.6 每句有效率）
- 方法绑定：KB §6.5/§6.6；参考标尺大爽点间隔行三口径（情感重场口径＝重场可容忍至 25-30 万字——重场吃章的章级放大）
- 红线：揭示章拆多单元平行摊薄＝重场失焦；深挖≠对话注水（每句过"删了剧情受影响吗"）
- 落点：细纲段单元列表＋"本章形状"节
- 停机条件：非揭示/非重场章不跑
- 冲突裁决：与 U3 冲突时本条赢（深挖权优先于均匀对账）；与章型字数档冲突时章型赢
- 运行时形态：大揭示章允许整章一个深挖单元：对谈、文档、公审都行；内部靠动作反应交替和阶段升级撑节奏。
- 出处：语料（十日 ch186/187 整章对谈、ch120 文档单元 53%、大奉 ch373）〔坍缩频率的跨书分布未采样——待实测验证〕

**U5 POV 换轴调度**（卷末/主角缺席/反应蒙太奇）——可弃
- 触发点：卷末章、主角缺席章、高潮反应段的单元排序时
- 思维序列：①本章换不换 POV 轴——卷末＝旧线余韵 1-2 单元＋新图开门 2-3 单元（清算在前开户在后） → ②反应蒙太奇冻结插入主时间线 → ③每个 POV 单元带一条独立新信息；旧信息复读必须过人物嘴变形（性格化反应）
- 方法绑定：五书总对照 1.2 共识#11（POV 轮换做信息差手术）＋#10（卷末清算＋下卷引信）
- 红线：POV 换轴单元无新信息＝纯视角搬运；卷末章仍锁主角 POV 错过开户位〔推断——待实测验证〕
- 落点：细纲段单元 POV 标注
- 停机条件：单 POV 常规章不跑
- 冲突裁决：与 O1 情绪接力冲突时情绪接力赢（换轴服务于情绪收束）
- 运行时形态：卷末章换 POV 轴：旧线余韵两三场、新图开门两三场；反应蒙太奇每视角带一条新信息。
- 出处：五书总对照共识#10/#11＋语料（大奉 ch500 三地换轴、主角全章缺席）

**预算说明**：本段占 5 席（3 核心＋2 可弃），第二波合计 ≤10 席的余量留给起草段；若挤压，U4/U5 先弃（其内容可由章型停机条件与"本章形状"节吸收）。

## 七、G 提案裁定建议

**G1（字数配给降参考带宽）——建议采纳（两级改造）**。语料证据：人类单元极差 2.2-17.9× 且随章型漂移，AI 现行 1.7-1.8× 近乎等宽——配额制均匀化在对照中坐实，方向一报告 1.2-1 节"配额诱导均匀化"假说获语料支持。但语料同时显示**章级总量纪律真实存在**（大奉均值 4106、高潮 1.9×、过渡 0.44×，与标尺三档行吻合），故建议两级落法：单元级配给降为参考带宽（±50% 浮动，写时随戏走），章级合计仍按目标带判（"合计低于下限＝加事不加字"现行规格句保留）。**R4 联动**：G1 采纳则 R4 冲突裁决由"配给赢"改判"写时权重赢、配给作参考带宽"（总分架构 §4.2-R4 与 §7-4 已预留联动裁定点），建议同批改；且 U3 条目把"不平均用力"前置到细纲生成端，与 R4 写时端两头夹击——配给从"验收口径"降为"预算基线"，权重判断在生成端先跑一轮。

**G2（场景权重写时升级）——建议改造采纳**。语料证据双向支持：正向——大奉公审模板的核心就是反应/崩塌单元吃掉重头字数（ch373 反应单元合计 2254 字超战斗单元），若细纲把它预判为"过场/带过"这场戏即废，写时升级通道是真实需求；反向——十日 ch116 借烟单元预判为喜剧调剂、写成密谈组织功能，功能升级实有其例。改造点：升级登记位建议挂候选事实段"场景升级"一行（方向一原文方案），并设停机条件——升级仅限配给带宽内浮动（超出带宽走偏离建议交回，防写时失控）；升级频次无实测数据〔推断——待实测验证〕。

**G6（问题式单元）——建议不采纳**。语料证据反方向：全部 11 章样本（含 3 个过渡/间歇章）单元均为事件序列形态——过渡章也不例外（ch16 日记条目即事件、ch116 喜剧+安顿+密谈皆事件）；"带问题进场"在十日的对应物是局规则颁布层（六段节拍的"颁布"段，规则本身即悬念），不是章内单元层。现行流程已有两处等价物：窗口条目滚动（章组级即时性）＋"起止边界"节（承上/交下）；且问题式单元会使配给合计核对、写前十查单元级检查失去取数位，成本大于收益。建议：粒度分级需求由停机条件吸收（O1-O4 及本批 U1-U3 的"过渡章简章降级"条款已是分级形态），不另立问题式单元。
