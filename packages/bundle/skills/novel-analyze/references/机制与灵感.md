# 机制与灵感

机制卡是参考分析正文的维护点：原作观察、解释、读者期待、人物选择与后果、成立条件、失效情形、可探索问题、不可照搬项、未知与其他解释分别呈现。报告汇编覆盖与机制链接，不再复制机制全文建立另一权威。分析有效只表示结构和来源证据仍可核对，不表示该解释已获作者认可或效果验证。

用机制提出当前故事的具体发展，重新考虑本书人物的欲望、条件和选择，不把原作事件链换名套用。跨书相似只称多书观察，不以计数、去专名或改动多少项证明原创性或版权。

新点子进 `<工作范围>/书房/灵感池`，机制留 `<工作范围>/书房/参考书/<sourceId>/机制`。新候选的参考依据固定 `参考书`、`原文版本`、`机制`、`机制版本`；原来的 `来源快照` 仍是 ISO 记录时间，旧三字段和自由正文保留，新增类型/标签可选，未知扩展不丢失。同次保存复用 operationId，不同点子使用不同身份。

来源变化或机制作者编辑只提示依据待核对，不自动改写、删除点子或目标书正式规划。删来源不删点子，删点子不删机制。作者明确收藏原机制时存简短笔记加引用；入池和分析生成均不是本书采纳。

## 重推演四步

由机制推演新点子的固定走法（借原理不搬事件）：

1. 读机制卡抽原理——它为什么有效（爽点机制／信息差／期待管理）？
2. 本书条件适配——我的金手指／人物／读者画像与原作差在哪，这个原理在我的条件下长什么样？
3. 落成自己的场景——用本书人物与设定重演这个原理，不搬原作事件；
4. 入池——推演产物按 save-idea 协议落灵感池（依据照锚）。
