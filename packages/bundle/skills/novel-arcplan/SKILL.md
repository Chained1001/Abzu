# 卷幕规划（Novel Arcplan）

本技能管「每卷、每幕的开头和收尾」：开卷＝强制多方向→卷规划→分幕与第一幕幕纲；收尾＝幕末结算→卷末与卷摘要。开书的一次性设计（契约、世界书、骨架、分卷）在《定调设计》；单章定稿沉淀在《定稿沉淀》。设计侧写入只经确认工具，每次作者确认产生 `design:` 提交；「留白」是合法状态，不为过检编造。

## 标准流程

开卷（含卷01 与每开一卷）思考程序按 [步骤卡-卷规划](templates/步骤卡-卷规划.md) 走；一幕写完按 [步骤卡-幕末结算](templates/步骤卡-幕末结算.md) 走（步骤卡试点：判据要点在卡上，卡住或作者要深挖时按「深挖」列整读对应件）。本节只留通道、判据与边界，不复述卡的思考程序。

判据读件（文字指针）：《定调设计》技能包 references/卷纲-节奏与高潮.md、卷纲-情节类型骨架.md、卷纲-卷功能与结构.md（整读）——判据件留在《定调设计》技能包 references 不动。

### 强制多方向（本卷首次确认卷纲前必跑；卷纲修订与滚窗不跑，路径 A 不跑）

- 读 `作品契约/契约.md` 的「核心看点与差异化」「阅读体验与情绪承诺」两部，列出作者已确认的承诺、禁区和既定事实，标注「不参与发散」。题材惯例只作候选参考，不自行加入“主角必须变强”等硬要求；
- 提出三条因果、人物选择或信息组织明显不同的路线；可用一条典型版作对照，但不默认它最好，也不强制把作者意图改成典型套路；
- 依据本卷矛盾选择发散轴，如代价承担者、揭露顺序、人物立场、解决问题的方式；不同路线应有实质差异，不局限于固定短表，也不只改名称；
- 每个方向都写代价与放弃项，只有好处的方向打回重写；
- 三个方向呈作者选择或组合。卷纲末尾「方向选择」小节格式按 [卷纲固定段规格](templates/卷纲固定段规格.md) 填——`已排除走向` 只记作者明确否决的走向，未选方案不自动成为禁区；

### 卷规划

规划第 NN 卷前先读 `大纲/分卷布局.md`「卷间衔接」节的待补便签——上一卷卷末落的「下卷注意·卷NN」在那里；本卷卷纲确认后把这条便签清掉（`novel_note_pending` 文本留空再调一次，该节若还有别的便签重写保留）。随后 `novel_confirm_volume_outline` 写卷纲或计划时间线（卷纲是整文件覆盖，叙事结构等各段与「方向选择」小节一并给全）；`novel_roll_window` 追加窗口条目。**信息释放台账建账（卷01 卷纲首次确认前，一次性）**：从故事骨架与世界书条目提取「读者最终该知道什么」的清单——力量体系条目同批（其升级节点与验证排期即揭示域条目）——通用写工具落 `<工作范围>/书房/信息释放/<书名>.md`（书房资产非真源，种子底子先例）；台账结构：头部「揭示域清单」表（列＝条目｜层级（卷内/全书）｜状态（未知/部分/已释）｜载体｜知情圈｜释放章｜仍不知道追问——载体＝本条历次释放各用什么载体，同一信息再次释放须换载体（日记/对话/通灵/古迹式为参照，自报载体亦可）；知情圈＝哪些角色已知（角色间信息差——谁知道、谁还不知道，随每次释放更新））＋正文逐章「揭示登记行」（`第N章｜释放条目（清单序号）｜累计已释 x/y＝z%｜新问号一句`——x＝已释条目数、y＝清单条目总数，累计为信息行不作案据；大揭示章 ≤70% 判据按本章口径取数——本章可释集＝台账中状态＝未知/部分且属本章计划范围的条目，可释集分母单源在本台账，判据全文在《细纲备料》技能包 templates/章细纲固定小节规格.md「信息边界」行）；卷02 起不开新账，只按新揭示域追加清单条目。卷纲在叙事结构、弧线、线索推进、卷末兑现四段之外加第五段 `## 压力升级检查`——五核对项（第⑤＝本卷升级位：主角位阶/实力本卷至少推进一处，对照 世界书/力量体系/ 条目台阶）、逐项写法与「方向选择」小节格式按 [卷纲固定段规格](templates/卷纲固定段规格.md) 逐条过；卷末兑现段写前先过「卷末三锚点核对」（三项是核对行不是新段，规格已列）；核对不过的项按留白处理并说明，不为过检编造；叙事结构段内可加结构类型行——给本卷叙事结构一个可命名的类型标注，参照枚举见规格；叙事结构段内可加心动位行——标出本卷必写的心动场景（作者自己最想写／读者最想看的一两处，作者原话记录，情绪锚不是顺序锚），行式与判据见同规格；首次确认或作者点名时可选走《定调设计》「确认前审查」的两席审读（评审两席仍在《定调设计》技能包 agents/）。

**卷级交叉思考**（卷纲正文写完、确认工具调用前过一遍；各条核心问句另挂 [步骤卡-卷规划](templates/步骤卡-卷规划.md) 对应步「同时想」，本处为单源）：

- 本卷节奏 × 上一卷卷摘要末段——上一卷收在高亢还是低谷？本卷开局要接住还是反差？
- 主战对手层级 × 主角当前实力——这个对手打得过吗？打不过靠什么翻？打得过悬念在哪？
- 换图 × 世界观扩展——本卷如果换图，新地图揭了哪些世界真相？不换图的话靠什么新鲜感？新地图起世界书条目时按《定调设计》技能包 templates/世界书/地图条目模板.md，本图班底与旧资产盘点写进条目——换图时对照《定调设计》技能包 references/参考标尺.md「换图 SOP」行核对；
- 伏笔兑现 × 读者期待——上一卷欠的账（卷对账偏离项），本卷怎么还？本卷准备新欠什么？
- 三线断档红线——按《定调设计》技能包 references/参考标尺.md「三线断档红线」行核对（数值与豁免口径照参考标尺单源），越线必须重排，不得带病确认；

**分幕与第一幕幕纲**（卷纲确认后）：在卷纲「叙事结构」段把本卷分成若干幕——每幕一行：幕号、幕名、一句任务、大致章数（体量照《定调设计》技能包 references/参考标尺.md「幕」行取，此处不重述数字）；然后只为**第一幕**写幕纲，正文逐段照 [幕纲固定段规格](templates/幕纲固定段规格.md) 写，经 `novel_confirm_volume_outline`（`目标: 幕纲`，带 `幕`／`幕名`）写入真源 `大纲/卷规划/卷<NN>/幕纲/幕<NN>-<幕名>.md`（`design:` 提交）；开幕时写不出的段（尤其「幕末结算」）留白合法，段标题须在位。**后续幕不在开卷时写**——上一幕写完时在幕末结算里写下一幕幕纲（见下「幕末结算」节）。幕是章序调整的授权范围（例：把后面的情节提前制造小高潮），调整只在幕纲「章组排布」段改、不另报；幕纲「查证清单」里查不到的项标 `【待采风：查询词】`——标【待采风】的项在写幕纲时即可派《素材库与采风》（novel-forage）执行，不攒到开写才补；

### 幕纲评审与关键幕门禁

幕纲起稿完成（路径 B 在设计草案同件）、经 `novel_confirm_volume_outline` 确认写入真源前，按幕派评审：

- **派发分工**：**第一幕与关键幕**的幕纲确认前必派两席评审；普通幕至少派作家评审，或由作者明确跳过（跳过时在呈报里记一句「作者跳过幕NN 作家评审」）。关键幕＝本卷第一幕、承担卷内大高潮的幕、卷末幕；作者可点名把任一幕升为关键幕。
- **串行与隔离**：读《定调设计》技能包 `agents/作家评审.md` 与 `agents/读者评审.md` 底本全文，按**作家→读者串行**各组装任务包派发子代理——两席独立互不通气（后席不读前席报告）；两席均首评默认，收到复评请求走增量复评（只回归上轮主问题＋处置台账「待复评」项，不重读全文）。
- **任务包**：对象类型＝幕纲；对象文件＝`大纲/卷规划/卷NN/幕纲/幕NN-<幕名>.md`（尚未写入真源时指设计草案同件）；判据目录＝《定调设计》技能包 `references/`。作家席另加「真源摘要」（契约相关分部、力量体系境界表与量级切片、世界常量切片、相关人物档案、`账本/线索.md`／`账本/承诺.md` 相关摘录、卷纲与分幕计划本身；只摘相关条目，不塞完整世界书/账本）；读者席只带三参数，不传真源摘要——读者席不审章级正文事实、不读世界书。
- **报告**：两席 return 后由宿主落 `<工作范围>/书房/评审/{书名}/幕NN_作家.md` 与 `幕NN_读者.md`；字段口径同「确认前审查」两席——报告头（评审编号/对象类型/对象路径与版本或哈希/判据版本/评审日期与轮次/主问题）＋七列处置台账＋增量复评节，真源/判定/常理层/预期/文本/差距/负载性（读者席真源列恒「不适用（本席不读真源）」）。
- **处置（门禁口径）**：评审不拦卡，作者可带伤确认；**关键幕的 🔴 硬伤未处置且作者未明确接受时，不得确认写入幕纲、不得开写整幕**——先呈报作者裁决（改幕纲再确认，或明确记「带伤开写」）；普通幕的发现项随幕纲呈报，作者不追即放行。报告落盘后主控读主问题与处置台账，作者裁决后更新台账并按需派增量复评。评审只审幕级结构与因果，不审逐句文笔。

## 幕末结算（一幕写完时，替代原段级刷新）

一幕的最后一章定稿入档后触发，六步依次做：

1. **核对写时发现遗留**：写时发现的分拣在每章沉淀步已执行（0.0.57 起草稿区随定稿清理，本步读不到候选事实段原文）——本步核对的是 `novel_note_pending` 里标「写时发现」来源的未消化条目＋各章沉淀时列入第六节「入档后回写候选」但未落实的遗留，逐条落实（处分口径同《定稿沉淀》沉淀步的「写时发现分拣」——尚未写进正文的新伏笔经 `novel_note_pending` 记到本卷卷纲「线索推进」节，作者确认后在后续细纲排期；人物/设定新发现记对应工件；改窗口/改卷纲先记待改）；
2. **核对线与伏笔**：对照本幕幕纲「线与伏笔」段逐条核——埋的埋了没有、该兑现的兑现了没有（对照 `账本/线索.md`、`账本/承诺.md`）；未兑现的如实写未兑现，不含混；幕纲里写了但本幕没排上的，记入下一幕幕纲的锚点或本卷卷纲待改；
3. **更新出场人物状态**：本幕主要人物的状态变化按《定调设计》技能包 templates/世界书/人物档案条目模板.md 的认知节/台阶节写进世界书条目（经 `novel_confirm_worldbook_entry` 落盘，`design:` 提交）；无变化跳过，不为填节编造；
4. **读者通读（可选，作者要才跑）**：派读者评审子代理通读本幕全部定稿正文，看连续读下来哪里疲劳、哪里会弃——底本用《定调设计》技能包 `agents/读者评审.md`，任务包说明对象是**「一幕的定稿正文」**（对象类型＝幕正文，检查清单见该底本「对象＝幕正文」节）；报告落 `<工作范围>/书房/评审/{书名}/幕NN_读者.md`；
5. **写入幕末结算段**：把上述结果（写时发现分拣结果／伏笔埋收核对／人物状态变化／下一幕锚点建议）写进本幕幕纲的「幕末结算」段——经 `novel_confirm_volume_outline`（`目标: 幕纲`，带本幕 `幕`／`幕名`，`正文` 给整份幕纲含更新后的幕末结算段）**覆盖写入**，版本 +1；向作者呈报；
6. **写下一幕幕纲**：按本技能「卷规划」节的分幕写法写下一幕幕纲草案（照 [幕纲固定段规格](templates/幕纲固定段规格.md) 六段）；按「幕纲评审与关键幕门禁」派评审——下一幕是第一幕/关键幕时两席串行并处置硬伤（未处置且作者未明确接受不得确认写入、不得开写整幕），普通幕至少作家评审或作者明确跳过；然后经同一工具写入、作者确认后进入下一幕——**下一幕的第一章前再按幕成批出细纲**（《细纲备料》「按幕成批出细纲」）。

幕纲未建的旧书（未分幕）：本流程跳过，按原序章节奏写；作者想开始分幕时，从当前章的下一幕起点建第一份幕纲。

## 卷末与卷摘要（当前卷收束后）

每卷末触发：卷末章定稿后依次 卷对账→卷摘要→下卷注意事项，三件一批——卷的最后一幕的幕末结算与卷末流程合并做，不重复（幕末结算六步见上「幕末结算」节）。

本卷已定稿章齐、卷对账处置完毕后，卷摘要走「候选→确认落盘」：

1. **候选（只算不写）**：跑卷摘要候选脚本（随《定稿沉淀》技能包分发：`node <resourceBase>/scripts/卷摘要候选.mjs --book <bookRoot> --卷 <卷>`）——读本卷已定稿章的章摘要全文、账本已收/进行中/已兑现线索、卷纲「卷末兑现」段汇编候选（JSON，`候选` 字段）；任一已定稿章缺章摘要即如实报缺（`ok:false`＋`缺章摘要`），不产候选更不落盘——先补齐章摘要再跑；
2. **呈报**：候选与对账状态一并呈作者——卷对账 `待核对` 非空时，候选与呈报都不得写「无偏离」「已兑现」；候选是汇编不是创作判断，作者可改任何字；卷末呈报时另对照本卷卷纲「压力升级检查」③卷末去向、④终局暗手两项核对实际落稿，未兑现项如实列入呈报；**下卷注意事项**＝作者确认卷摘要时问一句：这一卷写下来，有什么要提醒下一卷注意的？有则调 `novel_note_pending`（`relPath: 大纲/分卷布局.md`，`节名: 卷间衔接`）记一条待补便签——文本以「下卷注意·卷<NN+1>：」开头，多条合成一段写；写入前先读该节现有便签，有旧内容就并成一段再写，不覆盖掉别的便签；作者说的是对方法论或工具本身的意见（不是这本书的事），当场告诉作者「这条属于产品反馈，不记进书里」；下一卷卷纲确认后把这条便签清掉（`文本` 留空再调一次 `novel_note_pending`；该节若还有别的便签，重写保留它们）——本技能「卷规划」节会读它；
3. **确认落盘**：作者明确同意后调 `novel_confirm_volume_outline`（卷、`目标: 卷摘要`、正文）落真源 `大纲/卷规划/卷<NN>/卷摘要.md`——版本协议沿用（首次 v1、再确认版本 +1／父版本指旧版、原样重跑复用版本），随 `design:` 提交；不设上限、不截断；
4. 卷摘要落盘后是该卷权威摘要：下一卷首章备料的「近期正文衔接」自动带它（整文件），本卷后续章材料按章号边界切片；修订同样走候选→再确认，不手写真源。

## 工具

**写入前先读目标**：卷纲（含计划时间线）、幕纲、卷摘要已存在时，先在主会话用原生 `read` 读取目标再调用确认工具（与《定调设计》同规则）；`FS_STALE_VERSION` 时重读并核对作者/外部改动，不覆盖新内容。

| 工具 | 何时用 | 不要 |
|---|---|---|
| `novel_get_book_progress` | 开卷前查待补便签（卷间衔接的下卷注意）与未决偏离 | 跳过校准直接规划 |
| `novel_confirm_volume_outline` | 卷纲/计划时间线/幕纲/卷摘要的确认与覆盖写入 | 手工编辑真源文件；幕纲覆盖写入不给整份正文 |
| `novel_roll_window` | 追加近期窗口条目（卷首与批量补位） | 每章滚一次 |
| `novel_note_pending` | 卷末记「下卷注意·卷<NN+1>」便签（分卷布局「卷间衔接」节）；下一卷卷纲确认后清除 | 把对方法论/工具的意见记进书仓 |

## 重入
