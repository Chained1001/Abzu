## 分层与行 schema

- **L0 通用不变量**：跨样本成立、可脱离题材表述的功能要求；全定性，不写绝对章数/字数/比例。只有 L0 可默认 `gate:true`。
- **L1 通用比率**：分子分母可写清的比率/归一化区间；不写死绝对章数。只有「口径稳定、n≥4、无跨样本冲突」的 L1 可 `gate:true`；低置信、待校准、未验证一律 `gate:false`。
- **L2 模式档**：按驱动／篇幅／连载形态／章长模式／结构型／POV／结局型／世界类型八轴取值；每个值必须带 `轴=值` 键，不用题材标签当轴键。L2 默认 `gate:false`，只作对照。
- **L3 本书覆盖**：本书自报档位＋已定稿章节统计出的本书基线；本书基线 `gate:true`（用于本书后续章节），通用行只做离群预警。本书自报与通用行冲突时以本书自报为先，但必须留痕。

**行字段**：`id`、行名、判定口径/参考值、归一化口径或说明、`consumer`（消费位）、`status`、`confidence`、`gate`、`legacy`。

- `status`：`hard`｜`range`｜`qualitative`｜`experimental`。
- `confidence`：`high`｜`partial`｜`low`｜`unverified`。
- `gate`：`true`｜`false`。低置信／待校准／未验证不得为 `true`；L2 默认 `false`；L3 本书基线 `true`。
- `legacy`：旧行名或旧行名族；无旧行名写 `—`。旧行名索引在文末，一名一行，保证消费点可检索。

**本版纪律**：L0 不出现阿拉伯数字（ID 除外）；L1 只写比率、章级小窗口 run length 与每百万字密度；L2 的绝对值只在本层出现；L3 才允许写本书的绝对章数/字数。低置信、待校准、未验证项只提示，不拦卡。旧头部「取数速查表」已降入 §四 L3 参考，不 gate；对手梯队取数只取 L1 比率与 L2 档位。
