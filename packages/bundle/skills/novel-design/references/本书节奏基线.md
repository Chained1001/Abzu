# 本书节奏基线

> 件定位：外部先验（《参考标尺》通用四层）之外的第二把尺——**本书自己从已定稿章节实测出来的节奏**。设计、卷幕、细纲、审读一律**先对照本书基线，再对照通用参考标尺**；本书基线优先，通用参考标尺只做离群预警。
> 单源声明：本书基线的**工件路径、八项汇总口径、冷启动门槛、卷末更新与自报覆盖写法只在本件**；通用数值仍只在《参考标尺》，本件不复制数值、不另设门禁。
> 上游接口：《参考标尺》§四 L3「本书覆盖」——L3-01 本书档位、L3-02 章长基线、L3-03 钩型基线、L3-04 兑现间隔基线、L3-05 POV/场景基线、L3-06 人物出场基线、L3-07 自报覆盖、L3-08 偏离记录。本件补的是「怎么数、什么时候数、数出来放哪、样本不够怎么办」。
> 门禁口径：本书基线对本书后续章节生效（对应 L3 的 `gate:true`）；偏离本书基线**先解释**，偏离通用参考标尺**只做离群预警**——不拦卡、不判分、不反向裁稿。

## 一、工件与边界

| 项 | 值 |
|---|---|
| 工件 | `<工作范围>/书房/开书/<书名>/节奏基线.md` |
| 属性 | 书房资产，非真源；不入书仓 git |
| 写入口 | 主控用通用写工具落盘（种子底子／信息释放台账先例）；不经确认工具、不产生 `design:` 提交 |
| 读者 | 设计（契约／骨架／分卷／卷纲）、卷幕（卷规划／卷末）、细纲（章细纲／写前十查）、审读（派发材料里的基线摘要） |
| 非目标 | 不是及格线、不是评分表；不改正文、不改通用参考标尺、不改契约 |

- **只增不改历史**：每次更新版本 +1 并追加一行「变更记录」；旧值不覆盖、不删。
- **不凭印象填**：每项写出取数口径与样本量；数不出来写「样本不足」或「未建」，不估、不凑。
- **不反向约束正文**：本书基线描述本书实际节奏，不用它逼正文改数值；正文偏离基线**先解释**，解释得通就登记进 L3-08 偏离记录。

## 二、八项汇总与取数口径

表列：项｜记什么（汇总值）｜取数口径（从定稿章／章摘要／细纲怎么取）｜样本门槛｜覆盖的通用行。

| 项 | 记什么 | 取数口径 | 样本门槛 | 覆盖的通用行 |
|---|---|---|---|---|
| 章长中位/波动 | 中位数、P25、P75、最短/最长章、波动幅度（IQR÷中位） | 定稿章正文汉字数（`定稿/卷<NN>/<NNNN>-<章名>.md`；口径＝正文含章标题、不含 frontmatter 与候选事实，汉字数只计 Unicode Han）；先逐章列原始值再算分位；终卷放量章、番外、前传章单独列，不混进常态分布 | ≥10 章（不足见 §三） | L3-02；L2-A4-01 每章字数（只作离群预警） |
| 钩型配比 | 张力类／情绪类／泄压类章末主钩占比；双钩章逐钩登记后按**钩数**计 | 以定稿章**章末实际钩**为准，对照细纲 `### 章末双钩` 逐钩核（细纲登记了承诺与兑现章号，正文改了按正文改登记）；钩型分类照 L2-A1-03 两层制（张力类＝威胁/期待供给，泄压类＝高潮余波位，日常中性不进张力/泄压计量）；章未定稿标「待定稿」，不进分母 | ≥10 章且 ≥5 个钩 | L3-03；L2-A1-03 章末钩型配比；L1-04 危机钩兑现（硬红线照旧，不被本书基线覆盖） |
| 兑现间隔 | 承诺→兑现章号差的中位、最长间隔、超红线章数（只计已兑现） | 来源：`账本/承诺.md`（进行中／已兑现）与 `账本/线索.md`（已埋／已示／已收）的章号；细纲 `### 章末双钩` 里的「承诺→兑现章号」作辅助核对；差＝兑现章号−承诺章号；**未兑现单列**，不进间隔分布，不改写账本状态 | ≥5 个已兑现承诺 | L3-04；L1-01 章级兑现密度；L1-02 连续无兑现上限 |
| POV 数 | 本书在用 POV 数、主 POV 章占比、切换频率（平均每 N 章换一次主 POV） | 逐章取章首视角（细纲「视角与焦点」或定稿章首段），主 POV＋接力副 POV 按序列写法登记；只数**已出场**的 POV，计划中未出场的不算 | ≥10 章 | L3-05；L2-AX-06 POV 轴（只作对照） |
| 场景数/章 | 每章场景数中位与极值；单章最多场景数 | 定稿章按场景切换标记切分（或细纲「章组排布／单元行」的场景数）；标记口径与审读速览表「场景切换套路标记」同源；旁白式无切换的章记 1 场 | ≥10 章 | L3-05 |
| 对话密度 | 对话段字符占正文字符的比例；均值与分位 | 定稿章正文逐章统计：对话段（引号内与对话行）字符数÷正文字符数；本书内同一算法，不换算法对比；中文引号与破折号对话分别计 | ≥10 章 | 覆盖审读参考线的「对话密度」通用值——本书基线优先，通用值只作离群预警 |
| 卷长 | 每卷定稿章数与字数；常态卷长（中位）；末卷倍率（末卷÷常态卷） | 按 `卷摘要`＋该卷各定稿章汇总：卷内定稿章数、卷内正文字数（同章长口径加总）；未完结卷只登记「本卷目前」，不进常态卷 | ≥1 卷完结 | L2-A3-01 单卷体量；L1-11 卷数口径；L1-12 终卷放量 |
| 卷内高潮位 | 卷内高潮章位置（第几章／占本卷章数 %）、高潮前铺垫章数、卷末兑现章距卷末章数 | 以**已定稿章实际烈度**定高潮章（对照卷纲「叙事结构」幕高潮标记与章摘要强度描述），标章号后算相对位置；卷纲标记与实际落稿不一致时以实际为准，差异记一行 | ≥1 卷完结 | L2-A1-01 大爽点间隔；L2-A1-02 第一个大高潮位置；L2-A5-02 爽点铺垫（只作离群预警） |

- 所有占比写清分母（章数还是钩数）；分母不同的数分行记，不合算成一个数。
- 字数、对话密度、场景数一律按同一口径逐章重算，不复用草稿期估算值；换算法必须标「口径变更」，新旧值不直接比。

## 三、冷启动：前 1–10 章只有少量数据

- **前 1–10 章**样本少，**一律标「样本不足」**：只登记逐章原始计数（章长、钩型、场景数、对话密度），不给中位／占比／倍率等汇总结论，**不伪造稳定基线**。
- 冷启动期按契约自报值与 L2 模式档写作，本书基线暂不生效；通用参考标尺此时仍只作离群预警。
- 样本门槛（默认；作者可调并留痕）：

| 样本量 | 状态 | 能写什么 |
|---|---|---|
| 0 章 | 未建 | 不建件，或建件只写「未建」 |
| 1–9 章 | 样本不足 | 只写逐章原始计数与观察；一律写「样本不足」，不写稳定汇总值 |
| ≥10 章（或卷01 完结） | 初步基线 v1 | 可写八项汇总值，必须标样本量；与通用参考标尺冲突只作说明 |
| ≥2 卷完结 | 稳定基线 | 可作本书常态对照；卷长、末卷倍率按完结卷计 |

- 单卷章数不足时按「章」凑样本，不拿未定稿章凑数；「样本不足」是合法状态，不阻断写作、审读与卷末流程。

## 四、更新：卷末三件之后

- **触发点**：卷末三件（卷对账→卷摘要→下卷注意事项）落盘之后（与卷末设定审计同场），更新本书节奏基线；幕末结算只可登记原始计数、不升版本；**不逐章更新**。
- 每次更新必须记：**样本量**（章数／卷数，分项写）、**版本**、**变化**（升／降／无变化及一句话原因）、**作者确认**（作者可改任何数值或退回，留痕）。
- 版本协议：首次建件 v1；每次更新 +1；原样重跑复用版本，不重复升版。
- 变更记录表（写进基线件，一行一版）：

| 版本 | 更新时点 | 样本量 | 各分项变化 | 作者确认 |
|---|---|---|---|---|
| v<N> | 卷NN 卷末三件后 | <n> 章／<m> 卷完结 | <项：↑/↓/—＋原因> | <日期与方式> |
- 只增不改：旧版本行保留；口径变了（分母、统计方法、脚本口径）必须写「口径变更」。
- 本卷未更新时件内标「本卷未更新（样本量 x/y 章）」，不把旧值当最新。

## 五、消费：先本书基线，再通用参考标尺

**对照顺序（所有消费位一致）**：

1. 先读本书基线对应项：本章／本卷落在本书基线的什么位置？
2. 偏离本书基线：**先解释**——为什么这次不同，是一次性例外还是新常态；具名例外记 L3-08 偏离记录，作者确认留痕；解释得通就放过。
3. 本书基线未建或该项「样本不足」：不用它判，退回 L2 模式档与契约自报值。
4. 最后才看通用参考标尺：只做**离群预警**（离得远就提示一句「此处离群，是否需要理由」），不拦卡、不当及格线、不据此裁稿。

| 消费位 | 怎么消费 |
|---|---|
| 设计·契约「章节篇幅」 | 开书按 L2-A4-01 三档与作者自报定；开写后本书基线的章长中位/波动取代通用区间，改契约前先看基线是否已漂 |
| 设计·骨架/分卷 | 体量对账仍照《参考标尺》；已完结卷的卷长、卷内高潮位作后续卷粗排的本书参照，与参考标尺冲突时先解释本书值 |
| 卷幕·卷规划 | 卷级交叉思考与分幕排章长时，先对本书基线的章长中位/波动、卷长、卷内高潮位，再对通用行；偏离写进「方向选择」或呈报一句 |
| 细纲·章细纲/写前十查 | 章长目标、场景数、对话密度、章末钩型以本书基线为第一参照；写前十查⑥爽点铺垫对照本书兑现间隔，不照抄通用间隔 |
| 审读·材料包/任务包 | 派发时带「本书基线摘要」（八项＋样本量＋版本，格式见 §七）；审读先按本书基线判，通用分档行只在离群时提示 |
| 卷幕·卷末 | 三件后更新基线，并把本卷偏离本书基线的处登记进 L3-08 与卷摘要 |

- 本书基线与契约自报冲突：以作者最近一次确认为先，并在基线条目内记一行「契约自报 vs 实测」差异，不静默改契约。

## 六、自报覆盖：本书基线覆盖了哪条通用参考标尺

- **覆盖原则**：本书基线只覆盖**已有实测样本**的项；未达样本门槛的项**不覆盖**，继续照通用参考标尺（只预警）。
- 每个覆盖项写清：覆盖哪条通用行、本书基线值（含样本量）、**理由**（为什么本书不同：题材／驱动／章长模式／契约自报）、**作者确认**（时间与方式）、状态（生效／待确认）。
- 覆盖记录表（写进基线件）：

| 覆盖项 | 覆盖的通用行 | 本书基线值（含样本量） | 理由 | 作者确认 | 状态 |
|---|---|---|---|---|---|
| <项> | L3-0x | <值＋样本量> | <为什么本书不同> | <日期与方式> | 生效／待确认 |

- 覆盖不是豁免：L0 通用不变量一律不覆盖；硬红线（如危机钩兑现 ≤5 章）不可被本书基线覆盖，只可登记例外并说明理由。
- 未覆盖项与不适用项逐条留痕（照 L3-07），不静默跳过；覆盖理由与作者确认缺一即不算生效（照 L3-07／L3-08 的留痕要求）。

## 七、审读携带：材料包/任务包带基线摘要

- 审读子代理隔离运行、读不到书仓文件，**基线摘要由主控在派发时随材料包/任务包带上**（放在固定件部分的「判据参考」里，与通用分档行并列）。
- 摘要格式（一行一项共八项，前后各一行头部与对照顺序）：

```markdown
本书节奏基线 v<N>（样本 <n> 章 / <m> 卷完结；标「样本不足」的项照通用参考标尺只作离群预警）
- 章长：中位 x 字（P25 a / P75 b；波动 IQR÷中位 c%）
- 钩型：张力 x%／情绪 y%／泄压 z%（分母 n 钩）
- 兑现间隔：中位 x 章，最长 y 章（已兑现 n 条；未兑现 m 条另计）
- POV：n 个（主 POV 章占比 x%；平均每 y 章切换）
- 场景数/章：中位 x（范围 a-b）
- 对话密度：x%（正文字符口径）
- 卷长：常态卷 x 章/y 万字（末卷倍率 z）
- 卷内高潮位：第 x 章位（占本卷 n%），高潮前铺垫 m 章
（对照顺序：先本书基线，偏离先解释；再通用参考标尺，只作离群预警）
```

- 本书基线未建或全项「样本不足」时，摘要只写一行「本书基线：样本不足（n 章），本任务按通用参考标尺只作离群预警」，不编数值。
- **不改审读底本与派发模板**：审读侧的文字与口径归 `novel-review` 技能包；本件只定义摘要怎么摘、主控怎么带，底本内不内联本书数值，也不把基线指针写进审读底本。

## 八、边界与反例

- 不伪造稳定基线：样本不足就写样本不足，不给「差不多」的中位。
- 不把本书基线当及格线：它是描述与对照，不是配额；偏离可解释。
- 不反向改正文：不为对齐基线改已定稿章；已定稿只经吃书补偿更正。
- 不以本书基线覆盖 L0 与硬红线；硬红线例外只登记、要理由。
- 不把 L2 模式档当本书判据：L2 只作对照，本书基线优先。
- 反例：前 5 章就写「本书章长中位 3200」并据此裁稿——阶段错误，应标样本不足。
- 反例：审读拿通用章长区间直接判本书超短——顺序错，应先对本书基线，通用只提示离群。
