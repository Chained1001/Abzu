# 标尺使用日志

> 件定位：记录本书在哪些地方**显式引用**了《参考标尺》，以及每次引用做了什么决定——采用、偏离、自报覆盖、不适用；留下理由、作者确认与事后结果。它是「本书怎么用参考标尺」的证据链，不是第二套参考标尺。
> 单源声明：日志的工件路径、字段、使用时机、不记流水口径、卷末汇总与变更包衔接只在本件；通用数值仍在《参考标尺》，本书实测仍在《本书节奏基线》。本件不复制数值、不另设门禁。
> 上游接口：《参考标尺》§四 L3「本书覆盖」——L3-07 自报覆盖、L3-08 偏离记录；《本书节奏基线》§六「自报覆盖」；《变更影响分析》的 L0–L4 定级与变更包模板。
> 属性：书房资产，非真源，不入书仓 git。本件只留痕，不拦卡、不判分、不反向裁稿。

## 一、工件与边界

| 项 | 值 |
|---|---|
| 工件 | `<工作范围>/书房/开书/<书名>/标尺使用日志.md` |
| 属性 | 书房资产，非真源；不入书仓 git |
| 写入口 | 主控用通用写工具落盘（种子底子／节奏基线先例）；不经确认工具、不产生 `design:` 提交 |
| 读者 | 设计（契约／骨架／分卷／体量对账）、卷幕（卷规划／分幕／卷末）、细纲（章细纲／写前十查）、审读（材料包／任务包／复盘）、卷末汇总、下一卷规划 |
| 非目标 | 不改《参考标尺》数字；不是每章流水账；不是及格线或评分表；不替代《本书节奏基线》的八项汇总，也不替代《卷末设定审计》的五类清单 |

- **一行一个显式决定**：同一章里多个行 ID 若做了同一个决定，可合一行；不同决定拆行。
- **只追加，不覆盖历史**：结果列可从「待观察」改为「有效／无效／反例」，改时在该格附复评日期；旧结论不删、不改写。
- **不抄通用数值**：行 ID 是引用键；本书基线值可写（带样本量），参考标尺的章数／字数／比例不在本件重述。
- **覆盖不生效的写法**：作者未确认的自报覆盖照实写「未确认（待裁决）」，不算生效；L0 与硬红线不可覆盖。

## 二、什么时候记（使用时机）

**触发规则：设计／卷幕／细纲／审读，每出现一次显式引用参考标尺的决定，就记一行。** 显式引用＝点名行 ID、点名档位、引通用区间或阈值做判断，或宣布某行不适用。没有显式引用、只是照本书基线写，不记。

| 时机 | 必记什么 | 不必记什么 |
|---|---|---|
| 设计（契约／世界书体量／骨架／分卷／体量对账／确认前审查） | 选 L2 档位、引用 L1 区间、宣布 L0 或某行不适用、自报覆盖、体量对账中低于或高于建议项的处理 | 按默认文风写作、按契约字数写作 |
| 卷幕（卷规划／分卷核对／幕纲／卷末三件／卷末设定审计） | 卷级交叉思考与压力升级检查里对某行的取数或偏离；换图／三线／反派层级的档位选择；卷末汇总 | 每章按卷纲推进、没有显式引用参考标尺的排期 |
| 细纲（章细纲／写前十查） | 章级目标与本书基线或 L2 行冲突时的偏离；某行不适用于本章的原因；双钩登记中引用硬红线的例外 | 每章都写一句「按基线」；逐章抄章长／钩型／场景数数值 |
| 审读（材料包／任务包／报告／复评） | 用参考标尺行判离群、判例外、判不适用；审读发现项要求偏离或覆盖 | 把本书基线摘要原样重抄；对正常章节逐章记「无偏离」 |
| 卷末汇总 | 本卷决定／结果计数、未结项、升级变更包、下卷注意 | 重抄每行原文、把卷对账或审计表搬进来 |

- **冷启动**（本书基线「样本不足」或「未建」）照通用行写作时，只在**做了一次显式档位选择**时记一行；不逐章记。
- **复用**：同一决定在多个消费点复用，记最早一次；后续行写「复用｜<首次日期或日志行号>」，不重复造行。
- **卷末汇总**：卷末三件落盘、本书节奏基线更新之后同场做；只汇总本卷，不回写历史卷。

## 三、字段与写法

**日志表头（照此建表）**：`| 日期/卷章 | 引用的行 ID | 本书基线值/样本量 | 决定 | 理由 | 作者确认 | 结果 | 是否升级为变更包 |`

| 字段 | 写什么 | 取值／口径 |
|---|---|---|
| 日期/卷章 | 决定发生的时间与位置 | `YYYY-MM-DD｜卷NN/第N章`；设计期无章号写 `设计：<步骤>`；卷级写 `卷NN`；不写「最近」「这几天」 |
| 引用的行 ID | 本次决定引用的参考标尺行 | `Lx-xx`，多条用「、」；可附旧行名作检索（如 `L1-07 反派层数`）；不抄数值 |
| 本书基线值/样本量 | 本次对照的本书实测值 | 照《本书节奏基线》抄值＋样本量（如 `章长中位 3200（n=28 章）`）；未建或样本不足写「本书基线：未建」或「样本不足（n 章）」，不估不凑 |
| 决定 | 本次怎么处理 | 四选一：`采用`／`偏离`／`自报覆盖`／`不适用`；同一行涉及多个决定时拆行，不写「部分采用」 |
| 理由 | 为什么这样决定 | 采用：为什么选这个档；偏离／覆盖：打破条件＋证据（题材／驱动／章长模式／契约自报／样本）；不适用：为什么该行不管这件事；不写「感觉」「都行」 |
| 作者确认 | 谁在何时以什么方式确认 | `YYYY-MM-DD 对谈确认`／`编辑器确认`／`书面确认`；未确认写 `未确认（待裁决）`；作者可改任何值或退回 |
| 结果 | 这个决定后来怎样 | 四选一：`待观察`／`有效`／`无效`／`反例`；刚记时一律 `待观察`；复评后改并附日期（如 `有效（YYYY-MM-DD 复评）`） |
| 是否升级为变更包 | 是否触发书内变更 | `否`；或 `是（变更包 <编号>，主级 Lx）`；参考标尺行本身的校准问题不在此列（见第五节第 5 条） |

### 决定类型

| 决定 | 含义 | 必填证据 | 结果口径 |
|---|---|---|---|
| 采用 | 照该行／该档执行，本书基线没有相反实测 | 选档依据；本书基线值／样本量（无则写未建） | 后续按基线或审读复评 |
| 偏离 | 本书值或本书计划落在该行／该档之外，或主动不照该行执行 | 打破条件＋理由；本书自报或实测证据 | 未定时一律 `待观察`；无效或反例要写原因 |
| 自报覆盖 | 本书契约／本书基线覆盖某条通用行（L3-07／L3-08） | 覆盖哪条行、本书基线值＋样本量、理由、作者确认；L0 与硬红线不可覆盖 | 作者确认后才算生效；状态在《本书节奏基线》同步 |
| 不适用 | 该行不适用于本书当前驱动／模式／篇幅 | 不适用理由＋替代行（没有替代写「无替代」） | 不写「跳过」，不把不适用当合格 |

## 四、不记什么（防日志膨胀）

- **不记正常按基线写作的每章流水**：章长在基线带内、钩型按基线、兑现未越线，不记。
- 不记「今天没偏离」「本章正常」这类空行；没有显式决定就不写。
- 不逐章重抄参考标尺数值或本书基线八项；需要对照时只写行 ID＋基线的值／样本量。
- 不替代《本书节奏基线》的八项汇总、卷末设定审计的五类清单、卷对账的三账对齐；这些件各自的账不搬进日志。
- 同一决定不因换消费点重复记；复用行只写指针。
- **不在日志里改《参考标尺》数字**；参考标尺修订走校准任务或变更流程，本件只记「是否升级为变更包」。

## 五、与本书节奏基线、自报覆盖、变更包的衔接

1. **先基线后参考标尺**：任何一行先写本书基线值／样本量，再写引用的通用行；基线未建或样本不足时明确写出，不拿通用值冒充本书值。
2. **自报覆盖双记**：L3-07 自报覆盖、L3-08 偏离记录写进《本书节奏基线》与《参考标尺》L3；日志行是证据链，必须指向同一行 ID、同一作者确认与同一理由。两处不一致时先对齐再继续。
3. **变更包升级**：偏离导致要改契约／世界书／骨架／分卷／卷纲／幕纲／细纲／正文时，按《变更影响分析》定级 L0–L4、出变更包、呈作者裁决；日志「是否升级为变更包」写 `是（编号，主级）`，未升级写 `否`。命中已定稿按 L4 吃书补偿，不在日志里静默改数。
4. **结果回填**：卷末或下一卷复评时把 `待观察` 改为 `有效／无效／反例`；`无效` 或 `反例` 写一句为什么，并在卷末汇总里单列；不回写《参考标尺》。
5. **不改数字**：日志发现某条参考标尺行系统性失真，只出校准建议（另档留痕），不在本件改数字、改 gate 或改版本号。

## 六、卷末汇总

- **时点**：卷末三件（卷对账→卷摘要→下卷注意事项）落盘、本书节奏基线更新之后，与卷末设定审计同场；只汇总本卷，不重写历史卷。
- **汇总表**：

| 卷 | 采用 | 偏离 | 自报覆盖 | 不适用 | 待观察 | 有效 | 无效 | 反例 | 升级变更包 | 下卷注意 |
|---|---|---|---|---|---|---|---|---|---|---|
| 卷NN | n | n | n | n | n | n | n | n | n（编号） | 一句 |

- **必写**：未结项（仍 `待观察` 或待作者裁决）逐条列编号；`无效`／`反例` 逐条写原因；升级变更包的编号与主级；需要下一卷继续观察的行。
- **与设定审计分工**：审计管设定真源冲突与设定债；本日志管「参考标尺使用决定」的留痕与结果，不重复审计五类清单。审计发现的参考标尺或基线冲突，按第五节升级，不直接写进审计表冒充已裁决。
- **不伪造汇总**：本卷没有显式决定就写「本卷无显式参考标尺决定」，不凑行数。

## 八、反例

- 逐章记「按基线」「无偏离」——日志膨胀，真正的决定被淹没；
- 只写「偏离参考标尺」不写行 ID 与理由——无法回查，卷末汇总也做不成；
- 自报覆盖没有作者确认——照 L3-07 不算生效，不能当已覆盖；
- 拿日志改《参考标尺》数字或改 gate——越权，参考标尺修订另有校准流程；
- 把日志当门禁拦稿——日志只留痕，拦卡仍按审读与门禁件；
- 把通用值抄进日志当本书基线——两套数并存，后续对照全错；
- 卷末汇总只填数字不列未结项与无效／反例——下一卷照旧踩同一个坑。
