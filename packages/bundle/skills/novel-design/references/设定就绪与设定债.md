# 设定就绪与设定债

> 件定位：设计期按故事需求检查设定「够不够用」的清单、设定债的记录格式与补写通道。消费位：《定调设计》确认前的设定就绪检查、评审设定缺口的转记、起草待查的归口、卷末设定审计。
> 单源声明：八类检查表、必须与可留白的裁剪口径、设定债字段与状态、补写与变更包的分流只在本件；SKILL 只写入口与路径，不重述判据。
> 适用范围：开书设计、卷规划、细纲与起草发现设定不够用时。只查故事实际会用到的那一小块，不要求开书前写满；写全书百科不是本件的目的。

## 一、三条口径

1. **按故事需求裁剪**：不是按题材套模板。本书当前卷与近期窗口会写到的，才进入检查；还没写到的，留白合法。
2. **必须只到可执行**：「必须」指这一处能写出具体后果、读者能按它推演下一步，不指资料齐全。一条规则能回答触发、代价、上限、例外，就够用。
3. **未定义不等于可自由编**：真源没写的地方，是作者还没决定的留白，不是评审、设计或起草可以顺手定值的空白。已依赖而没定义的，登记为设定债，由作者裁决补还是留。

设定就绪检查**不是开书门禁**：它不拦开写、不要求所有项达标，只负责把「已经欠着的设定」摆到作者面前。作者说留白就留白，作者说以后再补就挂着。

## 二、按故事需求裁剪：必须与可留白

对每一类设定问三句，三句都「是」才算必须：

1. 本卷或近期窗口会写到这里吗？
2. 写到这里时，读者会按具体值推演后果吗（钱够不够、路走多久、权限允不允许、能力付什么代价）？
3. 这个值缺失时，情节会塌、人物会失真，或者两章之间会自相矛盾吗？

三句有一句「否」就归可留白。可留白不是欠账：它表示故事还没依赖，作者也还没决定。

每类设定有三种状态，别混：

| 状态 | 含义 | 处理 |
|---|---|---|
| 不适用 | 本书不用这类设定（如无超自然的现实题材的「超自然」类） | 整类标「不适用」，不进检查、不算债 |
| 可留白 | 本书会用，但当前剧情还没依赖具体值 | 保持留白，不编造；被依赖时再升为必须 |
| 必须 | 当前剧情已经依赖，且读者会按它推演后果 | 必须有可执行定义；没有就登记设定债 |

## 三、八类检查表

表里的问题按需取用，不要求逐条填表。左列是「现在是必须」时至少要能回答的；右列是同一类里常见的可留白项。

| 设定类 | 现在是必须时，至少要能回答 | 这类里常见的可留白项 |
|---|---|---|
| 力量 | 能力从哪来、怎么触发、消耗与代价、上限与边界、克制与反制、升级门槛与量级台阶；主角此刻能用什么、不能用什么 | 更高境界的完整名录、全书力量体系起源、未登场强者的能力细节、远期天花板真相 |
| 经济 | 主角当下收入与开销、关键物价（吃住行、武器、情报、门票）、交易媒介与结算方式、谁付代价、什么稀缺 | 全书物价总表、宏观税制与财政、远期经济危机、非登场行业的利润结构 |
| 社会 | 主角与他人的身份权限、称谓与礼制、越权后果、关键组织的流程与权力关系、律法与习俗红线 | 无关地区的官制全表、历史沿革、非出场阶层的日常、未登场组织的完整人事 |
| 地理 | 当前场景的空间尺度与出口、地点之间的路径与脚程/耗时、季节与气候、势力边界 | 未登场大陆的地图、全星球气候带、精确经纬与里程、远期要换的地图细节 |
| 日常 | 维持场景可信的最低量：吃什么、住哪、怎么照明取暖、怎么通讯、作息与卫生下限 | 非场景需要的节庆全表、娱乐清单、服饰史细节、无关行业的劳作流程 |
| 信息 | 谁知道什么、从哪知道、何时知道、传播速度与载体、误知与隐瞒、信息差怎么维持 | 全书所有角色的完整认知表、远期真相的知情名单、未登场势力的情报网 |
| 军事 | 暴力由谁掌握、兵力与调动速度、关键装备、冲突的规则与代价（谁付伤、谁善后、官府怎么反应） | 未参战势力的军队编制、武器参数表、战役史、战略层面的后勤总账 |
| 超自然 | 超自然力量的规则、代价、可见度、边界与禁忌；普通人如何认知与应对 | 神系全谱与创世史、终极真相、非本卷规则怪谈的完整条目、远期禁忌清单 |

**没有的类就写「不适用」**：军事、超自然在都市日常里可以整类不适用，这不是留白也不是债；反过来，种田文的经济与日常、军事文的军事，通常从第一章起就是必须。

## 四、设定债：定义与边界

**设定债＝已经依赖、但真源尚未定义的设定。**

- 「已经依赖」指下游真的用了：正文写到了、细纲要排这一场、卷纲要兑现这个承诺、人物动机要靠这个值成立；
- 「真源尚未定义」指在契约、世界书条目、故事骨架、分卷布局、卷纲/幕纲、人物档案、世界常量、账本与定稿事实里查不到，或明确留白；
- 只「以后可能用到」不算债，那是可留白。

与相邻概念分清：

| 概念 | 判断位 | 谁处理 |
|---|---|---|
| 可留白 | 故事还没依赖，作者也还没决定 | 不动，等被依赖 |
| 设定债 | 故事已经依赖，真源没有定义 | 登记，由作者裁决补或留 |
| 设定缺口 | 审读时正文已写死具体值，真源无据（《全面审读》技能包 agents/世界内合理性审读.md 的判定四值之一） | 评审只报缺口与应补哪类真源，不补标准；宿主转记为设定债 |
| 真源冲突 | 两个真源对同一事实说法不同 | 呈作者裁决或更正真源，不拿正文当裁判 |

**评审不凭空补**：作家席与世界内合理性审读判「设定缺口」时，只报「缺哪类真源、缺在哪一处、该补什么」，不给默认值、不替作者拍板；读者席不读真源，正文没给足信息只报阅读问题，不报设定缺口。设计也不代补：呈报设定债，等作者说补还是留。**不把「未定义」当「可自由编」**——起草不能因为查不到就自造数值，细纲不能因为没设定就跳过后果。

## 五、记录格式

设定债落 `<工作范围>/书房/开书/<书名>/设定债.md`：书房资产、非真源、不入书仓 git，用通用写工具落盘（种子底子先例）。它只记欠账，不代替世界书条目，也不因记了一行就变成已确认设定。

```markdown
# 设定债（<书名>）

> 书房资产，非真源，不入书仓 git。只记「已依赖但真源未定义」的设定；补写落点填真源路径。

| 编号 | 设定类 | 已依赖处 | 缺什么 | 影响 | 状态 | 作者裁决 | 补写落点 |
|---|---|---|---|---|---|---|---|
| 设定债-01 | 力量 | 卷01 卷纲「线索推进」第 3 行 | 金手指每日可用次数上限 | 决定第 12 章能否连用两次 | 待补 | 待裁决 | 世界书/力量体系/<条目>.md |
```

字段写法：

- **编号**：`设定债-01` 起顺序编号，不复用、不删号；
- **设定类**：力量/经济/社会/地理/日常/信息/军事/超自然之一；
- **已依赖处**：工件＋节/行或章号，写到能回查；不写「正文里」这种没法定位的话；
- **缺什么**：具体到值、规则或事实，不写「设定不足」；
- **影响**：这个缺口会卡住哪一章、哪个人物选择或哪条兑现；
- **状态**：`待补` / `已补` / `作者保留留白` / `已升级变更包` / `已失效`；
- **作者裁决**：待裁决／补／留白／升级变更包，附裁决轮次或日期；
- **补写落点**：补写后填真源路径与条目名；未补时填空。

一条债只记一处缺口。同一条依赖牵出多个缺口就拆多行，别用一行打包。候选值可以附在「缺什么」后面并标「候选」，但它不是已确认内容，不得写进真源。

## 六、消费位：什么时候记、谁来记

1. **设计确认前**：路径 B 五步聊完、写入前，路径 A 摘要过目后，按第三节清单走一遍；「必须」却查不到定义的，登记为债并随确认前审查呈报。
2. **评审发现项**：作家席或世界内合理性审读判「设定缺口」的发现项，由宿主按本件格式转记，不把评审建议当标准；评审报告本身仍是书房资产，不回写真源。
3. **细纲与起草**：写时发现缺值，按既有「待查」「停笔报告」通道登记，收稿后归口到设定债；不边写边编。
4. **卷末设定审计**：逐条对账，三去向＝补写／保留留白／升级变更包；「已补」「已失效」归档不删。
5. **下一卷规划**：只消费「已补」与「作者保留留白」；「待补」项继续挂账，带入下一卷，不因换卷自动消失。

债不挡开写：只要本章能按模糊写法处理，就继续；**本章必须写死该值时**，停下呈作者裁决，不拿候选值当已确认值往下写。

## 七、补写、留白与升级为变更包

作者裁决后按三种去向处理：

**补写**（新增或细化真源）：只在留白处新增定义、与既有真源不冲突、不动主线/人物/契约的，走对应确认工具写进真源（世界书条目用 `novel_confirm_worldbook_entry`，契约分部用 `novel_update_contract`，骨架/分卷/卷纲各用对应工具）；写后状态改「已补」并填补写落点。补写不得只落在正文或细纲里。

**保留留白**（作者决定不补）：状态改「作者保留留白」；下游按模糊处理，不写具体值，不把留白解释成「可以随便编」。以后剧情逼到必须写死时，重新打开为「待补」，再走一次作者裁决。

**升级变更包**（补写会改动已确认或硬设定）：先读 [变更影响分析](变更影响分析.md) 定级 L0-L4，出变更包、作者裁决后按依赖顺序同批整改，**不直接写死**。

| 补写会动到什么 | 通道 |
|---|---|
| 只在留白处新增、与既有真源不冲突、不改主线/人物/契约 | 对应确认工具直接补真源，状态「已补」 |
| 人物身份、职业、动机、关系方向、能力用法、知识来源，或某段剧情走向 | [变更影响分析](变更影响分析.md) L2，完整变更包＋影响分析前置呈报＋作者裁决 |
| 世界规则、力量体系与台阶、金手指规则、组织/地图/世界常量硬约束、契约六部 | 同上 L3；命中已定稿按 L4 处置 |
| 已定稿或已发布文本本身 | 同上 L4 吃书补偿，定稿区只增不改 |
| 只改表达、事实不变 | L0，不补真源、不出变更包 |

判断拿不准时按高一级处理。任何一级都不允许「先在正文写死、回头再补真源」：两套事实并存，下一章仍按旧口径写。

## 八、反例

- **把未定义当可自由编**：正文自造每日三次上限，后文真源补出「每日一次」，读者看到两套事实；
- **把检查表当开书门槛**：为填满八类提前编终局、编未登场势力，违反留白纪律，还把作者没决定的东西写成已确认；
- **评审代补标准**：评审判了「设定缺口」，顺手给出「建议设为每日三次」，等于替作者拍板；
- **补写绕过变更包**：直接改世界书硬设定，下游没有同批整改，影响分析复跑仍有未处理下游；
- **债只记不消费**：表建了没人读，下一卷仍按旧口径写，欠账越滚越大；
- **换卷自动清账**：把「待补」当过期删掉，下一卷重新发现同一处缺口。

判断标准只有一条：已依赖的设定，要么在真源里有可执行定义，要么在设定债里有明确状态与作者裁决；两者都没有，就是欠账。
