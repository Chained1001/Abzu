# 证据台账（参考标尺配套）

> **定位**：本台账是 [参考标尺](参考标尺.md) 的证据登记册，不是数值源。数值、区间、`status`、`confidence`、`stability` 与 `gate` 一律以参考标尺为单源；本台账只登记每行／每组行的来源、样本量、方法、区间来源与 `stability`，供复核、抽查与升版。
>
> **适用范围**：与参考标尺一致——中文长篇连载网文（章回体、连载更新、类型叙事）。L0／L1 只在该范围内成立，不宣称「所有小说通用」；短篇／中篇、纯文学、实体非连载、互动或分支叙事只可借功能句，不套数值档。每条目的适用范围另见「备注」列（如只作 L2 档、只作生产参数、不 gate），样本量 n 只表示证据强度，不作通用性宣告。
>
> **样本边界**：样本只用匿名编号——正样本 S1–S5（全本或近全本拆解报告），边界样本 S6（抽样）与 S7（弱样本）。本台账不复制原文，不写书名／作者名／角色名／组织专名；编号与真实作品的对应关系只存仓外，不入仓。
>
> **引用方式**：参考标尺行以 `EV-xx` 引用本台账（一行可被一个组条目覆盖）；台账编号一旦分配即稳定，升版只追加、不重编号。新增或改动参考标尺行时，必须同步登记本台账；台账覆盖的 ID 必须在参考标尺中存在。

## 二、分层登记口径

- **L0 组（EV-01～EV-06）**：全部 `invariant`，不写数值；覆盖按不变量簇分条（前十二条一组，角色功能位、世界因果层、接口与位移、背景事件、善后各一条）。单本弱支持只进备注，不改不变量身份。
- **L1 组（EV-07～EV-11）**：`stable` 与 `provisional` 分组登记——EV-07 为口径稳定、n≥4、无跨样本冲突的行；EV-08～EV-11 为口径未统一、可计数样本不足或由其他层换算的行。`stable` 只表示可作基准，不等于 `gate:true`；`provisional` 不得因区间好看升 `stable`。
- **L2 模式档（EV-12～EV-20）**：按参考标尺的表格分组登记；幕级按 U1／U2 两级切分（EV-19），仅「至少两类压力源」「幕末有接口」两个下限／存在性子句为 `stable`（EV-20），同行参考区间仍按 `provisional` 读；L2 默认只对照、不 gate。
- **L3（EV-21）**：`stable` 只表示「本书内稳定」，不是跨样本证据；本书自报与通用行冲突时以本书自报为先并留痕。
- **长度换算（EV-22）**：只有换算系数、没有产品行 ID；属于粗算参考，不参与任何 gate。

## 三、维护与边界

- **改行即改台账**：参考标尺任何行的口径、样本量、区间来源或 `stability` 变动，都在同一次改动里同步本台账；台账编号不复用。
- **不得悬空**：台账「覆盖行」里的 ID 必须在参考标尺中存在；参考标尺中的每一行都必须被本台账覆盖，不允许出现未登记的 `stable`／`provisional` 行（测试守）。
- **不复制原文**：本台账只写方法、样本量与区间来源，不摘录原作文句、不写书名与角色名；区间数值以参考标尺为单源，本台账不重述。
- **边界样本不外推**：S6 只有抽样、S7 只有弱样本，只作边界与反例，不作 L0／L1 的正证据；未覆盖形态按参考标尺「适用范围」句处理，不在此编造。
