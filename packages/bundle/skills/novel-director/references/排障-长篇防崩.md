## §8.10 长篇防崩：状态台账与一致性审计

> **核心卡**（必读；下方全文为深读扩展）
> - 意图：百万字不崩的方法不是"记得住"，是把"谁知道什么/谁在哪/谁欠什么"外置成台账，并把"每处都对"和"整条弧对"分成两层审计。
> - 判据：被否决的支线污染设定账了吗｜状态表分四栏吗｜人设之外有亲历记忆检索吗｜局部事实对但弧读对了吗
> - 路径：提交语义｜状态四栏｜双部件决策｜分层审计｜四类知识bug
> - 错误：最新值覆写无历史｜一张人设表走全书｜只查局部不查弧
> - 原语：信息差、动机链、变化
> - 共思：§8.6（伏笔没收）、§4.8（伏笔怎么埋）、§6.1（一章写什么）

### 这一节要解决的底层意图
想清楚**长篇为什么必然崩**——不是灵感枯竭，是状态管理超载：人物知识、持有物、位置、承诺随字数平方增长，而记忆线性。AI 辅助写作加倍需要这一节：模型上下文有限且会"顺滑地在错误前提下继续"（语气自然≠记忆忠实）。

### 为什么有效（机制）
多线研究收敛于同一结论：长篇一致性的核心是**状态台账＋会合条件**——"局部接缝一致≠全局历史一致"，人物生死/知识/持有物的远距离跨线矛盾是大坑；AI 长篇系统实证：局部事实准确率 .98 的模型，弧级进展仅 .08——**每处都对、整条弧读错**可能是独立故障层；人物决策复现实验：全局人设描述＋问题相关具体记忆双部件最接近作者真实选择——单一人设表不够。

### 判断标准
- [ ] 状态表分四栏吗？（当前值／变更史／谁知道／客观事实——只有最新值的覆写式台账会丢历史）
- [ ] 只有写进正文的才算数：被否决/没写出来的支线设定，污染设定账了吗？
- [ ] 人物决策点：除了人设卡，检索到相关亲历记忆了吗？（"吃素的玛丽吃汉堡"式文本内特质冲突，常识检查抓不到，要专项查）
- [ ] 审计分两层吗？（局部事实逐条对≠弧正确；弧级单独读一遍：人物比开卷时变了吗、往预期方向变了吗）
- [ ] POV/知识错误四分类查了吗？（泄未来／冒充在场／忘亲历／混淆来源；且视角错误平均是"就近"错误——近距查视角、远距查时间地理）
- [ ] 会合有共同事件吗？（两线收拢＝互动/冲突/状态互作用，同地同季不算会合）
- [ ] 用 AI 维护梗概/大纲时，四层错误分开查了吗？（对齐/连贯/忠实/遗漏——连贯的梗概可以漏掉主线人物，命题忠实的摘要仍可严重遗漏）
- [ ] 只靠脑子记状态吗？（开新章要回忆很久、写时总觉得哪里不对、越写越依赖临场补丁＝信息失控；四线任一掉线，中后期就崩）
- [ ] 开书登记齐了吗？（角色/伏笔/时间线/世界观/卷纲各归既有工件，缺哪处补哪处，不另起账本）

### 外部记忆与最小管理（并进现有三账，不另起账本）

- **分工**：脑子管灵感/场景/情绪/对白/冲突感觉；系统管角色目标/关系变化/伏笔埋点/时间顺序/设定规则。灵感很多、执行越来越乱，是信息复杂度超出脑力管理上限，不是状态问题。
- **最小管理四卡全落既有工件**：主线卡（主角要做什么/为什么必须做/最大阻碍）→ 全书大纲「核心冲突与对抗力量」＋卷纲阶段目标；角色卡（想要什么/与主角关系/制造什么冲突/后面怎么变化）→ 人物档案；伏笔卡（埋在哪/真实作用/什么时候收）→ `账本/线索.md`；阶段进度卡（本阶段主线推进了什么/新增哪些问题/哪些坑必须收）→ 章摘要＋卷末对账。不另建第五张表。
- **开书五处登记**（都是既有工件，不新增一套账本）：角色表→人物档案｜伏笔表→`账本/线索.md`｜时间线表→时间线变更｜世界观表（不能乱改的底层规则）→ 世界书固定规则条目｜卷纲表（一卷目标/核心冲突/主要阻力/关系变化/高潮/结尾新问题）→ 卷纲四段。
- **四线同管**：主线（阶段目标）／角色线（关系变化）／世界线（新增设定）／伏笔线（埋点与回收）——只盯主线、另外三条掉线不自知，是中后期崩的主因。阶段自查四问：主角最重要的目标是什么？核心角色关系变没变？新增设定影响旧规则没？最近埋的信息怎么接？
- **失控四信号**：主角越来越忙但越来越不明确｜角色越来越多但没有分工｜设定越来越多只能靠临时补丁｜章节在推进、结构没推进（每章都发生事，但主线没抬高、人物没变化、伏笔没兑现）。
- **时间线五类节点**：关键事件发生时间／角色首次得知某信息的时间／能力身份变化时间／关系转折时间／伏笔埋下与回收间隔；"谁现在知道"按状态四栏的「谁知道」栏记，不另开知情表——很多 bug 不是事件写错，是人物知道信息的顺序错了。
- **大纲校准（每 3–5 万字）**：回看核心轴（世界观/金手指/终极目标）、结构链（卷纲/大事件/情感战力曲线）、细纲（章纲/冲突拆解）三层；核心轴三词是否还清楚——欲望目标、核心阻碍、独特钩子。每次主角升级必须同时出现新难题或失去；只有变强没有新压力，成长曲线会塌。校准只做记录与修正，不新增确认步骤。

### 常见实现路径

| 路径 | 怎么做 | 例子 |
|---|---|---|
| 三层账本 | 伏笔表（信息差账）＋状态台账（谁知道/在哪/欠什么）＋会合验收线（共同事件） | 卷末对账三件套 |
| 状态四栏 | current/history/holder/fact 分栏，变更必须留痕 | 重生文记忆与世界状态分开记 |
| 双部件决策 | 人设卡＋决策点亲历记忆检索 | 主角对"背叛"的反应查他上次被背叛的戏 |
| 双部件检索位 | 决策点回查先走台账再叠人设卡：亲历记忆从状态四栏的变更史与"谁知道"栏检索，人设卡只供特质底色——检索位在台账不在人设表 | 主角对"背叛"的反应——查他被背叛那章的四栏记录，不凭人设卡现编 |
| 分层审计 | 局部事实审计（逐条）＋弧级审计（整体读）各走一遍 | 每卷一次弧审计 |
| 梗概四查 | 对齐/连贯/忠实/遗漏分栏 | 追更大纲维护 |

### 判断你写对了没有
随机抽一个退场三章以上的人物：他的关键知识、持有物、与主角的恩怨，台账里查得到吗？查不到＝台账欠账。

### 常见错误

| 错误 | 本质 | 改法 |
|---|---|---|
| 覆写式状态表 | 只存最新值，丢变更史 | 四栏制 |
| 一张人设表走全书 | 决策需要亲历记忆不只标签 | 双部件 |
| 只做局部审计 | 局部对≠弧对 | 两层审计 |
| 会合=同地同框 | 无相互作用不算会合 | 共同事件验收 |
| 有意跳切当断裂修 | 代理最优≠作者顺序，牺牲平滑换悬念是合法技巧 | 修订时区分"有意不平滑"与"真断裂" |

### 路径示例
- 卷末对账流程：伏笔表过一遍（挂账/回收）→ 状态台账 diff 本卷变更 → 两线会合处查共同事件 → 弧级通读一章。
- 重生/循环文加一层：一致性体制开书声明（过去可改/不可改/部分可改），跨周目记忆与世界状态分开记，"会合不合并历史"——收线后各线的所知所欠不自动归一。

### 循环/重生/时间线题材一致性体制（条件触发）

- **体制三选一并开书声明、全篇一致**：过去不可改（固定单历史）/可改（分支多历史）/部分可改（固定点＋可变区）——中途混用是本类崩坏主因，读者会拿第 1 章的声明来审你。
- **记忆持久规则显式化**：跨周目记忆与世界状态分开记账，各角色记忆持久/可变等级开书定死——世界回滚，记忆（显式例外）不回滚。
- **固定点判据**：改变它会破坏"使旅行本身成立"的因果环——不是拍脑袋的"必须发生"。
- **会合不合并**：多线/多周目收拢后，各线所知/所欠/所伤不自动归一，收线逐线对账。
- **分界**：角色跨轮记忆＋学习才叫循环，否则只是重述。
