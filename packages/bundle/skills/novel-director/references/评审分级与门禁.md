# 评审分级与门禁

> 件定位：给每个待审对象定一个**默认审查强度**——不再所有对象都跑全量最严。按「对象 × 风险 × 强度」查表路由；低风险可以轻审或留白，但降级、跳过、带伤开写都要留记录。
> 单源声明：对象×风险×强度默认表、升降档规则、作者降级/跳过记录格式只在本件。L0-L4 判据、变更包与吃书补偿在《定调设计》技能包 `references/变更影响分析.md`（05）；设定就绪与设定债在 `references/设定就绪与设定债.md`（06）；两席报告头、七列处置台账与增量复评在《定调设计》技能包 `agents/作家评审.md`、`agents/读者评审.md`（04）；幕纲六段规格与关键幕执行步骤在《卷幕规划》（03）。本件只做路由与门禁判定，不重述这些判据。
> 适用范围：设计侧（全书大纲/分卷/卷纲/幕纲）、章级（章纲/正文）与表达层（润色）的评审派发。它是**默认强度表，不是硬拦卡**：作者可显式降级或跳过并记录；只有关键卷/幕的硬伤未处置又不带伤确认时，才禁止静默开写（见第五节）。

## 一、三轴总览

### 1.1 对象轴（七类）

| 对象 | 何时出现 | 默认审什么 | 不审什么 |
|---|---|---|---|
| 全书大纲 | 书级基线：全书大纲首次确认或结构性修订 | 九部结构、核心冲突、对手梯队、伏笔骨架、终局方向 | 逐章执行、文笔 |
| 分卷 | 书级基线：分卷布局首次确认或结构性修订 | 卷目标与卷末状态、主战层级、阶段分配、卷间接口 | 单章细纲 |
| 卷纲 | 卷级规划：每卷卷纲确认或大偏差修订 | 卷功能、弧线、线索推进、卷末兑现、方向选择 | 幕以下执行细节 |
| 幕纲 | 卷级规划：整幕开写前确认幕纲 | 本幕故事、线与伏笔、出场人物、章组排布、幕末结算 | 逐句文笔、章级事实 |
| 章纲 | 章级：候选细纲确认前 | 固定小节完整性、信息边界、冲突爽点、章型、十查 | 正文文字质量 |
| 正文 | 章级：待审稿就绪后 | 九维：结构/人物/情节/信息/线索/节奏/承诺/文风/世界合理性 | 上游设计是否值得重写 |
| 表达 | 正文表达层：字词、句式、段落节奏、对话口气、描写密度 | 只改表达、不改事实 | 设定、剧情、人物口径 |

**对象换层就换档**：同一份内容从草案写入真源、从全书大纲细化为卷纲、从章纲落成正文，都按**当前对象**取强度，不沿用上游档位。评审只审本对象，越层问题转对应对象处理。

### 1.2 风险轴

风险由两部分合成，**取高不取低**：

**（A）变更级 L0-L4**（判据单源在 05，本件只取用）：

| 级 | 一句话 | 对门禁的含义 |
|---|---|---|
| L0 | 表达层，事实与因果不变 | 不派评审，交润色；作者可跳过润色并登记 |
| L1 | 单章内可核实的局部事实，不动动机/关系/长期设定 | 不新增评审维度；设计对象不派评审，走确定性检查与影响分析 |
| L2 | 人物身份/职业/动机/关系方向/能力用法/知识来源，或某段剧情 A→B | 默认表「普通」档，至少作家/全量，不得留白 |
| L3 | 契约六部、世界铁则、力量体系、金手指规则、主角原则、关系边界、创作禁区、叙事方式 | 升到两席（设计对象）或全量＋定向（正文），先走 05 变更包与作者裁决 |
| L4 | 已入档定稿或已发布文本本身 | 按 05 吃书补偿四件处置，只回归补偿点，不重审全文；作者裁决 |

**（B）位置档**：

| 位置档 | 判定 | 例 |
|---|---|---|
| 关键卷/幕 | 卷01、卷末卷、承担卷内大高潮的幕、卷末幕，或作者点名的卷/幕 | 开卷卷、卷末兑现幕、全书高潮幕 |
| 普通 | 其余按大纲正常推进的卷/幕/章 | 常规升级卷、常规推进幕 |
| 过渡 | 两段强情节之间的衔接、日常/过场、信息整理，且**无新硬设定、无读者承诺变更、不命中已定稿** | 赶路章、休整章、日常过渡幕 |

**章级位置档直接取 `章型` 字段，不再用散文重判**（0.0.87 起，章型双轴已落候选细纲 frontmatter）：

- `章型: 关键·*` → 位置上按**关键章**档（承诺档已含卷末兑现／大高潮／重大揭示／读者承诺承载／作者点名，与本节旧列表同义，不重复判）；
- `章型: 过渡·*` → 位置按**普通**档，再按情绪位细调——`过渡·余波`／`过渡·高潮` 仍须跑「确定性＋单维」（余波查连续钝收与泄压钩居位、高潮查烈度是否到位），`过渡·切换`／`过渡·铺垫` 才是真正的「过渡」档（可留白）；
- `章型` 未标 → 按**关键章**走（宁可多审）。缺字段不是少审的理由。

上面的旧散文定义（卷末兑现章、大高潮章……）只作为 `章型` 缺失时的兜底判据，不再是与 `章型` 并列的第二套标准——两处说法不一致时以 `章型` 字段为准。

**冲突时取高**：L3/L4 命中关键卷/幕 → 按关键档；普通卷里出现 L3 变更 → 按关键档；过渡章里出现读者承诺变更 → 按关键章。位置档只是默认值，L 级可以把它抬上去，不能把它压下来。

### 1.3 强度轴（六档＋留白）

从重到轻；**可叠加**（如「全量＋定向」「确定性＋单维」），叠加后取最高档记：

| 强度 | 做法 | 产出与落点 | 适用对象 |
|---|---|---|---|
| 两席 | 作家评审＋读者评审，按作家→读者串行、两席互不通气；首评默认，复评走增量 | 两份评审报告落 `书房/评审/{书名}/`，带报告头与七列处置台账 | 全书大纲/分卷/卷纲/幕纲 |
| 全量 | 《全面审读》9 维合并章程一次派发跑完；另跑确定性检查脚本 | 9 个模块逐个回写审核记录 | 正文 |
| 作家 | 只派作家评审一席（同一底本，单席出具） | 一份作家评审报告 | 全书大纲/分卷/卷纲/幕纲 |
| 单维 | 只查一个维度：正文派 9 份单维底本中的 1 份；设计/章纲由主控按对象规格的对应维度定向核对，不派语义子代理 | 单维报告或核对行，落审核记录/呈报 | 正文、卷纲、幕纲、章纲 |
| 确定性 | 只跑机械检查：正文跑 `确定性检查.mjs`；章纲跑「十查机械」四查＋固定小节规格核对；设计对象跑影响分析脚本与版本/引用核对 | 脚本回写载荷或核对表，不产出语义发现项 | 正文、章纲、设计对象 |
| 润色 | 表达层交《精修润色》，不派评审、不重跑审读脚本 | `novel_record_polish` 承接或跳过登记 | 表达 |
| 留白 | 不审、不派子代理；只在呈报/记录里写一句「本对象按表留白」 | 评审分级记录一行 | 低风险对象 |

**「单维」不是「确定性」**：单维仍有语义判断（人读/子代理读），确定性只认机械结果。**「作家」也不是「两席的缩水版」**：单席仍守同一份底本与报告字段，只是不派读者席。

## 二、默认表（对象 × 风险 × 强度）

查表步骤：先定对象 → 再按 1.2 定位置档与 L 级（取高）→ 查下表得默认强度 → 需要时按第三节升降档。表中「高档」列已含关键卷/幕、L3-L4 与全书大纲/分卷首次确认；「普通」列对应 L2；「过渡」列对应 L0-L1 或过渡章/幕。

| 对象 | 高档（关键卷/幕、L3-L4、首次确认） | 普通（L2、常规推进） | 过渡（L0-L1、过渡章/幕） |
|---|---|---|---|
| 全书大纲 | 两席 | 作家 | 留白（走 05 影响分析，不派评审） |
| 分卷 | 两席 | 作家 | 留白（走 05 影响分析，不派评审） |
| 卷纲 | 两席 | 作家 | 单维（章节结构或情节与因果） |
| 幕纲 | 两席 | 作家（作者可跳过） | 单维（章节结构） |
| 章纲 | 单维（按承载维度选信息披露/情节与因果/章节结构之一） | 确定性（十查机械＋固定小节规格核对） | 留白 |
| 正文 | 全量审读＋定向加深 | 全量审读 | 确定性＋单维（章节结构或文风与表达） |
| 表达 | 润色 | 润色 | 润色（作者稿可登记跳过） |

**默认表怎么读**：

- 全书大纲/分卷没有「卷/幕位置」，用变更级代替位置档：首次确认或 L3 修订＝高档两席，L2 修订＝作家，L0/L1＝留白＋走影响分析；
- 卷纲/幕纲的「作家」是**默认下限**，不是上限：关键卷/幕必须两席；作者可点名把任一普通卷/幕升为关键档；
- 章纲的普通章不派语义子代理，但「十查机械」与固定小节规格照跑；关键章只挑承载维度定向核，不因关键就自动上两席——**本行是目标口径，尚未实装**：现行《细纲备料》对任何章型都跑完整十查，没有按强度分派的入口（见第六节末）；
- **章纲与正文的位置档先从候选细纲的 `章型` 字段读**（`关键·*` → 高档列，`过渡·余波`／`过渡·高潮` → 中间列，`过渡·切换`／`过渡·铺垫` → 过渡列，未标 → 高档列）；表里三列是给「章型缺失或作者改判」时用的兜底，不是与章型并行的第二套判定。章纲与正文读同一个 `章型` 字段，不再各自重判——这正是旧设计里两处判定对不上的来源；
- 正文的普通章仍是全量 9 维（一次派发，不分 9 次）；过渡章才降到「确定性＋单维」（换算表在《全面审读》技能包 `references/章型取档.md`，本件不复制）；表达问题一律交润色，不占审读模块；
- 表达对象没有「两席/全量/作家」档：表达层只有润色；一旦改动触及事实，它已不是 L0，按 L1 以上重新定级，不能借「润色」绕过事实审读。

**低风险留白合法**：过渡章/幕、L0/L1 对象按表留白即可，不搞全量最严；留白不是漏审，在评审分级记录里写一行「本对象按表留白」即可。低风险轻审同样合法，不必为了「审过」把过渡章抬到全量。

## 三、升级规则

以下情形**至少升一档**，升完在评审分级记录里写「升档原因」：

1. **触发硬设定（L3）**：契约六部、世界铁则、力量体系与台阶、金手指规则、组织/地图/世界常量的硬约束、主角原则、关系边界、创作禁区、叙事方式。设计对象升两席；正文升「全量＋定向」（世界内合理性/信息/承诺等命中维度）；同时先走 05 变更包与作者裁决。
2. **命中已定稿/已发布（L4）**：按 05 吃书补偿四件（正文/认知/承诺/账本摘要）处理，升「补偿审查」；不重审全文，只回归补偿点。不得因为「只是文字」把 L4 降成 L0。
3. **读者承诺变更**：契约情绪承诺、卷末兑现、主线目标、类型承诺、卷间接口变化。卷纲/幕纲升两席（或至少作家＋读者承诺单维）；正文升全量并加读者承诺单维。
4. **关键卷/幕/章**：符合 1.2 定义即按高档；作者点名升档一律照办。
5. **跨卷/跨幕结构改动，或影响 ≥3 章**：在默认档上再升一档（设计对象：单维→作家→两席；正文：确定性→单维→全量→全量＋定向）。
6. **同一对象连续两轮同类硬伤未处置**：升一档，并在复评时只回归这些硬伤，不顺带重审全文。
7. **作者点名加深**：作者要求「再仔细看看」「重点审这一块」时，按点名维度加派单维或升档。

**升档顺序**（设计对象）：留白 → 确定性 → 单维 → 作家 → 两席；**正文**：留白 → 确定性 → 单维 → 全量 → 全量＋定向。**只升不降**：没有作者明示，主控不得把默认强度往下调；作者明示降档时按第四节记录。

## 四、作者降级、跳过与记录

**门禁是默认强度**：作者可显式降级/跳过并记录，可以两席→作家→单维→确定性→留白逐级降，也可以直接跳过任一对象。主控不得自行降级、不得用「看起来没问题」代替作者决定。

### 4.1 可跳过条件

满足任一即可由作者决定跳过：

- **L0 表达层**：默认只走润色；作者说「这章不用润色」时登记跳过润色。
- **过渡章/幕/卷**：无新硬设定、无读者承诺变更、不命中已定稿；章纲**按上表标称可留白但尚未实装**（见二节末注解），正文可只跑确定性＋单维。
- **全书大纲/分卷的 L0/L1 修订**：不派评审，走影响分析与沉淀。
- **作者明示跳过**：作者说「这章不用审」「跳过幕NN 评审」「先按我的来」，主控复述一次确认后记录；作者口头/文字均可。

### 4.2 不可跳过与不可静默

- **关键卷/幕的 🔴 硬伤未处置**，且作者没有明确接受「带伤开写」：不得确认写入卷纲/幕纲，不得开写整卷/整幕——先呈报裁决，不得静默开写（见第五节）。
- **L3/L4 变更**：不得跳过评审与作者裁决；L4 只能走补偿，不能重写定稿。
- **缺输入、缺真源、工具失败**不是跳过理由：按「缺口」呈报，补料后按原强度重跑；把「查不到」写成「留白」＝伪造结论。
- **主控不得以省事、赶进度、章节短为由降档**；降档只能由作者发起，或作者确认主控的降档建议。

### 4.3 记录格式与落点

所有降级/跳过/升档都记一行，落 `<工作范围>/书房/评审/{书名}/评审分级记录.md`（书房资产非真源，通用写工具可写，不入书仓 git）。已有评审报告的，报告头写「评审强度：默认 X／实际 Y」，台账备注列写同一条记录；没有报告的（留白、跳过）只落分级记录。

| 字段 | 填法 |
|---|---|
| 对象 | 全书大纲/分卷/卷纲/幕纲/章纲/正文/表达 |
| 对象路径与版本 | 真源或草案路径＋版本/哈希（没有版本写「无」） |
| 位置档 | 关键卷/幕、普通、过渡 |
| 风险级 | L0-L4；含 L4 处置时另注「含 L4 处置」 |
| 默认强度 | 按第二节表查得的强度 |
| 实际强度 | 实际执行的强度（可低于或高于默认） |
| 降级/跳过理由 | 作者原话或一句可回查的理由 |
| 作者裁决 | 作者原话/确认轮次/日期；主控建议降档时写「作者已确认」 |
| 硬伤处置 | 未处置硬伤编号；或「带伤确认」＋作者原话 |
| 记录人/日期 | 主控；YYYY-MM-DD |

追加写、不改旧行；同一对象多轮记录按日期往下排。作者反悔要恢复默认强度时，另记一行「恢复默认」并说明从哪一轮起生效。

## 五、门禁与开写

### 5.1 关键卷/幕（硬门禁，但可带伤）

- 关键卷的卷纲、关键幕的幕纲：默认两席；**🔴 硬伤未处置且作者未明确接受时，不得确认写入、不得开写整卷/整幕**——这是唯一会实际拦住开写的门禁。
- **作者可带伤确认**：作者明确说「带伤开写」「先这样写，后面再补」时，可以放行，但必须在评审分级记录里写「带伤确认」＋未处置硬伤编号，并在下一次复评/幕末结算时回归这些硬伤；不得把「带伤」写成「已解决」。
- 普通卷/幕：发现项随卷纲/幕纲呈报，作者不追即放行；无硬伤就不必为「审过」再等一轮。
- 评审报告是书房资产，不硬拦确认：报告没跑或没跑完，主控如实播报「未审/未跑完」，由作者决定照常推进还是补审；补审后按增量复评只回归主问题。

### 5.2 章级

- 关键章：正文按全量＋定向；硬伤未处置不得进入定稿准备（沿用《全面审读》处置口径）。
- 普通章：全量审读；建议级按《全面审读》默认处置口径处理，不必逐条呈作者。
- 过渡章：确定性＋单维即可；作者可跳过正文评审，但表达层仍可交润色。
- 章纲：关键章按承载维度单维核对；普通章确定性核对；过渡章标称留白**但尚未实装**（现行仍跑十查，见二节末注解）——这一项不阻断开写，正文阶段仍按正文档审。

### 5.3 「静默开写」的判定

同时满足以下三条才算静默开写：①对象是关键卷/幕或关键章；②存在未处置的 🔴 硬伤；③作者没有明确接受带伤、也没有明确跳过。三条缺一，主控都不算违规；但降级/跳过没记录，仍算记录缺失。

## 六、四个消费位（按表路由，不靠临场发挥）

| 消费位 | 取什么 | 怎么用 |
|---|---|---|
| 《工作台总控》节点路由 | 默认强度总表与升降档规则 | 派评审前先按本件定档；审核行不再默认「所有对象全量」，按对象查表 |
| 《定调设计》确认前审查 ③ | 全书大纲/分卷/卷纲的默认强度、作者降级/跳过记录 | 首次确认前查表：全书大纲/分卷/关键卷两席，普通卷作家，过渡可单维/留白；作者降级须记录 |
| 《卷幕规划》幕纲评审与关键幕门禁 | 关键幕判定、两席/作家/单维、带伤开写口径 | 关键幕两席，普通幕作家（作者可跳过），过渡幕单维/留白；关键幕硬伤未处置先呈报 |
| 《全面审读》`references/章型取档.md`「取档表」 | 章型 → 审读维数的换算（`关键·*`／未标＝9 维全跑，`过渡·*`＝确定性＋单维） | 该表管「跑几维」，本件 1.2 管位置档、5.2 管门禁与「关键章另加定向加深」——两边是有意分工，不是两套标准；本件不复制那张换算表 |

**路由纪律**：消费位只写「去哪查」，不复制整张表（正文那行指向取档表，是因为正文档位的单源在那里）；本件改表时各消费方自动跟随。主控派发时把「对象、位置档、风险级、实际强度」四项写进任务包/呈报，子代理不需要自己判断档位。

**为什么只有这四个（别再照着旧表补《细纲备料》《精修润色》两行）**：**章纲**的程序是固定的——《细纲备料》技能包 `agents/写前十查.md` 对所有章型都跑十查、过渡章只把⑧放宽成隔章，不按本件三档派发强度；第二节「章纲」行的「过渡＝留白」在《细纲备料》侧**未实装**（过渡章纲同样跑十查，从不留白），给章纲补指针等于开一条比现行程序更松的路，属新造门禁。**表达层**三档全是「润色」，没有档位可路由；《精修润色》只需守住「改写只换说法不换事实」（润色心智「删留三分判」）与「不重跑审读脚本」（标准流程 5）、并按「作者稿默认不润色」登记跳过，不需要知道对象×风险×强度这套档位。

## 七、常见误用

| 误用 | 为什么错 | 正确做法 |
|---|---|---|
| 所有对象都两席/全量 | 把默认表当最高档，低风险被过度审 | 按表取档；过渡可单维/确定性/留白 |
| 「评审不是门禁」当全跳过 | 跳过没有作者明示、没有记录 | 门禁是默认强度；降级/跳过须作者明示并记录 |
| 关键幕硬伤未处置先开写 | 读者承诺与卷末兑现会带病滚大 | 先呈报；作者带伤确认后记录并回归 |
| 缺料写成「留白」 | 把查不到伪装成作者决定 | 写缺口、补料重跑，不伪造 |
| L3 变更借「润色」绕过 | 表达层不审事实，硬设定会静默改 | 先按 05 定级 L3，走变更包与两席/全量 |
| 已定稿重审全文 | 重复劳动，且改不动定稿 | 按 L4 补偿审查，只回归补偿点 |
| 跳过不记录 | 下轮无法复评，作者决定不可追溯 | 落评审分级记录一行，报告头写默认/实际强度 |

## 八、示例（三个典型档）

**例一：关键幕（卷01 第一幕）**
对象＝幕纲，位置＝关键幕（第一幕＋承担卷内大高潮），风险＝L2 但位置档抬到高档 → 默认两席。审出 🔴 硬伤 2 条：作者选择改幕纲再确认，改后按增量复评只回归这 2 条；若作者说「带伤开写」，记录「带伤确认＋硬伤编号」后放行。

**例二：普通卷（卷03 过渡卷）**
对象＝卷纲，位置＝过渡（无新硬设定、无承诺变更）→ 默认单维（章节结构）。审出建议 3 条，随卷纲呈报；作者不追即放行。若作者点名「这卷是全书转折」，升关键档两席，原单维记录标「升档」。

**例三：过渡章（赶路章）**
对象＝章纲＋正文，位置＝过渡，风险＝L1 → 章纲标称留白（**尚未实装**，现行仍跑十查）；正文确定性＋单维（章节结构），表达交润色。作者说「这章不用审」→ 记录「作者跳过正文评审，仅跑确定性」；硬设定/承诺变更出现时，本章不再是过渡章，按普通或关键档重定。

## 九、派发/收尾检查清单

派发前：

- [ ] 对象与路径写清；是草案还是真源；
- [ ] 位置档（关键/普通/过渡）与 L 级已定，冲突取高；
- [ ] 查表得默认强度；有升档原因就写清；
- [ ] 作者降级/跳过已获明示，记录字段齐；
- [ ] 关键卷/幕的硬伤处置状态已核（未处置先呈报，不静默开写）。

收尾时：

- [ ] 实际强度与默认强度不一致的，已落评审分级记录；
- [ ] 报告头写「评审强度：默认 X／实际 Y」，台账备注同步；
- [ ] 硬伤处置、带伤确认、复评范围写清；
- [ ] 留白/跳过只对低风险对象，未覆盖 L3/L4 或关键卷/幕未处置硬伤。
