# 写作卡（起草任务包场景判据卡）

八卡是创作时刻的判据形态：卡文即判据，主 Agent 按本章各单元「场景功能」选卡后**原文内联**任务包，不让子代理翻手册；每卡卡头标注节源（07_正文写作.md 的 §x.y），主 Agent 需要超出卡文的深挖时按该节号定位只读该节，不整文件读入。卡文判据执行、例外照卡内边界句处理；卡与本章硬约束冲突时硬约束优先。趣味卡按场景标签带：本章含幽默/轻松/玩梗标签的单元时带。

## 推进卡 ←§7.1＋§7.7

- 先判这条信息有没有戏剧性：情绪场景必展示，过场信息直接讲述提速；讲述不连排超过两句。
- 情绪落在动作里，不停在形容词上；抽象评价换成一个具体行动让读者自己判断。
- 动笔前想清这段要呈现哪一幅画面，删掉画面外的庞杂描写。
- 读者现在在等什么？他最想看的那一秒用五感拉长慢放，其余快写。
- 高潮后留喘气口；紧张时拆句多换行，舒缓处长句大段。
- 笔墨花在读者最关心的地方，不平均用力。
- 单元没写够配给先查有没有漏拍的戏（缺拍补拍），不是加描写凑数。

## 塑造卡 ←§7.2＋§7.9

- 盖住名字能分得出谁在说；分不出就按性格重写说话方式（暴躁打断用短句／自卑吞吐自否／沉稳先结论）。
- 每句对话三占一：推进剧情／暴露性格／有潜台词（嘴上说的与心里想的错位），一句不占就删。
- 台词透出的信息须是这个身份能知道、会自然说出口的；不借角色嘴念背景设定。
- 写情绪先找手在干什么、眼睛在躲什么；写大情绪用小动作。
- 每个动作碰到什么、留下什么——给环境反馈，不写空招。
- 感官细节只取精准的一个不堆一串；细节必须专属——换个故事还能原样用的换掉。
- 本章写人物死亡时：回收死前埋设的日常细节至少一处（遗物/口头禅变奏），临终一句＋一个动作收——不给大段独白补设定（埋设自查在《细纲备料》技能包备料段「死亡预埋自查」）。

## 动作卡 ←§7.3

- 打之前先定输赢代价：赢了会怎样、输了会怎样——赌注不明读者不关心输赢。
- 招式写力量反馈与后果（收刀后落叶断成两截），不写空泛招式名。
- 打斗段用短句制造节奏；每招有效果，一招一果。
- 打太久就砍——删到读者为主角捏汗为止。

## 环境卡 ←§7.4

- 下笔前先问这段环境为四作用之一服务吗：渲染气氛／烘托心情／塑造人物／推动情节——一个都不占就是风景明信片，砍或绑情绪。
- 按场景核心变化挑 1-2 条感官通道（打斗→视觉＋听觉；密室→触觉＋听觉＋嗅觉），不堆全感官。
- 人景合一：人物与环境发生关系（寒风刺向骨头缝），不旁观罗列。
- 聚焦一两个代表性细节以小见大，不写全景清单。
- 环境呼应人物此刻心情：把心情换了这段还成立，就重绑。

## 开场卡 ←§7.10

- 读者现在需要知道这个吗？不需要的背景往后挪，用到时再给。
- 背景拆成碎片在冲突中释放（对话／物件／他人反应），不提前倒。
- 开场第一页就进冲突；场景先立起来再谈解释。
- 闪回只在张力最紧时用；不写「你还记得吗」式交代，改用物件暗示。

## 趣味卡 ←§7.12

- 好幽默靠信息差误会：双方信息不对等制造误会，误会层层递进笑点层层升级；不硬讲笑话。
- 笑点从人物身上长出来：口头禅＋逻辑荒谬却能自圆其说的脑回路；口头禅回锅就是笑点。
- 自己读这段会笑才算数；不会笑＝硬写了，回头加误会或加铺垫。

## POV 自查卡 ←§7.5

- 一段只锁一个视角人物；只写他能看见、听见、想到的。
- 同一段出现两个人物的直接心理描写＝视角漂移，改回一个。
- 切视角先关门：换章／空行／分隔符；切换后前三句放进新视角人物的信息。
- 视角落地的开篇用「我看到／听到／想到」锚定，不飘。

## 行文自查卡 ←§7.13

- 主语：每个省略的「他／她」指谁唯一？有竞争人物在场显式重提姓名；跨段界、换视角、对话插入后显式重提；不逐句机械补全主语。
- 标点：句号跟五类转移走（话题／人物／活动／时间／空间换其一就断句），不设字数阈值；一逗到底必拆。
- 语气词：对白里该有的在吗——指令／建议句的「吧」为对方留拒绝空间；粒子串按「的→了→呢/吧/吗→啊」由内向外排序。
- 话语标记：相邻分句无连接词时隐式关系须唯一可读；「因为…所以…但是…」连串删掉；「我觉得」只留在知识范围外／结盟／启动叙述处。
- 怪描述词从头捋一遍（过度套路描写读着就删就改）——判断标准是人感，不是检测率。
