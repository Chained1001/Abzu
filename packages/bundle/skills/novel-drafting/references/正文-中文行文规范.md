## §7.13 中文行文怎么不怪异（主语·标点·语气词）

> **核心卡**（必读；下方全文为深读扩展）
> - 意图：治中文行文的五类"机器味"——主语滥用、标点失能、语气词缺失/失序、逻辑显式化过度、对白标记单一化。
> - 判据：每个省略的"他/她"指谁唯一吗｜段界/换角显式重提了吗｜句号跟五类转移走了吗｜对白语气词在吗｜"我觉得"该删还是该留｜怪描述词捋一遍了吗（人感≠AI率）
> - 路径：主语与指称｜标点分句｜语气词系统｜话语标记｜语序检查
> - 错误：主语每句补全｜一逗到底｜粒子失序｜因为所以连串
> - 原语：变化、信息差
> - 共思：§7.2（对话怎么写）、§7.9（细节怎么选）

### 这一节要解决的底层意图
想清楚**中文行文的"自然感"从哪来**——不是修辞好坏，是主语、标点、语气词、连接词这几套中文特有的系统有没有按母语者的条件规则运转。AI 输出的"翻译腔"和"机器味"主要栽在这五处，而不是词汇量。

### 为什么有效（机制）
中文是话题优先语言（不是主语优先）：话题链、零形式主语、后置新信息都是合法组织；主语省略由"句法资格＋局部连续＋段界＋竞争人物"多条件许可，机械补全和机械省略都会出错；句号选择由"意义完整性"驱动——话题/人物/活动/时间/空间五类转移促句号、语义延续促逗号；句末语气词是有分层排序的系统而非随意点缀；母语叙事多数逻辑关系靠隐式衔接而非连接词。

实战旁证：编辑判"网感"三要素＝正叙、视角不漂移、无 AI 味；且 **AI 味≠AI 率**——满血模型可做到 100% 人工率仍满身 AI 味，编辑不跑检测、以人感为准。

### 判断标准
**主语与指称簇（治头号病灶：每句补全"他"的翻译腔）**
- [ ] 每个零主语位：候选先行词在语义上唯一兼容吗？（有竞争人物即显式重提姓名）
- [ ] 跨段界、换视角、对话插入后：显式重提了吗？（打断处**大概率**需要重提——零链可跨段但须逐处检查实际结构，非硬规则）
- [ ] 新人物/新物件首次出场：可以后置呈现（"那把刀，他藏了三年"式话题句）而不是硬塞进主语位吗？
- [ ] 连续分句挂同一话题链了吗？（同话题下后续分句不必重起主语）

**标点分句簇**
- [ ] 每个候选句号位：相邻分句间发生了五类转移（话题/人物/活动/时间/空间）之一吗？有则倾向句号
- [ ] 是详述/扩展且有连接标记（"就是""而且"）则倾向逗号
- [ ] 没有字符阈值——不设"长句超 X 字必须断"

**语气词系统簇**
- [ ] 对白里该有语气词的地方在吗？（指令/建议句的"吧"为对方保留拒绝空间——它不是"犹豫"标记）
- [ ] 粒子串按"的→了→呢/吧/吗→啊"由内向外排序了吗？
- [ ] 句末"了"先判定身份：完成体还是"新情况"惊异标记？

**话语标记簇**
- [ ] "我觉得"：落在人物有知识权威的评价上——删；落在知识范围外/结盟/启动叙述——留
- [ ] "你看/你说"：是招引注意/引用对方，不是字面视觉义
- [ ] 相邻分句无连接词时：隐式关系唯一可读吗？（因果/转折有竞争即需显化或改写）；显式连接词连用两次以上即冗余
- [ ] 从头到尾捋过一遍怪描述词了吗？（"嘴里铁锈味""指甲陷进肉里""劈在天灵盖上"式过度套路描写读着就删就改；判断标准是人感，不是 AI 检测率）

### 常见实现路径

| 路径 | 怎么做 | 例子 |
|---|---|---|
| 指称条件检查 | 零位查先行词唯一性，段界/竞争处显式重提 | 竞争人物在场时"他"→用名字 |
| 五类转移断句 | 句号跟着意义单元走，不跟字数走 | 人物一换话轮、场景一转即句号 |
| 语气词排序 | 粒子串由内向外：的→了→呢/吧/吗→啊 | "走了吧"（的→了→吧 内外序正确）；逆序如"吧了走"才是错序——但低频逆序并非绝对不可接受，按语境判断 |
| 隐式衔接优先 | 先写无连接词版，关系不清再加 | "因为…所以…但是…"连串即改写 |
| 语序五因素检查（无口诀） | 两句皆合语法而一句不自然时查：宾语前文提及？指称形式？长度？动词构式偏好？前句平行？ | 把字句前置与否查五因素（无口诀：长短宾语都可能前置，中长最不易——U 形倾向） |

### 判断你写对了没有
把一段对白遮住说话人名，还能分清谁在说吗？把一段叙述的每个"他/她"还原成名字，有没有哪处你犹豫"这是谁"？（犹豫＝指称条件被破坏）

### 常见错误

| 错误 | 本质 | 改法 |
|---|---|---|
| 主语每句补全 | 英语主语优先的迁移；中文零回指是常规形态 | 按指称条件检查省/补 |
| 一逗到底 / 句号碎切 | 标点没跟意义转移走 | 五类转移检查 |
| 对白零语气词 | 书面腔；语气词是口语立场系统 | 按语境补，注意排序 |
| 因为所以但是连串 | 逻辑显式化过度（母语叙事多为隐式） | 先删后查关系是否唯一 |
| 每人一个口头禅 | 人物区分≠专属词汇；功能词倾向（代词选择、句式频率）才是稳定模式 | 跨场景查功能词分布 |
| Gemini 式感官堆叠开篇 | "咬唇扑怀＋睫毛颤动＋浑身抖动＋紧抓衣襟＋耳边呢喃"五连——编辑一眼识破 | 换成"我看到/听到/想到"的落地叙述 |
| GPT 碎句指纹 | 三五字小碎句＋频繁换行，编辑已形成条件反射 | 合并成正常句长，控制换行密度 |

### 路径示例
- 新参与者后置呈现：无话题呈现句里，新人物/新物件常在**动词后**出场、进入语篇后才成为话题——"门口站着个瞎眼的老头"优于硬把新物件塞进句首主语位；已确立的话题才适合提到句首（"那把刀，他藏了三年"是旧话题前置，不是新信息后置）。
- "吧"的机制："明天再来吧"为对方留了拒绝空间；删掉"吧"变成通知——言语行为变了。
- AI 味开篇正反例：反——"他咬着唇一下扑到他怀里，睫毛颤动，浑身抖动，紧紧抓着他的衣襟，在他耳边呢喃，声音带着嘶哑"；正——"我看到白月光扑在渣男怀里，哭诉他健身的事"。同一场戏，前者是模型指纹，后者是人写的视角落地。
