# 素材库与采风（Novel Forage）

本技能管 `<工作范围>/书房/灵感库/`（书房共享库，零件跨书通用）与采风检索：建库初始化、日常积累、按任务采风、裁决归档与翻库取用——细纲、起草、评审、卷末各阶段按需加载。灵感池（创作点子）与立项流程在《灵感与立项》；写法类桥段参照在《细纲备料》技能包 references/桥段参照.md（已随 0.0.58 迁出灵感库）。

## 建库初始化

首次采风或翻库前，`<工作范围>/书房/灵感库/` 不存在时，从本技能包 `assets/灵感库种子/` 全量展开——建八个部子目录（一部一册 `零件卡.md`，册内子标照下）：

- `人/`——人物原型（子标：人设标签、反差矛盾点——声线／弧光／缺陷／欲望等人物设计零件）
- `地/`——方言风物、地域景观、现实场所（子标先立，零件待采）
- `物/`——年代器物、物价、日常物件（子标先立，零件待采）
- `事/`——时事与社会情绪、真实案件奇闻、历史事件（历史事件即原「历史事实」类并入；原「现实生活」空类撤销、其观察面并入 地／物／事 各子标说明）
- `知/`——冷知识、行业职业细节、游戏规则机制、设定概念模式（设定概念册迁入＋新子标待采；世界观概念模式／规则概念／力量体系概念——可跨书复用的通用概念素材，本书专属的设定点子仍入灵感池〔池库分工不破〕，库收的是「换个故事还能用」的概念模式；来源常为日常积累与采风）
- `言/`——台词金句、命名人名/地名/组织功法、圈层黑话（子标：金句语感／命名构词／黑话——人名〔罕见真实姓氏——公有领域事实可逐字；名的用字与声韵搭配法；人物气质与名字气质的匹配法〕、地名〔构词法——方位+地理+雅字等；真实古地名雅称〕、组织·器物·功法名〔构词模式与用字库〕；本部零件的「为什么好」写音韵/字形/联想原理，「反例」收拗口组合/歧义谐音/气质错配）
- `象/`——古词古句·意象（三子标照旧：诗词古文〔人物台词引用〕、雅称谚典〔雪→六出、月→冰轮，章名标题用〕、意象母题〔月雪灯舟——文化内涵＋经典用法＋化用方向〕）、文化元素（文化符号／民俗，下设热梗零件单独子标）、感官素材（子标先立，零件待采）
- `镜/`——影视动漫桥段、对标观察（名场面解析——演出逻辑／张力机制，仅作灵感参考，不作事实依据；对标观察待采）

种子内零件卡逐件复制进对应部目录（起步 131 条，采集说明随册保留——零件行与其上采集注记一并照抄），种子根下 `索引.md` 复制到库根（每部一行：部名｜零件数｜一句话范围｜最近更新），另建空 `_采风站点经验.md`（站点通道经验，按域名一条）；种子八部均建册（空册子标先立、行待采，首次归档时按十列行追加）。库已存在则不动（不合并不覆盖）。库存在但缺索引或缺某部零件卡时，仅补拷库中缺失且种子中存在的件，不覆盖库中已有件。旧版灵感库（0.0.57 前展开的旧类目）不重构：存量照旧可 grep 可追加，新归档行按八部去向落册，索引缺行仅补行。`_待裁决_采风_{YYYY-MM-DD}.md` 由采风执行时按日落暂存，`_待裁决_日常_{YYYY-MM-DD}.md` 由日常随手积累按日落暂存。**部总数 8 封顶**（防碎片化）——再有新类别诉求先归入既有八部，不开第九部。

**池库分工**：`<工作范围>/书房/灵感池/`＝创作点子（一脑洞一文件，随手记产物，已存在不动）；`<工作范围>/书房/灵感库/`＝采集零件（一部一册——裁决后 append 进对应部 `零件卡.md` 追加行，防碎片化）。**两库互不合并**。**池库互转**：翻库或读零件激发的新点子按随手记入池，frontmatter 记激发它的零件序号；池内点子需要素材支撑时，采风任务单的来源标记带池子身份（点子文件的身份名），零件采回即有挂靠。

**零件卡字段**（一行一零件，十列逐字照抄）：`序号｜关键词（2-4个）｜一句话（骨）｜为什么好（魂·原理一句）｜化用启示（适合什么质地的人物/场景，不写"用在第X卷"）｜反例（何时不可信/不可用）｜来源｜可信度｜已用于｜时效`。时效三态：`长青`（默认且**必填**——长青就写长青）／`时效`（值式 `时效｜首发YYYY-MM-DD｜半衰期约N月`）／`年代锚`（值式 `年代锚｜流行于YYYY年代`，供年代文/重生文对表）。序号＝部简称＋采集日期＋两位序（如 `言-20261016-03`，册内同日顺延；部简称八值〔人/地/物/事/知/言/象/镜〕与可信度四态枚举单源在 [采风检索](agents/采风检索.md)；种子存量行沿用采集时类前缀——人物/台词/命名/古词/文化/影动/设定）——孤证与归纳常态入库，标注即诚实；`已用于` 归档时初始为空，零件被某本书消费后回写该书书名；类别列只在暂存报告出现（裁决路由用），归档后类别即所在目录，不另立列。

**索引与检索**：不建复杂索引——关键词列在零件行内，检索一律 `grep "关键词" <工作范围>/书房/灵感库/*/零件卡.md`；`索引.md` 维持部级轻量（每部一行：部名｜零件数｜一句话范围｜最近更新），计数对账＝各部零件卡内数据行数与索引该部计数相等，归档时计数+1、最近更新改当日。

**生产通道三条**（灵感库＝作家的日常生活积累本，采风检索＝主动的头脑风暴与上网查外部资料——前者随时收，后者按任务查）：①采风采集——按「触发源六个」组任务单，派采风 agent 或主对话内联执行（见「执行」节）；②存量盘点——触发源⑤，对已有灵感库盘点补缺；③日常随手积累——作者日常撞见好名/好词/好概念说「存着」时，主对话直接按十列零件格式落 `<工作范围>/书房/灵感库/_待裁决_日常_{YYYY-MM-DD}.md`（`来源` 列＝日常积累·{YYYY-MM-DD}＋作者口述出处；`时效` 列照三态口径填；不经采风代理），随下次裁决一并呈作者归档。

**触发源六个**：①评审转来——《定调设计》确认前审查指导意见的【待采风：查询词】标记，作者同意后汇总成任务单；②开书备料——立项期题材考据（作者说「帮我查查这个题材」）；③热梗补给（trend-patch）——作者点名补梗或评审建议，查询式「梗名＋出处/用法」，梗句逐字入库＋时效列 `时效｜首发日期｜半衰期` 三件套，作者裁决后可固化进人物档案条目模板声线节口头禅（转长青＝时效列改 `长青`）；④即席查询——作者点名即查；⑤存量盘点——对已有灵感库盘点补缺，任务单来源标记写报告路径，跳过网络源，去重照走；⑥幕纲锚点缺素材——幕纲「查证清单」与细纲「查证行」标【待采风：查询词】的项即任务单来源，写幕纲/细纲时即可组单派采（写幕纲时派采的口径见《卷幕规划》），不攒到开写才补。

**执行**：读本技能包 [采风检索](agents/采风检索.md) 底本全文，组装任务包派发采风 agent（子代理），或在主对话内联执行（单条小任务）——均按底本走**两源**与红线：①素材库＝`<工作范围>/书房/灵感库/` 索引＋各部零件卡去重＋`<工作范围>/书房/灵感池/` 点子对照；②网络＝宿主联网工具可用时（查询词中文、只采国内源、境外源记「已排除」、摘要类路径结果最高标孤证；不可用降级单源如实标注；存量盘点触发源固定不走本源）。任务单格式照底本「调用契约」节，触发源随任务包传。采风报告 return 后暂存落 `<工作范围>/书房/灵感库/_待裁决_采风_{YYYY-MM-DD}.md`（派发时由子代理按底本落盘；内联执行时由你落）。

**裁决交互与归档**：暂存（`_待裁决_采风_` 与 `_待裁决_日常_` 两式）一行一条呈作者——`序号｜一句话｜为什么好｜去向建议`，作者逐条批「入/弃/改道」；裁决后由你（主 Agent）机械归档——「入」与「改道」按去向 append 进对应部 `零件卡.md`（一行一零件，十列全填，类别列不入册）＋`索引.md` 该部计数+1、最近更新改当日，「弃」不归档；评审转来的零件消费去向写回 `<工作范围>/书房/评审/{书名}/` 对应评审报告的建议列。零件好坏与采用与否由作者裁决，你不评判不筛除。

**拆书与采风边界**：有原文＝拆书机制卡（走《参考小说拆解》受管拆解）；无原文、只有别人的解析＝采风灵感库（走本技能）。

## 翻灵感库

作者要翻灵感库时（写前找参照、起名取词、点子要素材），按需求选一式：

1. **按部翻**：读 `<工作范围>/书房/灵感库/索引.md` 看各部一句话范围与零件数，再读目标部 `零件卡.md` 全册；
2. **按关键词 grep**：`grep "关键词" <工作范围>/书房/灵感库/*/零件卡.md`——关键词从题材、场景元素、情绪词取，多试两三个变体；
3. **按场景需求问**：作者只描述场景需求（如「写一场雪夜告别」）时，你自提关键词（场景元素＋情绪词）去 grep，命中零件连同「为什么好＋化用启示」一并呈报。

起名取词翻 `言/`（命名构词）与 `象/`（雅称谚典、意象母题）两册——雅称/意象词/好名好字可直接入名，无库跳过。

**四分管法（检索视图）**：按用途把八部投影成四分视图——**人设标签库**（人的反差矛盾点行）、**剧情钩子库**（事／镜的桥段行）、**金句语感库**（言）、**对标拆书库**（镜＋参考库机制卡）——卡文找钩子、不会写高潮、起名取词时按视图关键词 grep 对应部，素材仍存八部不分家（视图只是检索投影，不另建目录）。

翻到零件后三去向：

1. **入材料包**：走《细纲备料》「自主补充材料」，`来源` 带 `域: 书房` 与零件卡路径，机制现成；
2. **固化进人物档案**：热梗转长青通道的泛化——台词句式/口头禅类零件经作者裁决后固化进人物档案条目模板声线节；
3. **激发新点子入灵感池**：按随手记落 `<工作范围>/书房/灵感池/`，frontmatter 记零件序号。

**融合规则三条**（选→化→落→记 之后核一遍）：①梗与热点主要落**人物台词与群像反应**，叙述者慎用（叙述者玩梗易出戏）；②古代与异世界背景只取**机制**不搬原句（换载体换称谓再化用）；③真实灾难与悲剧**不娱乐化**（可做背景与动机，不做笑点）。

**过期软提示**：呈报命中零件时，`时效` 列为时效态的按「首发日期＋半衰期」核对——过半衰期的附一句「已过半衰期，建议复核」；`年代锚` 态按年代对表取用（年代文/重生文查流行年代）；`长青` 不提示——只提示不拦用。**消费回写**：零件被本书采用（入材料包/固化进人物档案）后，回写零件卡对应行「已用于」列（书名）。
