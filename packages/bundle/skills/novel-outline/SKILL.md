# 细纲备料（Novel Outline）

本技能分两段：**细纲段**（章细纲，跨真源边界，必须走工具确认）与**备料段**（材料包，幂等重建）。候选细纲的正文由你撰写、经 `novel_new_outline_draft` 的 正文 参数落草稿区，本技能只定流程与契约。

## 细纲段：标准流程

先读作品契约“阅读体验与情绪承诺 / 章节篇幅”。已确认时继承目标和上下限，未配置或未确认如实注明，不由主控补成固定默认值。在现有“情绪与节奏目标”中说明本章完成的主要任务、结束后的变化及预计总篇幅，并在叙事单元的“目标”中附预计汉字数；合计围绕章目标安排，预算可调整，不变成额外确认门槛。

两千字示例可以集中完成一次交锋：局面与压力约 300、主要行动与交锋约 1200、结果与余波约 500；这是分配重心的例子，不是所有章节的固定比例或结构。若细纲同时承诺多次交易、重要人物登场和关系转变，应减少本章任务量或提出拆并建议，保留主要行动的动机、过程和结果。修改已有确认细纲或窗口仍沿用原修订流程，不自动拆章、不靠灌水凑下限。

约束按来源分级：作者明确要求和既定事实形成硬边界；推荐手法属于软建议；未限定的局部写法保留自由空间。不要把自己提出的节奏、句式或未选路线自动升级为硬约束。

上层远期暂定/留白不是本章必须补齐的终局。当前章确实需要某处方向时说明缺口，按《工作台总控》提出候选并复用已有提案；作者采纳后再写。参考书机制只作建议材料，先核对当前证据状态，不将原作事实、结局或未采纳分岔升级成本书约束。

**章纲分级（落候选前先定级）**：**关键章**＝卷首章／卷内高潮章／卷纲心动位★章／换图章——判据源＝卷纲「卷末兑现」「心动位」行与分卷「卷目标与卷末状态」的主战层级行，机械信号优先、不凭体感；**过渡章**＝其余。关键章走全规格：固定小节全填＋写前十查全项。过渡章走**简章**：定位段核心节（视角与焦点／信息边界／情绪与节奏目标／冲突与爽点／章末双钩）照常填，其余节一行带过或显式留白——留白合法，细则照 [章细纲固定小节规格](templates/章细纲固定小节规格.md) 简章节；确认协议不变：约束分级＋来源引用两道硬门槛照过，core 空模板不动；写前十查机器四查照常跑（机械零成本），⑧近五章重复可放宽为隔章跑，其余照常（[写前十查](agents/写前十查.md) 有放宽口径）。

1. **读窗口与卷纲**：`大纲/卷规划/卷<NN>/近期窗口.md` 锁定本章任务与拆并关系（已消费/已失效条目不再是候选章）；同目录 `卷纲.md` 的「方向选择」小节取本卷 `选定方向` 与 `已排除走向`，该小节缺失即本卷未跑多方向；
2. **落候选**：调 `novel_new_outline_draft`（卷/章名/正文/来源引用）在草稿区生成候选；正文含两段——
   - **定位段**：来源窗口项及拆并关系、章节功能、视角与焦点、时空锚定、起止边界、故事线与承诺分配、信息边界、情绪与节奏目标、**前置条件核对结果** 九节，其后另加四节——`### 本章形状`／`### 已排除走向`／`### 冲突与爽点`／`### 章末双钩`；四节写法与既有节固定行（时间行、核心情绪前→后、POV 增减知、承上/交下、信息预算四行、跨章资产行——本章无新埋时写「本章新埋：零」声明行等）逐行照 [章细纲固定小节规格](templates/章细纲固定小节规格.md) 写。「本章形状」写它前先读本卷已确认细纲最近三章的同一节：不足三章就读现有的，早先的章没有这一节就跳过，本卷首章回上一卷 `章细纲/` 目录读；与近期形状比较以发现无意重复；重复若服务本章目标可以保留，不为求异硬换结构；「已排除走向」只承接卷纲或作者本次明确排除的走向，未选路线不自动排除；
   - **细纲段**：叙事单元列表，每单元六个字段——`目标`、`人物`、`时空`、`行动/冲突`、`信息披露`、`状态变化`，字段名逐字照抄（第四项本身带斜杠）；行内约束分级 `〔硬〕〔软〕`，无标记＝自由空间；单元可另加可选增补行——`- 决定（三型）：行动／挂起（＋重启条件）／承受（＋处境改变＋代价）`、`- 场景功能：推进/塑造/展开/预置`、本章单元实现卷纲「心动位」时该单元行标 `★`（情绪锚不是顺序锚——选读该单元写法判据时可加权重，判据见规格）——可选增补不参与确认校验，缺了不拦、写了不校；
   - 判据：读 [06_章纲](references/06_章纲.md) §6.9（情绪怎么量化）→「情绪与节奏目标」节；§6.10（本章视角怎么选）→「视角与焦点」节；§6.7（信息怎么分配——知道不知道矩阵选信息差型，读者比主角多/主角比读者多/读者和主角一样多等，一步步给、留悬念）→「信息边界」节（本书记忆有文风画像条目时，其逻辑层——信息释放节奏与章形钩型偏好——可参照）；§6.5（场景节拍怎么排）→细纲段单元列表；§6.3（冲突怎么分层）＋§6.4（爽点怎么设计）→`### 冲突与爽点` 节；§6.6（节奏密度怎么控）的章末钩相关判据→`### 章末双钩` 节；用读取工具按 `## §x.y` 标题定位后只读该节，不整文件读入；
   - **双参照（可选）**：①机制卡——本章含标志场景型（打脸/对决/升级/告白等）且 `书房/参考书/` 已有受管参考书时，可选调 `novel_reference_query search`（关键词从场景型与本章元素取）查一次机制卡；命中的机制卡读作写法参照——对照它怎么铺节奏、怎么压信息、怎么放钩；**借魂不借形**：不复制事件、人物组合与结局；没拆过参考书直接跳过，不提示不阻塞；②灵感库零件卡——本章需要特定意象或台词句式时，`grep "关键词" <工作范围>/书房/灵感库/*/零件卡.md`（关键词＝场景元素＋情绪词）；命中零件的「化用启示」读作写法参照，**借骨不借皮**：取句式与化用方向，不搬例证原文；两路都可选不阻塞，灵感库未建直接跳过；
   - **确认两道硬门槛（写候选时就带上，不等到确认再补）**：①**约束分级**——正文至少一行带行内标记 `〔硬〕`/`〔软〕`/`〔自由〕`（放「章节功能」或单元行里，不要另开「约束分级」小节）；②**来源引用**——合法形态只有三种：`来源:<仓内相对路径>@<版本>`（如 `大纲/卷规划/卷01/卷纲.md@1`，版本用对应工件当前版本号）、`来源:作者自定义`、`来源:对谈共创`；锚点、行号、绝对路径、纯工件名都无效。空模板不含标记行，照抄空模板必然过不了确认；
   - **写时整合**（写定位段各节时的心智模式——不是先写完再逐项查，而是写时就同时想）：
     - 写「情绪与节奏目标」时——同时想上章末尾读者带着什么情绪离开、本章要转到什么情绪、本章在卷里的节奏位置（铺垫期/高潮期/收束期）
     - 写「信息边界」时——同时想读者此刻最渴望知道什么、你最不想让他们知道什么、哪个信息透露一半比全说更抓人
     - 写「冲突与爽点」时——同时想这个冲突强度在卷里排第几、上一章的冲突是什么级别、读者看完这章的爽感够不够"想翻下一章"
     - 写「章末双钩」时——同时想下章细纲已经排了什么（近期窗口可读）、这个钩子下章拿什么还、如果下章还没排，钩子够不够指引下章方向
3. **改候选**：候选落盘后需要调整的，用宿主 `edit` 逐单元替换（一次一个单元或一节，old_string 取该单元完整多行原文），改完 `read` 回读；不整文件重写，也不为标点级差异反复打磨；确认失败报字段缺失时只补缺的单元；
4. **写前十查**：候选落盘后、呈确认前，读本技能包 `agents/写前十查.md` 全文执行——机器四查（①三约束对照／②能力越级＋金手指对账／③伏笔到期／④接钩预检）你机械跑，过目单六查（⑤平章／⑥爽点铺垫／⑦动机三问／⑧近五章重复／⑨情绪落点／⑩钩子承诺）进呈确认件；十查底本的判据来源补充知识库引用——⑤平章检查对照 [06_章纲](references/06_章纲.md) §6.1（一章写什么）的"变化"判据；⑥爽点铺垫对照 §6.4 的铺垫要求；⑨情绪落点对照 §6.9（按 `## §x.y` 标题定位只读该节）；查完进步骤 5 一张表呈报，不拆两轮；
5. **呈确认**：呈确认件统一格式（一张表，三段）：
   - **门槛**（工具校验必拒项）：约束分级标记有吗？来源引用合法形态吗？——失败＝工具必拒，改完再呈；
   - **四查结论行**：①三约束：… ②能力对账：… ③伏笔到期：… ④接钩：…；
   - **六查过目表**（固定六行）：⑤平章 … ⑥爽点铺垫 … ⑦动机 … ⑧重复 … ⑨情绪落点 … ⑩钩子承诺 …；
   - **雷点快扫行**（固定末行）：感情线/战力兑现/煽情/视角切换类单元按《写前十查》底本文末的高发雷点内联判据快扫，命中项与无命中各写实一句；
   - 🔴 项（越级/到期未兑现/平章）标红呈作者裁决——十查是检查不是门禁；两类检查一张表呈报，别分成两轮。

   向作者概述定位与情节点，获明确同意后调 `novel_confirm_outline`（卷/章/章名/summary/`批次文件`），只传章键，不重传正文；章号须与近期窗口和已确认细纲连续，不确定时先问作者。

## 细纲段：重入（已有确认细纲再进＝改细纲，不是重拟）

- 真源已有确认细纲、草稿区重新出现候选＝修订流程：改完候选再 `novel_confirm_outline`，**版本自动 +1**；
- **已定稿章的细纲勘误（笔误/小修）同样走候选→再确认**：该章窗口条目已消费不影响确认（真源已有确认细纲即重入，版本 +1、父版本指旧版，定稿 frontmatter `来源细纲版本` 不回写）；只改设计工件时跑影响分析脚本呈报即可，**无需吃书补偿**；正文若受影响另走提案/吃书；
- **人物自决类轻量改纲**：正文层发现「人物不会这么做」而细纲要改时——改动限于单章内的行动/冲突字段、不产生下游承诺变更（无伏笔/线索/窗口条目受影响）的，按勘误通道同款处理：改候选→再确认（版本 +1），不跑影响分析、不吃书补偿；有下游影响则仍走影响分析前置呈报；
- 改前跑影响分析脚本（本技能包 `scripts/影响分析.mjs`，只算不写；失败按《工作台总控》「脚本失败分流」表处理）做**影响分析前置呈报**：受影响未定稿下游同批整改，整改文件列入 `批次文件`，**整批一次确认、一次 `design(chNNNN):` 提交**；已定稿下游走吃书补偿；影响面过大拆提案；
- **幂等可重放**：真源已落位、候选已删时重跑确认＝只补提交不重写文件；确认结果带 `commitState`，`unchanged` 表示无新增提交、不是失败，不为产生新提交重复调用；工具报「已落盘但未提交」（`commitState: failed, retryable: true`）处理失败原因后重跑补提交。
- **滚动窗口段级刷新**：每完成一个卷内高潮（或约 10 章），基于已定稿章摘要回顾本段——实际走向与卷纲的偏差、人物活了带来的新脉络，据此重排下一段窗口；卷纲要动先走《定调设计》卷纲修订，窗口批量追加用 `novel_roll_window` 逐条补——不是每章滚一次。

## 备料段：材料包（十段固定结构）

先跑备料脚本 `node <resourceBase>/scripts/材料备料.mjs --book <bookRoot> --卷 <卷> --章 <章> --章名 <章名>`（只算不写，输出给出十段全文与在缺清单；失败按《工作台总控》「脚本失败分流」表先分流，两类都排除＝脚本缺陷，停下报作者）读包判断；确认后调 `novel_assemble_materials`（卷/章/章名）落盘到 `草稿区/材料包/卷<NN>-<章名>/`（写入器内重算，幂等重建）：

本章任务与确认细纲／硬约束禁区完成条件／当前事实与连续性／人物、关系、地点、组织、规则、物件／时间位置与信息边界／故事线承诺线索／近期正文衔接／文风〔条目切片〕／暂定与警告／来源与版本清单。

各段是**切片不是全文**：近期正文衔接＝上一章定稿末尾＋最近章摘要，账本段按最近条目与本章命中取用；任何段一律全文进包，不设上限也不截断，「材料清单.json」逐段记 `字数`（包记 `合计字数`）供你自行判断体量。

- **重入＝幂等整包覆盖**；已消费版本的条目固定，条目更新不得让已确认工件静默失效；
- 返回值带缺口清单（细纲与来源级）与**写作就绪播报**，逐段完整性查 `材料清单.json` 的 `段[].完整性`；十段是声明式编排，**不是开写门槛**，够不够开写由你向作者如实播报后判断；
- 书房里作者自备的资料严禁把正文抄入真源区，引用只写来源路径与版本。

## 自主补充材料

十段是自动备料基线。发现早期伏笔、关系变化、作者决定或资料未覆盖时，先读取相关原文，再调用 `novel_assemble_materials` 补齐本章材料；普通选料无需逐项再请作者批准。开书期存在 `<工作范围>/书房/开书/<书名>/种子底子.md` 时，第一章备料可经补充操作（域: 书房）把种子底子带进材料包；灵感库零件可作另一路补充来源——按《灵感与立项》「翻灵感库」命中的零件，同样经补充操作（域: 书房）引零件卡路径进包，机制现成。

1. 传 `模式: 预览` 与 `补充操作`，每项 `操作: 设置`、稳定 `编号`、`标题`、`理由`、`性质: 原文|建议`，以及 `来源: { 域: 本书|书房, 路径, 起行?, 终行? }`。本书路径相对书仓，书房路径相对同工作范围的 `书房/`；禁止用索引或检索结果代替原文。
2. 核对返回的 `补充预览[].原文`。保存时传 `模式: 保存`、预览返回的 `材料清单哈希`，并把 `补充预览[].操作` 作为 `补充操作` 原样带回，其中已含 `来源.读取哈希`。只传短引用及校验值，不重传原文，不自行算哈希。
3. 修改某项用同编号重新预览和设置；移除用 `{操作: 移除, 编号}`。不传操作或传空数组都是保留，不是清空。移除后清单不再登记，遗留附件不能再读入模型。
4. 普通重建保留已选摘录；来源过期、清单冲突、附件损坏时按提示重读、预览并显式设置或移除，不手改清单/附件，不把新来源悄悄盖在旧依据上。

补充与十段在同一 `材料清单.json` 中，快照在 `补充/<编号>.md`。理由、来源、行范围、哈希、性质和字数都在清单；补充原文保真，建议不当作事实。需要缩小范围时由主控显式调整选料，不在写稿或审读侧偷偷截断。

## Off-limits

- 状态取值按工件取族，不自造近义词：候选细纲与确认细纲的 `状态` 属工件族（候选／已确认）；材料包状态属轮次族（组装中／段齐备／段有缺／有冲突／已过期／已消费；段齐备/段有缺只是各段在缺的如实播报，够不够开写由你判断）；卷规划各件属计划族（已确认／暂定／留白）；
- 涉及未写章节走向变动先出建议稿，不直接覆盖卷规划与世界书；
- 草稿区工件可丢弃可重建，大胆迭代；确认状态与各段在缺如实播报，不粉饰「已就绪」；
- 走向定在卷纲层：细纲承接卷纲选定方向与作者明确排除项，不擅改走向；需要改变时另提建议。本章形状每章自选，不受此限。
