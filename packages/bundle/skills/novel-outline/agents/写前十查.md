# 写前十查（细纲呈确认前十查）

纪律：确认硬门槛（约束分级标记/来源引用合法形态）失败＝确认工具必拒；十查🔴＝呈作者裁决不自动拦卡——两类检查一张表呈报，别分成两轮。十查全部是**呈确认前的检查**，不是门禁——🔴 项（越级/到期未兑现/平章）呈报作者裁决，不自动拦卡；查了什么都写在呈报里，没查成的项如实注明缺什么。①-④ 机器四查由你（主 Agent）机械执行；⑤-⑩ 过目单六查是作者过目件的固定内容，连写时＝差异呈报必报行。

章纲分级放宽：本章为过渡章（分级判据见《细纲备料》SKILL 细纲段「章纲分级」）时，机器四查照常跑（机械零成本），⑧近五章重复放宽为隔章跑——连续过渡章隔一章比对一次，跳过时呈报表⑧行如实注明「过渡章隔章」；比对序列重启的首章与孤立过渡章（前后皆关键章）照常比对，不隔；其余六查照常。关键章十查全项。

## 机器四查（候选落盘后、呈确认前）

1. **三约束对照**：读 `大纲/卷规划/卷<NN>/近期窗口.md` 当前条目行＋同目录 `卷纲.md` 的「方向选择」小节，对照候选定位段的「视角与焦点」「信息边界」「情绪与节奏目标」三节＋各单元「信息披露」字段——本章任务、卷方向、口径不一致的逐处列出；
2. **能力越级＋金手指对账**（当前为世界书规则行语义对账，位阶机器级🔴判定未实装（二期）——如实声明，不声称机器核过）：本章动用的能力/金手指逐项 → read `世界书/力量体系/` 相关条目的境界表与金手指轨道位、`世界书/世界规则/` 条目的铁则表 → 对照规则行写结论，格式「已核对 世界书/<模块>/<条目>，本章动用 <能力> 与当前设定一致/越级」；判越级＝🔴；
   - 本章动用金手指时三查（对照 `世界书/力量体系/` 条目金手指轨道位四行）：
     - 代价已结否：对照代价分型——本章动用了而代价没结＝🔴 当场落账；
     - 越档：动用超出当前升级档＝🔴（档位对照金手指轨道位台阶定位行）；
     - 泄底：出场角色的认知对照可见度牌——不知道的人表现出知道＝🔴；
   - 判据延伸（内联摘要——02/03 文件在《定调设计》技能包，跨包链接不可达，只内联核心判据）：
     - 主角×金手指衔接（源出 02_人物设计 §2.18）：金手指盖过主角风头了吗？主角有独立性格还是成了金手指的陪衬？把金手指拿走，主角还立得住吗？——本章解法若属"没金手指就什么都干不成"，按金手指抢戏呈报；
     - 等级排位判断（源出 03_世界观设计 §3.9）：等级不是数字是社会身份——动用能力前核当前等级对应的地位、圈子与资源；升一级世界应变（能进的场合/能说的话/别人的默认态度）；越级挑战要有铺垫（门槛/代价/机缘），无铺垫越级＝🔴；
     - 完整版在《定调设计》技能包的 references/02_人物设计.md §2.18 与 references/03_世界观设计.md §3.9；
3. **伏笔到期**：read `账本/线索.md`，过滤「预期兑现区间」覆盖本章且「状态」＝已埋/已示的行，与候选「故事线与承诺分配」节对账——本章应兑现的落进单元行；不该本章兑现的确认候选未提前兑现；到期未兑现＝🔴 呈报；本查过滤命中同时是章纲分级「伏笔/线索到期兑现章」的判据源——命中即本章按关键章定级（分级枚举见《细纲备料》SKILL 细纲段「章纲分级」）；
4. **接钩预检**：read 上一章 `大纲/卷规划/卷<NN>/章摘要/<NNNN>-<章名>.md` 末行＋上一章定稿末段，对照候选「起止边界」——写明上章钩的回应点在本章哪一场；候选「时空锚定」时间行的上章末时间衔接一并核对；接不上的列为呈报差异项。本卷首章无上章时如实注明「首章无接钩」。

四查结论行（呈确认播报固定四行，逐查一行、写实际结论不写套话）：

```
①三约束：…｜②能力对账：…｜③伏笔到期：…｜④接钩：…
```

## 过目单六查（作者过目件固定含；连写时＝差异呈报必报行）

5. **平章检查**：逐单元读「状态变化」字段，按三型标注——
   - 空或「无变化」→标红（平章嫌疑，全章各单元皆空＝整章平章，🔴 呈报）；
   - 行动型：有变化✓；
   - 挂起型：须带重启条件（何时/何条件下回到这条线）——无重启条件＝弃线→标红；
   - 承受型：须带处境改变＋代价——纯情绪反应无处境改变→标红；
   - 判据延伸：读 [06_章纲](../references/06_章纲.md) §6.1 一章写什么——"这一章结束后什么变了"的变化判据；
6. **爽点铺垫对账**：本章爽点位的铺垫在前文哪——查 `账本/承诺.md` 已埋条目＋上一章章摘要，写明「爽点位←铺垫于<章号/条目>」；无铺垫的爽点如实标注；
   - 判据延伸：读 [06_章纲](../references/06_章纲.md) §6.4 爽点怎么设计——四步铺垫展开（亮底牌/占理/可恨反派/阶梯递进）；
7. **动机三问**：
   - 主角为什么非干不可（内核欲望没变吗）？
   - 反派为什么现在动手？
   - 配角为什么在场？
   - 人物行为有突变再加一问：变化垫了三级台阶吗（认知水位不退/代价证明）？
   - 答不上＝降智/工具人/无铺垫突变，标注呈报；
   - 判据延伸：读 [06_章纲](../references/06_章纲.md) §6.3 冲突分层——挑冲突的料（八类常见矛盾）给动机找源头；
8. **近五章结构重复**：read `大纲/卷规划/卷<NN>/章细纲/` 最近五份确认细纲的「本章形状」节＋单元行，比对同款开场/转折/爽点位型（机械比对由你做）；命中重复的呈报，改不改由作者定；
   - 判据延伸：读 [06_章纲](../references/06_章纲.md) §6.5 场景节拍——情绪转向与动作反应交替是形状比对的底版；
9. **情绪落点**：候选「情绪与节奏目标」节末尾补一行「读者带什么情绪离开本章」；缺此行＝补写再呈；与「核心情绪前→后」行分工——前→后是位移（章首读者处于什么情绪、章末转到什么），落点是读者离开时带什么，两行各有职责不互相顶替；
   - 判据延伸：读 [06_章纲](../references/06_章纲.md) §6.9 情绪怎么量化——三个拐弯＋前松后紧＋最后一个拐弯是主角主动选择；
10. **钩子承诺**：读候选「章末双钩」节——逐钩写明承诺什么、下章拿什么还；承诺列缺失＝补写再呈。
   - 判据延伸：读 [06_章纲](../references/06_章纲.md) §6.6 节奏密度怎么控——章末留钩与钝收边界的判据。

## 呈报格式

呈确认播报＝一张统一呈报表（与《细纲备料》SKILL 步骤 5 同格式）：门槛核对（约束分级标记有吗/来源引用合法形态吗——失败＝确认工具必拒，改完再呈）＋定位与情节点概述＋四查结论行＋六查过目表（🔴 项标红，呈报作者裁决——十查不自动拦卡，裁决与确认都归作者）＋雷点快扫行（判据见文末）；两类检查一张表呈报，别分成两轮。连写模式的差异呈报里六查行是必报行，格式见《工作台总控》「章内接续」连写授权档。

六查过目表（固定六行，结论写实际内容不写套话）：

| 查 | 行 |
| --- | --- |
| ⑤平章 | 逐单元三型结论（行动✓/挂起＋重启条件/承受＋处境改变＋代价；标红项列名） |
| ⑥铺垫 | 爽点位←铺垫于<章号/条目>（逐点位一行） |
| ⑦动机 | 三问各一句（有突变加三级台阶一问） |
| ⑧重复 | 与近五章形状比对的命中项（无则写「无同款」） |
| ⑨情绪落点 | 读者带什么情绪离开本章（一句） |
| ⑩钩诺 | 信息钩承诺…／情绪钩承诺…（各一句，含下章拿什么还） |
| 雷点快扫 | 命中项写明查到哪条（无则写「无命中」） |

雷点快扫行（呈报表固定末行，接在六查过目表之后）：候选涉及感情线推进、战力兑现、煽情桥段、视角切换时，按高发雷点内联判据快扫——感情线类（绿帽/送女、恋爱脑误主线、感情线抢主线）、圣母行为、无铺垫越级、憋屈虐主无平行补偿线、强行煽情、视角乱切、开篇堆设定；命中项写明查到哪条，无命中写「无命中」；🔴 呈作者裁决，不自动拦卡。完整清单源在《定调设计》技能包 references/雷点清单.md（跨包链接不可达，只内联高发项）。
