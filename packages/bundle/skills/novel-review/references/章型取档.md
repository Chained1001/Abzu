# 章型取档与审读强度

> 判据单源。任务包「第一部分之二」给出本章 `章型`（承诺档·情绪位），审读按本表取档，不另判。
> 章型的解析与派发口径在 core `packages/core/src/outline/chapter-type.ts`（`派发口径()`），本表是它的审读侧展开。
> 本表只管「章型 → 审读强度」的换算；对象×风险×强度的默认表、升降档规则与作者降级/跳过记录在《工作台总控》技能包 `references/评审分级与门禁.md`（本表不复制那套档位）。

## 取档表

| 章型 | 审读强度 | 说明 |
| --- | --- | --- |
| `关键·*` | 9 维全跑 | 关键章不降档，与旧口径一致 |
| `过渡·余波` | 确定性＋单维（章节结构） | **余波重点是「连续钝收」与「泄压钩居位」**，两件都在结构维；同时核对本章是否已指定调剂式（日常/喜剧/清算），未指定即一条发现项 |
| `过渡·高潮` | 确定性＋单维（节奏与张力） | 高潮章查烈度是否真的到位、兑现是否足额 |
| `过渡·切换` | 确定性＋单维（情节与因果） | 桥接章查是否「只过场不推进」 |
| `过渡·铺垫` | 确定性＋单维（线索与伏笔） | 铺垫章查埋的东西后文能不能接上 |
| 未标 | 9 维全跑 | 宁可多审——缺章型不是少审的理由 |

## 两条纪律

**降档不等于降低标准。** 单维照该维度的信号与裁决全跑，只是不跑其余八维。若单维审读中发现跨维问题（例如结构问题其实是信息边界问题），照实报告并注明「超出本章型档位」，不要因为降档就压掉发现。

**写前十查不跟着降。** 十查强度由 core `派发口径()` 的 `十查` 字段决定：`过渡·余波` 是「简章但十查全项」——余波最容易犯连续钝收与泄压钩错位，细则可简、查项不可省。

## 与旧口径的关系

旧设计只有「关键章／过渡章＝其余」一条轴，过渡章一律降档。问题是余波章被误分到低规格侧，而余波恰是高设计密度章。拆成两轴后：

- 承诺档（关键/过渡）决定**细纲规格密度**；
- 情绪位（铺垫/高潮/余波/切换）决定**流程负担与收束方式**。

两者组合出八格，其中 `过渡·余波` 是旧设计漏掉的一格：细则可简，但十查必须全项。
