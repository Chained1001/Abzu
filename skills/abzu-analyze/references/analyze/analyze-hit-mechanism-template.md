# 爆款机制模板

> **消费点**：拆书分析域 Stage 6 全量加载——爆款机制_{书名}.md 的落盘模板
> **边界**：管产物结构与填写标准；四层框架定义归 references/analyze/analyze-method.md「爆款机制四层」节

## 目录

- 定位注记
- 字段定义表
- 填写示例
- 模板正文

## 定位注记

- **产物**：`拆书/{书名}/爆款机制_{书名}.md`——全书亮点的归因分析
- **何时创建**：拆书分析域 Stage 6（六维拆书之后，停靠点二）
- **生产者**：拆书分析域 Stage 6，输入取自 `六维拆书_{书名}.md` 与 `结构块.csv`
- **消费方**：作者（对照选题与自己的开篇设计）；选题决策「能爆的原因」字段的方法参照（本域不直接写 scan 产物，验证回填见 workflow「选题决策回填」节）
- **约束**：Top 3 亮点 × 四层解释；缺任何一层不合格；禁止空泛结论

## 字段定义表

| 字段 | 说明 | 生产来源 | 必填 |
| --- | --- | --- | --- |
| 亮点排序 | Top 3，按证据强度与独特性排序 | Stage 5/6 产物对照 | 必填 |
| 表层表现 | 可指着原文说出来的桥段/设定/写法 | 定点回查原文 | 必填 |
| 叙事机制 | 结构上怎么运作：调动了哪些循环要素、信息差怎么摆 | 结构块.csv | 必填 |
| 读者心理 | 击中了什么代偿/焦虑/好奇 | Stage 5 人物内在需求 + 双时间线 | 必填 |
| 可迁移原则 | 换题材的复用一句话 + 复用条件 | 四层递进归纳 | 必填 |
| 证据档位 | 每条归因按明确/强推断/暂定标注 | 全 Stage | 必填 |

## 填写示例

```markdown
# 爆款机制：《潮汐灯》

- 拆解日期：20260907
- 亮点来源：六维拆书 + 结构块（全书 14 块）

## Top 1 灯塔看守的"有限视角"破案

- 表层表现：主角只能通过灯塔视野与港务档案两条窄通道逼近真相（明确·第 6/12 章）
- 叙事机制：每块循环的"加压"都靠信息差收窄实现——读者比主角多知半步，全程等他踩坑（强推断·块 2/5/8 同构）
- 读者心理：解谜代偿 + 全知视角的优越感，双重满足（强推断）
- 可迁移原则：把主角的信息通道物理性收窄（一个地点/一种职业/一件信物），悬念自然可控；复用条件是通道必须天然带新信息流入
- 证据档位：强推断（三处结构同构 + 六维双时间线互证）

## Top 2 …
```
