# 拆书分析方法

> **消费点**：拆书分析域 Stage 1/3 全量加载，Stage 5/6/7 按需
> **边界**：本文件管拆书的方法与判据（档位、置信、切块、字段、归因框架）；流程顺序归 references/analyze/analyze-workflow.md；产物落盘格式归各 template 文件

## 输入三档

| 档位 | 判定 | 拆解纪律 |
| --- | --- | --- |
| 全文 | 完整原文 | 完整拆解，全维度可下结论 |
| 大部分 | 缺部分章节（缺失 < 全书 1/3〔abzu 自定〕） | 产物头部声明缺失范围及其影响（哪些维度结论受限）；缺失区间的结构块一律标暂定 |
| 梗概 | 简介/大纲/他人转述 | 全部产物头部标「暂定分析——基于梗概」，只做方法假设不做事实断言 |

未知不补写：原文没有的信息写「未知」，禁止用类型常识脑补——脑补出的"规律"混进结论会污染下游借鉴。

## 证据三分

每个结论标注置信档位，三档定义：

| 档位 | 标准 | 写法 |
| --- | --- | --- |
| 明确 | 有原文书证 | 结论 +（书证：第 N 章） |
| 强推断 | ≥2 处线索同向指向 | 结论 + 列出线索 |
| 暂定 | 单一信号或无书证 | 结论 +（暂定） |

书证指向原文位置时用章节号或 source_locator；梗概档无原文可证，全部结论最高只能给暂定。

## 结构块判据

结构块是拆书的语义最小单位：一个完整的戏剧循环。切块是拆书的第一刀，块切错了后面全错。

戏剧循环五要素：

1. 缺口：出现一个未解决的问题、威胁或欲望
2. 加压：代价升高、选项收窄、期限逼近
3. 转折：信息反转、力量反转或关系反转
4. 兑现：给读者一次情绪兑现（爽点/解谜/团圆）
5. 新阅读债：兑现同时抛出新悬念，绑定读者继续读

三档块长（按章数）：2-5 / 5-12 / 12-30〔abzu 自定〕。超过 30 章仍凑不齐一个完整循环 → 如实标注「循环缺要素」，禁止硬划。

锚点章（块边界优先落在这些位置）：黄金三章（第 1-3 章）、末三章、卷界（卷首/卷末）、信号章（出现重大转折、换地图、新势力入场的章）。

过渡章并入规则：纯过渡章（无循环要素、只为衔接）并入相邻块，不单立成块；前后都搭得上 → 并入承接其兑现的后块。

切块操作顺序：先标锚点章 → 相邻锚点之间按循环要素归块 → 逐块校验五要素齐全（缺哪个记哪个）→ 落盘 `结构块.csv`。

## 六维拆书

六个维度构成单书拆解的总表，全部结论按证据三分标注。维度职责：人物与关系管"谁在推动"，冲突与双时间线管"张力从哪来"，叙事顺序与三维节奏管"怎么递到读者手里"。

### 人物设定（12 字段）

| 字段 | 说明 |
| --- | --- |
| 身份地位 | 出场时的社会位置与处境 |
| 外在目标 | 明面上追什么 |
| 内在需求 | 暗地里缺什么（与外在目标冲突时即是戏眼） |
| 能力与代价 | 会什么，每次动用要付出什么 |
| 性格底色 | 稳定的行为倾向 |
| 价值观 | 什么能做、什么碰都不碰 |
| 创伤与软肋 | 过去的洞与现在的死穴 |
| 成长弧线 | 起点态 → 终点态 |
| 行事原则 | 遇事的第一反应模式 |
| 信息掌握度 | 他知道什么、不知道什么（信息差调度的原料） |
| 功能定位 | 推动剧情 / 强化主角 / 双重功能（三型见下） |
| 语言标记 | 口癖、称呼习惯、标志性句式 |

人物功能三型：推动剧情（事件因他而转）、强化主角（衬托、供养情绪、当垫脚石或磨刀石）、双重功能（两者兼有——好书常见配置，标注出来）。

### 关系图谱

关系必须用有方向的动词描述，禁止「朋友/敌人」式静态标签——标签不带信息量，动词才携带剧情。常用动词表：利用、保护、试探、依附、制衡、遮蔽、引导、背叛、亏欠、争夺、结盟、提防。每条关系写成：A →（动词）→ B + 一句书证。

### 冲突矩阵

冲突五类：外部对抗（人对人、势力对势力）、环境压力（天灾、资源、规则）、人际纠葛（情感与立场错位）、内心冲突（欲望与价值观互搏）、价值观冲突（两种道理都成立的对撞）。矩阵按「冲突线 × 所属五类 × 对应结构块」落表。

### 双时间线与信息差

- 真实顺序：故事世界里事件实际发生的先后。
- 披露顺序：读者获知该事件的先后。
- 信息差三类：读者知人物不知（悬念——等他踩坑）、人物知读者不知（好奇——他为什么这样）、都不知（突转——揭晓时一起震惊）。

每处显著错位记录四件套：事件 → 真实位置 → 披露位置 → 偏移目的（吊悬念 / 延后兑现 / 误导再反转）。

### 叙事顺序与偏移目的

叙事顺序管整卷的编排策略（顺叙、插叙、倒叙、多线交叉）；双时间线管单个事件的错位，两者分工不混。每段编排选择记录其偏移目的——没有目的的炫技编排是负资产，照实指出。

### 三维节奏

三个独立刻度，不得合并成一个「节奏分」——合并会丢掉错位信号（高剧情低情绪＝赶稿区，低剧情高情绪＝缓冲区，错位本身是诊断点）：

- 剧情强度 1-5：事件推动力，本章结束时局面变化多大
- 情绪强度 1-5：读者情绪唤起，爽/怒/疼/暖的烈度
- 描写密度 1-3：环境、心理、动作描写的占比

按结构块记录三维值并标块号，标出全书节奏曲线的错位段。

### 题材体量

题材标签、总字数、卷结构、单章字数分布——从 `章节索引.csv` 直接读出，不为此重读原文。

## 爆款机制四层

对每个入选亮点做四层解释，逐层递进；缺任何一层即不合格，禁止「节奏好」「人设讨喜」式空泛结论：

1. 表层表现：它是什么桥段、设定或写法——可指着原文说出来的东西
2. 叙事机制：它在结构上怎么运作——调动了哪些循环要素、信息差怎么摆
3. 读者心理：它击中了什么代偿、焦虑或好奇——读者为什么吃这套
4. 可迁移原则：换个题材怎么复用这个机制——一句话原则 + 复用条件

## 黄金三章拆解维度

前 3 章逐章过以下维度（开篇是网文生死线，例外于结构块粒度）：

- 本章钩子：章末留了什么（对照戏剧循环的新阅读债）
- 悬念调度：抛了几个问题、回收了几个、压了几个
- 金手指披露时点：核心优势第几章露头、露到什么程度
- 信息差操作：开篇用了哪类信息差
- 兑现与新阅读债：本章给了什么爽点、又欠下什么
- 主角入场策略：以什么状态与处境入场，与读者建立什么共情

三章合看：归纳开篇策略（悬念前置的节奏、金手指披露曲线、共情建立的先后）。

## 原创迁移与相似性审计

仅用户明示要求时执行，默认不生成——防照搬，也不越权替用户做创作决定。

1. 抽灵魂：从爆款机制四层的可迁移原则中选 1-2 条
2. 抽骨架：取结构块序列的编排模式（只看编排，不看具体桥段）
3. 生成 3 个故事种子：不同题材、人设、金手指，各一句话（题材差异是相似性的第一道防线）
4. 相似性审计：逐种子对照原书查四类相似——设定相似、桥段相似、关系结构相似、语句相似；设定或桥段出现「换皮」判定即废弃重生成，语句相似零容忍
