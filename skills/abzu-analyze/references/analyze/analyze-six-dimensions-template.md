# 六维拆书模板

> **消费点**：拆书分析域 Stage 5 全量加载——六维拆书_{书名}.md 的落盘模板
> **边界**：管产物结构与填写标准；六维字段定义与判据归 references/analyze/analyze-method.md「六维拆书」节

## 目录

- 定位注记
- 字段定义表
- 填写示例
- 模板正文

## 定位注记

- **产物**：`拆书/{书名}/六维拆书_{书名}.md`——拆书域的权威产物
- **何时创建**：拆书分析域 Stage 5（结构块识别之后）
- **生产者**：拆书分析域 Stage 5，数据主要取自 `结构块.csv`（Stage 3 产出）
- **消费方**：作者（学习方法与对照自己的书）；本域 Stage 6（爆款机制的输入）；会话恢复时的进度锚（本文件存在＝拆解已完成）
- **约束**：自包含——每个结论自带书证，禁止「见另一文件」式占位；梗概档全部结论标暂定

## 字段定义表

| 字段（节） | 说明 | 生产来源 | 必填 |
| --- | --- | --- | --- |
| 头部信息 | 书名、拆解日期、输入档位、章节范围 | Stage 1 档位判定 + 章节索引.csv | 必填 |
| 人物设定 | 主要人物每人数 12 字段（12 字段定义见 analyze-method） | Stage 3 关系增量 + 定点回查 | 必填 |
| 关系图谱 | 有方向动词的关系清单，每条带书证 | Stage 3 关系增量 | 必填 |
| 冲突矩阵 | 冲突线 × 五类 × 对应结构块 | Stage 3 循环要素 | 必填 |
| 双时间线与信息差 | 显著错位四件套（事件/真实位置/披露位置/偏移目的） | Stage 3 结构块 | 必填 |
| 叙事顺序与偏移目的 | 整卷编排策略及其目的 | Stage 3 结构块 | 必填 |
| 三维节奏 | 逐块三维刻度值 + 错位段标注 | Stage 3 节奏锚点 | 必填 |
| 题材体量 | 题材标签、总字数、卷结构、单章字数分布 | 章节索引.csv 直接读出 | 必填 |
| 证据档位标注 | 每条结论按明确/强推断/暂定标注 | 全 Stage | 必填 |

## 填写示例

```markdown
# 六维拆书：《潮汐灯》

- 拆解日期：20260907
- 输入档位：全文
- 章节范围：第 1-120 章（两卷），共 36 万字

## 人物设定

### 主角 沈眠
- 身份地位：滨海小城灯塔看守（明确·第 1 章）
- 外在目标：查清父亲沉船真相（明确·第 2 章）
- 内在需求：承认自己想离开小城（强推断·第 4/19 章两次独白同向）
- 功能定位：双重功能——真相线由他推动，守塔日常供养情绪（强推断）

## 关系图谱

- 沈眠 →（试探）→ 港务局长：第 7 章借还档案试探口风
- 港务局长 →（遮蔽）→ 沉船事故责任人：第 30 章调阅记录被搁置

## 三维节奏（按结构块）

- 块 1（1-3 章）：剧情 4 / 情绪 3 / 描写 2
- 块 2（4-9 章）：剧情 2 / 情绪 4 / 描写 3——缓冲区，情绪供养
- 错位段：块 5-6 连续高剧情低情绪（剧情 4-5 / 情绪 2），赶稿信号

## 题材体量

都市悬疑；36 万字；两卷；单章 2800-3400 字，均值 3000 字
```
