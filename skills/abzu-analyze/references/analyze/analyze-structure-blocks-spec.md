# 结构块 CSV 表头与字段说明

> **消费点**：拆书分析域 Stage 2/3 全量加载——两份 CSV 的表头契约与填写规则
> **边界**：管 CSV 列定义与填写规则；切块判据归 references/analyze/analyze-method.md「结构块判据」节

本域两份 CSV 分工：`章节索引.csv` 是脚本产物（机械，只定位不承载语义）；`结构块.csv` 是分析产物（语义，承载戏剧循环拆解）。两者的章定位都以 `章节索引.csv` 的 source_locator 为准。

## 章节索引.csv（脚本产物）

由 `scripts/build-chapter-index.js` 生成，禁止手写或手工编辑。五列固定表头：

| 列 | 含义 |
| --- | --- |
| chapter | 全局章号（多卷重编，全书 1 起连续） |
| title | 章标题原文（去标记符） |
| source_locator | 原文行区间，形态 `L{起}-L{止}`（1 起行号，含章标题行；定点回读原文的唯一依据） |
| char_count | 本章正文字符数（去空白后） |
| status | ok＝正常识别；empty＝正文字符数为 0 |

## 结构块.csv（分析产物）

Stage 3 产出，六列固定表头：

```text
block_id,chapter_range,cycle_elements,relation_delta,pacing_anchor,idea_atoms
```

| 列 | 含义 | 填写规则 |
| --- | --- | --- |
| block_id | 块号 | 全书 1 起连续 |
| chapter_range | 章节范围 | 形态 `1-3`（与章节索引全局章号对应） |
| cycle_elements | 戏剧循环五要素 | 格内用全角「｜」分隔五要素，形态 `缺口：{____}｜加压：{____}｜转折：{____}｜兑现：{____}｜新债：{____}`；某要素缺失照实标 `缺：{要素名}`，禁止硬凑 |
| relation_delta | 关系增量 | 本块内人物关系变化，有方向动词 + 人名；无变化写 `无` |
| pacing_anchor | 节奏锚点 | 三维刻度，形态 `剧情{1-5}/情绪{1-5}/描写{1-3}` |
| idea_atoms | 灵感原子 | 可复用的点子碎片，多条用全角「｜」分隔；无写 `无` |

CSV 通用规则：字段值内禁止出现英文逗号（用全角「，」或「｜」替代，避免引号转义）；文件编码 UTF-8；首行为表头。

## 示例行

```text
block_id,chapter_range,cycle_elements,relation_delta,pacing_anchor,idea_atoms
1,1-3,缺口：退婚羞辱｜加压：婚约只剩三天｜转折：捡到残卷｜兑现：当众立誓退回去｜新债：残卷来历,主角 →（制衡）→ 退婚家族：由被轻视转为被忌惮,剧情4/情绪4/描写2,退婚宴当众翻盘的仪式感
2,4-9,缺口：残卷来历不明｜加压：典当行追杀｜转折：残卷认主｜兑现：首次反杀｜新债：认主代价,主角 →（依附）→ 老掌柜：求庇护,剧情2/情绪4/描写3,以代价换力量的规则感
```
