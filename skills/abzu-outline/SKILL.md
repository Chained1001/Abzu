# Abzu · 大纲域（abzu-outline）

## 入口判定

作用：判「全新开书」还是「续跑」——进域只读本节，不必先读其他文件。

0. **Agent 部署检查**（静默，幂等——每次触发都跑，快到无感）：查本目录 `.claude/agents/web-scraper.md` 是否存在。不存在 → 从 `<skill 目录>/references/web-scraper.md` 复制过去（`.claude/agents/` 目录不存在则一并创建）；已存在 → 跳过。**不部署不往下走**——Stage 2 的采风依赖此 agent。
1. **判定**（只按文件证据，不凭对话记忆）：查**本目录**有无 `创作进度.md`——**一次即采信**，不加测第二轮。无＝全新开书（走『首问』）；有＝读其产物状态表，向作者报出「你在哪」，再按所在步骤读 `references/outline-stage-spec.md` 对应节接续；状态表点名的产物文件若不在 → 如实报缺失、请作者裁决（重建空模板续填或先停下），不得静默继续。
   - **本目录＝会话根目录**（＝发起 `/abzu-outline` 时所在的那个文件夹）。**取法**：跑一次 `pwd`，以它的输出为准；产物（`创作进度.md`／`基本规格.md`）就落在这个目录下。**不是** skill 自身目录（`.claude/skills/abzu-outline/`），也不是子目录。本文件通篇的「本目录／书目录／会话根」都指这同一个地方。
   - **只认本目录这一层，不递归子目录**：实现＝对该确切路径做存在性判定（读 `创作进度.md`：读得到＝有、报不存在＝无）；**禁用递归式写法**（如 `**/创作进度.md`）。子目录里的同名件是备份或另一本书，不构成本目录已开书——实测踩过：`旧产物/创作进度.md` 曾被当成「本目录有书」而直接跳进续跑，把一份本该全新开书的会话领错了路。
2. **报建设状态行**（逐字）：

   > 大纲域现在只能走**规格**这一段——把这本书的规格聊清楚、定下来；采资料、写大纲、打磨定稿这几步还没做，AI 不会假装能做。

3. **全新开书首问**（逐字，选项列表）：「在这个文件夹里开新书吗？」[开新书／只是问问]
   - 开新书 → 读 `references/outline-stage-spec.md`（「流程概述」节先读），从其 1.0 起继续；
   - 只是问问 → 只答疑，不落任何文件。
   - 状态行是通报非问句，可与首问同消息。

**读不到项目文件时**（本会话无文件工具或无读取权限）：先报建设状态行 → 如实说明读不到 → 先换模型重试一次，仍无则停下请作者换带文件工具的会话；不得以作者口述替代文件证据，不得用联网工具探测本地路径。

作者要求中途停止、或表达其他域意图 → 读 `references/outline-workflow.md`「中断契约」节，按其接手。

## 工作流

作用：声明各件的加载时机。

四阶段流程（规格、资料、草稿、打磨定稿）。大纲生成细则＝`references/outline-stage-spec.md`（流程概述＋1.0–1.3 步骤与逐字话术）——**开新书确认后一次读入**。域级事务（Stage 路由／中断契约／副作用／文件总表）＝`references/outline-workflow.md`——**中断或交接时才读**。本文件不复制两件内容。

## 阶段确认点与交互原则

作用：入口首问要用到的交互规则在此。

- 阶段确认点＝阶段级硬停：确认／要改／先停。
- 每问句按模态执行——模态标注（对话式／选项列表）是执行指令，**不进作者可见文本**；选项列表＝宿主选项组件（每题 2-4 项、开放集可自填；组件不可用则文本列编号选项）；对话式＝纯文本。
- **选项组件三件**：题头 ≤6 字；每个选项配一句口语说明（零黑话）；话术的「」是引号记号——输出时不带外层「」，内文逐字。
- 阶段确认点（含其「先停下」分支）须落产物状态表行。

备注：其余各条（同屏定义、逐项发送、表单已收不重问、话术逐字含用字、状态值枚举与落行式样、中途暂停三级）见 `references/outline-stage-spec.md`「流程概述」节——本文件不自重复。

## 运行前提

- Node.js 22+（2.1 联网取数第三层 CDP 浏览器直取需要；缺失时退到第一、二层照常工作）

## 语言

作用：对作者话术**零黑话**——内部术语（阶段确认点、产物状态表之类）不得进入作者可见话术。
