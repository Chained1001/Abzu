# Abzu · 大纲域（abzu-outline）

## 入口判定

（进域只读本节——零引用读。）

1. **判定**（只按文件证据，不凭对话记忆）：查**本目录**有无 `创作进度.md`——**一次即采信**，不加测第二轮。无＝全新开书（走第 3 步）；有＝读其产物状态表，向作者报出「你在哪」，再按所在步骤读 `references/outline-stage-spec.md` 对应节接续。
   - **本目录＝作者的工作目录**（这次会话打开的文件夹，也就是书目录）——**不是** skill 自己的目录（`.claude/skills/abzu-outline/`）；本文件通篇的「本目录／书目录／工作目录」都指同一个地方。
   - **只认本目录这一层，不递归子目录**：实现＝对该确切路径做存在性判定（读 `创作进度.md`：读得到＝有、报不存在＝无）；**禁用递归式写法**（如 `**/创作进度.md`）。子目录里的同名件是备份或另一本书，不构成本目录已开书——实测踩过：`旧产物/创作进度.md` 曾被当成「本目录有书」而直接跳进续跑，把一份本该全新开书的会话领错了路。
2. **报建设状态行**（逐字，出处就在本节——每建成一个新阶段改此行）：

   > 大纲域现在只能走**规格**这一段——把这本书的规格聊清楚、定下来；采资料、写大纲、打磨定稿这几步还没做，AI 不会假装能做。

3. **全新开书首问**（逐字，选项列表）：「在这个文件夹里开新书吗？」[开新书／只是问问]
   - 开新书 → 读 `references/outline-stage-spec.md`（〇节先读），从其 1.0 的④产物起继续；
   - 只是问问 → 只答疑，不落任何文件。
   - 状态行是通报非问句，可与首问同消息。

**读不到项目文件时**（本会话无文件工具或无读取权限）：先报建设状态行 → 如实说明读不到 → 先换模型重试一次（有模型自述无文件工具而实际具备——已登记前提），仍无则停下请作者换带文件工具的会话；不得以作者口述替代文件证据，不得用联网工具探测本地路径。

作者表达其他域意图时，如实告知对应命令与建设状态（本套件三域：`/abzu-outline`／`/abzu-volume`／`/abzu-write`），不强行走完本域流程。

## 阶段确认点与交互原则

- 阶段确认点＝阶段级硬停：确认／要改／先停。
- 中途暂停三级：单问可跳／本步暂停／阶段暂停。
- 每问句按模态执行——模态标注（对话式／选项列表）是执行指令，**不进作者可见文本**；选项列表＝宿主选项组件（每题 2-4 项、开放集可自填；组件不可用则文本列编号选项）；对话式＝纯文本。
- **选项组件三件**：题头 ≤6 字；每个选项配一句口语说明（零黑话）；话术的「」是引号记号——输出时不带外层「」，内文逐字。
- 阶段确认点与中途暂停须落产物状态表行。
- 交互执行语义其余各条（同屏定义、逐项发送、表单已收不重问、话术逐字含用字、状态值枚举与落行式样）见 `references/outline-stage-spec.md` 〇节——本文件不自重复。
