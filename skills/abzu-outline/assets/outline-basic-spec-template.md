# outline-basic-spec-template（基本规格产物模板）

> 消费点：Stage 1（规格步）1.0／1.1 产出 `基本规格.md` 时读——填空位与枚举位按本件；字段推导与联动校验的逐步口径见 `references/outline-stage-spec.md` 1.1。
> 边界：只含「一页商品标签」类字段（五段式）；不收金手指、主角设定等创作决策类字段（住草稿步），也不含卷纲／正文域产物。

## 一、定位注记

- 产物是什么：`基本规格.md`——把「想写一本什么书」压成一页规格（商品标签，不是内容），是后续全部创作决策的约束集。
- 何时创建：1.0 开书与脚手架建为空模板 → 1.1 规格收集填至草稿态 → 2.3 实测回填「参考标尺」段 → 4.3 定格。
- 生产者：大纲域 Stage 1（1.0 建空模板、1.1 填字段）。
- 消费方：大纲域后续 Stage（资料收集步以其参考偏好为唯一分派依据；进草稿步时它是全部创作决策的约束集）；定稿后经交接清单交卷纲／正文域。

## 三、默认值与完整填写示例

**默认值及推导规则**（1.1 段二「我来补」静默回读时给出）：

- 读者画像＝平台＋题材推导（三件）。
- 卷数＝区间填写（如 5-8 卷）——按字量给建议区间，定位参考值，标尺实测后收窄（不承诺）。
- 每章字数＝平台默认（起点 3000-4000／番茄 2000-3000）。
- 终局倾向／感情线倾向＝可选倾向：有想法填，无则按基调／题材推演标注「倾向待定，3.1 定」（准入律）。
- 参考偏好＝主 1＋辅≤3；基调＝`references/outline-emotion-words.md`「取值规则」节选 2-4 词。

**示例行**（可套用，来自真实场景）：

`基调｜热血燃、正剧（词序即主次）｜1.1 段三（词表选词）`
`卷数｜5-8 卷（参考值，标尺实测后收窄）｜1.1 默认推导`

## 四、模板正文

填写引导话术（逐字）见 `references/outline-stage-spec.md` 1.1⑥——采集按该三段式走（段一·你先说／段二·我来补／段三·还差这几个）。

填空位写作 `{____}`、枚举位写作 `{A/B}`；业务变量用中文（如 `{书名}`）。枚举一律开放集（可自填组合，反复需要即增项入表），带「：」的空位同时给出该位的提示词。

### 约束（联动校验四规则＋区间外处置话术）

- 承诺性字段（冲突＝红灯即时确认）：题材↔平台、平台↔读者、题材↔读者（题材↔平台↔读者三角的三条边）；基调↔终局倾向。
- 参考性字段（不符＝软提示，不拦）：字数↔卷数量级。
- 区间外处置话术：「{字段}超出常规区间（{建议区间}）。两个走法：a 确认原值＋适配说明；b 改建议区间——按哪个？」
- 生命周期三态注记：草稿（1.1）→ 实测（2.3 回填「参考标尺」段）→ 定格（4.3）。
