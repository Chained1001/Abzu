# outline-basic-spec-template（基本规格产物模板）

> 消费点：Stage 1（规格步）1.0 建空模板、1.1 填至草稿态、1.2 写入与核验按本件逐项核——填空位与枚举位按本件；**填好的完整样子见 `assets/outline-basic-spec-example.md`（成品样张）**，形态以样张为准。
> 边界：只含「一页商品标签」类字段（四段式）；不收金手指、主角设定等创作决策类字段（住草稿步），也不含卷纲／正文域产物。
> 产物实例化纪律：按模板正文逐段逐字段产出，**不得增模板外行**（含状态行——状态由「创作进度.md」承载）；**括注一律原样保留**（如「（选 2-4 词、词序即主次）」——括注是对字段的长期说明，不是待拆的脚手架）。

## 一、定位注记

- 产物是什么：`基本规格.md`——把「想写一本什么书」压成一页规格（商品标签，不是内容），是后续全部创作决策的约束集。
- 何时创建：1.0 开书与脚手架建为空模板 → 1.1 规格收集填至草稿态 → 1.2 写入核验并写入核验结论 → 2.3 实测回填「参考标尺」段 → 4.3 定格。
- 生产者：大纲域 Stage 1（1.0 建空模板、1.1 填字段、1.2 核验）。
- 消费方：大纲域后续 Stage（资料收集步以其参考偏好为分派依据——分析侧重与凭什么火归 2.x 实测产物，不在本件；进草稿步时它是全部创作决策的约束集）；定稿后经交接清单交卷纲／正文域。

## 三、默认值与样张

**默认值及推导规则**（1.1 段二「我来补」静默回读时给出）：

- 读者画像＝平台＋题材推导（三件，每件标签式短语、一件不超过 12 字）。
- 底色交织＝按段一聊到的味道推（可空）。
- 基调＝`references/outline-emotion-words.md`「取值规则」节选 2-4 词。

**成品样张**：`assets/outline-basic-spec-example.md`——填好的完整示例，字段形态、括注保留、核验结论写法以它为准。

## 四、模板正文

填写引导话术（逐字）见 `references/outline-stage-spec.md` 1.1⑥——采集按该三段式走（段一·你先说／段二·我来补／段三·还差这几个）。

填空位写作 `{____}`、枚举位写作 `{A/B}`；业务变量用中文（如 `{参考作品名}`）。枚举一律开放集（可自填组合，反复需要即增项入表），带「：」的空位同时给出该位的提示词。

### ③参考偏好

- 主参考：`{参考作品名}`（恰一本）
- 辅参考：`{参考作品名}`（每本一行，最多三行；没有则删除本行）

### ④参考标尺

- `{占位——2.3 实测回填；形态示例：开篇 3 章内首个钩子／章均 2000-2400 字／爽点间隔不超过 2 章}`

### 约束（联动校验规则＋核验结论）

> 本节为长期规则与核验结论的写入位，产物中须原样保留（含本句）。

- 承诺性字段（冲突＝红灯即时确认）：题材↔平台、平台↔读者、题材↔读者（题材↔平台↔读者三角的三条边）。
- 区间外处置话术：「{字段}超出常规区间（{建议区间}）。两个走法：a 确认原值＋适配说明；b 改建议区间——按哪个？」
- ④参考标尺生命周期：占位（1.2 核验时确认未误填）→ 实测回填（2.3）→ 定格（4.3）。
- 本次核验结论：`{1.2 写入核验的结论一行——必写}`
