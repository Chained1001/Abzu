# outline-reference-archive-template

> 作用：参考作品档案模板（采风检索档）——13 节约 24 字段＋一页结论提炼层，一本一档。
> 备注：产物纪律——产物首行写 `# 参考作品档案：{参考作品名}`；**13 个节标题一律 `###`（照本模板层级，不得改级）**；**占位符整体替换——花括号连同其中提示词一起删掉、换成纯文本值，产物正文不出现 `{` `}` 与反引号，值外不加任何包裹**（填法提示一律在花括号内、填后随花括号消失；行尾括注＝产物须保留的说明，原样保留）；**推断值就地标（推断）或 ⚠️——「局限与待核实」栏只汇总、不替代就地标记**；**作品名去书名号《》、去作者名**；逐字段产出、不得增模板外行；来源标注如实分记（LLM 记忆／联网核实不得混写；联网核实逐条附 URL 与访问日期 YYYY-MM-DD）；三层穷尽仍无可靠来源的字段写「未能采得」亦算档完，**核心五节**（基本信息／内核定标／主线结构／人物档案／来源标注）不得缺；头部「状态」翻成 `档完` 是 2.3 入统计的门槛。字段设计借鉴 [analyze-hit-novel](https://github.com/ciel-oliver/analyze-hit-novel)（六维拆书／冲突矩阵／叙事顺序手法），按本书目的与采源约束改造。
