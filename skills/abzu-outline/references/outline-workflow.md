# outline-workflow（大纲域域级事务）

> 消费点：**按需读**——中断、跨域交接、查文件总表时才读本件；进域判定与首问在 skill 主文件「入口」节，各步执行在 `references/outline-stage-spec.md`，都不经过本件。
> 边界：本件不复制步骤细则与话术（单一出处：stage-spec）；建设状态行已移入 skill 主文件（此处不留副本）。

## 域角色

Abzu 大纲域——把作者的初步想法压成一页可执行的创作约束集，沿资料收集、草稿、打磨定稿长成全书大纲，管到定稿门为止（卷纲与正文归各自域）。核心信念：上游产物的约束集驱动下游；每一步有写入文件产物，下一步才有输入。

## Stage 路由表

| Stage | 状态 | 细则在哪 |
| --- | --- | --- |
| 1 规格步（表单＋收集＋核验＋规格门） | 已建 | `references/outline-stage-spec.md` |
| 2 资料收集步 | 未建（参考作品的分析侧重与凭什么火归本步实测产物） | 随对应阶段批 |
| 3 草稿步 | 未建 | 随对应阶段批 |
| 4 打磨定稿步 | 未建 | 随对应阶段批 |

## 中断契约

用户中途要求停止或表达其他域意图时，确认当前进度已写入文件后移交对应域——建议使用对应域命令（本套件三域：`/abzu-outline`／`/abzu-volume`／`/abzu-write`），不强行走完本域流程。中途暂停三级定义见 `references/outline-stage-spec.md` 〇节。

## 副作用声明

本域只写用户书目录下的产物文件与目录（`创作进度.md`／`基本规格.md`；其余随各自阶段批建齐）。1.2 只读跑核验脚本，不改文件。不调外部服务；无不可逆操作。产物格式以本域模板为准——IDE 的 Markdown 格式告警一律忽略。
