# 人物卡模板

> **消费点**：Stage 2 人物卡实例化时全量加载——设定/人物卡/{角色}.md 的落盘模板
> **边界**：管产物结构与填写标准；双面建档方法归 references/outline/outline-method.md「人物双面法」节；字段消费方归 references/outline/outline-schemas.md

## 定位注记

- **产物**：`设定/人物卡/{角色}.md`——一角色一文件
- **生产者**：大纲域 Stage 2 人物卡实例化（**不随脚手架落位**——出场即建档，不预建群像）
- **消费方**：write 域上下文包装配按需检索（别名与代称为装配命中键）；volume 域卷末状态校准（弧线面）
- **约束**：设定面与弧线面互为校验——设定面的能力与动机必须撑得起弧线面的欲望与终点，撑不起的改设定或降终点；快照面是正文域写入区，本域不填；别名与代称收全（绰号 / 称号 / 他称）

## 字段定义表

| 字段 | 说明 | 生产来源 | 必填 |
| --- | --- | --- | --- |
| 身份 | 出场时的社会位置与处境 | 人物双面法（读 project 与总纲因果链） | 必填 |
| 动机 | 他想要什么 | 人物双面法 | 必填 |
| 能力 | 会什么、动用的代价 | 人物双面法（对照设定集力量体系） | 必填 |
| 关系 | 与谁、什么关系（方向动词） | 人物双面法 | 必填 |
| 口癖 | 语言标记（口头禅 / 称呼习惯 / 标志句式） | 人物双面法 | 必填 |
| 别名与代称 | 绰号 / 称号 / 他称（主 / 辅键） | 人物双面法（收全——正文域装配命中用） | 必填 |
| 起点状态 | 出场时的处境与心态 | 人物双面法（弧线面） | 必填 |
| 欲望 | 贯穿全书的渴求 | 人物双面法（弧线面） | 必填 |
| 终点预期 | 弧线落点 | 人物双面法（弧线面） | 必填 |
| 当前弧线阶段 | 现在走到弧线哪一段 | Stage 2 维护更新 | 必填 |
| 快照面 | 当前位置 / 已知信息 / 关系变化 / 最近出场 | 占位——write 域写入区 | 本域留空 |

## 模板正文

```markdown
# 人物卡：{角色}

## 设定面

- 身份：{出场时的社会位置与处境}
- 动机：{他想要什么}
- 能力：{会什么，动用的代价}
- 关系：{与谁、什么关系——用方向动词，如 利用/保护/制衡}
- 口癖：{口头禅 / 称呼习惯 / 标志句式}
- 别名与代称：{绰号 / 称号 / 他称，收全}

## 弧线面

- 起点状态：{出场时的处境与心态}
- 欲望：{贯穿全书的渴求}
- 终点预期：{弧线落点}
- 当前弧线阶段：{现在走到弧线哪一段}

## 快照面

（占位——正文域写入区，本域不填）
```

## 填写示例

```markdown
# 人物卡：林昭

## 设定面

- 身份：青云宗外门弟子，退婚事件的当事者，族中弃子
- 动机：证明自己不是废物；查明父亲当年被逐出宗门的真相
- 能力：吞噬神鼎（见设定集 力量-01）；剑法入门；每次吞噬后三天虚弱期
- 关系：制衡 内门首席赵拓（退婚方）｜依附 长老陈九（庇护者，动机存疑）｜ 亏欠 苏晚（替他挡过一次暗算）
- 口癖：受激时低声自语「再来」；称呼对手一律「阁下」（无论强弱）
- 别名与代称：林师弟、废柴林、鼎主（后期）

## 弧线面

- 起点状态：修为被废、未婚妻退婚、族人冷眼——谷底
- 欲望：从「证明自己」走向「守护自己在乎的人」
- 终点预期：以自身为鼎封印吞天之劫，成为新秩序的立规者而非复仇者
- 当前弧线阶段：第 1 卷——证明自己阶段（动机仍以反击羞辱为主）

## 快照面

（占位——正文域写入区，本域不填）
```
