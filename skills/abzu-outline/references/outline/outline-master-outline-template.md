# 总纲模板

> **消费点**：Stage 2 大纲线落盘时全量加载——大纲/总纲.md 的落盘模板
> **边界**：管产物结构与填写标准；因果链生产方法归 references/outline/outline-method.md「主线因果链法」节；字段消费方归 references/outline/outline-schemas.md

## 定位注记

- **产物**：`大纲/总纲.md`——全书骨架，volume 域卷纲的直接输入
- **生产者**：init-book.js 落初稿骨架 → 大纲域 Stage 2 大纲线填充
- **消费方**：volume 域卷纲全量读取；write 域上下文包（逐字段见 references/outline/outline-schemas.md「总纲」节）
- **约束**：因果链每个节点必须 因→果 成对（断链即剧情漏洞，补桥或删节点）；⏸② 确认后的改动属修订，在设定集变更记录或打磨报告中留痕；分卷规划的卷末状态预期是下一卷的直接输入，必须可检验

## 字段定义表

| 字段 | 说明 | 生产来源 | 必填 |
| --- | --- | --- | --- |
| 一句话故事 | 全书最压缩的概括 | 主线因果链法（从 project 核心卖点起归纳） | 必填 |
| 核心冲突 | 主角欲望 × 阻力 | 主线因果链法 | 必填 |
| 主线因果链 | 节点列表，每节点 因→果 | 主线因果链法 | 必填 |
| 大高潮 | 全书最大兑现点与代价 | 主线因果链法 | 必填 |
| 分卷规划 | 每卷一句话＋卷末状态预期 | 主线因果链法 | 必填 |
| 主题 | 全书想说的那件事 | Stage 2 大纲线归纳 | 必填 |

## 模板正文

```markdown
# 总纲

- 一句话故事：{____}
- 核心冲突：{主角想要什么 × 谁/什么在阻止他}
- 主线因果链：
  1. 因：{____} → 果：{____}
  2. 因：{____} → 果：{____}
  3. {按需递增——每节点因→果成对}
- 大高潮：{全书最大兑现点——什么被兑现、代价是什么}
- 分卷规划：
  - 第 1 卷：{这一卷一句话} ｜ 卷末状态预期：{____}
  - 第 2 卷：{这一卷一句话} ｜ 卷末状态预期：{____}
- 主题：{全书想说的那件事}
```

## 填写示例

```markdown
# 总纲

- 一句话故事：被退婚的废柴少年凭一口吞噬神鼎，把欺辱过他的宗门逐一踩在脚下，最终鼎吞诸天
- 核心冲突：主角要逆天改命 × 鼎的秘密引来诸方势力绞杀
- 主线因果链：
  1. 因：退婚受辱当晚祖鼎觉醒 → 果：主角获得吞噬功法能力，踏入修行
  2. 因：宗门大比迫近 → 果：主角吞噬叛逃长老的功法，大比一鸣惊人
  3. 因：大比暴露鼎的线索 → 果：上宗势力入场搜刮，主角被迫出走
  4. 因：出走遭遇鼎的原主人残魂 → 果：得知鼎的来历与诅咒，主线目标升级
- 大高潮：鼎吞诸天——主角以自身为鼎封印吞天之劫，代价是永世不能再吞噬
- 分卷规划：
  - 第 1 卷：宗门篇——退婚到出走 ｜ 卷末状态预期：主角修为入内门前列，鼎的秘密初露，与上宗结怨
  - 第 2 卷：荒野篇——出走到自立 ｜ 卷末状态预期：主角建立自己的势力，鼎的诅咒显形
- 主题：吞掉的是别人的路，走出来的是自己的道
```
