## 方法六组与所辖字段

模板字段必须有生产策略——无生产策略的字段禁止入模板。六组方法各管一段字段；例外：`project.md` 的 `schema` 与立项日期两字段由 init-book.js 生成（确定性归脚本），不配方法。

### 立项六要素法（Stage 1 → project 全字段）

- 读什么：开书双问与回读补问的全部对话素材；（如存在）扫榜产物 `选题决策.md`。
- 怎么归纳：六要素（题材 / 核心卖点 / 金手指 / 目标读者 / 参考作品 / 章节字数目标）各归纳为一句可执行表述——禁止「热血爽文」式空标签，每要素具体到能指导下一阶段（如卖点写清「读者为什么追」）。金手指拆能力 / 来源 / 成长边界三子字段；目标读者拆平台 / 年龄段 / 口味标签三子字段。
- 完备度校验：六要素齐才可请求 ⏸①；「待定」项逐一呈报作者确认接受，不静默带过。

### 设定最小可行原则（Stage 2 设定线 → 设定集条目）

- 读什么：`project.md`（题材与金手指）、`大纲/总纲.md` 已有内容。
- 怎么归纳：每个设定条目先答「它承载哪条剧情」再写内容——答不出承载的设定不入集（设定完备本身不是目标，永不登场的设定是死重）。力量体系从金手指的成长边界推；地理 / 势力 / 规则从主线因果链将经过的场景倒推。
- 补全节奏：不为完备而补——剧情推进需要什么补什么，⏸② 前做一次承载盘点即可。

### 主线因果链法（Stage 2 大纲线 → 总纲因果链 / 分卷规划）

- 读什么：`project.md`（核心卖点 / 金手指 / 目标读者）、`设定/设定集.md` 已有条目。
- 怎么归纳：主线拆为节点列表，每节点一行 因→果；因果断链（无因之果、无果之因）即剧情漏洞，逐个补桥或删节点。分卷规划每卷一句话＋卷末状态预期（下一卷的直接输入）。
- 校验：每个节点回问「它服务核心卖点吗」——服务不了的节点标可疑并呈报。

### 人物双面法（Stage 2 → 人物卡设定面 / 弧线面）

- 读什么：`project.md`、`大纲/总纲.md` 因果链（人物在哪些节点出场 / 转折）、`设定/设定集.md`。
- 怎么归纳：设定面＝静态档案（身份 / 动机 / 能力 / 关系 / 口癖 / 别名与代称）；弧线面＝动态轨迹（起点状态 / 欲望 / 终点预期 / 当前弧线阶段）。两面互为校验：设定面的能力与动机必须撑得起弧线面的欲望与终点，撑不起的改设定或降终点。别名与代称收全（绰号 / 称号 / 他称——正文域装配命中用）。
- 实例化：一角色一文件（`设定/人物卡/{角色}.md`），出场即建档，不预建群像；快照面留空（正文域写入区）。

### 文风初稿输入清单（Stage 1 → 文风指南四节）

- 读什么（输入四件）：叙述人称偏好 / 参考作品文风描述 / 作者禁忌 / 参考作品采风样本段（1-2 段〔abzu 自定〕氛围参照）。
- 怎么归纳：四件输入落为四节规则集——人称偏好落「叙事偏好」；参考文风描述与样本段落「词汇偏好」「句式特征」；作者禁忌落「情绪基调」的禁区情绪与「词汇偏好」的禁用词。规则化表述（可校验的清单），不写成散文。

### 设定三查（Stage 2 轻打磨 → 设定集条目打磨校验）

| 查 | 问句 | 不合格信号 |
| --- | --- | --- |
| 自洽 | 条目之间互相矛盾吗（力量等级 / 地理关系 / 势力立场） | 同一对象两处描述冲突 |
| 承载 | 每条设定有它服务的剧情吗 | 找不到承载的悬浮条目 |
| 无冗余 | 有没有两条设定在做同一件事 | 同功能条目重叠 |

不合格处置：悬浮条目删除或为其找到承载；冲突条目按主线需要裁一边并记「变更记录」。

## 轻打磨自检清单

⏸② 前与设定三查一起跑，逐项结论记入 `大纲/打磨报告.md`：

1. 产物完备：六产物对照 references/outline/outline-schemas.md 字段表无缺项
2. 总纲与设定一致：主线经过的每个场景，其设定条目存在且自洽
3. 人物弧线与主线咬合：主要人物的终点预期与主线大高潮同向
4. 底线完备度：核心卖点＋主线终点＋主角欲望三件齐（缺任一呈报作者，不静默补齐）

## 挂载点（待萃取）

下列位置的方法论待定向萃取（设计文档 §3.5 对应行），当前按方法六组骨架执行；萃取件建成后嵌入对应组替换骨架：

| 骨架步骤 | 挂载方法论 |
| --- | --- |
| 立项·卖点 / 题材 / 金手指提炼 | 此处需 选题定位方法论（题材×卖点×读者匹配）·待萃取 |
| 立项·对标引导 | 此处需 对标分析方法论（同类作品拆解视角）·待萃取 |
| 立项·文风指南初稿 | 此处需 文风要素方法论（视角 / 语感 / 禁忌清单化）·待萃取 |
| 设定·力量体系 / 地理 / 势力 | 此处需 世界观构建方法论（最小可行设定）·待萃取 |
| 大纲·主线因果链 / 分卷 | 此处需 情节骨架方法论（因果链与大高潮设计）·待萃取 |
| 人物卡·双面属性 | 此处需 人物构建方法论（设定面 / 弧线面）·待萃取 |
| 大纲打磨·三评委 | 此处需 评委人设与审查维度（读者爽点 / 编辑市场 / 同行结构）·待萃取 |

三评委 spawn 打磨循环属五期建设——当前轻打磨用自检清单＋设定三查。

## 萃取纪律

- 萃取时点：对应方法论建设批开工前定向翻阅，不预先全扫。
- 书源：referFile 七本专业书（路径与书目**未预验**，待萃取批现场核定后回填本节；外部参考只读纪律）。
- 萃取件形态：思考指令优先于知识描述（引导怎么想，不是罗列知识）；头部带前置知识检查清单。
