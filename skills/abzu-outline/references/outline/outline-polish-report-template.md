# 打磨报告模板

> **消费点**：Stage 2 轻打磨时全量加载——大纲/打磨报告.md 的落盘模板
> **边界**：管产物结构与填写标准；自检清单与设定三查内容归 references/outline/outline-method.md；字段消费方归 references/outline/outline-schemas.md

## 定位注记

- **产物**：`大纲/打磨报告.md`——大纲打磨的留痕账本
- **生产者**：init-book.js 落初稿骨架 → 大纲域 Stage 2 轻打磨逐轮追加
- **消费方**：断点续跑（打磨中状态的判定证据——末条 R{N}）；作者复核
- **约束**：append-only——每轮打磨追加一节（编号 R1、R2…递增），禁止改动既往记录；问题清零轮必须显式写明「清零」结论，作为 ⏸② 请求的依据

## 字段定义表

| 字段 | 说明 | 生产来源 | 必填 |
| --- | --- | --- | --- |
| 轮次 | R{N} 递增编号＋日期 | Stage 2 轻打磨（每轮一节） | 必填 |
| 自检清单 | 四项逐项结论（完备 / 一致 / 咬合 / 底线） | 轻打磨自检清单 | 必填 |
| 设定三查 | 自洽 / 承载 / 无冗余 各自结论 | 设定三查 | 必填 |
| 发现与处置 | 本轮问题与处理（含未处理原因） | 轻打磨过程 | 有则必填 |

## 模板正文

```markdown
# 打磨报告

（append-only——每轮打磨追加一节，不改动既往记录）

## R1：{YYYY-MM-DD}

- 自检清单：
  - 产物完备：{结论}
  - 总纲与设定一致：{结论}
  - 人物弧线与主线咬合：{结论}
  - 底线完备度：{结论}
- 设定三查：自洽 {结论} ｜ 承载 {结论} ｜ 无冗余 {结论}
- 发现与处置：{本轮发现的问题与处理；无问题写「本轮清零」}
```

## 填写示例

```markdown
# 打磨报告

（append-only——每轮打磨追加一节，不改动既往记录）

  - 总纲与设定一致：主线第 3 卷经过的「北荒」在设定集无地理条目——已补 地理-02
  - 人物弧线与主线咬合：女主苏晚的终点预期与最终卷脱节——已对齐
  - 底线完备度：核心卖点 / 主线终点 / 主角欲望三件齐
- 设定三查：自洽 力量-01 与 规则-01 边界表述冲突已统一 ｜ 承载 势力-02 无承载剧情，已删 ｜ 无冗余 通过
- 发现与处置：发现 2 处问题均已本轮处理

## R2：2026-09-13

- 自检清单：
  - 产物完备：通过
  - 总纲与设定一致：通过
  - 人物弧线与主线咬合：通过
  - 底线完备度：通过
- 设定三查：自洽 通过 ｜ 承载 通过 ｜ 无冗余 通过
- 发现与处置：本轮清零
```
