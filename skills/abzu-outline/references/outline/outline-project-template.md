# 立项档案模板

> **消费点**：Stage 1 立项落盘时全量加载——project.md 的落盘模板
> **边界**：管产物结构与填写标准；六要素生产方法归 references/outline/outline-method.md「立项六要素法」节；字段消费方归 references/outline/outline-schemas.md

## 定位注记

- **产物**：书项目根 `project.md`——立项产物，全书方向的单一真源（schema 载体）
- **生产者**：init-book.js 落初稿骨架 → 大纲域 Stage 1 填充为草稿
- **消费方**：见 references/outline/outline-schemas.md「project.md」节逐字段映射
- **约束**：头部 `schema` 与立项日期两字段由脚本生成，禁止手改；⏸① 确认后的改动走「修订记录」区留痕；书名可空（暂定名不阻塞）

## 字段定义表

| 字段 | 说明 | 生产来源 | 必填 |
| --- | --- | --- | --- |
| schema | 书项目结构版本（初值 1） | init-book.js | 必填（脚本生成） |
| 书名 | 暂定名 | Stage 1 对话采集 | 可空 |
| 题材 | 主类型＋副类型 / 梗 | 立项六要素法（开书双问＋回读补问①） | 必填 |
| 核心卖点 | 读者为什么追 | 立项六要素法 | 必填 |
| 金手指 | 能力 / 来源 / 成长边界三子字段 | 立项六要素法（回读补问②主角种子佐证） | 必填 |
| 目标读者 | 平台 / 年龄段 / 口味标签三子字段 | 立项六要素法（开书双问·平台） | 必填 |
| 参考作品（对标） | 主参考 1＋辅助 ≤3 | Stage 1 参考作品引导（必填 ≥1） | 必填 |
| 章节字数目标 | 单章目标字数区间 | 立项六要素法（回读补问⑤更新节奏） | 必填 |
| 立项日期 | YYYY-MM-DD | init-book.js（落稿日） | 必填（脚本生成） |

## 模板正文

```markdown
# 立项档案：{书名（暂定，可空）}

schema: 1

- 书名：{____（暂定，可空）}
- 题材：{主类型 ＋ 副类型/梗}
- 核心卖点：{读者为什么追这本书——一句话，具体到能指导写作}
- 金手指：
  - 能力：{主角获得的超越常规的优势是什么}
  - 来源：{它从哪来、为何落在主角身上}
  - 成长边界：{它能长到多强、代价与限制是什么}
- 目标读者：
  - 平台：{目标发布平台}
  - 年龄段：{主力读者年龄段}
  - 口味标签：{读者偏好的题材标签}
- 参考作品（对标）：
  - 主参考：{1 本——最像想写的这本书的作品}
  - 辅助参考：{≤3 本，可空}
- 章节字数目标：{单章目标字数区间，如 2000-3000 字}
- 立项日期：{YYYY-MM-DD}

## 修订记录

（⏸① 确认后的改动在此追加：日期 ＋ 改了什么 ＋ 为什么）
```

## 填写示例

```markdown
# 立项档案：吞天鼎（暂定）

schema: 1

- 书名：吞天鼎（暂定）
- 题材：玄幻 ＋ 东方玄幻/废柴流/吞噬成长
- 核心卖点：废柴少年靠吞噬功法快速变强——每吞噬一个强敌就拿到对方的本事，成长肉眼可见
- 金手指：
  - 能力：神秘鼎可吞噬功法与武技，转化为主角自身修为
  - 来源：祖传破鼎在主角被退婚当晚觉醒，认主
  - 成长边界：吞噬有上限等级（不能吞高出两个大境界的目标），每次吞噬后有虚弱期
- 目标读者：
  - 平台：起点
  - 年龄段：18-30 男性
  - 口味标签：升级流、扮猪吃虎、宗门斗争
- 参考作品（对标）：
  - 主参考：《吞噬星空》（成长节奏范本）
  - 辅助参考：《斗破苍穹》（退婚流开局）
- 章节字数目标：2000-3000 字
- 立项日期：2026-09-10

## 修订记录

（暂无）
```
