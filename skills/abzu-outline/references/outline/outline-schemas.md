## project.md

头部 `schema: 1`（初值本批定义；skill 会话开始读此字段做升级检测）。

| 字段 | 说明 | 消费方 |
| --- | --- | --- |
| schema | 书项目结构版本号 | 升级检测 |
| 书名 | 暂定名 | 无消费方（记录性） |
| 题材 | 主类型＋副类型 / 梗 | 总纲分卷规划；三评委·编辑代理 |
| 核心卖点 | 读者为什么追 | 总纲因果链校验基准；三评委·读者代理 |
| 金手指 | 能力 / 来源 / 成长边界三子字段 | 设定集力量体系；总纲因果链 |
| 目标读者 | 平台 / 年龄段 / 口味标签三子字段 | 文风指南；三评委·读者代理 |
| 参考作品（对标） | 主参考 1＋辅助 ≤3 | 拆书域输入清单；采风定向采集锚点 |
| 章节字数目标 | 单章目标字数区间 | write 域字数断言（评估场景 3） |
| 立项日期 | YYYY-MM-DD | 无消费方（记录性） |

## 设定集（设定/设定集.md）

活文档：一致性词典＋变更事件源。分节（力量体系 / 地理 / 势力 / 规则），每条目带条目 ID。

| 字段 | 说明 | 消费方 |
| --- | --- | --- |
| 条目 ID | {分节前缀}-{两位序号}（如 力量-01） | 一致性词典键——write 域引用与变更事件定位 |
| 条目内容 | 设定本体 | volume / write 域只读；一致性扫描 |
| 剧情承载 | 该条目服务的剧情线 | 大纲域自身（设定三查·承载） |
| 变更记录 | 时间 / 字段 / 旧值 / 新值 / 影响范围 | write 域影响扫描（变更事件） |

## 人物卡（设定/人物卡/{角色}.md）

| 字段 | 说明 | 消费方 |
| --- | --- | --- |
| 设定面·身份 / 动机 / 能力 / 关系 / 口癖 | 静态档案 | write 域上下文包装配按需检索 |

| 快照面 | 当前位置 / 已知信息 / 关系变化 / 最近出场 | write 域写入区（本域不填） |

## 创作进度（创作进度.md）

状态机唯一真源、全域会话恢复入口——自身即消费方，不另标逐字段。

| 字段 | 说明 |
| --- | --- |
| 当前阶段 | 状态机当前值（枚举：未开始 / 立项-待确认 / 大纲-设定大纲并行 / 大纲-打磨中 / 大纲-已完成 / 卷 N-各子状态 / 全书完成） |
| 上一阶段 | 转换来源 |
| 当前焦点 | 最近产物 |
| 最新更新时间 | ISO 时间戳 |
| 产物状态表 | 各产物版本与状态（行序即时间序） |
| 风格路径 | 细纲党 / 灵感流（volume→write 过渡时写入，本域预留） |

## 文风指南（文风/文风指南.md）

结构化规则集（非散文），供机械与统计校验。

| 字段 | 说明 | 消费方 |
| --- | --- | --- |
| 词汇偏好 | 常用词清单 / 禁用词清单 | write 域上下文包；写后自检（机械匹配） |
| 句式特征 | 平均句长范围 / 短句占比 / 常用句式模式 | write 域写后自检（统计比对） |
| 叙事偏好 | 视角 / 描写密度 / 对话与叙述比例 | write 域；style 域卷末审计 |
| 情绪基调 | 目标情绪关键词 / 禁区情绪 | style 域卷末审计 |
| AI 痕迹清单 | 从四节派生＋通用清单兜底（占位——write / style 域建设后启用） | write 域写后自检；style 域审计 |
| 变更记录 | 时间 / 节 / 变更 / 触发原因 | style 域迭代（卷末审计后更新） |
