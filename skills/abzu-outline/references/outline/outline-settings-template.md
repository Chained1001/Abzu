# 设定集模板

> **消费点**：Stage 2 设定线落盘时全量加载——设定/设定集.md 的落盘模板
> **边界**：管产物结构与填写标准；最小可行原则归 references/outline/outline-method.md「设定最小可行原则」节；字段消费方归 references/outline/outline-schemas.md

## 目录

- 定位注记
- 字段定义表
- 模板正文
- 填写示例

## 定位注记

- **产物**：`设定/设定集.md`——活文档：一致性词典＋变更事件源
- **生产者**：init-book.js 落初稿骨架 → 大纲域 Stage 2 设定线逐条填充
- **消费方**：volume / write 域只读；一致性扫描与变更事件定位（条目 ID 为键，逐字段见 references/outline/outline-schemas.md「设定集」节）
- **约束**：每条目必须回答「它承载哪条剧情」，答不出承载的设定不入集；修改已有条目必须追加变更记录（时间 / 字段 / 旧值 / 新值 / 影响范围），不静默改；条目 ID 发出不复用

## 字段定义表

| 字段 | 说明 | 生产来源 | 必填 |
| --- | --- | --- | --- |
| 条目 ID | {分节前缀}-{两位序号}，如 力量-01 | 设定最小可行原则（分节内递增编号） | 必填 |
| 条目名 | 设定的名称 | 设定最小可行原则 | 必填 |
| 条目内容 | 设定本体（规则 / 机制 / 关系） | 设定最小可行原则 | 必填 |
| 剧情承载 | 该条目服务的剧情线 | 设定最小可行原则（承载问答） | 必填 |
| 变更记录 | 时间 / 字段 / 旧值 / 新值 / 影响范围 | Stage 2 异常分支（作者改口）与后续修订 | 有变更时必填 |

## 填写示例

```markdown
# 设定集

条目 ID 规则：{分节前缀}-{两位序号}（力量 / 地理 / 势力 / 规则）——正文域引用与变更定位的键，发出不复用。

## 力量体系

### 力量-01：吞噬神鼎

- 内容：可吞噬功法与武技转化为主角修为；上限为高出两个大境界的目标不可吞；每次吞噬后虚弱期三天，期间不可动用修为
- 剧情承载：主角成长主线——每次关键战斗的翻盘手段；虚弱期制造大比与追杀中的危机

## 地理

### 地理-01：青云宗

- 内容：主角所在宗门，分外门 / 内门 / 真传三级；后山禁地封印着鼎的原主人残魂
- 剧情承载：第 1 卷主舞台；禁地为第 2 卷出走事件的发生地

## 势力

### 势力-01：上宗天衡殿

- 内容：统辖七宗的上宗，掌握鼎的线索，行事以「回收神物」为名
- 剧情承载：第 1 卷末冲突的发动者；全书前期主要压力来源

## 规则

### 规则-01：吞噬反噬

- 内容：吞噬同源功法（同出一门的传承）会引发反噬，轻则重伤重则道基崩毁
- 剧情承载：限制主角无脑吞——宗门斗争中主角必须甄别功法来源，制造抉择

## 变更记录

| 时间 | 字段（条目 ID） | 旧值 | 新值 | 影响范围 |
| --- | --- | --- | --- | --- |
```
